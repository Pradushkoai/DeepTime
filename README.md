## Структура документации

Документация существует в **двух вариантах** для двух разных потребителей:

### 🤖 `docs/ai/` — для ИИ-ассистентов (машинно-ориентированная)

- Структурирована по доменам
- Каждый файл имеет метаданные (статус, зависимости, дата последнего обновления)
- Явные кросс-ссылки
- Журнал решений (decision_log.md), реестр открытых вопросов (open_questions.md), глоссарий
- Может быть многословной и подробной
- Используется ИИ-ассистентом как «память проекта»

### 📖 `docs/user/` — для человека (читабельная)

- Нарративная, как design bible
- Чистые таблицы, без метаданных
- ~14 глав по темам + открытые вопросы в конце
- Ссылки на `docs/ai/` для деталей

### 📦 `docs/archive/` — архив

- Старые версии документов (история эволюции концепции)

## Ключевые принципы (краткий список)

1. **Реальная Земля, нетронутая природа** — климат как в 0 н.э. (близок к современному), без следов человеческой деятельности (нет Суэцких каналов, нет вырубок, нет изменённых рек)
2. **Эмерджентная эволюция** — ни технологии, ни строй, ни экономика не открываются по расписанию эпох, а возникают из выполнения предпосылок
3. **Вождь-управление через тренды** — игрок задаёт ценности, приоритеты, эдикты; граждане самоорганизуются
4. **Золотое правило** — ничто не появляется из воздуха: все ресурсы/инструменты/оружие/лошади/телеги/еда/одежда/сырьё — только через добычу, торговлю или производство
5. **География = судьба** — каждый старт уникален через архетипы и историческое размещение племён
6. **Слоистая доступность ресурсов** — поверхностные доступны сразу, глубокие требуют технологий
7. **Самоорганизующиеся граждане** — через utility score по приоритетам, ценностям, эдиктам
8. **Физико-химические предпосылки технологий** — например, медь плавится при 700°C, кирпич держит 800-900°C → можно плавить медь; железо требует 1500°C → нужна продвинутая печь
9. **Логика отделена от рендера** — обязательно для будущей мультиплеерной совместимости
10. **Никаких перманентных смертей** — провал не убивает сейв навсегда

## Открытые вопросы (требуют проработки)

Подробный список — в `docs/ai/_meta/open_questions.md`. Кратко:

- **Бессмертный вождь** — сохранить или сделать сменяемых? Нужны альтернативы
- **Зонирование локальной карты** — детальная механика
- **Миграция рабочей силы** — система вакансий + личные приоритеты + стимулы
- **Бронирование технологий** — лучшие практики
- **Баланс фракций** — чтобы было интересно играть
- **AI соседей** — как начать торговлю с дальними/продвинутыми
- **Стартовый пакет ресурсов** — что давать на старте
- **Альтернативные пути развития** — для каждой народности свои
- **Блокировки эволюции** — на основе исторического опыта
- **Преступность и суд** — система наказаний
- **Банковская система** — без фанатизма
- **Собственность** — как формализовать
- **Детальность почв/флоры/фауны** — максимальная, но не избыточная

## Технические ориентиры

- **Движок**: Unity 2022 LTS + C# (предварительно)
- **Архитектура**: симуляция отделена от рендера, DOTS/ECS для тысяч сущностей
- **Платформы**: Windows (early access) → Android
- **Сеттинг**: 10 000 до н.э. — 500 н.э.

## Как работать с репозиторием

1. Любое изменение концепции — коммит с понятным сообщением
2. Большие концептуальные правки — через новый раздел в `decision_log.md`
3. Новые открытые вопросы — в `open_questions.md` со статусом `OPEN`
4. Решённые вопросы — переводятся в статус `RESOLVED` со ссылкой на decision_log
5. Глоссарий обновляется при появлении новых терминов
