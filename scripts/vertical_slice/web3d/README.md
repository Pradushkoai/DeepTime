# DeepTime 3D — Vertical Slice Prototype

> 🎮 **3D прототип** на Three.js. Чистый HTML+JS, без сборки. Открывается одной командой.

## 🚀 Запуск

### Windows
1. Скачай `run_windows.bat` (или весь репозиторий)
2. Дважды кликни на `run_windows.bat`
3. Браузер откроется автоматически на `http://127.0.0.1:5002/`

**Требования**: Python 3 (для HTTP сервера), браузер.

### Любая ОС с Python
```bash
cd scripts/vertical_slice/web3d
python -m http.server 5002
# открой http://127.0.0.1:5002/ в браузере
```

### Без Python (просто открыть файл)
Можно открыть `index.html` напрямую двойным кликом — но CDN-скрипты (Three.js) могут не загрузиться из-за CORS. Лучше использовать HTTP сервер.

## 🎮 Как играть

- **▶ Ход** — один шаг симуляции (1 сезон)
- **⏩ 5 / ⏩ 20** — авто-игра (5 или 20 ходов)
- **Мышь** — вращать камеру (OrbitControls)
- **Колесо** — зум
- **🔄 Новая игра** — сменить архетип/seed/population

## 📊 Что видно

### 3D сцена (Three.js)
- **Хижины** (треугольные пирамиды) — до 8 штук
- **Костёр** — анимированное пламя + точечный свет
- **Деревья** — 18 штук по периметру
- **Граждане** — цветные сферы:
  - 🔴 красный = охота
  - 🟢 зелёный = собирательство
  - 🔵 синий = рыбалка
  - 🟡 жёлтый = стройка
  - 🟣 фиолетовый = ритуал
  - ⚫ серый = отдых
- **Голодные** — красное кольцо вокруг
- **Сезонные цвета** — зелёный (весна/лето), жёлтый (осень), белый (зима)
- **Зимой** — костёр больше, свет ярче

### UI панели
- **Сверху**: сезон, год, ход, население, голодающие + кнопки управления
- **Слева**: вождь (давление с прогресс-баром), запасы, действия граждан
- **Справа**: фракции (с обидой), хроника, решения, метрики

## 🏗 Архитектура

```
web3d/
├── index.html      # HTML + CSS (UI overlay)
├── sim.js          # Симуляция (порт Python v0.36b)
├── render.js       # Three.js 3D рендер
├── ui.js           # UI контроллер
└── run_windows.bat # Windows launcher
```

### Технологии
- **Three.js r128** (CDN) — 3D движок
- **OrbitControls** — управление камерой
- **Чистый JS** — без сборки, без npm
- **CSS overlay** — UI поверх 3D canvas

### Симуляция (sim.js)
Порт Python-прототипа v0.36b:
- 8 архетипов с долями калорий и навыками
- 8 систем: needs, actions, production, consumption, factions, chief, aging, crises
- 11 типов событий (auto-resolve smart стратегией)
- Game loop: ход = 1 сезон, 4 сезона = 1 год
