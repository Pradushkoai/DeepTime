## 🔍 Что было изменено в v0.35

### 1. Снижен рост давления вождя (system_chief)
- Голод: max +5/ход (вместо +15)
- Зима: +2/зиму (вместо +5)
- Смерти: +recent*1 (вместо *3)
- Обида фракций: убрана (обида влияет через фракции)
- Спад давления: -2/ход (вместо -1)

### 2. Поднято производство ягод (system_production)
- Множитель ×3 (вместо ×2) — помогает RIVER_VALLEY и TROPICAL

### 3. Снижена агрессивность фракций (system_factions)
- Порог обиды от давления вождя: 80 (вместо 60)
- Рост обиды: +3/ход (вместо +5)

### 4. Поднят порог мятежа (system_events_check)
- FACTION_GRIEVANCE триггерится при обиде > 90 (вместо > 80)

### 5. Чаще чемпион реформ (system_events_check)
- Шанс CHAMPION_PROPOSES: 10% (вместо 5%)

## 🎯 Выводы

### Что подтверждено архитектурно (v0.35)

1. **ECS (T-002)** — 50+ граждан, семьи, фракции, события работают стабильно
2. **Game loop (T-001)** — 72 прогона × 100 ходов = 7200 ходов без крашей
3. **EventSystem (T-005)** — 11 типов, очередь, resolver — корректно обрабатывает 7000+ событий
4. **Архетипы (D-009)** — все 8 дают разные результаты (от 66 до 97 чел)
5. **Стратегии AI** — smart (3.00/3) > auto (2.92/3) > random (2.50/3) — логично
6. **R9 предохранители** — handle_chief_death работает (9 передач власти, без застреваний)
7. **Баланс** — 0 гибелей из 72 прогонов, все архетипы выживают

### Что НЕ подтверждено

- **Fun или нет** — Python-прототип без UI не отвечает на этот вопрос
- **Долгая игра** — 100 ходов = 25 лет, нужно 400+ ходов (100 лет)
- **Сложные сценарии** — нет войн, соседей, стадий (только палеолит)

### Возможные следующие шаги

1. **Долгие прогоны** — 400 ходов (100 лет) — проверить, не вырождается ли симуляция
2. **Экстремальные сценарии** — population=200, 10; turns=400
3. **UI для прототипа** — чтобы видеть решения в реальном времени
4. **Перенос на Unity** — когда баланс стабилен (v0.35 стабилен)
