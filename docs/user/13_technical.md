# Глава 13 — Технический подход

## Движок

**Unity 2022 LTS + C#** (предварительно). Основной выбор для:
- Кросс-платформенности (Windows + Android)
- Большого комьюнити и готовых ассетов
- Поддержки DOTS/ECS для симуляции тысяч сущностей

## Архитектура — обязательный принцип

**Логика симуляции полностью отделена от рендера.** Это архитектурное решение, подтверждённое пользователем. Смысл:

- Симуляция (game logic) — чистый модуль, не зависящий от движка/графики
- Это позволяет:
  - Легко добавить мультиплеер (логика на сервере, рендер на клиентах)
  - Делать unit-тесты геймдизайна без UI
  - Переиспользовать логику на разных платформах
  - Заменять движок при необходимости

Архитектурно это означает:
```
GameLogic/         ← чистая логика, не зависит от Unity
  - WorldSim
  - TechTree
  - ResourceBank
GameView/          ← Unity-специфичный код
  - TileRenderer
  - UI
  - CameraController
```

## Стиль: low-poly + кинематограф

Low-poly Manor Lords-стиль — умный выбор:
- Идеально сочетается с большим масштабом (тысячи граждан, тысячи зданий)
- Хорошо стареет (стилизованная графика не устаревает через 5 лет, в отличие от реалистичной)
- Узнаваемая эстетика (Manor Lords, Farthest Frontier, Going Medieval)

Поднимается до «кинематографического» качества через post-processing (Bloom, color grading, depth of field, volumetric fog/light shafts, dynamic time-of-day, particle systems).

## Три уровня рендеринга

Для производительности с 30 000+ граждан на карте используется многоуровневый рендеринг. Переключение между уровнями происходит автоматически при зуме камеры.

| Уровень | Что рендерится |
|---|---|
| **Близкий (локальный вид)** | 100 граждан в 3D low-poly с анимацией. 50 зданий в 3D. Растительность: GPU instancing. Полный post-processing. |
| **Стратегический (высоко)** | Граждане как 2D иконки. Здания в simplified 3D. Без post-processing. Туман войны, торговые пути. |
| **Глобальная карта** | 2D тайлы поверх реальной карты. Иконки поселений, армий, торговых путей. UI-наложение (политические границы, ресурсы). |

## Хитрости производительности

- **LOD (Level of Detail)** — 3 версии модели (high/med/low poly), движок выбирает по расстоянию
- **Occlusion culling** — не рисуется то, что за горой или зданием
- **Impostors** — дальние здания рендерятся как 2D-биллборды
- **HLOD (Hierarchical LOD)** — целые кварталы объединяются в одну модель
- **DOTS/ECS** — Entity Component System для симуляции тысяч сущностей в одном потоке
- **Частоты симуляции** — разные слои (гражданин/семья/поселение/регион) тикают с разной частотой

## Технологический стек

| Компонент | Технология |
|---|---|
| Движок | Unity 2022 LTS + C# |
| Симуляция (если мультиплеер) | .NET 8 + Entity Framework |
| Геоданные | GDAL + QGIS для подготовки |
| Тайлы | H3 (Uber) или собственная гекс-система |
| Хранение сейвов | SQLite (легче) или BSON |
| UI | UI Toolkit (Unity) для десктопа |

## Платформы

- **Windows (Steam Early Access)** — первый релиз, основная платформа
- **Android** — вторая платформа, после стабилизации на десктопе, с упрощённым UI
- **Linux/macOS** — опционально, через Unity мультиплатформенность
