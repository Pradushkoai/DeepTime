# Глава 6 — Технологии и эволюция

## Принцип эмерджентности

Главное правило эволюции общества в игре: любая технология, общественный строй или экономическая форма появляются только когда выполнены предпосылки, а не когда «пришло время».

В отличие от Civilization, где эпохи идут линейно и технологии открываются по расписанию, в «Цивилизации Прадушко» общество развивается через **эмерджентное возникновение новшеств** из выполнения условий. Это значит, что разные стартовые локации дают радикально разные пути развития.

Примеры:
- Альпийский старт может никогда не достичь «государства», но стать «конфедерацией племён с развитой металлургией»
- Египетский — ранние государства, города, ирригация, без металла до поздно
- Скандинавский — мореплавание, торговля, викинги, без земледелия
- Кочевой — степная империя, монгольский сценарий

## Пять категорий предпосылок

Любое нововведение в игре требует комбинации из пяти типов предпосылок. Если хотя бы одна категория не выполнена, нововведение не происходит, сколько бы лет ни прошло.

### 1. Знания (когнитивные)
Предшествующие технологии, накопленный опыт, передача через торговлю/захват. Например, для плавки меди нужно знание контроля огня + многократное наблюдение плавки в костре.

### 2. Ресурсы (материальные)
Доступ к конкретному ресурсу в регионе, достаточное количество для специализации, транспортная доступность. Например, для бронзы нужен одновременно источник меди И источник олова. Если в регионе нет олова — будет только медь, без бронзы.

### 3. Социальная сложность
Размер населения, плотность поселений, наличие городов, избыток еды (чтобы кормить спецов), специализация труда. Например, для «раннего государства» нужно 5000+ в одном городе.

### 4. Культурные ценности
Готовность общества принять новшество, приоритеты вождя, религиозные убеждения, этнические традиции. Например, при сильной «традиции» и слабом «знании» технологии открываются в 2-3 раза медленнее.

### 5. Физико-химические пороги ⚡ NEW

**Принцип**: технологии, связанные с плавкой, обжигом, химической обработкой, имеют физико-химические пороги. Нельзя «открыть» технологию без материала, способного выдержать требуемые условия.

| Технология | Требует | Порог | Что нужно сначала |
|---|---|---|---|
| Плавка меди | Печь, держащую ≥700°C | 700°C | Кирпич из обычной глины (держит 800-900°C) → достаточно |
| Плавка бронзы | Печь, держащую ≥950°C | 950°C | Кирпич из огнеупорной глины |
| Плавка железа | Печь, держащую ≥1500°C | 1500°C | Шамотный кирпич / огнеупорная глина + меха для нагнетания воздуха |
| Обжиг керамики | Печь, держащую 800-1200°C | варьируется | Глиняная печь достаточна |
| Производство стекла | Печь, держащую ≥1200°C | 1200°C | Огнеупорная глина + кварцевый песок |
| Производство цемента/извести | Печь, держащую ≥900°C | 900°C | Обычный кирпич достаточен |

**Игровая механика**: игрок не может «исследовать плавку железа» без разработки огнеупорного материала и печи. Чтобы разработать огнеупорный материал, нужен доступ к огнеупорной глине. Это создаёт «бутылочное горлышко»: без нужного материала — нет технологии. Исторически достоверно: древние цивилизации упирались именно в материалы печей.

## Четыре типа знаний

Знания в игре делятся на четыре типа по способу приобретения и социальной функции.

- **Эмпирические знания** — накапливаются опытом: «эта ягода не ядовитая — мы ели, не умерли», «кремень даёт искру о другое камень». Появляются автоматически.
- **Технологии** — открывают возможности: «плавка меди» → доступ к медным орудиям, «гончарный круг» → массовая керамика, «колесо» → телеги. Требуют предпосылок.
- **Культурные практики** — организуют общество: «земледелие» → оседлость и города, «письменность» → долговременные знания и школа, «религия» → мораль и лояльность.
- **Контакты (передаются от соседей)** — торговля → перенимание идей, завоевание → ассимиляция населения, миграции → принесённое знание.

## Десять механизмов ускорения

Изучив реальную историю человечества, выделяем десять механизмов, которые общества использовали для ускорения технологического и социального развития.

| Механизм | Исторический пример | Игровая механика |
|---|---|---|
| Торговая диффузия | Финикийцы разнесли алфавит; Шёлковый путь — бумагу, порох | Приоритет «торговля» → шанс перенять технологию соседей |
| Военное давление | Спарта милитаризовалась из-за угрозы илотов; Ассирия | Угроза со стороны соседей ускоряет военные технологии |
| Ресурсная необходимость | Япония — интенсивное земледелие из-за дефицита пашни | Дефицит ресурса даёт бонус к его альтернативам |
| Реакция на кризис | Чума XIV в. покончила с крепостничеством | Кризисные события временно снижают сопротивление реформам |
| Плотность населения + избыток | Речные долины → урбанизация | Рост населения → специализация → инновации |
| Религиозные институты | Храмы как первые банки; монастыри — грамотность | Финансирование храмов → поддержка учёных |
| Харизматический лидер | Хаммурапи, Солон, Пётр I | «Чемпион реформы» — конкретный гражданин-новатор |
| Миграция мастеров | Гиксы принесли колесницу в Египет | Приезд экспертов извне = tech boost |
| Завоевание носителей знаний | Ассирийцы сгоняли ремесленников в Ниневию | Захват города с мастерами = massive tech boost |
| Стандартизация | Вавилонские гирьки, китайские экзамены | Стандарты (весы, мера, грамота) → умножают эффект |

## Эволюция, а не «открытие»

Ключевая разница с Civ и подобными: переходы не мгновенны.

Пример перехода от бартера к товарным деньгам:

1. Чистый бартер — жители меняют товар на товар напрямую
2. Жители начинают использовать зерно как «универсальный эквивалент» (потому что зерно всем нужно, легко делится, измеримо)
3. Зерно становится мерой стоимости. Появляются «зернохранилища-банки». Казна вождя принимает зерно как налог.
4. Появляются металлические слитки — более компактные, не портятся
5. Металл по веслу. Серебро/медь отвешивается на гирьках. Цены в «граммах серебра».
6. Игрок (вождь) решает чеканить монеты. Стандартный вес, клеймо вождя = гарантия.

Каждый переход занимает годы/десятилетия игровой истории. Игрок не «включает» — он создаёт условия, общество эволюционирует.

## Система одомашнивания (NEW)

Одомашнивание — отдельная ветка технологий. Для каждого вида животного (собака, овца, коза, корова, лошадь, верблюд, лама и т.д.) и для каждой культуры (пшеница, ячмень, рис, кукуруза, картофель, лён и т.д.) нужно:

- Найти **дикого предка** в регионе (географическая привязка)
- Иметь знания о содержании/выращивании
- Иметь социальную готовность к оседлости (для культур)
- Иметь ресурсы (пастбища для скота, поля для растений)

Это создаёт географическую уникальность: не во всех регионах есть дикие предки нужных животных/растений. Создаёт стимул к торговле и экспансии за видами/семенами.
