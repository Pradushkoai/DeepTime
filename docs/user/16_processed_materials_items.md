## 🌳 Дерево технологий (tech_tree)

11 эпох (палеолит → электронная) — для ориентира. Эпохи 1-4 детализированы (25 технологий с предпосылками, результатами и связями). Эпохи 5-11 — заготовки (TBD).

### Ключевые «бутылочные горлышки»:

| Переход | Критично |
|---|---|
| Неолит → Халколит | Плавка меди (древесный уголь + 700°C) |
| Халколит → Бронза | Олово (касситерит!) + 950°C |
| Бронза → Железо | Шамот + графит + 1500°C |
| Железо → Индустриализация | Кокс + домна + сталь |
| → Алюминий | Электричество + бокситы + криолит |
| → Демография 20 в. | Габер-Бош (NH₃) |
