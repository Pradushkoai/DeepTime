## 🎯 Обзор

Пути развития описываются **двумя слоями** (не одной плоскостью):
- **Слой 1 — источник калорий** (что кормит племя)
- **Слой 2 — специализация** (что делаешь с избытком)

Доли источников калорий **вычисляются из полей гекса** (не выбираются игроком). «Основной» = максимальная доля — для идентичности архетипа, не для управления.

> **Принцип**: игрок не выбирает «мы охотники» — это лишний тумблер, противоречащий концепции вождя-тренда и «географии = судьбы». Доли определяются регионом.

## 📐 Слой 1: Источник калорий

### 5 источников

| Источник | Что | В палеолите? | Технология открытия |
|---|---|---|---|
| 🏹 **Охота** | Мясо диких животных | ✅ Да | Старт (T-004, T-005) |
| 🌿 **Собирательство** | Растения, ягоды, орехи, коренья | ✅ Да | Старт |
| 🐟 **Рыболовство** | Рыба, моллюски | ✅ Да | Старт (если есть вода) |

## 📊 Вычисляемые доли

> ⚠️ **B в round_11**: «Доли вычисляются из полей гекса, которые уже существуют: `Fauna`, `Flora`, `WaterAccess`, `TerrainType`, `Fertility`. Отдельной таблицы заводить не нужно.»

> ⚠️ **Принцип 14 (Тест на один справочник)**: не создаём второй справочник «источники по архетипам». Вычисляем из существующих полей гекса.

### Формула

```
Для каждого гекса региона:

  доля_охоты       = fauna_richness × 0.4
  доля_собиратель  = flora_richness × 0.4
  доля_рыболовства = water_access × 0.3
  доля_земледелия  = fertility × 0.3 (если T-015 открыта, иначе 0)
  доля_скотоводства = pasture_quality × 0.3 (если T-030 открыта, иначе 0)

  total = доля_охоты + доля_собиратель + доля_рыболовства + доля_земледелия + доля_скотоводства

  нормализованные доли = каждая / total (сумма = 100%)

  основной = max(доли) — для идентичности, не для управления
```

### Поля гекса (из GDD)

| Поле | Что | Откуда | Пример |
|---|---|---|---|
| `fauna_richness` | Богатство фауны (0-1.0) | `fauna/index.md` → плотность видов | 0.8 (степь — много дичи) |
| `flora_richness` | Богатство флоры (0-1.0) | `flora/index.md` → плотность растений | 0.6 (лес — ягоды, орехи) |
| `water_access` | Доступ к воде (0-1.0) | Реки, озёра, море | 1.0 (устье реки) |
| `terrain_type` | Тип рельефа | Горы / равнина / степь / лес / пустыня | "steppe" |
| `fertility` | Плодородие почвы (0-1.0) | `soils/index.md` → S-007 Chernozems = 0.9 | 0.9 (чернозём) |

### Примеры вычисления

#### Пример 1: Степной архетип (палеолит)

```
fauna_richness = 0.9 (много дичи — сайгак, кулан)
flora_richness = 0.3 (степные травы, мало съедобных растений)
water_access = 0.2 (редкие ручьи)
fertility = 0.7 (чернозём, но земледелия нет — T-015 не открыта)
pasture = 0.8 (хорошие пастбища, но скотоводства нет — T-030 не открыта)

доля_охоты       = 0.9 × 0.4 = 0.36
доля_собиратель  = 0.3 × 0.4 = 0.12
доля_рыболовства = 0.2 × 0.3 = 0.06
доля_земледелия  = 0 (нет T-015)
доля_скотоводства = 0 (нет T-030)

total = 0.36 + 0.12 + 0.06 = 0.54

Нормализованные:
  Охота: 67% ← основной
  Собирательство: 22%
  Рыболовство: 11%
```

> Степь в палеолите = **67% охота**. Племя — охотники на диких копытных.

#### Пример 2: Речно-долинный архетип (палеолит)

```
fauna_richness = 0.6 (дичь у реки)
flora_richness = 0.7 (дикие злаки, ягоды)
water_access = 1.0 (река!)
fertility = 0.8 (Fluvisols, но земледелия нет)

доля_охоты       = 0.6 × 0.4 = 0.24
доля_собиратель  = 0.7 × 0.4 = 0.28
доля_рыболовства = 1.0 × 0.3 = 0.30

total = 0.82

Нормализованные:
  Охота: 29%
  Собирательство: 34%
  Рыболовство: 37% ← основной
```

> Речная долина = **37% рыболовство, 34% собирательство**. Сбалансированный старт — поэтому рекомендуется новичкам.

#### Пример 3: Лесной архетип (палеолит)

```
fauna_richness = 0.7 (лоси, кабаны)
flora_richness = 0.9 (ягоды, орехи, грибы)
water_access = 0.5 (ручьи)

доля_охоты       = 0.7 × 0.4 = 0.28
доля_собиратель  = 0.9 × 0.4 = 0.36
доля_рыболовства = 0.5 × 0.3 = 0.15

total = 0.79

Нормализованные:
  Охота: 35%
  Собирательство: 46% ← основной
  Рыболовство: 19%
```

> Лес = **46% собирательство**. Больше растений, чем дичи.

## 🛠️ Слой 2: Специализация

> Специализация = **что делаешь с избытком**. Сначала кормишься (слой 1), потом специализируешься (слой 2).

### 3 типа специализации

| Специализация | Что | Условие | Пример |
|---|---|---|---|
| 🔨 **Ремесло** | Производство изделий | Избыток ресурсов + T-020 (деревообработка) / T-050 (медь) | Кузница, гончарня, ткацкая |
| 💰 **Торговля** | Обмен ресурсами | T-022 (колесо) + торговый путь (D-005) | Караван, рынок |
| ⛏️ **Добыча редких ресурсов** | Медь, обсидиан, олово, соль | Источник в регионе + T-050 (металлургия) | Рудник, каменоломня |

### ⚠️ Торговля — НЕ ось (B в round_09)

> Оси отвечают «что производишь». Торговля = «как обмениваешь». Путь «торговца, который ничего не производит» = товар без происхождения. Торговля живёт в **слое 2**.

### Механика специализации

```
1. Племя имеет избыток калорий (слой 1 удовлетворён)
2. Избыток = часть населения свободна от добычи еды
3. Свободное население → специализация (слой 2)
4. Выбор специализации = через эдикты вождя (D-001) + фракции (D-004)
5. Ремесленники усиливают фракцию ремесленников (D-004)
6. Торговцы усиливают фракцию купцов (D-004)
```

## 🦣 Вызов вымирания мегафауны

> ⚠️ **B в round_11**: «Начало игры (10 000 до н.э.) совпадает с вымиранием мегафауны. Если доля крупной дичи высока, а фауна угасает, племя вынуждено **само** перекашиваться. Никаких искусственных событий — динамика от реальной истории и каталога фауны.»

### Принцип

> Мегафауна (мамонты, шерстистые носороги, гигантские ленивцы) вымирает ~10 000 до н.э. Племена, зависящие от охоты на крупную дичь, **вынуждены** адаптироваться.

### Механика

```
1. Старт: fauna_richness включает мегафауну (мамонт, носорог)
2. Каждые 100-200 лет: мегафауна сокращается (−0.05 fauna_richness)
3. Через 500-1000 лет: мегафауна = 0 (вымерла)
4. доля_охоты падает → доля_собирательства/рыболовства растёт
5. Племя **само** перекашивается — без событий, без эдиктов
6. Игрок видит в слое видимости (D-007): «доля охоты падает»
```

### Влияние на геймплей

| Этап | Что происходит | Что видит игрок |
|---|---|---|
| Старт (10000 до н.э.) | Мегафауна есть, охота = 60-70% | «Ваша стоянка у реки мамонтов» |
| +200 лет | Мегафауна сокращается, охота = 50% | «Мамонты уходят на север» |
| +500 лет | Мегафауна почти исчезла, охота = 30% | «Дичи меньше — собирайте больше» |
| +1000 лет | Мегафауна вымерла, охота = 15% | «Старый мир охоты ушёл» |

### Связь с каталогом фауны

> B: «сверить профили гексов с каталогом фауны — если крупная дичь там есть, вызов получается бесплатным.»

| Каталог | Мегафауна (вымирает) | Обычная дичь (остаётся) |
|---|---|---|
| `fauna/index.md` | A-038 Слон (Африка — не вымирает), мамонт (Сибирь — вымирает) | A-031 Лось, A-032 Олень, A-034 Кабан |
| | A-042 Антилопа гну (Африка — остаётся) | A-035 Заяц, A-036 Бобр |

> **Реализация**: мегафауна помечается в каталоге фауны флагом `megafauna: true` + `extinction_year: ~9000 до н.э.`. При достижении этого года — fauna_richness падает.

## 🔄 «Нетипичный путь» (земледелие в степи)

> ⚠️ **B в round_09**: «Не нуждается в новой механике. В проекте уже согласовано: "игрок может перебить предрасположенности эдиктами и реформами, но это требует усилий и встречает сопротивление фракций". Подключить согласованное сопротивление фракций (Q-005).»

### Механика

```
1. Игрок хочет земледелие в степи (где fertility = 0.7, но flora_richness = 0.3)
2. Игрок открывает T-015 (земледелие)
3. Игрок эдиктом «насаждать земледелие» → +вероятность сдвига доли
4. НО: фракция охотников (D-004) сопротивляется → +обида
5. Игрок проводит реформу (D-001, 5 шагов) → снижение сопротивления
6. Через 50-100 лет → доля земледелия растёт (медленно, с болью)
```

> **Не отдельная механика** — подключение существующих (D-001 реформы + D-004 фракции + D-006 собственность).
