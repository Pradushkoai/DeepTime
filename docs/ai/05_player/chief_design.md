# D-001: Вождь-гибрид — Спецификация

> 📋 **Спецификация D-001** — ядро игры. Вождь-гибрид: сменяемый (умирает от старости/болезни/войны), наследуется, но существует meta-механика «память племени».
>
> **Основано на**: Q-001 (гибрид), Q-017 (масштаб времени), Q-019 (детали). См. `discussions/consensus.md`.

---

## 🎯 Обзор

Игрок = вождь племени. Вождь — конкретный персонаж с именем, чертами, навыками, жизненным циклом. Вождь умирает → игрок управляет наследником. Между правлениями действует «память племени» — meta-слой, сохраняющий обиды, договоры, достижения через поколения.

**Принцип**: игрок не вечный сверхчеловек, а «дух племени», реализуемый через сменяемых лидеров. Каждый новый вождь — новый геймплей (другие черты, навыки). Кризис преемственности — источник драмы.

## 📊 Структура данных вождя

### Поля персонажа

| Поле | Тип | Описание |
|---|---|---|
| `name` | string | Имя вождя |
| `age` | int | Текущий возраст (лет) |
| `era` | enum | Эпоха вождя (YOUNG / MATURE / OLD / DECLINING) |
| `traits` | list[Trait] | Черты характера (3-5 штук) |
| `skills` | dict[Skill, int] | Навыки (0-100): военный, дипломатический, экономический, религиозный, научный |
| `health` | int | Здоровье (0-100) |
| `legitimacy` | int | Легитимность (0-100) — право на власть |
| `heir` | Person \| null | Наследник (если назначен) |
| `regent` | Person \| null | Регент (если вождь малолетний) |
| `reign_start` | int | Год начала правления |
| `pressure` | int | Давление непоглощённого изменения (0-100) |
| `adaptations` | list[Reform] | Завершённые реформы-адаптации |

### Черты (Traits)

Черты — врождённые особенности, не меняются в течение жизни. 3-5 на вождя.

**Примеры черт** (по категориям):

| Категория | Черты | Эффект |
|---|---|---|
| Военные | Храбрый, Осторожный, Стратег | +военный / +оборона / +планирование |
| Дипломатические | Красноречивый, Замкнутый, Хитрый | +дипломатия / −дипломатия / +шпионаж |
| Экономические | Щедрый, Скупой, Расчётливый | +счастье / +казна / +эффективность |
| Религиозные | Набожный, Скептик, Фанатик | +жречество / −жречество / +традиция |
| Научные | Любопытный, Консерватор | +наука / −наука +традиция |
| Физические | Крепкий, Болезненный, Долгожитель | +здоровье / −здоровье / +жизнь |

## 🔄 Жизненный цикл вождя

```
Рождение → Детство (0-15) → Вступление (16+) → Правление → Смерть → Наследование
                                                          ↑
                                                     Регентство (если мал)
```

### 1. Рождение и детство (0-15 лет)

- Вождь рождается как NPC в семье предыдущего вождя
- Черты определяются **случайно** при рождении (3-5 из общего пула)
- Навыки = 0 при рождении, растут через **воспитание**
- Игрок **не управляет** вождем в детстве

### 2. Воспитание наследника (Q-017 — «наследник растёт на глазах»)

Игрок влияет на воспитание наследника **до** его вступления:

| Действие | Эффект | Цена |
|---|---|---|
| Назначить наставника | +навык в области наставника | Политический капитал |
| Военный опыт (поход) | +военный навык, −здоровье | Риск ранения |
| Дипломатическая миссия | +дипломатия, +отношения | Время |
| Религиозное образование | +религиозный, +жречество | −наука |
| Светское образование | +наука, −традиция | −жречество |

**Ключевое решение**: готовить наследника под **новые технологии** (= живая адаптация, см. §5) или под **старые традиции** (= не адаптирует).

### 3. Вступление (16+ лет)

- При смерти вождя наследник вступает на престол
- Если наследник <16 → регентство (см. §6)
- При вступлении:
  - `legitimacy` = базовая (50) + бонусы (наследник +20, черты ±10)
  - `pressure` = наследуется от предыдущего вождя (50% — см. §8 «память племени»)
  - `era` = YOUNG

### 4. Правление

Игрок управляет вождём через:
- **Эдикты** (директивы — см. Q-002 зонирование, Q-003 миграция)
- **Ползунки ценностей** (5 ползунков GDD)
- **Реформы** (5-шаговый процесс — см. §5)
- **Дипломатию** (Q-006)
- **Назначения** (чемпионы, регенты, наследники)

### 5. Смерть

Вождь умирает от **первого из двух** (Q-017 — «годы = рамка, давление = ускоритель»):

| Причина | Условие | Эффект |
|---|---|---|
| Старость | `age` ≥ базовой продолжительности (см. §7) | Плавная смена |
| Давление | `pressure` ≥ 100 | Кризис преемственности (см. §9) |
| Болезнь | Случайное событие (эпидемия) | −health, может убить раньше |
| Война | Случайное событие (битва) | Риск смерти в бою |
| Убийство | Заговор (обида фракции >90) | Кризис преемственности |

## 📈 Старение = непоглощённое изменение (Q-017)

### Принцип

> **Старение = изменение − успешно поглощённая адаптация**

Не «сколько изменилось», а **«сколько осталось непереваренным»**.

### Источники изменения (давление растёт)

| Событие | Давление | Обоснование |
|---|---|---|
| Открыта новая технология | +5-15 (по значимости) | Общество изменилось |
| Смена доминирующей фракции | +20 | Политический сдвиг |
| Эпохальный переход (стадия) | +30 | Структурное изменение |
| Война (поражение) | +15 | Кризис |
| Эпидемия | +10 | Кризис |
| Торговый путь открыт | +5 | Культурный контакт |

### Источники адаптации (давление падает)

| Действие | Снижение | Условие |
|---|---|---|
| Завершённая реформа (5-шаговый процесс) | −10-30 | Реформа соответствует изменению |
| Наследник под новые технологии | −5/год | Живая адаптация (см. §2) |
| Время (без новых изменений) | −1/год | Естественное переваривание |

### Формула давления

```
pressure = pressure + Δ_change - Δ_adaptation

где:
  Δ_change = сумма изменений за год
  Δ_adaptation = сумма адаптаций за год

pressure ≥ 0 (не может быть отрицательным)
pressure ≤ 100 (при 100 → смерть от давления)
```

### Пример

```
Вождь 40 лет, pressure = 20

Год 1: Открыта плавка железа (+15), проведена реформа перевооружения (−10)
  pressure = 20 + 15 - 10 = 25

Год 2: Смена доминирующей фракции (+20), реформа не проведена
  pressure = 25 + 20 - 0 = 45

Год 3: Эпохальный переход — город (+30), реформа администрации (−15)
  pressure = 45 + 30 - 15 = 60

Год 4: Без изменений, время (−1)
  pressure = 60 + 0 - 1 = 59

Вождь стареет, но не умирает — давление < 100
```

## 🔄 Адаптация = завершённая реформа (Q-017, Q-019)

### Принцип

> Адаптация = **завершённая реформа**, не тумблер. Если адаптация мгновенна и бесплатна — давление ничего не значит.

### 5-шаговый процесс реформы (из GDD раздел 14)

```
1. ИДЕНТИФИКАЦИЯ → Игрок (или событие) определяет необходимость реформы
2. КОАЛИЦИЯ → Набрать ≥50% поддержки фракций (Q-005)
3. СТРАТЕГИЯ → Выбрать тактику проведения (поэтапно / радикально)
4. ОКНО ВОЗМОЖНОСТЕЙ → Дождаться подходящего момента (кризис = окно)
5. ИСХОД → Реформа проведена (или провалена)
```

### Типы реформ-адаптаций

| Реформа | К какому изменению адаптирует | Снижение давления |
|---|---|---|
| Перевооружение армии | T-057/T-058 (железо) | −10 |
| Учреждение писцов | T-037 (алфавит) | −10 |
| Реформа администрации | T-043 (города) | −15 |
| Аграрная реформа | T-015 (земледелие) | −10 |
| Военная реформа | T-005 (лук) / T-023 (колесница) | −10 |
| Религиозная реформа | T-041 (религия) | −15 |
| Торговая реформа | T-100 (монеты) | −10 |

### Если реформа не пройдена

- Фракции сопротивляются → реформа провалена → давление **не снижается**
- При следующем изменении → давление растёт дальше
- При pressure ≥ 100 → кризис преемственности (см. §9)

## 👶 Регентство (Q-019)

### Когда возникает

Вождь умер, наследник <16 лет → регентство до совершеннолетия.

### 3 варианта регента

| Вариант | Кто | Риски | Плюсы |
|---|---|---|---|
| **Регент от фракции** | Фракция с наибольшей силой | Узурпация (если сила >80 → ультиматум Q-005) | Стабильность |
| **Регент-наставник** | Игрок выбирает из кандидатов | Наставник может оказаться плохим | Контроль |
| **Регент-мать** | Мать наследника | Клан матери доминирует | Исторически часто |

### Взаимодействие с Q-005 (фракции)

> ⚠️ «Регент от фракции >80» = ультиматум в новой обёртке. Зафиксировать, чтобы два правила не выстрелили одновременно.

- Если регент от фракции с силой >80 → **не запускать** ультиматум Q-005 (уже сработал через регентство)
- Регент правит до 16-летия наследника
- Если наследник умирает до 16 → кризис преемственности (см. §9)

## 👤 NPC-наследник (Q-019)

### Принцип

> **Принять / Отстранить** — БЕЗ «устранения-реролла».

«Устранение» (= реролл черт) — **отклонено** (B поймала порочный стимул: гача с ресайклом + опора на удалённый Q-010).

### Варианты действий

| Действие | Эффект | Цена |
|---|---|---|
| **Принять** | Наследник становится вождём со своими чертами | Игрок терпит |
| **Отстранить** | Назначить другого кандидата | **Гарантированная** плата (не вероятность) |

### Цена отстранения (гарантированная, не рискованная)

| Последствие | Механика |
|---|---|
| **Постоянная обида родового клана** | +обида фракции (Q-005), **переживает вождя** |
| **Утрата «наследника на глазах»** | Десятилетия работы обнуляются |
| **−легитимность** | −20 легитимности (право на власть ослабло) |

> Это **не ресайкл, а долгосрочное обязательство**. Несколько отстранений → клан в ярости → кризис.

### Система преступности (Q-010) НЕ нужна

«Устранение» с «риском раскрытия» требовало бы систему расследования → Q-010 (преступность). Но Q-010 убран. Поэтому отстранение = **гарантированная цена**, а не риск.

## 📜 Хроника племени (Q-019)

### Принцип

> Хроника = лента событий прошлых правлений. **Точность зависит от письменности** (Принцип 13 — палеолитный тест).

### Содержание хроники

| Категория | Что | Пример |
|---|---|---|
| **Лента событий** | Ключевые события прошлых правлений | «Вождь Ур победил северян» |
| **Обиды** | Активные обиды (кто, за что, когда) | «Северяне убили торговца 150 лет назад» |
| **Договоры** | Действующие договоры (с соседями, фракциями) | «Мир с Египтом, 50 лет» |
| **Достижения** | Великие деяния прошлых вождей | «Храм Солнца построен» (+легитимность текущему) |

### Точность от письменности

| Эпоха | Письменность | Точность хроники |
|---|---|---|
| До T-035 (пиктограммы) | Нет | Устные предания без дат: «давным-давно вождь Ур подружился с северянами» |
| T-035 (пиктограммы) | Первичная | События без точных дат: «при вожде Ур — война с северянами» |
| T-036 (клинопись) | Развитая | События с приближенными датами: «~год Ур — война» |
| T-037 (алфавит) | Полная | Точные даты и полные имена: «год 1247 — война с северянами, вождь Ур» |

### UI хроники

- Отдельный экран «Хроника племени»
- Фильтр по вождю (показать события правления NN)
- Фильтр по типу (обиды / договоры / достижения)
- До письменности — события без дат, в хронологическом порядке преданий
- После письменности — события с датами, в календарном порядке

## ⏳ Числа продолжительности жизни (Q-019)

### Принцип

> **Годы = рамка, давление = ускоритель.** Вождь умирает от первого из двух.

### Базовая продолжительность по эпохам

> ⚠️ Только базовая колонка. Модификаторы (медицина, ранения) — на плейтестах (Принцип 2).

| Эпоха игры | Базовая жизнь (лет) | Обоснование |
|---|---|---|
| Палеолит | 60-80 | Медленный темп, долго живущие вожди |
| Неолит | 50-70 | Чуть быстрее |
| Бронза | 45-65 | Урбанизация = болезни |
| Железный век | 40-60 | Войны |
| Античность | 40-55 | Стабилизация |
| Средние века | 35-50 | Эпидемии |
| Ренессанс | 40-55 | Медицина |
| Индустриальная | 50-70 | Современная медицина |
| Современная | 60-80 | Антибиотики |
| Электронная | 70-90 | Генная инженерия |

### Модификаторы (направление, не числа)

| Фактор | Эффект | Примечание |
|---|---|---|
| +Богатство (хорошая еда/жильё) | +жизнь | На плейтестах |
| +Медицина (травы → врачи) | +жизнь | На плейтестах |
| −Войны/ранения | −жизнь | На плейтестах |
| −Болезни (эпидемии) | −жизнь | Q-016 убран, но болезни как событие остаются |
| +«Божественное наследие» | +жизнь | Если вождя считают полубогом |
| Черта «Долгожитель» | +жизнь | Врождённая |

### Связь с давлением

```
смерть = min(age ≥ базовой_жизни, pressure ≥ 100)
```

Вождь умирает от **первого** из двух:
1. Достиг базовой продолжительности → смерть от старости (плавная смена)
2. Давление ≥ 100 → смерть от давления (кризис преемственности)

## 🧠 Память племени (Q-001, Q-019)

### Принцип

> Память племени — **внешний домен** (между цивилизациями), не внутренний (между фракциями). Обиды и договоры **переживают вождя**.

### Разделение доменов (из Q-003 дискуссии)

| Домен | Что | Переживает вождя? |
|---|---|---|
| **Обида фракций** (Q-005) | Внутренний — между фракциями | ✅ Да (но убывает) |
| **Память племени** (Q-006) | Внешний — между цивилизациями | ✅ Да (вендетты столетней давности) |

### Что наследуется

| Элемент | Наследование | Эффект на нового вождя |
|---|---|---|
| Обиды фракций | 100% (не сбрасываются!) | Фракции помнят старые обиды |
| Договоры с соседями | 100% | Действуют до нарушения |
| Вендетты с цивилизациями | 100% | «Ты убил торговца 150 лет назад» (Q-006) |
| Великие достижения | 100% | +легитимность новому вождю |
| Давление | 50% | Половина непоглощённого изменения |
| Личные навыки/черты | 0% | Новый вождь = новые черты |

### Почему обиды НЕ сбрасываются при смене вождя

> Из Q-003 дискуссии: «Сброс на 50% при смене вождя — порочный стимул. Превращается в инструмент зачистки. Обида живёт дольше вождя? Тогда её нельзя сбрасывать при вожде».

Обида **убывает** (покаяние, компенсация, время), но **не сбрасывается** при смене вождя.

## ⚠️ Кризис преемственности (Q-017)

### Когда возникает

| Ситуация | Что происходит | Игрок |
|---|---|---|
| ✅ Наследник есть, взрослый | Плавная смена | Выбирает из 1-3 кандидатов |
| ⚠️ Наследник мал (<16) | Регентство (10-15 лет) | Назначает регента (§6) |
| ❌ Наследника нет | Кризис | 3 варианта (ниже) |
| 💀 Вождь убит | Резкий кризис | Экстренный выбор (часто гражданская война) |
| 💀 Давление ≥ 100 | Кризис от давления | Зависит от наличия наследника |

### 3 варианта при отсутствии наследника

| Вариант | Что | Риски |
|---|---|---|
| **Узурпатор** | Сильная фракция ставит своего кандидата | −легитимность, +обида других фракций |
| **Распад** | Племя распадается на несколько | Потеря территории, населения |
| **Вассалитет** | Подчинение более сильному соседу | −независимость, +защита |
