# D-006: Собственность — Спецификация

> 📋 **Спецификация D-006** — право собственности в игре. Две оси (КТО × ЧТО) вместо 7 типов + рабство как отдельная шкала (разделение доменов).
>
> **Основано на**: Q-012 (собственность). См. `discussions/consensus.md` → Вопрос 05.
>
> ⚠️ **Проверено перед написанием**:
> - consensus.md → Вопрос 05 (все детали)
> - round_04: B дописала драйверы движения по осям + правило UI (подпись + чек-лист)
> - round_06: B уточнила рабство как отдельную шкалу (разделение доменов: вещи vs люди)
> - Подтверждено: рабство не требует той же технологии, что продажа (разные условия включения)

---

## 🎯 Обзор

Собственность в игре описывается **двумя осями** (не 7 типами):
- **Ось 1 — КТО владеет**: Община → Семья → Индивид → Институт
- **Ось 2 — ЧТО можно делать**: Пользовать → Передавать → Продавать → Закладывать

Игрок видит **подпись текущего состояния** (не сырые координаты) + чек-лист открытых/закрытых прав.

**Рабство — отдельная шкала** (разделение доменов: вещи vs люди). Две оси = право на вещи, шкала = право на людей. Одно не выводится из другого.

**Принцип**: собственность — это не «тип», а **комбинация прав**. Игрок не объявляет тип эдиктом, а создаёт **прецеденты**, которые сдвигают точку на осях.

## 📐 Две оси

### Ось 1: КТО владеет

| Уровень | Кто | Пример | Эпоха |
|---|---|---|---|
| 0 | 🏞️ **Община** | Земля — роду, орудия — лично | Палеолит |
| 1 | 🏠 **Семья** | Земля — семье (наследуется) | Неолит |
| 2 | 👤 **Индивид** | Земля/фабрика — частному лицу | Античность+ |
| 3 | 🏛️ **Институт** | Земля/скот — храму/государству | Бронза |

### Ось 2: ЧТО можно делать

| Уровень | Что | Пример | Технология |
|---|---|---|---|
| 0 | 🔄 **Пользовать** | Пахать землю, жить в доме | С первого хода |
| 1 | 📜 **Передавать по наследству** | Земля переходит детям | T-043 (города → учёт) |
| 2 | 💰 **Продавать** | Договор купли-продажи | T-037 (алфавит → договор) |
| 3 | 🏦 **Закладывать** | Залог под кредит | T-100 (чеканка → мерная единица) |

### Матрица 4×4 = 16 комбинаций

> Игрок видит **подпись**, не координаты. Но под капотом — точка на матрице.

| КТО \ ЧТО | Пользовать | Передавать | Продавать | Закладывать |
|---|---|---|---|---|
| Община | «Родовая собственность» | «Род с наследованием» | — | — |
| Семья | «Семейная собственность» | «Семейная, наследуемая» | «Семейная торговля» | «Семейный залог» |
| Индивид | «Личная собственность» | «Личная, наследуемая» | «Частная собственность» | «Частный залог» |
| Институт | «Государственная» | «Государственная, наследуемая» | «Государственная торговля» | «Государственный залог» |

### Стартовая точка (палеолит)

```
Ось 1: Община (уровень 0)
Ось 2: Пользовать (уровень 0)

Подпись: «Родовая собственность»
```

## 🔄 Драйверы движения по осям

> ⚠️ **B дописала драйверы в round_04** — без этого решение было неполным.

### Ось «ЧТО можно делать» — двигается ТЕХНОЛОГИЯМИ

| Технология | Что открывает | Обоснование |
|---|---|---|
| T-043 (города) | Передавать по наследству | Нужен учёт (запись владения) |
| T-037 (алфавит) | Продавать | Нужен договор (письменный) |
| T-100 (чеканка монет) | Закладывать | Нужна мерная единица (монета) |

> **Жёсткая правая граница**: дальше технологии — дальше не продвинешься. Нельзя «продавать» без письменности.

### Ось «КТО владеет» — двигается СОБЫТИЯМИ и ФРАКЦИЯМИ

| Драйвер | Сдвиг | Пример |
|---|---|---|
| Купец купил землю | Община → Индивид | Богатый купец выкупает общинную землю |
| Храм выдал ссуду | Семья → Институт | Храм становится крупным землевладельцем |
| Военный захватил надел | Семья → Индивид | Полководец получает землю за заслуги |
| Реформа redistribution | Индивид → Институт | Государство национализирует землю |
| Распад общины | Община → Семья | Род дробится на семьи |

### Эдикты — ПРЕЦЕДЕНТ, не указ

> ⚠️ Игрок **не может** объявить «частную собственность» эдиктом. Эдикт создаёт **прецедент** — сдвиг вероятности.

| Эдикт | Эффект | Как работает |
|---|---|---|
| «Защищать имущество купцов» | +вероятность сдвига к Индивид/Продавать | Растёт доверие к сделкам |
| «Разрешить наследование земли» | +вероятность сдвига к Семья/Передавать | Больше семей фиксируют землю |
| «Запретить продажу храмовых земель» | −вероятность сдвига от Институт | Храм сохраняет земли |
| «Национализация» | Сдвиг к Институт (событие, не эдикт) | Государство забирает — с ценой (обида) |

### Механика сдвига

```
Каждый год для каждого региона:
1. Вычислить вероятность сдвига по каждой оси
2. Вероятность = базовая + драйверы (события + фракции + эдикты)
3. Если вероятность > порог → сдвиг на 1 уровень
4. Сдвиг = одно событие (например, «купец купил землю»)

Пример:
- Эдикт «защищать имущество купцов» → +5%/год к сдвигу оси КТО → Индивид
- Через 10-20 лет → сдвиг происходит (событие «купец выкупил землю»)
- Точка на оси сдвигается: Семья → Индивид
```

## ⛓️ Рабство — отдельная шкала

> ⚠️ **B уточнила в round_06**: две оси = право на **вещи**. Шкала несвободного населения = право на **людей**. Разные домены, не выводятся друг из друга.

### Принцип разделения доменов

| Домен | Что | Механика |
|---|---|---|
| **Вещи** (две оси) | Право собственности на объекты | КТО × ЧТО |
| **Люди** (шкала) | Статус части населения | Доля несвободного населения (0-100%) |

> Римлянин мог владеть землёй (ось) и иметь рабов (шкала) — одно не выводилось из другого.

### Шкала несвободного населения

| Параметр | Значение |
|---|---|
| Стартовое значение | 0% (палеолит — нет рабства) |
| Активация | Война + социальная сложность (см. ниже) |
| Максимальное | 50% (исторический максимум — античные плантации) |

### Условие активации (Принцип 13 — палеолитный тест)

> ⚠️ Рабство не требует той же технологии, что продажа. Рабство возникает из **войны и поимки**, продажа — из **письменности**. Они появляются в разное время.

| Условие | Что нужно | Эпоха |
|---|---|---|
| Война | Победа → пленные | С первого хода (племенные войны) |
| Социальная сложность | Поселение (D-002) + избыток пищи | T-012 (глинобитное) + T-015 (земледелие) |
| Институционализация | Города (T-043) → закон о рабстве | Бронза+ |

**Палеолит**: рабство возможно как **единичные случаи** (пленные после войны), но не как институт. Шкала = 0-2%.

### Эффекты рабства

| Эффект | Направление | Обоснование |
|---|---|---|
| 💰 Дешёвый труд | +производство (сельхоз, стройка) | Рабы не получают зарплату |
| 😟 −Счастье | −счастье свободных | Вид угнетения |
| ⚠️ +Риск бунта | +обида (D-004) | Рабы могут восстать |
| 🧠 −Инновации | −скорость исследований | Зачем изобретать, если есть рабский труд? |

> **Историческое обоснование** (от B): античность с рабством vs средневековье без массового рабства — инновационный разрыв. Отказ от рабства = игровое решение, а не моральный ярлык.

### Механика изменения шкалы

| Источник | Эффект | Пример |
|---|---|---|
| Победа в войне | +5-15% | Захват пленных |
| Покупка рабов (торговля) | +2-5% | Торговля с регионами рабства |
| Репродукция рабов | +1%/год | Дети рабов = рабы |
| Манумиссия (освобождение) | −5-10% | Эдикт «освободить рабов» (с ценой) |
| Запрет рабства | → 0% | Эдикт «запретить рабство» (−экономика, +счастье, +инновации) |
| Бунт рабов | −10-20% | Спартак → потеря рабов + разрушения |

## 🔄 Связи с другими механиками

| Механика | Связь |
|---|---|
| **D-001 Вождь** | Эдикты вождя создают прецеденты → сдвиг осей. Запрет рабства = +давление (изменение) |
| **D-003 Миграция** | Частная собственность → больше вакансий (частные мастерские). Рабы → −вакансии (рабский труд) |
| **D-004 Фракции** | Фракции давят на оси: купцы → Индивид/Продавать, жречество → Институт. Рабство → +обида (D-004) |
| **D-005 AI соседей** | Торговля требует оси «Продавать» (T-037). Приём беженцев → +население (не рабы). Требование возмещения = память племени |
| **Q-009 Блокировки** | Диагноз «собственность тормозит» → причина → реформа |
| **Q-011 Банки** | Банки требуют оси «Закладывать» (T-100). Ростовщичество = эдикт «разрешить долги» + частная собственность |
| **Q-015 Стадии** | Стадия-отражение: «Город» требует собственности Семья+. «Государство» требует Институт |
| **Q-020 Слой видимости** | Собственность = одна из 7 категорий (подпись + чек-лист + шкала рабства) |

## 🧊 Палеолитный тест (Принцип 13)

| Элемент | Работает в 10 000 до н.э.? | Условие включения |
|---|---|---|
| Ось КТО = Община | ✅ Да | Старт (уровень 0) |
| Ось ЧТО = Пользовать | ✅ Да | Старт (уровень 0) |
| Сдвиг оси КТО (события) | ✅ Да | С первого хода (купец купил = обмен) |
| Сдвиг оси ЧТО (технологии) | ❌ Нет | T-043 (Передавать), T-037 (Продавать), T-100 (Закладывать) |
| Эдикты-прецеденты | ✅ Да | С первого хода (защита имущества) |
| Рабство | ❌ Нет | Война + социальная сложность (T-012 + T-015). Шкала стартует в 0% |
| UI (подпись + чек-лист) | ✅ Да | С первого хода (подпись «Родовая собственность») |

> **Палеолит**: «Родовая собственность» (Община; Пользовать). Орудия — личные, земля — родовая. Рабства нет (0%). Можно создать прецедент защиты имущества. Сдвиг оси КТО — через события (распад общины на семьи).
