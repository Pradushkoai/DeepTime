## 🎯 Обзор

Банковская система — **низкоприоритетная**, производная от 3 согласованных вещей:
1. Собственность (D-006) — ось «закладывать» (T-100)
2. Стадии денег (GDD) — от товарных к чеканным
3. Дерево технологий — T-041, T-085, T-130

> ⚠️ **B в round_09**: «Зафиксировать основу — 4 стадии и связь с осью — и отложить механику (кредит/вклад/банкротство) до наступления соответствующей эпохи. Это не "откладывание дыры" (Принцип 12 не нарушен — дыры нет, есть поздний контент).»

> ⚠️ **Принцип 14**: 2 подключения к GDD (не новые механики):
> 1. Ростовщичество = эдикт «разрешить долги» (уже в GDD)
> 2. Финансовый кризис = триггер вырождения (GDD, глава 12)

## 📊 4 стадии банковской системы

### Стадия 1: 🏛️ Храмовые ссуды

| Параметр | Значение |
|---|---|
| **Что** | Жречество выдаёт ссуды зерном/металлом по весу |
| **Условие** | T-041 (религия) + стадии 2-3 денег (товарные/металл по весу) |
| **❌ НЕ T-100** | Чеканные монеты — Лидия ~600 до н.э., храмовые ссуды — Шумер ~3000 до н.э. Разрыв **2400 лет** |
| **Кто** | Храм (институт, D-006 ось КТО = Институт) |
| **Что ссужает** | Зерно, металл по весу (НЕ монеты) |
| **Обеспечение** | Земля, скот (залог — но без оси «закладывать», формально) |

> ⚠️ **Историческая поправка** (B, round_09): «Храмовые ссуды — Шумер и Вавилон ~3000-1700 до н.э., шли зерном и металлом по весу. Чеканные монеты — Лидия ~600 до н.э. Разрыв ~2400 лет. По стадиям денег GDD храмовые ссуды укладываются в стадии 2-3 (товарные деньги), а не стадию 4 (монеты).»

### Стадия 2: 💰 Ростовщичество

| Параметр | Значение |
|---|---|
| **Что** | Частные лица дают в долг под процент |
| **Условие** | Эдикт «разрешить долги» (уже в GDD) + частная собственность (D-006: ось КТО = Индивид) |
| **Кто** | Частные ростовщики (индивиды) |
| **Что ссужает** | Металл по весу → монеты (T-100, если открыта) |
| **Обеспечение** | Залог земли/имущества (D-006: ось «закладывать» — T-100) |

> ⚠️ **Подключение 1 к GDD** (B, round_09): «Эдикт "запрет/разрешение долгов" уже есть в GDD (категория экономических эдиктов). Стадия 2 открывается не абстрактным условием, а **включением этого эдикта** — плюс частная собственность. Существующий рычаг, а не новая кнопка.»

### Стадия 3: 🏦 Гильдейские банки

| Параметр | Значение |
|---|---|
| **Что** | Гильдии объединяют капитал, выдают ссуды под залог |
| **Условие** | T-085 (университеты) + гильдии (D-004: фракция ремесленников) + частная собственность |
| **Кто** | Гильдии (кооператив, D-006: ось КТО = Институт/кооператив) |
| **Что ссужает** | Монеты (T-100), векселя (долговые расписки) |
| **Обеспечение** | Залог имущества, земли, товаров |

> Исторически: Италия, 13-15 вв. (Медичи, Барди, Перуцци). Гильдии = объединение ремесленников/торговцев.

### Стадия 4: 🏦 Государственные банки

| Параметр | Значение |
|---|---|
| **Что** | Центральный банк, эмиссия денег, государственный кредит |
| **Условие** | T-130 (паровая машина → индустриализация) + D-011 стадия «Индустриальная» |
| **Кто** | Государство (D-006: ось КТО = Институт) |
| **Что ссужает** | Бумажные деньги, кредиты фабрикам |
| **Обеспечение** | Государственные доходы, налоги |

> Исторически: Банк Англии (1694), Банк Франции (1800). Государственный банк = инструмент индустриализации.

## 🔗 Связь с осью «закладывать» (D-006)

> ⚠️ **B**: «Связь с осью "закладывать" — правильно. Без неё нет залога, значит нет банкротства с конфискацией.»

### Зависимость стадий от оси собственности

| Стадия банков | Ось «ЧТО» (D-006) | Ось «КТО» (D-006) | Технология |
|---|---|---|---|
| Храмовые ссуды | Пользовать (0) | Институт (3) | T-041 + стадии 2-3 денег |
| Ростовщичество | Продавать (2) | Индивид (2) | Эдикт «разрешить долги» |
| Гильдейские | Закладывать (3) | Институт/кооператив (3) | T-085 |
| Государственные | Закладывать (3) | Институт (3) | T-130 |

> **Ключевое**: ось «закладывать» (T-100 чеканка) требуется для **полноценного** банкротства с конфискацией залога. Без неё — ссуды есть, но без юридического механизма возврата.

## ⚠️ Финансовый кризис = триггер вырождения

> ⚠️ **Подключение 2 к GDD** (B, round_09): «Финансовый кризис — не отдельная механика, а триггер вырождения. В GDD уже есть "долговые кризисы" как экономическая причина вырождения. "Паника → обвал" = частный случай готовой системы.»

### Механика

```
1. Экономический кризис (голод, война, разрыв торговли)
2. Должники не могут вернуть ссуды → банкротства
3. Кредиторы (храм/ростовщики/гильдии) теряют капитал
4. → Триггер вырождения (GDD, глава 12):
   - «Долговой кризис» как причина вырождения
   - Стадии вырождения: расцвет → застой → упадок → тёмный век
5. Игрок может:
   - Списать долги (эдикт «прощение долгов» — уже в GDD)
   - Запретить ростовщичество (эдикт «запретить долги»)
   - Реформировать финансовую систему (D-001, реформа 5 шагов)
```

> **Не создаём новую механику** — подключаем готовую систему вырождения (GDD, глава 12).

## ⏳ Отложенная механика (кредит/вклад/банкротство)

> ⚠️ **B в round_09**: «Отложить механику до наступления соответствующей эпохи. Это не "откладывание дыры" (Принцип 12 не нарушен — дыры нет, есть поздний контент).»

### Что отложено

| Элемент | Когда | Почему отложено |
|---|---|---|
| Кредит (взять в долг) | Стадия 2+ (ростовщичество) | Ранняя игра = нет банков |
| Вклад (отдать под %) | Стадия 3+ (гильдейские) | Нужны институты |
| Банкротство (конфискация) | Стадия 2+ (нужна ось «закладывать») | Нужен T-100 |
| Эмиссия денег | Стадия 4 (государственные) | Нужен T-130 |
| Процентная ставка | Стадия 2+ | Формула — на плейтестах (Принцип 2) |

### Почему это не нарушает Принцип 12

> Принцип 12: «Сначала дыры, потом разработка». Но здесь **дыры нет** — есть поздний контент. Банки появляются с T-041 (религия, бронза), что далеко от палеолитического старта. Ранняя игра = без банков = нормально.

## 📊 Структура данных (когда активируется)

```yaml
banking_system:
  stage: 0                    # 0=нет, 1=храмовые, 2=ростовщичество, 3=гильдейские, 4=государственные
  active: false               # true при stage > 0
  
  # Стадия 1: Храмовые ссуды
  temple_loans:
    enabled: false
    condition: "T-041 + money_stage >= 2"
    lender: "temple"          # институт (D-006)
    currency: "grain_metal_weight"  # НЕ монеты
    interest_rate: 0.1        # 10% (направление, числа — плейтесты)
  
  # Стадия 2: Ростовщичество
  usury:
    enabled: false
    condition: "edict_allow_debts + property_who >= 2"  # Индивид
    lender: "individual"
    currency: "metal_weight_or_coins"
    interest_rate: 0.2        # 20% (выше храмовых)
  
  # Стадия 3: Гильдейские банки
  guild_banks:
    enabled: false
    condition: "T-085 + guilds + property_what >= 3"  # Закладывать
    lender: "guild"
    currency: "coins_bills"
    interest_rate: 0.15
  
  # Стадия 4: Государственный банк
  state_bank:
    enabled: false
    condition: "T-130 + stage_industrial"
    lender: "state"
    currency: "paper_money"
    interest_rate: 0.05       # ниже (государство дешёвее)
    emission: true            # может эмитировать деньги
  
  # Финансовый кризис
  financial_crisis:
    trigger: "economic_crisis + high_debt"
    effect: "degeneration_trigger"  # GDD глава 12
    mitigation: ["edict_debt_forgiveness", "edict_ban_usury", "reform"]
```

## 🖥 UI/UX спецификация

### Банковская панель (появляется при активации — стадии 1+)

```
┌──────────────────────────────────────────┐
│ 🏦 Финансы                                 │
│                                           │
│ Стадия: 🏛️ Храмовые ссуды                  │
│ Кредитор: Храм                             │
│ Валюта: Зерно / металл по весу            │
│ Ставка: 10%                                │
│                                           │
│ Активные ссуды:                            │
│   📜 Купец Абрам: 50 зерна (1 год, 10%)   │
│   📜 Фермер Ор: 20 зерна (6 мес, 10%)     │
│                                           │
│ Казна храма: 200 зерна                    │
│ Доход от процентов: 7/год                 │
│                                           │
│ [💰 Выдать ссуду] [📜 Списать долг]       │
│ [⚠️ Запретить долги]                      │
└──────────────────────────────────────────┘
```

> ⚠️ Панель **не показывается** в палеолите — банки не активны (стадия 0).

### Алерты

| Событие | Алерт |
|---|---|
| Банки активированы (стадия 1) | ℹ️ «Храм начинает выдавать ссуды зерном» |
| Должник не вернул | ⚠️ «Купец Абрам не вернул ссуду — долг растёт» |
| Финансовый кризис | 🚨 «ДОЛГОВОЙ КРИЗИС: массовые банкротства → риск вырождения» |
| Эдикт «запретить долги» | ℹ️ «Ростовщичество запрещено — ссуды прекращены» |
| Эдикт «простить долги» | ℹ️ «Долги прощены — кредиторы в убытке» |
