# T-008: Vertical Slice — Спецификация

> 📋 **Спецификация T-008** — план минимального играбельного среза по GDD §20 Фаза 1. Первый код, первая играемая версия.
>
> **Принцип**: один регион, ~50 граждан, 5 ресурсов, 3 технологии, 1 угроза, 2-3 месяца работы. Цель — проверить, весело ли ядро (аудит Модели B).

---

## 🎯 Обзор

GDD §20 Фаза 1: «Прототип поселения (2-3 месяца). Один регион 100×100 км (с реальными данными). ~50 граждан с именами и потребностями. 5 базовых ресурсов, 3 профессии. Простое дерево технологий (3 уровня). Один тип угрозы (хищник или зима)».

Аудит Модели B (P2): «Vertical slice поднять в приоритет. GDD Фаза 1 — прямо сейчас единственный честный ответ на вопрос "а это игра?"».

Эта спека:
1. Определяет scope (что входит, что НЕ входит)
2. Связывает с дизайн-спеками D-001..D-017
3. Определяет архитектурные решения для среза
4. Оценивает трудозатраты
5. Определяет метрики успеха

## 🏗 Архитектурные решения для среза

### Упрощения (по сравнению с full game)

| Полное (T-001..T-007) | Срез |
|---|---|
| 30 000 граждан | 50 граждан (все индивидуальные) |
| 64 800 гексов | 1 гекс + 25×25 локальная карта |
| 8 частот тика | 2: 1/сек (граждане) + 1/ход (события, вождь, фракции) |
| 2 слоя AI (макро/полный) | Нет AI |
| 3 уровня рендеринга | 2: близкий + стратегический |
| Save/Load с SQLite | Простое JSON-сейв |
| Replay | Нет |
| Мультиплеер | Нет |

### Что остаётся как в full

- ECS/DOTS (Unity DOTS или собственная ECS)
- 4 слоя (Data/Simulation/Render/UI)
- Детерминизм (seed + input)
- EventSystem (T-005)
- LOD-симуляция (упрощённая, 2 частоты)

## 📅 План реализации (2-3 месяца)

### Месяц 1: Фундамент

| Неделя | Что | Артефакт |
|---|---|---|
| 1 | Настройка Unity проекта, Assembly Definitions (T-001) | Пустой проект с модулями |
| 1 | Импорт 1 гекса из генератора мира (T-004) | 1 гекс с террайном |
| 1 | Базовая ECS-структура (T-002) | Citizen entity, компоненты |
| 2 | Каталоги: 5 ресурсов, 5 зданий, 3 технологии (ScriptableObjects) | Каталоги |
| 2 | Локальная карта 25×25 с сидом из hexId (T-004) | Процедурная карта |

| 3 | CitizenNeedSystem, CitizenMovementSystem | Граждане живут |
| 4 | FamilySystem (рождения, смерти, роли) | Семьи работают |

| Неделя | Что | Артефакт |
|---|---|---|

|---|---|---|

| 10 | 3 технологии (T-004 охота, T-005 огонь, T-014 керамика) | Дерево техов |

## 📊 Метрики успеха среза

### Играбельность

| Метрика | Цель | Что измеряет |
|---|---|---|
| Решений с последствиями / час | ≥ 5 (D-015) | Играбельность |
| Дроп-офф первого часа | ≤ 30% | Онбординг |
| Вспоминание истории через 24 часа | ≥ 5 сюжетных битов | Драма |
| «Хочу ещё сессию» после 2 часов | ≥ 70% | Ядро петли |
| Фрустрация непрозрачности | 0 (R7) | Explainability |

### Технические

| Метрика | Цель |
|---|---|
| FPS (близкий вид, 50 граждан) | 60 |
| RAM usage | < 1 ГБ |
| Load time | < 5 сек |
| Time per turn (1 сезон) | < 100 ms |
| Save/Load | < 1 сек |

### Качественные вопросы для плейтестеров

1. «Что было весело?»
2. «Что было скучно?»
3. «Что было непонятно?»
4. «Хотел бы ты играть ещё 30 минут?»
5. «Что бы ты изменил?»
6. «Перескажи судьбу племени за 5 минут» (тест драмы)
7. «Был ли момент "почему?!" (фрустрация)?»

## 🚀 Что после среза

### Если ядро Fun ✅

- Расширять: +AI соседей (D-005), +торговля, +война (D-014)
- Глобальная карта (T-004 — 64 800 гексов)
- Стадии (D-011) — переход к темпу «поколения»
- Save/Load (T-006 — SQLite + BSON)
- Локализация (en, uk)

### Если ядро НЕ Fun ❌

- Анализ: какие глаголы не работают?
- Итерация: правка дизайн-спек (D-001/D-004/D-015)
- Новый срез с правками
- Цикл повторяется

> Это нормальный процесс. Лучше узнать «не весело» за 3 месяца, чем за 12.
