# Фауна — Индекс связей (Принцип 10: обязательная связность)

> 📋 **Этот файл — структурированный индекс ключевых животных** (~140 видов, агрегированных в 60+ карточек). Каждый элемент имеет ID, категорию, входящие/исходящие связи, альтернативы, роль. Содержит все связи, необходимые для валидации (Принцип 11).

---

## 🎯 Принципы индекса

1. **ID-система**: A-001 ... A-060 (A = Animal)
2. **Категории**: 🐄 домашние (одомашненные), 🦌 дикие травоядные (дичь), 🐺 хищники (мех/угроза), 🐟 рыбы, 🐦 птицы, 🐝 насекомые
3. **Входящие связи**: биом → пища → животное
4. **Исходящие связи**: → ресурсы (мясо, молоко, шерсть, кожа, жир, мех, тяга), → процессы (дойка, стрижка, дубление), → технологии (скотоводство T-030, кочевое T-032, верховая езда)
5. **Альтернативы**: какие животные заменяют данное
6. **Роль**: бутылочное горлышко? критично для цепочки? рядовой?

## 🔗 Карточки ключевых животных со связями

> Подробно описаны только **бутылочные горлышки** и **стратегические** животные. Остальные — в сводной таблице выше + в [README.md](README.md).

### A-001: Собака (Canis familiaris)

**Категория**: 🐄 домашняя (первая одомашненная!)
**Состав**: мясо, шкура, рабочая сила
**Процесс**: приручение → селекция

**Входящие связи**:
- дикий предок → [Волк A-050](#a-050-волк-canis-lupus)
- Vavilov Center → повсеместно (палеолит, ~30000 до н.э.)

**Исходящие связи**:
- ресурс: → [собака](../resources/08_food_resources.md) (мясо в голод)
- ресурс: → [мех](../resources/09_hides_leather.md) (шкура)
- услуга: → охота (загон дичи), охрана, тягловая (сани)
- технология: → [T-007 Приручение собаки](../../06_technology/tech_tree.md), → [T-030 Скотоводство](../../06_technology/tech_tree.md) (сторож стада), → [T-032 Кочевое скотоводство](../../06_technology/tech_tree.md) (сани)

**Альтернативы**: НЕТ (единственное животное для охраны/охоты до лошади)

**Роль**: **бутылочное горлышко для палеолитической охоты** — без собаки нет эффективной охоты на крупную дичь. Первое одомашненное животное.

**Роль**: **бутылочное горлышко для шерсти** — без овцы нет массовой шерстяной ткани. Также основа кочевого скотоводства (степи).
