# Соли и минералы для химии

> Химическая индустрия древности: от дубления кож до производства стекла, от медицины до металлургии. Эти минералы — «клей» между многими технологиями.

---

## 🟢 Поверхностные (легкодоступные)

### Известь / Обожжённый известняк (Quicklime / CaO)

**Категория**: 🟢 Поверхностный (производный)
**Получение**: обжиг известняка при 900°C
**Состав**: CaO (оксид кальция)
**Где встречается**: рядом с известняковыми карьерами
**Как получается**: CaCO₃ + тепло 900°C → CaO + CO₂
**Где используется**:
- **Строительный раствор** (главное — с песком → известковый раствор)
- Штукатурка (античные дома)
- Дезинфекция (посыпать ран, могилы)
- Кожевенное дело (золение — снятие шерсти)
- Производство стекла (флюкс для понижения T плавления)
- Сельское хозяйство (известкование кислых почв)
- Очистка воды
**Технологические цепочки**:
- известняк → обжиг 900°C → CaO → + H₂O → Ca(OH)₂ (гашёная) → + песок → раствор
- CaO + Na₂CO₃ → NaOH (щёлочь) + CaCO₃
**Особые свойства**:
- **КРИТИЧЕСКИ ВАЖНО** для строительства и многих процессов
- Римский цемент (с добавлением пуццолана = вулканической золы)
- Историческая основа античной архитектуры
**Источники»: USGS, Mindat.org

### Пуццолан / Вулканическая зола (Pozzolana)

**Категория**: 🟢 Поверхностный (в зонах вулканизма)
**Состав**: алюмосиликаты с активным кремнезёмом
**Где встречается**: вулканические зоны
**Реальные месторождения**:
- **Неаполь (Италия)** — главный источник для римского цемента!
- Говерладья (Греция)
- Байя (Италия)
- Камчатка, Япония
**Где используется**:
- **Римский цемент** (известь + пуццолан → водостойкий раствор — критично для акведуков!)
- Самый прочный раствор древности (римские постройки стоят 2000 лет)
**Технологические цепочки**: CaO + пуццолан + H₂O → римский цемент → водостойкий
**Особые свойства**:
- Историческая итальянская монополия → римское строительство
- Затвердевает под водой (в отличие от обычного раствора)
- В игре: без пуццолана — нет водостойких акведуков и портовых сооружений
**Источники»: Mindat.org, «Roman Concrete» (Lancaster, 2005)

### Сода природная / Натрон (Natron / Na₂CO₃)

**Категория**: 🟢 Поверхностный (но только в натронных озёрах)
**Состав**: Na₂CO₃·10H₂O (карбонат натрия)
**Где встречается**: натронные озёра в засушливых регионах
**Реальные месторождения**:
- **Вади-Натрун (Египет)** — главный источник античности!
- Озеро Магади (Кения)
- Овенс-Лейк (Калифорния)
- Сёркё (Турция)
**Где используется**:
- **Мумификация** (Древний Египет — критически важный!)
- **Стекло** (сода — флюс, понижает T плавления песка с 1700°C до 1200°C!)
- **Мыло** (с жиром и маслом)
- Красильное дело (протрава)
- Кожевенное дело
- Очистка металлов
- Медицина (антисептик)
**Технологические цепочки**:
- Na₂CO₃ + песок + CaO → стекло при 1200°C (вместо 1700°C!)
- Na₂CO₃ + жир → мыло
- Натрон → обёртывание тела → мумия
**Особые свойства**:
- **КРИТИЧЕСКИ ВАЖНО** для производства стекла (без соды — нужны 1700°C!)
- Египетская монополия → стекло было египетской/сирийской монополией
- В игре: без соды — нет массового стекла (только для элиты с затратой 1700°C)
**Источники»: USGS, Mindat.org, «Glass» (Stern, 1981)

### Поташ / Карбонат калия (Potash / K₂CO₃)

**Категория**: 🟢 Поверхностный (производный)
**Получение**: выщелачивание древесной золы
**Состав**: K₂CO₃
**Где встречается**: в зонах лесозаготовки (нужно дерево!)
**Как получается**: 
1. Сжечь древесину → зола
2. Залить водой → растворить
3. Отфильтровать → концентрат
4. Выпарить → поташ
**Где используется**:
- **Стекло** (как флюкс — альтернатива соде!)
- **Мыло** (с жиром)
- **Удобрение** (калий — для растений!)
- Красильное дело (протрава)
- Кожевенное дело
- Лекарство
**Технологические цепочки**: дерево → сжигание → зола → выщелачивание → поташ → + песок → стекло
**Особые свойства**:
- **Альтернатива соде** для стекла — особенно в Европе (без натронных озёр)
- Исторически: Россия и Германия — крупные производители поташа (из древесины)
- В игре: без натронных озёр → стекло через поташ (нужно много дерева!)
**Источники»: USGS, «Potash» (Crow, 1929)

### Зола / Щёлок (Wood ash / Lye)

**Категория**: 🟢 Поверхностный (производный)
**Состав**: смесь KOH, K₂CO₃, CaO
**Где используется**:
- **Мыло** (с жиром)
- Клей, щёлочь
- Удобрение
- Красители
- Дезинфекция
**Технологические цепочки**: зола + вода → щёлок + жир → мыло
**Особые свойства**:
- Самый доступный источник щёлочи (даже без поташа)
- Использовалась с неолита

### Квасцы / Алунит (Alum)

**Категория**: 🟡 Подповерхностный (но выходы есть)
**Состав**: KAl(SO₄)₂·12H₂O (двойной сульфат)
**Где встречается**: 
- Алунит (Alunite — KAl₃(SO₄)₂(OH)₆) → обжиг → квасцы
- Эвапоритовые отложения
**Реальные месторождения**:
- **Толфа (Италия)** — папская монополия (15 в.)
- **Смирна (Турция)** — античные разработки
- **Митилини (Греция)**
- **Файюм (Египет)**
- **Парос (Греция)**
- **Мадагаскар**
**Где используется**:
- **Протрава для красителей** (критически важно! без квасцов — красители смываются)
- **Кожевенное дело** (дубление — критично!)
- **Медицина** (вяжущее, антисептик)
- Очистка воды (коагулянт)
- **Бумага** (later — sizing)
**Технологические цепочки**: алунит → обжиг 700°C → квасцы → раствор → + ткань + краситель = стойкая краска
**Особые свойства**:
- **КРИТИЧЕСКИ ВАЖНО** для текстильной промышленности и кожевенного дела
- Историческая папская монополия (Толфа) → огромный доход
- Без квасцов — нет стойких красок на тканях
- В игре: критическое «бутылочное горлышко» для текстиля
**Источники»: USGS, Mindat.org, «Alum in Antiquity» (Hall, 1930)

### Гипс / Селезнев камень (Gypsum / CaSO₄·2H₂O)

(см. 02_stone_construction.md — как стройматериал)

- Используется для форм литья металла

### Боракс / Бура (Borax / Na₂B₄O₇·10H₂O)

**Категория**: 🔴 Глубокий
**Состав**: борат натрия
**Где встречается**: эвапоритовые озёра в засушливых регионах
**Реальные месторождения**:
- **Тибет (озеро Боро)** — древнейший источник
- **Америка (Долина Смерти, США)**
- **Турция (Балья-Кестерел)**
- **Аргентина**
**Где используется**:
- **Флюс для металлургии** (понижает T плавления, очищает металл!)
- **Стекло** (добавка для термостойкости)
- **Керамика** (глазури)
- **Мыло** (как сода)
- Лекарство (антисептик)
- Консервант
**Особые свойства**:
- Критически важный флюс — понижает температуру плавления металлов
- В игре: «ускоритель» металлургии
**Источники»: USGS, Mindat.org

Дополнительно:

- Основа для египетской мумификации

## 🔴 Глубокие (требуют развитой горнодобычи)

### Сера / Самородная сера (Sulfur / Brimstone)

**Категория**: 🔴 Глубокий (но выходы есть в вулканических зонах)
**Состав**: S
**Где встречается**: вулканические зоны (фумаролы, сольфатары)
**Реальные месторождения**:
- **Сицилия (Италия)** — главный источник античности
- **Кушки (Россия, Самарская обл.)**
- **Ява (Индонезия)**
- **Либия**
**Где используется**:
- **Порох** (селитра + уголь + сера — критично!)
- Лекарство (антисептик, от кожных болезней)
- Серу используют для фумигации (дезинфекция)
- Вулканизация резины (позднее)
- Краситель (ультрамарин)
**Технологические цепочки**:
- S + KNO₃ + C → порох (взрывается при зажигании)
- S → горит → SO₂ → фумигация
**Особые свойства**:
- Критический компонент пороха
- Исторически: сицилианская монополия в античности
- В игре: «бутылочное горлышко» для пороха (как и селитра)
**Источники»: USGS, Mindat.org

### Плавиковый шпат / Флюорит (Fluorite / CaF₂)

**Категория**: 🔴 Глубокий
**Состав**: фторид кальция
**Где встречается**: гидротермальные жилы
**Реальные месторождения**:
- **Кастелет (Англия)** — голубой флюорит «синий Джон»
- **Дербишир**
- **Мексика**
- **Китай**
**Где используется**:
- **Флюс для металлургии** (как боракс — понижает T плавления)
- **Стекло** (особое оптическое — флюорит)
- Декоративный камень
**Особые свойства**:
- Исторически: как флюс → улучшение металлургии
- В игре: «ускоритель» металлургии
**Источники»: USGS, Mindat.org

### Мумия / Асфальт + смола (см. 04_organic_fuels.md)

### Пирит / Золото дураков (Pyrite / FeS₂)

**Категория**: 🔴 Глубокий (но выходы есть)
**Состав**: FeS₂
**Где встречается**: гидротермальные жилы
**Где используется**:
- **Источник серы** (обжиг → SO₂ → серная кислота, позднее)
- Огниво (с кремнём даёт искру — критично для палеолита!)
- Ювелирное дело (как украшение)
- Марказитовые украшения (инкрустация)
**Особые свойства**:
- Древнейшее использование — огниво (давал искру)
- Источником серы стал позже
**Источники»: Mindat.org

### Купоросы / Сульфаты (Vitriols)

**Категория**: 🔴 Глубокий (в зонах окисления сульфидов)
**Виды**:
- **Железный купорос** (FeSO₄·7H₂O) — из окисления пирита
- **Медный купорос** (CuSO₄·5H₂O) — из окисления халькопирита
- **Цинковый купорос** (ZnSO₄·7H₂O)
**Где встречается**: зоны окисления сульфидов
**Где используется**:
- **Протрава** для красителей (Fe — тёмные цвета, Cu — зелёные/синие)
- **Кожевенное дело** (дубление)
- **Лекарство** (антисептик, рвотное)
- **Фунгицид** (для винограда — бордоская жидкость)
- Красители (чернение тканей)
- Полудение железа
**Особые свойства**:
- Производные продукты от окисления сульфидов (см. 01_minerals_ores.md)
- Критически важны для текстиля и кожевенного дела
**Источники»: Mindat.org

## Цикл развития химии

```
1. 🟢 Зола + жир → мыло (неолит)
   ↓ позволяет: гигиена, мыловарение
   
2. 🟢 Известь → строительный раствор (античность)
   ↓ позволяет: монументальная архитектура
   
3. 🟢 Сода (натрон) → стекло (Египет, 1500 до н.э.)
   ↓ позволяет: стеклянные изделия (массово)
   
4. 🟢 Поташ → стекло в Европе (без натронных озёр)
   ↓ позволяет: европейское стекло (через дерево)
   
5. 🟡 Квасцы → стойкие красители (15 в.)
   ↓ позволяет: текстильная промышленность
   
6. 🟡 Пуццолан + известь → римский цемент
   ↓ позволяет: акведуки, гавани
   
7. 🔴 Селитра + сера + уголь → порох (13 в.)
   ↓ позволяет: военная революция
   
8. 🔴 Боракс, флюорит → улучшенная металлургия
   ↓ позволяет: сталь, сложные сплавы
   
9. 🔴 Купоросы → фунгициды, кожевенное
   ↓ позволяет: защита урожая, качественная кожа
```

## Принципы для дизайна

### 1. Стекло зависит от соды (натрона)

Без соды — нужен поток с температурой 1700°C. Это «бутылочное горлышко» — без натронных озёр (Египет) стекло очень дорогое.

### 2. Поташ — европейская альтернатива соде

Россия, Германия — массово производили поташ из дерева. Это давало европейское стекло, но ценой массовой вырубки лесов.

### 3. Квасцы — критический для текстиля

Без квасцов — красители смываются. Контроль квасцовых месторождений = контроль текстильной промышленности. Историческая папская монополия.

### 4. Пуццолан — римский секрет

Римский бетон (с пуццоланом) — водостойкий, держит 2000 лет. Без него — нет акведуков, портов, мостов. В игре: без пуццолана — нет водостойких конструкций.

### 5. Порох — три компонента

Селитра + сера + уголь = порох. Все три нужны. Без одного — нет пороха. Это создаёт три «бутылочных горлышка» для военной революции.

### 6. Кросс-технологические связи

- Известь → строительный раствор, стекло, кожевенное, медицина
- Сода → стекло, мыло, мумификация, красители
- Квасцы → красители, кожевенное, бумага

Многие минералы — «клей» между технологиями.

### 7. Истощение источников

Натронные озёра могли истощаться (Египет после падения Рима → импорт соды из Сирии). В игре: моделировать истощение.
