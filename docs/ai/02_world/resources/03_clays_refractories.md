# Глины и огнеупоры

> 📌 **КРИТИЧЕСКИ ВАЖНАЯ КАТЕГОРИЯ** — глины и огнеупоры являются «бутылочным горлышком» для металлургии. Без правильного материала для печи невозможна плавка металлов с высокой температурой плавления.

---

## 🟢 Поверхностные (легкодоступные)

### Обычная глина (Common clay)

**Категория**: 🟢 Поверхностный
**Состав**: гидратированные алюмосиликаты (каолинит, иллит, монтмориллонит) с примесями
**Виды**: красная (с Fe₂O₃), белая (каолин), серая, жёлтая
**Где встречается**: речные отложения, озёра, элювий
**Реальные месторождения**: повсеместно в речных долинах
**Как добывается**: сбор в руслах рек → ямы → карьеры
**Инструменты**: деревянные лопаты, корзины
**Где используется**:
- **Гончарное дело**: посуда, амфоры, кирпич-сырец, статуэтки
- **Строительство**: глинобитные дома, обмазка стен
- **Печи**: первые печи из обычной глины (держат ~800-900°C)
- **Металлургия**: тигли и формы для литья меди (нужна обработка)
- **Герметизация**: обмазка корзин, швов
**Технологические цепочки**:
- глина + сушка на солнце → кирпич-сырец (адоб)
- глина + обжиг 800-900°C → керамика
- глина + формовка → тигель для плавки меди (700°C держит!)
**Особые свойства**: при обжиге 800-900°C — необратимо керамизуется, держит до 900°C. **Это и есть тот самый материал, что позволяет плавить медь!**
**Источники**: SoilGrids (ISRIC), Mindat.org, «The Potter's Dictionary» (Hamer, 2004)

### Каолин (China clay)

**Категория**: 🟢 Поверхностный (в россыпях) → 🟡 (в жильном виде)
**Состав**: чистый каолинит Al₂Si₂O₅(OH)₄
**Виды**: первичный (жильный), вторичный (россыпной)
**Где встречается**: продукты выветривания полевых шпатов (пегматитов)
**Реальные месторождения**:
- Корнуолл (Англия) — главный европейский источник
- Цзиндэчжэнь (Китай) — родина фарфора
- Малайзия, Украина (Просяновка)
- Кыяти (Чехия)
**Как добывается**: россыпное — промывка; жильное — шахты
**Где используется**:
- **Фарфор** (нужен каолин + полевой шпат + кварц + T=1300°C)
- Белая керамика
- Огнеупорные изделия (чистый каолин держит до 1500°C!)
- Бумажная промышленность (только в поздние эпохи)
**Технологические цепочки**: каолин + полевой шпат + кварц → плавка 1300°C → фарфор; чистый каолин + обжиг 1500°C → шамот (огнеупор)
**Особые свойства**: после обжига при 1500°C становится **шамотом** — огнеупорным материалом, критичным для железной металлургии
**Источники**: USGS, Mindat.org, «Kaolin» (Bundy, 1993)

### Лёсс (Loess)

**Категория**: 🟢 Поверхностный
**Состав**: ветровой эоловый суглинок (мелкие частицы SiO₂, карбонатов, глины)
**Где встречается**: ледниковые перигляциальные зоны
**Реальные месторождения**:
- Северный Китай (Лёссовое плато) — крупнейшее в мире
- Великая Венгерская равнина
- Пальпен (Аргентина)
- Рейнская долина
- Среднерусская возвышенность
**Где используется**:
- Глинистый материал для кирпича-сырца
- Почва (высокое плодородие!)
- Строительство жилищ (пещеры в лёссе — Китай)
**Особые свойства**: одновременно строительный материал и почва
**Источники**: SoilGrids (ISRIC), «Loess Deposits» (Pye, 1995)

### Ил (Silt)

**Категория**: 🟢 Поверхностный
**Где встречается**: русла рек, поймы
**Где используется**: гончарное дело, удобрение, отделка
**Источники**: —

## 🟡 Подповерхностные (нужно исследовать)

### Бентонит (Bentonite)

**Категория**: 🟡 Подповерхностный
**Состав**: натриевый или кальциевый монтмориллонит
**Где встречается**: продукты выветривания вулканического пепла
**Реальные месторождения**:
- Бентон (США) — название
- Саригух (Армения)
- Гумбри (Грузия)
- Россия (Курган, Подольск)
**Где используется**:
- **Герметизация**: плотины, колодцы (набухает в воде)
- **Литьё металла**: формы (т не теряет формы при нагреве)
- **Кожевенное дело**: обезжиривание
- **Очистка масел** (только поздние эпохи)
**Технологические цепочки**: бентонит + вода → гель → формы для литья
**Особые свойства**: набухает в воде (10-15 раз), термостабилен. Ценен для точного литья
**Источники**: USGS, Mindat.org

### Огнеупорная глина (Fire clay)

**Категория**: 🟡 Подповерхностный
**Состав**: каолинит с низким содержанием примесей (Fe, щёлочи)
**Где встречается**: под угольными пластами
**Реальные месторождения**:
- Стаффордшир (Англия)
- Донбасс (Украина)
- Пенсильвания (США)
**Где используется**:
- **Огнеупорный кирпич** (держит 1300-1500°C!)
- Тигли для плавки бронзы и железа
- Футеровка печей
**Технологические цепочки**: огнеупорная глина + обжиг 1300°C → шамотный кирпич → печь для плавки железа (1500°C)
**Особые свойства**: **КРИТИЧНО ВАЖНО** — без этого материала невозможна плавка железа. Это ключевое «бутылочное горлышко» железной металлургии
**Источники**: USGS, Mindat.org

## 🔴 Глубокие (требуют развитой добычи и обработки)

### Шамот (Chamotte / Grog)

**Категория**: 🔴 Глубокий (продукт обжига каолина/огнеупорной глины)
**Состав**: обожжённый при 1300-1500°C каолин
**Виды**: шамотный песок, шамотный кирпич
**Как получается**: каолин или огнеупорная глина → обжиг 1400°C → помол → шамот
**Где используется**:
- **Футеровка металлургических печей** (держит до 1700°C!)
- Тигли для плавки железа и стали
- Домина/печь для обжига извести
- Стекловаренные печи
**Технологические цепочки**: каолин → обжиг 1400°C → шамот → формовка с глиной → обжиг → шамотный кирпич → футеровка печи для железа (1500°C)
**Особые свойства**: материал, без которого невозможна железная металлургия в полном объёме. Римляне знали, но широко — только в средние века
**Источники**: «Refractories Handbook» (Schacht, 2004)

### Доломит (Dolomite)

**Категория**: 🔴 Глубокий
**Формула**: CaMg(CO₃)₂
**Виды**: массивный, кристаллический
**Где встречается**: осадочные месторождения
**Реальные месторождения**: повсеместно
**Как добывается**: карьеры
**Где используется**:
- **Огнеупор** (доломитовый кирпич — до 1700°C)
- Флюс для металлургии (добавка в руду при плавке)
- Строительный камень
- Источник магния
**Технологические цепочки**: доломит → обжиг → CaO+MgO → огнеупор
**Особые свойства**: важный флюс в металлургии
**Источники**: USGS, Mindat.org

### Магнезит (Magnesite)

**Категория**: 🔴 Глубокий
**Формула**: MgCO₃
**Виды**: массивный, кристаллический
**Где встречается**: метаморфические месторождения
**Реальные месторождения**:
- Магнезитовые Альпы (Австрия)
- Сатка (Урал, Россия)
- Liaoning (Китай)
**Где используется**:
- **Огнеупор высшего качества** (до 2200°C!)
- Источник магния
- Тугоплавкий материал для самых горячих печей
**Технологические цепочки**: магнезит → обжиг 1500°C → MgO (периклаз) → огнеупор
**Особые свойства**: самый тугоплавкий природный материал
**Источники**: USGS, Mindat.org

## Цикл развития огнеупорной технологии

```
1. 🟢 Обычная глина → печь 800-900°C
   ↓ (позволяет плавить медь ~700°C, обжигать керамику)
   
2. 🟢 Каолин → улучшенная печь 1300-1400°C
   ↓ (позволяет плавить бронзу ~950°C, делать стекло ~1200°C)
   
3. 🟡 Огнеупорная глина → печь 1300-1500°C
   ↓ (позволяет раннюю плавку железа, но без шамота плохо)
   
4. 🔴 Шамот (каолин, обожжённый 1400°C) → футеровка 1700°C
   ↓ (полноценная металлургия железа)
   
5. 🔴 Магнезит → футеровка 2200°C
   ↓ (поздняя металлургия, сталь)
```

## Принципы для дизайна

### 1. Золотое правило: «без огнеупора — нет металлургии»

Каждый шаг в металлургии требует соответствующего огнеупорного материала. Это классический пример **кросс-технологических зависимостей** (см. `06_technology/prerequisites.md`).

### 2. Глины доступны почти везде, но огнеупорные — нет

Обычная глина есть в любой речной долине. Но огнеупорная глина, каолин, бентонит — в конкретных местах. Это создаёт **географическую уникальность**: народ с огнеупорной глиной в регионе → преимущество в металлургии.

### 3. «Бутылочное горлышко» железа

Для плавки железа (1500°C) нужен шамот. Для шамота нужен каолин или огнеупорная глина. Без этого — нет железа, какие бы месторождения железной руды ни были рядом.

### 4. Каолин — двойная ценность

Каолин даёт не только огнеупоры, но и фарфор (последняя керамика, открыли в Китае ~VII в. н.э.). Это делает каолиносные регионы (Корнуолл, Цзиндэчжэнь) стратегически ценными.

### 5. Бентонит — для точного литья

Когда нужно отлить сложный предмет (статуя, инструмент) — нужна форма, держащая форму при нагреве. Бентонит + песок = форма. Без него — только простые отливки.
