# Древесина (виды деревьев)

> Разные виды деревьев имеют разные свойства — твёрдость, упругость, плотность, долговечность. Это критично для орудий, оружия, строительства, кораблестроения. Различные биомы дают разные виды древесины — географическая уникальность.

---

## Принципы классификации

Древесина в игре — не абстрактный «ресурс дерево», а **конкретные породы**, каждая со своими свойствами:

| Свойство | Влияние на применение |
|---|---|
| Твёрдость | Орудия (твёрже = дольше держит лезвие), мебель |
| Упругость | Луки, спицы колёс |
| Плотность | Качество угля, вес корабля |
| Долговечность (гниение) | Стойки домов, корабли, сваи |
| Текстурная красота | Мебель, украшения |
| Смолистость | Качество топлива, смола |

## 🌲 Хвойные (мягкое дерево, смолистое)

### Сосна обыкновенная (Scots Pine)

**Биом**: boreal леса, умеренный пояс
**География**: Евразия (от Шотландии до Восточной Сибири)
**Свойства**: мягкая, смолистая, легко обрабатывается, средняя долговечность
**Использование**:
- Строительство (балки, доски)
- Корабли (мачты — высокие прямые стволы!)
- Топливо (среднее качество)
- Смола (подсочка)
- Дранка (кровля)
**Особые свойства**: высокие прямые стволы — идеальны для мачт
**Источники**: FAO, Plants of the World Online (POWO)

### Ель европейская (Norway Spruce)

**Биом**: boreal леса
**География**: Европа, Урал
**Свойства**: мягкая, белая, малосмолистая, легкая
**Использование**:
- Строительство (каркас домов)
- Музыкальные инструменты (резонансные деки скрипок!)
- Бумага (только в поздние эпохи)
**Особые свойства**: резонансные свойства → скрипичные деки (Страдивари)
**Источники**: FAO, POWO

### Лиственница (Larch)

**Биом**: boreal, горный
**География**: Сибирь, Альпы, Россия
**Свойства**: средне-твёрдая, очень долговечная (в воде/земле), смолистая
**Использование**:
- **Сваи** (Венеция на лиственничных сваях!)
- Строительство (особенно влажное)
- Корабли (долговечные)
- Топливо (хорошее)
**Особые свойства**: не гниёт в воде → идеальна для свай и подводных частей кораблей
**Источники**: POWO

### Кедр сибирский (Siberian Cedar / Pine)

**Биом**: boreal
**География**: Сибирь
**Свойства**: мягкая, долговечная, ароматная
**Использование**:
- Строительство (бани — аромат!)
- Кедровые орехи (пища)
- Смола
**Особые свойства**: двойная ценность — древесина + орехи
**Источники**: POWO

### Кедр ливанский (Cedar of Lebanon)

**Биом**: средиземноморский
**География**: Ливан, Турция, Кипр
**Свойства**: средне-твёрдая, очень ароматная, долговечная
**Использование**:
- **Корабли** (финикийские корабли из кедра!)
- Строительство (Храм Соломона)
- Религиозные предметы
- Бальзамирование (египетские мумии — кедровое масло)
**Особые свойства**: исторический «золотой стандарт» корабельного дерева. Ливанские леса вырубили финикийцы → упадок
**Источники**: POWO, «Cedrus libani» (Meikle, 1977)

### Кипарис вечнозелёный (Cypress)

**Биом**: средиземноморский
**География**: Средиземноморье
**Свойства**: средне-твёрдая, очень долговечная, ароматная
**Использование**:
- **Скульптура** (статуя Зевса Олимпийского)
- Корабли
- Двери, ворота (долговечные)
- Саркофаги
**Особые свойства**: почти не гниёт → двери храмов
**Источники**: POWO

### Тис ягодный (Yew)

**Биом**: умеренный пояс
**География**: Европа, Кавказ, Малая Азия
**Свойства**: очень твёрдая, упругая, ядовитая (таксин)
**Использование**:
- **Луки!** (английский длинный лук, средневековые луки — тис)
- Копья, дротики
- Скульптура
- Мебель (только после снятия ядовитости)
**Особые свойства**: 
- Лучшее дерево для луков (упругость + прочность)
- Ядовитость — нужно осторожно обрабатывать
- Исторический дефицит в Европе в средние века (вырубили ради луков)
**Источники**: POWO, «The Yew Tree» (Hageneder, 2007)

## 🌳 Лиственные твёрдые (для орудий и ударных нагрузок)

### Дуб черешчатый (English Oak)

**Биом**: умеренный пояс
**География**: Европа, Малая Азия, Кавказ
**Свойства**: очень твёрдая, прочная, долговечная (даже в воде)
**Использование**:
- **Корабли** (киль, шпангоуты — критично!)
- Строительные балки
- Мебель (дорогая)
- Бочки (винные — дубильные вещества!)
- Топливо (лучшее!)
- Древесный уголь (высшее качество)
**Особые свойства**: 
- Дубильные вещества в коре → кожевенное дело
- Желуди → корм для свиней
- В воде становится твёрже (использовали для свай)
- Исторически — критический ресурс для средневекового мореплавания (вырубка лесов в Англии → кризис)
**Источники**: POWO, FAO

### Бук лесной (Beech)

**Биом**: умеренный пояс
**География**: Европа
**Свойства**: твёрдая, плотная, однородная
**Использование**:
- Мебель (гнутая — венские стулья)
- Посуда (деревянная)
- Топливо (отличное)
- Бочки (пиво)
**Особые свойства**: гнётся при обработке паром → гнутая мебель
**Источники**: POWO

### Граб (Hornbeam)

**Биом**: умеренный пояс
**География**: Европа, Кавказ
**Свойства**: очень твёрдая (твёрже дуба!), вязкая
**Использование**:
- **Оси телег** (не ломаются от ударов!)
- Колёса
- Копья, древки оружия
- Жернова (деревянные)
- Рукоятки инструментов
**Особые свойства**: твёрже дуба, очень устойчив к ударным нагрузкам → идеален для осей и колес
**Источники**: POWO

### Ясень обыкновенный (Ash)

**Биом**: умеренный пояс
**География**: Европа, Малая Азия
**Свойства**: упругий, прочный, ударостойкий
**Использование**:
- **Копья, древки** (гомеровские копья!)
- Лыжи, сани
- Криминальные луки (если нет тиса)
- Топорища
- Мебель (гнутая)
**Особые свойства**: упругость + ударная прочность → идеален для древков
**Источники**: POWO

### Клён (Maple)

**Биом**: умеренный пояс
**География**: Северное полушарие
**Свойства**: средне-твёрдая, красивая текстура
**Использование**:
- Мебель
- Музыкальные инструменты
- Посуда
- Струнные (гриф скрипки)
**Особые свойства**: декоративная текстура
**Источники**: POWO

## 🌴 Специальные (тропические и субтропические)

### Тик (Teak)

**Биом**: тропический муссонный
**География**: Индия, ЮВ Азия
**Свойства**: очень твёрдая, маслянистая (не гниёт в солёной воде!)
**Использование**:
- **Корабли** (лучшие в мире — не нужно обрабатывать смолой!)
- Палубы европейских кораблей (позднее)
- Мебель (дорогая)
**Особые свойства**: 
- Естественное масло защищает от гниения
- Не нуждается в покраске
- Исторически — стратегический ресурс (Британия импортировала из Индии)
**Источники**: POWO, «Teak» (Bryndum, 1987)

### Сандж (Sandalwood / Santalum album)

**Биом**: тропический
**География**: Индия, Индонезия
**Свойства**: ароматная (санталол)
**Использование**:
- Ароматные изделия (благовония)
- Религиозные предметы (буддизм, индуизм)
- Парфюм (позднее)
- Мебель (дорогая)
**Особые свойства**: аромат → ценился в религии
**Источники**: POWO, IUCN Red List (vulnerable)

### Чёрное дерево (Ebony / Diospyros)

**Биом**: тропический
**География**: Африка, Индия, Шри-Ланка
**Свойства**: очень твёрдая, чёрная, плотная
**Использование**:
- **Скульптура** (египетские статуи!)
- Четки, религиозные предметы
- Мебель (только для элиты — очень дорого)
- Инкрустация
**Особые свойства**: 
- Твёрже большинства металлов
- Полируется до зеркального блеска
- Исторически — роскошь фараонов
**Источники**: POWO, IUCN Red List

### Палисандр (Rosewood / Dalbergia)

**Биом**: тропический
**География**: Индия, Бразилия, Мадагаскар
**Свойства**: очень твёрдая, ароматная, тёмная, красивая текстура
**Использование**:
- Мебель (дорогая)
- Музыкальные инструменты (грифы гитар, клавиши ксилофонов)
- Шкатулки
**Особые свойства**: декоративная, очень дорогая
**Источники**: POWO, CITES Appendix I-II

### Бамбук (Bamboo)

**Биом**: тропический и субтропический
**География**: ЮВ Азия, Китай, Индия
**Свойства**: трубчатая структура, очень прочная на разрыв, быстрорастущая
**Виды**: Phyllostachys (китайский), Bambusa, Dendrocalamus
**Использование**:
- **Строительство** (каркасы, перекрытия)
- Корабли (плоты, джонки)
- Оружие (бамбуковые копья, стрелы)
- Бумага (только поздние эпохи)
- Музыкальные инструменты (флейты)
- Посуда, корзины
- Топливо (быстрорастущая!)
**Особые свойства**: 
- Возобновляемый — растёт до 1 м в день
- Прочнее многих пород дерева
- В Азии — «древесина бедных»: доступна везде
**Источники**: POWO, FAO

### Ива (Willow)

**Биом**: берега рек, влажные зоны
**География**: повсеместно
**Свойства**: гибкая, мягкая, быстро растущая
**Использование**:
- **Плетение** (корзины, мебель)

**Особые свойства**:

- Гибкость → идеальна для плетения

### Липа (Linden / Basswood)

**Биом**: умеренный
**География**: Европа

- **Резьба** (легко режется, не трескается)
- Музыкальные инструменты (гриф гитар)
- Корыта, посуда
- Волокно из коры (луб) — верёвки, мочало
**Особые свойства**: луб → верёвки, циновки
**Источники**: POWO

## 🌳 Особо значимые плодовые деревья

### Олива (Olive)

**Биом**: средиземноморский
**География**: Средиземноморье
**Свойства**: твёрдая, плотная, желтоватая
**Использование**:
- **Оливковое масло** (главное!)
- Древесина — мебель, скульптура
- Оливки (пища)
- Мыло (с золой)
**Особые свойства**: 
- Дерево живёт 1000+ лет
- Масло — пища, освещение, косметика, религия (помазание)
- Афины — Аттика = оливковые рощи. Основа экономики
**Источники**: POWO, FAO

### Инжир (Fig)

**Биом**: средиземноморский
**География**: Средиземноморье, Ближний Восток
**Использование**: плоды (пища), древесина (плохого качества)
**Особые свойства**: древнейшее одомашненное дерево (Иерихон, 9000 до н.э.)
**Источники**: POWO

### Финиковая пальма (Date Palm)

**Биом**: оазисы, пустыни
**География**: Сев. Африка, Ближний Восток, Ирак
**Свойства**: древесина средняя, но пальма даёт много продуктов
**Использование**:
- **Финики** (основная пища в пустынных регионах!)
- Ветви — кровля, плетение
- Волокно — верёвки
- Древесина — балки (когда пальма умирает)
- Сок — пальмовое вино
**Особые свойства**: «дерево жизни» в пустыне. 1000 применений
**Источники**: POWO, FAO

### Кокосовая пальма (Coconut)

**Биом**: тропические побережья
**География**: ЮВ Азия, Полинезия, Тихоокеанские острова
**Использование**:
- Кокосы — пища, масло, молоко
- Волокно (койр) — верёвки, циновки
- Листья — плетение, кровля
- Древесина — балки
- Скорлупа — посуда, уголь
**Особые свойства**: «дерево тысячи применений» в Полинезии
**Источники**: POWO, FAO

## Принципы для дизайна

### 1. Вид дерева = конкретные применения

Нельзя делать «абстрактное дерево». Разные породы дают разные изделия. Это создаёт:
- **Географическую уникальность**: тис есть только в Европе, тик — в ЮВ Азии
- **Дефицит**: для луков нужен тис → вырубка → импорт
- **Альтернативы**: нет тиса — ясень или граб

### 2. Деревья — возобновляемый, но медленный ресурс

Дерево растёт 30-100 лет. В игре должен моделироваться цикл: вырубка → восстановление (медленно) → истощение при перерубке.

### 3. «Бутылочное горлышко» для луков и кораблей

- Без тиса нет длинных луков → нет эффективной лучной пехоты
- Без дуба нет прочных килей кораблей → нет больших военных флотов
- Без кедра/тикa нет долговечных морских кораблей

### 4. Тропические особые породы

Чёрное дерево, палисандр, сандж — роскошные материалы. Только для элитной мебели, скульптуры, религиозных предметов. Дорогие торговые товары.

### 5. Бамбук — азиатская альтернатива

В ЮВ Азии бамбук заменяет половину древесины. Доступен массово, быстрорастущий, прочный. Это даёт азиатским племенам преимущество в дешёвых конструкциях.

### 6. Плодовые деревья — двойная ценность

Олива, финик, кокос, инжир — это и пища, и древесина, и масло. Одна роща — много ресурсов. Это делает их стратегически ценными.
