# Пищевые ресурсы

> 🍞 Пища — базовая потребность, от неё зависит выживание племени. Разные регионы имеют разные пищевые традиции. Историческое развитие — от охоты/собирательства к земледелию и животноводству.

---

## Структура категории

Пищевые ресурсы разделены на 6 подкатегорий:
1. Злаки (хлебные злаки)
2. Бобовые
3. Овощи и корнеплоды
4. Фрукты и ягоды
5. Орехи и семена
6. Продукты животноводства

---

## 1. Злаки (главный источник углеводов)

### Пшеница двузернянка / Эммер (Emmer / Triticum dicoccum)

**Биом**: умеренный, субтропический
**География**: Плодородный полумесяц (родина — Сирия/Турция, ~10000 до н.э.)
**Свойства**: 
- Зерно твёрдое,requires dehulling (чистка от плёнок)
- 12-15% белка
- Урожай 800-1200 кг/га (древний)
**Как производится**:
1. Посев (осень — озимая)
2. Уборка (лето)
3. Молотьба (отделение зерна от стебля)
4. Дехаллинг (отделение плёнок)
5. Помол → мука
**Где используется**:
- Хлеб (главный продукт!)
- Каша
- Пиво (ферментация)
- Корм для скота
**Технологические цепочки**: эммер → молотье → дехаллинг → помол → мука → тесто → хлеб
**Особые свойства**: 
- Древнейшая одомашненная пшеница (Джармо, 9000 до н.э.)
- Требует дехаллинга (трудно) → стимул селекции «голых» форм
**Источники**: Vavilov Centers, FAO, «Origins of Agriculture» (Smith, 1995)

### Пшеница однозернянка (Einkorn / Triticum monococcum)

**Биом**: горный, умеренный
**География**: Анатолия, Балканы
**Свойства**: 
- Очень устойчивая к болезням
- Низкая урожайность, но надежная
- 14-16% белка
**Где используется**: хлеб, каша
**Особые свойства**: 
- Самая ранняя одомашненная (9500 до н.э. — Карачадаг)
- До сих пор выращивается в горах как страховка
**Источники»: Vavilov Centers, FAO

### Твёрдая пшеница / Дурум (Durum / Triticum durum)

**Биом**: субтропический, сухой
**География**: Средиземноморье, Ближний Восток
**Свойства**: 
- Высокое содержание клейковины
- Твёрдое зерно
- Дает манную крупу и макароны (позднее)
**Где используется**:
- Манная крупа
- Паста/макароны (только в поздние эпохи)
- Кускус
**Особые свойства**: 
- Получена селекцией из эммера
- Выращивается в сухом климате
**Источники»: Vavilov Centers, FAO

### Мягкая пшеница (Bread wheat / Triticum aestivum)

**Биом**: умеренный
**География**: повсеместно (умеренный пояс)
**Свойства**: 
- Лучшая клейковина (для дрожжевого хлеба!)
- Высокая урожайность (1500-3000 кг/га)
- «Голое» зерно (не нужно дехаллинг)
**Где используется**:
- **Хлеб** (дрожжевой, кислый)
- Печенье, торты (позднее)
- Корм скоту
**Технологические цепочки**: пшеница → молотье (без дехаллинга) → помол → мука → дрожжевое тесто → хлеб
**Особые свойства**: 
- Самая молодая пшеница (~6000 до н.э.)
- Требует дрожжей для кислого теста (открытие брожения)
- Сейчас — 90% мировой пшеницы
**Источники»: Vavilov Centers, FAO

### Ячмень (Barley / Hordeum vulgare)

**Биом**: умеренный, boreal
**География**: Плодородный полумесяц (родина), Тибет, повсеместно
**Свойства**: 
- Устойчив к засухе и холоду
- Созревает раньше пшеницы (50-70 дней)
- 9-12% белка, низкая клейковина
**Где используется**:
- Каша
- Суп (ячменный)
- **Пиво** (главный источник для пива!)
- Корм для скота (особенно лошадей)
- Хлеб (только с примесью пшеницы)
**Технологические цепочки**: ячмень → солод → сушка в печи → ферментация с дрожжами → пиво
**Особые свойства**: 
- Древнейшая одомашненная культура (~8500 до н.э.)
- Кормовой резерв при осаде (главный корм коней в армии)
- Тибетский хлеб (цампы) — обжаренный ячмень
**Источники»: Vavilov Centers, FAO

### Рожь (Rye / Secale cereale)

**Биом**: boreal
**География**: Восточная Европа, Россия, Германия
**Свойства**: 
- Очень устойчива к холодам
- 9-13% белка, средняя клейковина
- Тёмная мука
**Где используется**:
- Чёрный ржаной хлеб (главный в России и Сев. Европе!)
- Квас (ферментированный напиток)
- Корм для скота
- Водка (после перегонки — поздняя эпоха)
**Особые свойства**: 
- Вторичная культура (сорняк в посевах пшеницы → одомашнена)
- Позволяет жить в холодных регионах
- Главный продукт восточно-европейской цивилизации
**Источники»: Vavilov Centers, FAO

### Овёс (Oats / Avena sativa)

**Биом**: boreal, влажный умеренный
**География**: Сев. Европа, Россия, Шотландия
**Свойства**: 
- Устойчив к влаге и холоду
- 12-15% белка, высокая питательность
**Где используется**:
- Каша (овсянка — главное блюдо Шотландии!)
- Овсяная мука (печенье, блины)
- Корм для лошадей (критично!)
- Эль (напиток)
**Особые свойства**: 
- Стимулирует рост мышц → корм скакуна
- Исторически: Шотландия ела овёс, когда Англия — пшеницу
**Источники»: Vavilov Centers, FAO

### Просо (Millet / Panicum miliaceum)

**Биом**: умеренный, засушливый
**География**: Китай (родина), Россия, Индия
**Свойства**: 
- Очень устойчиво к засухе
- 10-12% белка
- Быстрое созревание (60-90 дней)
**Где используется**:
- Каша (главное блюдо в Китае до риса)
- Корм для птицы
- Пиво (в Африке — просо)
**Особые свойства**: 
- Древнейшая китайская культура (Пейлиган, 7000 до н.э.)
- Подходит для полусухого климата
- Исторический «корм бедных» в засушливых регионах
**Источники»: Vavilov Centers, FAO

### Рис (Rice / Oryza sativa)

**Биом**: тропический влажный
**География**: Китай (родина — Яншао, 7000 до н.э.), ЮВ Азия, Индия
**Свойства**: 
- Требует много воды (затопленные поля)
- Высокая урожайность (2000-4000 кг/га)
- 6-8% белка
**Где используется**:
- Каша (главное блюдо Восточной Азии!)
- Лапша (из рисовой муки)
- Саке (рисовое вино)
- Рисовая бумага (позднее)
**Технологические цепочки**: 
- Посев в воду → рост → затопление поля → уборка → молотьба → лущение → варка
- **Ирригация** — критично! Без воды — нет урожая
**Особые свойства**: 
- Историческая основа Восточной Азии
- Требует коллективной ирригации → стимул к централизации (государства)
- В игре: рис → ирригация → ранние государства
**Источники»: Vavilov Centers, FAO

### Кукуруза / Маис (Maize / Zea mays)

**Биом**: тропический, субтропический
**География**: Мексика (родина — 7000 до н.э.)
**Свойства**: 
- Высокая урожайность
- 8-10% белка
- Гибридные сорта (селекция)
**Где используется**:
- Хлеб (тортилья — главный продукт Мезоамерики!)
- Каша (полента в Италии)
- Корм для скота
- Алкоголь (чича, бурбон — позднее)
**Технологические цепочки**: маис → помол → masa → тортилья (обжиг на плите)
**Особые свойства**: 
- Не может сам размножаться (человек должен сажать)
- Селекция ацтеков/майя → тысячи сортов
- Никстамализация (обработка щёлочью — для усвоения питательных веществ)
**Источники»: Vavilov Centers, FAO

### Сорго (Sorghum / Sorghum bicolor)

**Биом**: полусухой тропический
**География**: Африка (родина — Судан, 4000 до н.э.)
**Свойства**: 
- Очень устойчиво к засухе
- 10-12% белка
**Где используется**:
- Каша (главное блюдо Сахеля)
- Пиво (в Африке)
- Корм для скота
- Сироп (из стеблей)
**Особые свойства**: 
- Африканская альтернатива просу
- Растёт в самых засушливых регионах
**Источники»: Vavilov Centers, FAO

### Тэфф (Teff / Eragrostis tef)

**Биом**: горный тропический
**География**: Эфиопия (родина)
**Свойства**: 
- Мелкое зерно
- Высокое содержание минералов
**Где используется**:
- Инжера (главный хлеб Эфиопии)
**Особые свойства**: 
- Эфиопская монокультура
- Очень устойчив к болезням
**Источники»: Vavilov Centers, FAO

## 2. Бобовые (главный источник белка для земледельцев)

### Чечевица (Lentil / Lens culinaris)

**Биом**: умеренный полусухой
**География**: Плодородный полумесяц (родина, 9500 до н.э.)
**Свойства**: 
- 25-30% белка
- Созревание 80-110 дней
- Хорошо хранится (сухая)
**Где используется**:
- Суп (главное блюдо Ближнего Востока)
- Каша
- Мука
**Особые свойства**: 
- Древнейшая бобовая культура
- Библейское упоминание (Исаак и Исав — чечевичная похлёбка)
**Источники»: Vavilov Centers, FAO

### Горох (Pea / Pisum sativum)

**Биом**: умеренный
**География**: Анатолия (родина), Европа
**Свойства**: 
- 20-25% белка
- Морозостойкий
**Где используется**:
- Суп, каша
- Корм для скота
**Источники»: Vavilov Centers, FAO

### Нут / Бараний горох (Chickpea / Cicer arietinum)

**Биом**: субтропический
**География**: Плодородный полумесяц (родина), Индия
**Свойства**: 
- 19-25% белка
- Устойчив к засухе
**Где используется**:
- Хумус (главное блюдо Востока)
- Фалафель
- Каша
**Особые свойства**: 
- Важный продукт Ближнего Востока и Индии
**Источники»: Vavilov Centers, FAO

### Бобы конские / Фава (Fava bean / Vicia faba)

**Биом**: умеренный
**География**: Плодородный полумесяц, Европа
**Свойства**: 
- 25-30% белка
- Очень выносливы
**Где используется**:
- Каша, суп
- В римской культуре (главный продукт римских легионов!)
**Особые свойства**: 
- Исторический пищевой продукт Средиземноморья
- Бобы → «фаба» → «Фабиус» (римское имя от бобов!)
**Источники»: Vavilov Centers, FAO

### Соя (Soybean / Glycine max)

**Биом**: субтропический влажный
**География**: Восточная Азия (родина — Китай, 3000 до н.э.)
**Свойства**: 
- 35-40% белка (высокий!)
- 18-22% масла
**Где используется**:
- Тофу (китайский продукт)
- Соевый соус (ферментированный)
- Соевое молоко
- Корм для скота (позднее)
**Особые свойства**: 
- Самая белковая культура
- Основа азиатского белка (меньше животного белка)
**Источники»: Vavilov Centers, FAO

### Фасоль обыкновенная (Common bean / Phaseolus vulgaris)

**Биом**: тропический, субтропический
**География**: Мезоамерика (родина — Мексика, Перу)
**Свойства**: 
- 20-25% белка
- Разные сорта (фасоль, бобы)
**Где используется**:
- Главный продукт Америки
- В Европе — после Колумба
**Источники»: Vavilov Centers, FAO

### Вигна / Коровий горох (Cowpea / Vigna unguiculata)

**Биом**: тропический
**География**: Африка (родина)
**Свойства**: 
- 22-25% белка
- Засухоустойчива
**Где используется**: главная бобовая Африки
**Источники»: Vavilov Centers, FAO

## 3. Овощи и корнеплоды

### Репа (Turnip / Brassica rapa)

**Биом**: умеренный
**География**: Европа, Средиземноморье
**Где используется**:
- Вареный корнеплод
- Корм для скота
**Особые свойства**: 
- До картофеля — главный корнеплод Европы
- «Бросить в репу» — древнерусское выражение
**Источники»: Vavilov Centers

### Морковь (Carrot / Daucus carota)

**Биом**: умеренный
**География**: Афганистан (родина дикой), Голландия (культурная)
**Где используется**:
- Корнеплод (еда)
- Корм для скота
**Источники»: Vavilov Centers

### Свёкла (Beet / Beta vulgaris)

**Биом**: умеренный, субтропический (приморский)
**География**: Средиземноморье (родина)
**Где используется**:
- Корнеплод
- Сахар (только в 18-19 вв.)
**Источники»: Vavilov Centers

### Капуста (Cabbage / Brassica oleracea)

**Биом**: умеренный
**География**: Средиземноморье (родина дикой)
**Где используется**:
- Варёная, тушёная (главный продукт Восточной Европы)
- Квашеная (источник витамина C зимой!)
**Особые свойства**: 
- Квашеная капуста → витамин C → предотвращает цингу (моряки, зима)
**Источники»: Vavilov Centers

### Лук (Onion / Allium cepa)

**Биом**: умеренный, субтропический
**География**: Средняя Азия (родина)
**Где используется**:
- Приправа (главный продукт!)
- Лекарство (антибиотик)
**Особые свойства**: 
- Древнейшая культура (3000 до н.э. — Египет)
- Священный в Древнем Египте
**Источники»: Vavilov Centers

### Чеснок (Garlic / Allium sativum)

**Биом**: умеренный
**География**: Средняя Азия (родина)
**Где используется**:
- Приправа
- Лекарство (антибиотик, от холестерина)
**Особые свойства**: 
- Древняя культура
- Строителям пирамид Гизы давали чеснок (для силы)
**Источники»: Vavilov Centers

### Картофель (Potato / Solanum tuberosum)

**Биом**: умеренный, горный тропический
**География**: Анды (родина — Перу/Боливия, 8000-5000 до н.э.)
**Где используется**:
- Варёный, жареный (главное блюдо после 16 в. в Европе)
- Крахмал
- Водка (позднее)
**Особые свойства**: 
- Американское происхождение (завезён в Европу в 16 в.)
- Высокая урожайность → поддержал рост населения Европы
- Исторический «ирландский картофельный голод» (1840-х)
**Источники»: Vavilov Centers, FAO

### Батат / Сладкий картофель (Sweet potato / Ipomoea batatas)

**Биом**: тропический
**География**: Центральная Америка (родина)
**Где используется**:
- Корнеплод (главный в Полинезии и тропиках)
**Особые свойства**: 
- Завезён в Полинезию до Колумба (транс-тихоокеанская торговля)
**Источники»: Vavilov Centers, FAO

### Маниок / Кассава (Cassava / Manihot esculenta)

**Биом**: тропический
**География**: Бразилия (родина)
**Где используется**:
- Корнеплод (главный в тропиках: Африка, Бразилия, ЮВ Азия)
- Тапиока
**Особые свойства**: 
- Токсичен в сыром виде (цианид) → требует обработки
- Очень урожайный
- Основа тропической пищи
**Источники»: Vavilov Centers, FAO

### Ямс (Yam / Dioscorea)

**Биом**: тропический
**География**: Африка, Азия (разные виды)
**Где используется**:
- Корнеплод (главный в Западной Африке)
**Особые свойства**: 
- Африканская альтернатива картофелю
**Источники»: Vavilov Centers

## 4. Фрукты и ягоды

### Финики (Date / Phoenix dactylifera)

**Биом**: оазисы, пустынный
**География**: Сев. Африка, Ближний Восток, Аравия
**Где используется**:
- Плоды (сушёные — стратегический резерв)
- Пальмовое вино (сок)
**Особые свойства**: 
- Основа выживания в пустынях
- Сахар фиников → основной сахар Ближнего Востока
**Источники»: Vavilov Centers, FAO

### Оливки / Оливковое масло (Olive / Olea europaea)

**Биом**: средиземноморский
**География**: Средиземноморье
**Где используется**:
- Плоды (маслины)
- **Масло** (главный жир в Средиземноморье)
- Мыло (с зольной водой)
- Освещение (масляные лампы)
- Косметика, религия (помазание)
**Особые свойства**: 
- Основа греческой и римской экономики
- Дерево живёт 1000+ лет
- Афины и Спарта воевали за оливки
**Источники»: Vavilov Centers, FAO

### Инжир (Fig / Ficus carica)

**Биом**: средиземноморский
**География**: Ближний Восток (родина)
**Где используется**:
- Свежий и сушёный (стратегический резерв)
- Лекарство
**Особые свойства**: 
- Древнейшее одомашненное (Иерихон, 9400 до н.э.)
**Источники»: Vavilov Centers

### Виноград / Вино (Grape / Vitis vinifera)

**Биом**: средиземноморский
**География**: Ближний Восток (родина)
**Где используется**:
- Столовый виноград
- **Вино** (главный алкогольный напиток Средиземноморья)
- Изюм (сушёный)
- Уксус
**Особые свойства**: 
- Вино → религия (христианство, Дионис)
- Вино → торговля (греческие колонии ради вина)

## Цикл развития пищи

```
1. 🟢 Собирательство и охота → дикие злаки, дичь, рыба
   ↓ (палеолит — минимальная ёмкость земли)
   
2. 🟢 Одомашнивание злаков (Плодородный полумесяц, 10000 до н.э.)
   ↓ (эммер, эйнкорн, ячмень) — переход к оседлости
   
3. 🟡 Расширение культур (рис, кукуруза, просо — разные центры)
   ↓ (разные регионы — разная пища)
   
4. 🟡 Одомашнивание животных (коза, овца, корова, свинья)
   ↓ (молоко, мясо, шерсть — комплексный продукт)
   
5. 🔴 Сахар (Индия) → стратегический товар
   ↓ (Великий Шёлковый путь — индиго + специи + сахар)
   
6. 🔴 Транс-континентальные культуры (картофель, кукуруза, томат)
   ↓ (после Колумба — американские культуры в Европе)
```

## Принципы для дизайна

### 1. Злаковый «бутылочное горлышко» племени

Без злаков → нет избытка → нет городов. Злаки = основа цивилизации. Старт племени должен быть там, где есть дикий предок злака.

### 2. Разные центры одомашнивания = разная география

- Плодородный полумесяц → эммер, ячмень (Ближний Восток)
- Китай → рис, просо
- Мезоамерика → кукуруза
- Анды → картофель
- Африка → сорго, тэфф

В игре: игрок в разных регионах должен исследовать **разные** злаки.

### 3. Молоко — культурная эволюция

Лактозная толерантность возникла независимо в нескольких регионах (Сев. Европа, Африка). До этого — молоко только как сыр (ферментированный). Игрок: без лактозной толерантности → молоко только ферментированное.

### 4. Ирригация — для риса

Рис требует затопленных полей → коллективная работа → централизация. Историческая связь: рис = ранние государства.

### 5. Сохранение пищи — критично

Сушка, соление, ферментация (сыр, вино, пиво) —关键技术. Без них нет стратегического резерва на зиму/засуху. Соль = критична.

### 6. Витамины и болезнь

Дефицит витамина C → цинга (моряки, зима). Квашеная капуста, цитрусы — решения. Дефицит витамина D → рахит (на севере). В игре: моделировать болезни дефицита.
