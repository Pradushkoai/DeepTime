# Красители и пигменты

> Цвет — критически важный в древнем мире: социальный статус (пурпур — император!), религия (мумии), военное дело (татуировки), одежда. Красители — стратегические торговые товары. Шёлковый путь — отчасти «путь индиго».

---

## 🟢 Минеральные пигменты (доступны с палеолита)

### Охра красная (Red ochre / Hematite powder)

**Категория**: 🟢 Поверхностный
**Состав**: Fe₂O₃ + глина (натуральный пигмент)
**Где встречается**: железорудные месторождения
**Реальные месторождения**: повсеместно
**Цвет**: красный (оттенки от оранжевого до тёмно-красного)
**Как добывается**: сбор → помол → промывка
**Где используется**:
- **Наскальная живопись** (Альтамира, Ласко — 17000 до н.э.)
- Татуировки
- Покраска тел (ритуальная)
- Покраска керамики (перед обжигом)
- Косметика (помада, румяна)
**Особые свойства**: 
- Древнейший пигмент — использовался неандертальцами
- Стойкий, не выцветает
- В ритуалах захоронений (красная краска = кровь = жизнь)
**Источники**: Mindat.org, «The History of Art Pigments» (Feller, 1986)

### Охра жёлтая (Yellow ochre / Goethite)

**Категория**: 🟢 Поверхностный
**Состав**: FeO(OH) (гётит) + глина
**Цвет**: жёлтый (оттенки от лимонного до золотистого)
**Как добывается**: как красная охра
**Где используется**:
- Живопись
- Покраска стен (штукатурка)
- Керамика (под обжиг)
**Особые свойства**: при обжиге выше 250°C переходит в красную (дегидратация гётита → гематит)
**Источники**: Mindat.org

### Сиена (Sienna / Burnt sienna)

**Категория**: 🟢 Поверхностный
**Состав**: Fe₂O₃ + MnO₂ + глина (от Сиены, Италия)
**Цвет**: тёмно-коричневый
**Где используется**: живопись, керамика
**Источники**: Mindat.org

### Умбра (Umber)

**Категория**: 🟢 Поверхностный
**Состав**: Fe₂O₃ + MnO₂ (из Умбрии, Италия)
**Цвет**: тёмно-коричневый (почти чёрный)
**Где используется**: живопись, тёмные тона
**Источники**: Mindat.org

### Мел / Белила (White chalk / White lead)

**Категория**: 🟢 Поверхностный
**Состав**: CaCO₃ (мел) или PbCO₃ (свинцовые белила)
**Где встречается**: морские отложения (мел), зоны окисления свинца (церуссит)
**Цвет**: белый
**Где используется**:
- Белила (живопись)
- Покраска стен (пробел)
- Косметика (белила для лица — мода в античности)
- Штукатурка (основа для росписей)
**Особые свойства**: свинцовые белила токсичны (Pb), но千年 использовались как лучшая белая краска
**Источники**: USGS, Mindat.org

### Уголь / Сажа (Carbon black / Lamp black)

**Категория**: 🟢 Поверхностный (производный)
**Состав**: чистый углерод
**Получение**: 
- Сжигание смолистого дерева (задержка дыма)
- Сжигание масла в лампах (сажа на стекле)
- Сжигание костей (кость-чёрная)
**Цвет**: чёрный
**Где используется**:
- Чёрная тушь (Египет, Китай)
- Грим для бровей/глаз (kohl)
- Татуировки
- Покраска керамики (чёрные фигуры на красном)
**Особые свойства**: 
- Самый распространённый чёрный пигмент
- Использовался ещё в палеолите
**Источники»: Gettens, «The Materials of Painting» (1942)

### Азурит (Azurite)

**Категория**: 🟢 Поверхностный (зоны окисления меди)
**Состав**: Cu₃(CO₃)₂(OH)₂
**Цвет**: синий (бирюзовый до тёмно-синего)
**Где встречается**: с малахитом
**Где используется**:
- **Синяя краска** (древнейшая!)
- Ювелирное дело
**Особые свойства**: 
- Первый доступный синий пигмент
- В игре: критичен для культуры (синий — дефицит в античности)
**Источники**: Mindat.org, USGS

### Малахит (Malachite)

**Категория**: 🟢 Поверхностный
**Состав**: Cu₂(CO₃)(OH)₂
**Цвет**: зелёный
**Где используется**:
- Зелёная краска
- Декоративный камень
- Источник меди (обжиг)
**Особые свойства**: при обжиге → Cu + CO₂ + H₂O → можно плавить в медь
**Источники**: Mindat.org

## 🟡 Органические красители (нужно развивать)

### Индиго / Индигофера (Indigo)

**Категория**: 🟡 Подповерхностный (нужно выращивание и обработка)
**Источник**: Indigofera tinctoria (бобовое растение)
**География**: 
- Индия (родина — название = «индийский»)
- ЮВ Азия
- Позже: Америка (Indigofera suffruticosa)
**Цвет**: синий (темнее азурита, не выцветает)
**Как получается**:
1. Выращивание (90-120 дней)
2. Сбор листьев
3. Ферментация (в моче/щёлочи — извлечение индикана)
4. Окисление → индиготин (нерастворимый)
5. Восстановление (в щёлочи) → растворимый (для покраски)
6. Ткань вынимают → окисляется на воздухе → синяя
**Где используется**:
- Окрашивание тканей (главный синий до синтетики!)
- Живопись (если масляная, с маслом)
**Особые свойства**: 
- Историческая монополия Индии (до 16 в.)
- Позже: англичане выращивали в колониях
- В игре: для синих тканей нужен индиго → стимул торговли с Индией
**Источники**: POWO, «Indigo» (Balfour-Paul, 1998)

### Вайд / Вайда (Woad / Isatis tinctoria)

**Категория**: 🟡 Подповерхностный
**Источник**: Isatis tinctoria (капустное растение)
**География**: Европа (умеренный пояс)
**Цвет**: синий (бледнее индиго)
**Как получается**: подобно индиго (ферментация листьев)
**Где используется**:
- Синяя краска до индиго
- Окрашивание тканей (кельты — «Picts» = «раскрашенные» — синие от вайды!)
**Особые свойства**: 
- Европейская альтернатива индиго (хуже цвет, но доступно)
- Исторически: Британия экспортировала вайду → стратегический товар
- Индиго вытеснило вайду в 17 веке
**Источники**: POWO

### Марена красильная (Madder / Rubia tinctorum)

**Категория**: 🟡 Подповерхностный
**Источник**: корень Rubia tinctorum
**География**: Средиземноморье, Ближний Восток, Европа
**Цвет**: красный (от розового до тёмно-красного)
**Как получается**:
1. Выращивание (2-3 года)
2. Сбор корней
3. Сушка
4. Помол
5. Варка в воде → экстракт
6. Ткань в растворе с квасцами (протрава!)
**Где используется**:
- **Красная краска** (главная в Европе до 16 в.)
- Окрашивание тканей (красные мундиры британской армии!)
- Ковры (турецкие — традиционный цвет)
**Особые свойства**: 
- Протрава (квасцы) — нужна для закрепления
- Без протравы — цвет смывается
- «Turkey red» — самый стойкий красный
**Источники**: POWO, «Madder» (Cardon, 2007)

### Кермес (Kermes)

**Категория**: 🟡 Подповерхностный (насекомые на дубе kermes)
**Источник**: Kermes vermilio (насекомое)
**География**: Средиземноморье (дубы)
**Цвет**: красный (багровый, «королевский»)
**Как получается**:
1. Сбор насекомых с дубов (вручную!)
2. Сушка
3. Помол
4. Варка
**Где используется**:
- «Королевский пурпур» древности (до пурпура)
- Окрашивание царских одежд
**Особые свойства**: 
- Очень дорогой (1 г краски = тысячи насекомых)
- Исторически — до пурпура был «королевский»
**Источники»: Cardon, «Natural Dyes» (2007)

### Орсил / Орсейль (Orchil / Roccella)

**Категория**: 🟡 Подповерхностный
**Источник**: лишайники (Roccella, Lecanora)
**География**: Средиземноморье, Канары
**Цвет**: фиолетовый (как пурпур, но дешевле)
**Где используется**:
- Дешёвая альтернатива пурпура
- Покраска шерсти
**Источники»: Cardon, «Natural Dyes» (2007)

### Куркума (Turmeric / Curcuma longa)

**Категория**: 🟡 Подповерхностный
**Источник**: корневище Curcuma longa
**География**: Индия, ЮВ Азия
**Цвет**: жёлтый (яркий, но выцветает)
**Где используется**:
- Жёлтая краска
- Пряность (пища)
- Лекарство
**Особые свойства**: 
- Дешёвая замена жёлтой охры
- Не стойкая (выцветает)
**Источники**: POWO, FAO

### Сафлор (Safflower / Carthamus tinctorius)

**Категория**: 🟡 Подповерхностный
**Источник**: цветы Carthamus tinctorius
**География**: Египет, Индия
**Цвет**: жёлтый (цветки), красный (семена)
**Где используется**:
- Жёлтая и красная краска
- Масло (семена)
**Источники**: POWO

## 🔴 Дорогие органические (премиум)

### Пурпур / Тирский пурпур (Tyrian purple)

**Категория**: 🔴 Глубокий (дорогой)
**Источник**: Bolinus brandaris (морская раковина — мурекс)
**География**: 
- Финикия (Сидон, Тир — отсюда название «Тирский пурпур»)
- Греция, Крит
**Цвет**: пурпурный (от красного до фиолетового)
**Как получается**:
1. Сбор тысяч раковин мурекса
2. Разрушение раковин
3. Извлечение гипобранхиальной железы
4. Ферментация 3-7 дней
5. Варка
6. Окрашивание тканей
**Где используется**:
- **Царская/императорская одежда** (Рим — только император!)
- Религиозные предметы
- Тексты священных книг (пурпурный пергамент)
**Особые свойства**: 
- 1 г краски = тысячи раковин → невероятно дорого
- Историческая монополия Финикии
- Ценился дороже золота (по весу!)
- В игре: монополия на пурпур = стратегическое преимущество (если игрок — финикиец)
**Источники»: Cardon, «Natural Dyes» (2007)

### Кошениль / Кармин (Cochineal)

**Категория**: 🔴 Глубокий (премиум)
**Источник**: Dactylopius coccus (насекомое на опунции)
**География**: 
- Мексика (родина)
- Перу
- Позже: Канары (после испанского завоевания)
**Цвет**: красный (ярко-малиновый, очень стойкий)
**Как получается**:
1. Разведение насекомых на кактусах опунции
2. Сбор (вручную!)
3. Сушка
4. Помол
5. Варка
**Где используется**:
- **Лучший красный пигмент в истории**
- Британские мундиры (красные) — кошениль!
- Кармин (пищевая добавка E120 — до сих пор)
**Особые свойства**: 
- 1 кг краски = 100 000 насекомых → очень дорого
- Исторически: монополия ацтеков, потом испанцев (16 в.)
- Заменила марену и кермес в Европе
**Источники»: Cardon, «Natural Dyes» (2007)

### Бразилин / Бразильское дерево (Brazilwood)

**Категория**: 🔴 Глубокий
**Источник**: Caesalpinia echinata (дерево)
**География**: Бразилия (название страны от дерева!)
**Цвет**: красный (багровый)
**Где используется**:
- Красная краска (более дешёвая альтернатива пурпуру)
- Декоративная древесина
**Особые свойства**: 
- Исторически: главная экспортная статья Бразилии в 16 в.
- Страна названа в честь дерева
**Источники»: POWO

### Лак / Лаковый червец (Lac / Laccifer lacca)

**Категория**: 🔴 Глубокий
**Источник**: Laccifer lacca (насекомое)
**География**: Индия, ЮВ Азия
**Цвет**: красный (и/или оранжевый)
**Где используется**:
- Красная краска (cheap, smastable)
- Лак (шеллак) — отделка дерева
**Особые свойства**: 
- Историческая индийская монополия
- Двойное применение: краситель + лак
**Источники»: Cardon, «Natural Dyes» (2007)

### Логвуд / Кампеш (Logwood / Haematoxylum)

**Категория**: 🔴 Глубокий
**Источник**: Haematoxylum campechianum
**География**: Мексика, Юкатан
**Цвет**: чёрный (с протравой Fe), синий (с Cu), фиолетовый (с Al)
**Где используется**:
- Чёрная краска (главная для шерсти)
- Мореный дуб (окрашивание дерева)
**Особые свойства**: 
- Универсальная краска — даёт разные цвета с разными протравами
- Историческая монополия Испании в 16-18 вв.
**Источники»: POWO

### Гуммигут (Gamboge)

**Категория**: 🔴 Глубокий
**Источник**: Garcinia hanburyi (смола дерева)
**География**: ЮВ Азия (Камбоджа, Таиланд)
**Цвет**: жёлтый (яркий, прозрачный)
**Где используется**:
- Живопись (яичная темпера)
- Лак
- Желатиновые капсулы (позднее)
**Особые свойства**: 
- Очень стойкий жёлтый
- Исторически — азиатский экспорт
**Источники»: POWO

## Протравы (mordants) — критичны для органических красителей

### Квасцы (Alum)

**Состав**: KAl(SO₄)₂·12H₂O или другие двойные сульфаты
**Где встречается**: 
- Alunite (алунит) — зоны вулканизма
- Aegean (Смирна, Митилини) — античные разработки
- Tolfa (Италия) — папская монополия в 15 в.
**Использование**: 
- **Протрава для органических красителей** (критично для марены, индиго)
- Кожевенное дело (дубление)
- Медицина (вяжущее)
**Технологические цепочки**: алунит → обжиг → квасцы → раствор → протравленная ткань + краситель = стойкая краска
**Особые свойства**: 
- **КРИТИЧЕСКИ ВАЖНО** — без квасцов органические красители смываются
- Исторически: монополия Пап на квасцы → одна из причин Реформации
- В игре: без квасцов — нельзя делать стойкие цветные ткани
**Источники**: USGS, Mindat.org

### Железный купорос / Железо (Iron / FeSO₄)

**Состав**: FeSO₄·7H₂O
**Где встречается**: при растворении железа в серной кислоте (или из пириста)
**Использование**: 
- Протрава для чёрных/тёмных цветов
- Чернение тканей (эффект «седой»)
- Дубление (с летт)
**Источники**: Mindat.org

### Медный купорос / Медь (CuSO₄)

**Состав**: CuSO₄·5H₂O
**Где встречается**: зоны окисления сульфидов меди
**Использование**: 
- Протрава (зелёные/синие оттенки)
- Кожевенное дело
- Фунгицид (позднее — для винограда)
**Источники**: Mindat.org

### Олово (Tin)

**Состав**: Sn (металл)
**Использование**: 
- Протрава (яркие красные — «Turkey red»)
- Блестящие цвета
**Особые свойства**: 
- Дорогая протрава (нужно олово)
- Давала самые яркие цвета
**Источники**: USGS

## Цикл развития красителей

```
1. 🟢 Минеральные пигменты (охра, мел, уголь, азурит, малахит) → палеолит
   ↓ позволяет: наскальная живопись, косметика
   
2. 🟢 Простые органические (вайда, куркума) → неолит
   ↓ позволяет: окраска тканей (без стойкости)
   
3. 🟡 Сложные органические (индиго, марена, кермес) + протравы (квасцы)
   ↓ позволяет: стойкие цвета, premium окраска
   
4. 🔴 Пурпур (тирский) → монополия Финикии
   ↓ позволяет: элитная одежда, стратегический товар
   
5. 🔴 Кошениль, бразилин, лак, логвуд → глобальная торговля
   ↓ позволяет: новые цвета, новые монополии
```

## Принципы для дизайна

### 1. Цвет = статус

Исторически цветные одежды были доступны только элите. Пурпур — императору, шёлк + индиго — аристократии. В игре: цвет одежды граждан = их статус.

### 2. Дефицит синего и пурпура

До индиго в Европе синий был редок (только азурит — дорогой минерал). Пурпур был дороже золота. Это создаёт в игре стимул торговли с Индией (индиго) и Финикией (пурпур).

### 3. Без квасцов — нет стойких цветов

Квасцы = ключевой ресурс для текстильной промышленности. Без квасцов → все ткани линяют. Это делает месторождения алунита стратегически ценными.

### 4. Папская монополия на квасцы

Исторически Папы Римские монополизировали квасцы Толфа (Италия) в 15 в. Это давало им огромный доход. В игре: контроль квасцовых месторождений = экономическое доминирование.

### 5. Монополии красителей = монополии торговли

- Шёлковый путь — отчасти путь индиго и кошенили
- Путь индиго — из Индии через Персию в Европу
- Кошениль — ацтекская монополия, потом испанская
- В игре: контроль красителей = монополия торговли

### 6. Минеральные пигменты — точечный старт

На старте игры (10 000 до н.э.) доступны только минеральные пигменты (охра, мел, уголь, азурит, малахит). Для органических нужно развивать земледелие.
