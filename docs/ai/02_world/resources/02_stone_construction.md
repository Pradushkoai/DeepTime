# Камень и строительные материалы

> Камень — основа строительства, орудий, искусства и инструментов от палеолита до античности. Разные виды камня имеют разные свойства — критично для технологических цепочек.

---

## 🟢 Поверхностные (легкодоступные)

### Кремень (Flint / Chert)

**Категория**: 🟢 Поверхностный
**Формула**: SiO₂ (микрокристаллический кварц)
**Виды**: серый, чёрный, белый, роговой камень
**Где встречается**: осадочные породы, меловые отложения
**Реальные месторождения**:
- Гранд-Прессиньи (Франция) — крупнейшие древние разработки
- Криц (Польша)
- Бельгийский кремень
- Суворово (Украина)
- Эталоны: нуклеусы Сконской яшмы
**Как добывается**: сбор желваков → шахты в меловых отложениях
**Инструменты**: деревянные лопаты, костяные клинья
**Где используется**:
- Орудия: ножи, скребки, наконечники (палеолит-неолит)
- Оружие: наконечники стрел и копий
- Огневое добыча (откол с нагревом)
- Огниво (с искрой)
**Технологические цепочки**: кремень → оббивка → острое лезвие; кремень + железо = искра → огонь
**Альтернативы**: обсидиан (острее), кварц, яшма
**Особые свойства**: при раскалывании образует раковистый излом → острые края. Ключевой материал палеолита
**Источники**: Mindat.org, «The Flint Mines of England» (Shepherd, 1972)

### Обсидиан (Obsidian)

**Категория**: 🟢 Поверхностный
**Состав**: вулканическое стекло (аморфный SiO₂)
**Виды**: чёрный, коричневый, зелёный (мурашек), радужный
**Где встречается**: зоны вулканизма
**Реальные месторождения**:
- Аджи-Даг и Гёлю-Даг (Турция, Анатолия) — главный источник Ближнего Востока
- Липари и Сардиния (Италия)
- Мексика (Sierra de las Navajas)
- Палки (Венгрия)
- Карпаты (Украина)
- Пацин (Армения)
**Как добывается**: сбор → простые шахты
**Инструменты**: каменные молоты
**Где используется**:
- Орудия: острейшие лезвия (тоньше стальных!)
- Зеркала (полированный обсидиан)
- Украшения
- Ритуальные ножи (ацтеки)
**Технологические цепочки**: обсидиан → оббивка → острое лезвие; обсидиан → полировка → зеркало
**Особые свойства**: острее стали (края толщиной в молекулу). Ценный торговый товар — найден в могилах за 1000 км от источников
**Источники**: Mindat.org, «Obsidian in the Mediterranean and Near East» (Renfrew, 1973)

### Кварц (Quartz)

**Категория**: 🟢 Поверхностный
**Формула**: SiO₂
**Виды**: горный хрусталь (прозрачный), дымчатый, розовый, молочный
**Где встречается**: пегматитовые жилы, россыпи
**Реальные месторождения**: Бразилия, Альпы, Мадагаскар, Урал
**Где используется**: украшения, оптические свойства (линзы), оббивка → примитивные орудия
**Особые свойства**: пьезоэлектрический эффект, твёрдость 7 (высокая)
**Источники**: Mindat.org

### Песок (Sand)

**Категория**: 🟢 Поверхностный
**Состав**: смесь SiO₂ (кварц), карбонатов, обломков пород
**Виды**: кварцевый (белый), коралловый, вулканический (чёрный)
**Где встречается**: берега рек, морей, дюны
**Где используется**:
- Строительный раствор (с известью)
- Производство стекла (кварцевый песок — основа!)
- Абразив
- Гончарное дело (примесь в глину)
**Технологические цепочки**: кварцевый песок + сода + известь → плавка 1200°C → стекло
**Особые свойства**: кварцевый песок критичен для стекла
**Источники**: USGS

### Гравий и галька (Gravel)

**Категория**: 🟢 Поверхностный
**Где встречается**: берега рек, морей
**Где используется**: фундаменты, дренаж, метательные орудия
**Источники**: —

### Ракушечник (Coquina)

**Категория**: 🟢 Поверхностный
**Состав**: карбонат кальция (CaCO₃) из раковин
**Где встречается**: морские побережья
**Где используется**: строительный камень (мягкий, легко режется)
**Особые свойства**: лёгкий в обработке → ранние прибрежные цивилизации
**Источники**: USGS

## 🟡 Подповерхностные

### Песчаник (Sandstone)

**Категория**: 🟡 Подповерхностный
**Состав**: обломочный, цементированный песок
**Виды**: кварцевый, аркозовый, граувакковый
**Где встречается**: осадочные отложения
**Реальные месторождения**:世界各地
**Как добывается**: карьеры
**Инструменты**: каменные/медные/железные пилы, клинья
**Где используется**:
- Строительный камень (легко обрабатывается)
- Точильные камни (критично для орудий!)
- Жернова (зерно)
- Декоративная отделка
**Технологические цепочки**: песчаник → обтёсывание → блоки; песчаник → обтёсывание → точильный камень
**Особые свойства**: разные сорта имеют разную твёрдость → разные применения
**Источники**: USGS, Mindat.org

### Известняк (Limestone)

**Категория**: 🟡 Подповерхностный
**Состав**: CaCO₃ (карбонат кальция)
**Виды**: плотный, ракушечный, мергель, мел
**Где встречается**: осадочные отложения (морские)
**Реальные месторождения**: повсеместно
**Как добывается**: карьеры
**Где используется**:
- Строительный камень (Пирамиды Гизы!)
- Жжёная известь → раствор/штукатурка
- Помол → мел для покраски
- Производство извести (CaO) — обжиг 900°C
- Источник кальция
**Технологические цепочки**: известняк → обжиг 900°C → CaO (негашёная известь) + CO₂; CaO + H₂O → Ca(OH)₂ (гашёная); Ca(OH)₂ + песок = раствор
**Особые свойства**: основа строительства с античности
**Источники**: USGS, Mindat.org

### Мел (Chalk)

**Категория**: 🟡 Подповерхностный (мягкий известняк)
**Состав**: CaCO₃ (мягкий, пористый)
**Где встречается**: морские осадочные отложения
**Где используется**: белая краска, помол → раствор, удобрения
**Технологические цепочки**: мел → помол → белила
**Источники**: USGS

### Мергель (Marl)

**Категория**: 🟡 Подповерхностный
**Состав**: смесь CaCO₃ и глины
**Где встречается**: осадочные отложения
**Где используется**: цемент (натуральный), удобрение
**Особые свойства**: природный «римский цемент»
**Источники**: USGS

### Гипс (Gypsum)

**Категория**: 🟡 Подповерхностный
**Формула**: CaSO₄·2H₂O
**Виды**: селенит, алебастр, розовый гипс
**Где встречается**: эвапоритовые отложения
**Реальные месторождения**:
- Монмартр (Париж)
- Каррара (Италия) — алебастр
- Урал (Россия)
**Где используется**:
- Строительный материал (алебастр — декоративный камень)
- Жжёный гипс → штукатурка, скульптуры
- Пол для жилищ
- Формы для литья металла
**Технологические цепочки**: гипс → обжиг 150°C → полугидрат CaSO₄·0.5H₂O (парижский гипс) + вода → твердеет
**Особые свойства**: лёгкий, мягкий — древнейший скульптурный материал
**Источники**: USGS, Mindat.org

### Ангидрит (Anhydrite)

**Категория**: 🟡 Подповерхностный
**Формула**: CaSO₄
**Где встречается**: с гипсом
**Где используется**: строительный камень, помол → цемент
**Источники**: Mindat.org

### Туф вулканический (Tuff)

**Категория**: 🟡 Подповерхностный
**Состав**: уплотчнённый вулканический пепел
**Где встречается**: зоны вулканизма
**Реальные месторождения**: Римская Кампанья (жёлтый туф), Каппадокия (Турция)
**Где используется**: строительный камень (очень лёгкий, режется ножом)
**Особые свойства**: лёгкий, теплоизоляционный. Из него сделаны этрусские гробницы
**Источники**: Mindat.org

### Базальт (Basalt)

**Категория**: 🟡 Подповерхностный
**Состав**: вулканическая порода (тёмная, мелкозернистая)
**Где встречается**: зоны вулканизма
**Реальные месторождения**: Эфиопия, Сирия (древние разработки), Декан (Индия)
**Где используется**:
- Жернова (зерно!) — критически важный
- Стелы, статуи
- Брусчатка
- Каменные орудия (чаши)
**Технологические цепочки**: базальт → обтёсывание → жёрнов; базальт → обтёсывание → статуя
**Особые свойства**: твёрдый, истираемый — идеален для жерновов. Важный торговый товар в античности
**Источники**: USGS, Mindat.org

### Пемза (Pumice)

**Категория**: 🟡 Подповерхностный
**Состав**: вулканическое стекло (пористое)
**Где встречается**: зоны вулканизма
**Где используется**: абразив, отделка кожи, чистка, косметика
**Особые свойства**: плавает на воде → древний торговый товар
**Источники**: Mindat.org

## 🔴 Глубокие (требуют развитой техники добычи и обработки)

### Гранит (Granite)

**Категория**: 🔴 Глубокий
**Состав**: интрузивная порода (кварц, полевой шпат, слюда)
**Где встречается**: магматические тела
**Реальные месторождения**: Асуан (Египет) — древнейшие карьеры; Каррара (Италия)
**Как добывается**: карьеры, оббивка с железными клиньями
**Где используется**:
- Монументальное строительство (обелиски Египта!)
- Саркофаги
- Колонны
- Жернова (гранитные)
**Технологические цепочки**: гранит → обтёсывание с железными инструментами → обелиск/блок
**Особые свойства**: очень твёрдый — требует железных инструментов. Без железа — невозможно обработать крупно. Это «бутылочное горлышко» монументальной архитектуры
**Источники**: USGS, Mindat.org

### Диорит (Diorite)

**Категория**: 🔴 Глубокий
**Состав**: интрузивная порода (средняя по составу)
**Где встречается**: магматические тела
**Где используется**: статуи (Кодекс Хаммурапи!), жернова
**Особые свойства**: ещё твёрже гранита. Вавилонские статуи из диорита
**Источники**: Mindat.org

### Мрамор (Marble)

**Категория**: 🔴 Глубокий
**Состав**: метаморфическая порода (перекристаллизованный известняк)
**Виды**: белый (Каррара), цветной
**Реальные месторождения**:
- Каррара (Италия) — главный источник античности
- Пентеликон (Греция) — для Акрополя
- Парос (Греция) — для Венеры Милосской
- Прохор (Урал)
**Как добывается**: глубокие карьеры
**Где используется**:
- Скульптура (Греция!)
- Облицовка зданий
- Полы, колонны
**Технологические цепочки**: мрамор → обтёсывание + полировка → статуя/блок
**Особые свойства**: при полировке становится полупрозрачным — идеален для скульптуры
**Источники**: Mindat.org

### Сланец (Slate)

**Категория**: 🔴 Глубокий
**Состав**: метаморфическая порода (глинистая основа)
**Где встречается**: metamorphic зоны
**Где используется**: кровельные плитки, столешницы, письмена (стилосы)
**Особые свойства**: раскалывается на тонкие плиты
**Источники**: Mindat.org

## Принципы для дизайна

1. **Твёрдость определяет доступность**: мягкие камни (известняк, гипс) можно обрабатывать с каменными/медными инструментами. Твёрдые (гранит, диорит) — только с железными.
2. **Жернова — критический цикл**: базальт и песчаник нужны для переработки зерна. Без них — помол вручную, низкая производительность.
3. **Стекло зависит от песка**: кварцевый песок + сода + известь + температура 1200°C (нужна огнеупорная глина)
4. **Известь — основа строительства**: обжиг известняка при 900°C → CaO → раствор со смесью с песком
5. **Обсидиан — торговый товар**: ценился выше золота в раннем неолите. Торговые пути по 1000+ км
6. **Кремень — основа палеолита**: до металлов был главным материалом для орудий
