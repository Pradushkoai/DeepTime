# Кожи и шкуры

> Кожа — первый материал для одежды (до текстиля), обуви, защитного снаряжения, ремней, упряжи, навесов, военных доспехов. Разные животные дают разные по качеству кожи. Кожевенное дело — древнейшая сложная химическая технология.

---

## 🟢 Шкуры диких животных (легкодоступные)

### Оленья кожа (Deer hide)

**Биом**: boreal леса, тундра, тайга
**География**: повсеместно (олень, косуля, лось)
**Свойства**:
- Мягкая, эластичная
- Тонкая, но прочная
- Хорошо впитывает воду (но и сохнет)
**Как получается**:
- Охота → свежевание → мездровка (очистка от подкожного жира) → выделка
**Где используется**:
- Одежда (главный материал севера — алеуты, эскимосы, самский костюм)
- Обувь (мокасины)
- Перчатки
- Мешки, сумки
**Особые свойства**:
- Самая лёгкая из крупных шкур
- Северные народы делали из неё всё: от палаток до лодок
**Источники»: IUCN, «Leather in Ancient Times» (Waterer, 1968)

### Лосятина / Лосиная шкура (Elk/Moose hide)

**Биом**: boreal леса
**География**: Северная Евразия, Канада, Аляска
**Свойства**:
- Очень толстая и прочная
- Тяжёлая
- Используется для военных доспехов (стёганых кожаных)
**Где используется**:
- Доспехи (кочевники, азиаты)
- Подошвы обуви
- Щиты
**Особые свойства**:
- Лучший материал для кожаного доспеха (от стрел и мечей)
**Источники»: IUCN

### Медвежья шкура (Bear hide)

**Биом**: boreal, горный, лесной
**География**: повсеместно (бурый, чёрный, белый медведи)
**Свойства**:
- Очень тёплая (густой мех)
- Толстая кожа
- Большая (взрослый медведь)
**Где используется**:
- Тёплая одежда (шубы)
- Кровати, одеяла (шаманы, вожди)
- Ритуальные предметы (статус)
**Особые свойства**:
- Ритуальный/статусный предмет — символ власти
**Источники»: IUCN

### Волчья / Лисья шкура (Wolf / Fox pelt)

**Биом**: boreal, степь, тундра
**География**: повсеместно
**Свойства**:
- Мягкая, тёплая
- Меньше, чем медвежья (нужно много для одежды)
**Где используется**:
- Шапки (боярские, бояре)
- Воротники
- Манто
**Особые свойства**:
- Статусный предмет (дорогой)
**Источники»: IUCN

### Бобровая шкура (Beaver pelt)

**Биом**: берега рек
**География**: Северная Америка, Евразия
**Свойства**:
- Очень густой подшёрсток (водонепроницаемый!)
- Мягкая выделка
**Где используется**:
- **Шапки** (главное применение!)
- Воротники
- Плащи
**Особые свойства**:
- Исторически — стратегический товар (Новая Франция, Гудзонова компания — вырубили бобров ради шапок)
- Европейские бобры почти истреблены к 16 в.
- «Шапкa из бобра» = символ статуса
**Источники»: IUCN, «The Beaver» (Innis, 1930)

### Куница / Соболь (Marten / Sable)

**Биом**: boreal леса
**География**: Сибирь (соболь), Россия, Канада (куница)
**Свойства**:
- Очень мягкий, густой мех
- Тёплый
**Где используется**:
- Шубы (главное применение!)
- Манто, воротники
- Шапки
**Особые свойства**:
- **Соболь** — самый ценный мех в мире (царский!)
- Россия — монополист (Мантуров соболь)
- Исторический стратегический экспорт России
**Источники»: IUCN

### Рысь (Lynx pelt)

**Биом**: boreal леса
**География**: Евразия, Сев. Америка
**Где используется**: элитные меха
**Особые свойства**: статусный, очень дорогой
**Источники»: IUCN

## 🟡 Шкуры домашних животных

### Коровья / Бычья кожа (Cowhide / Bovine leather)

**Биом**: где разводят скот
**География**: повсеместно
**Свойства**:
- Толстая, прочная
- Жёсткая (нужно размягчать)
- Большая (1 корова = много кожи)
**Где используется**:
- **Подошвы обуви** (главное применение — очень износостойкая)
- Ремни (упряжь, лошадиные сбруи)
- **Щиты** (римские скутумы — из коровьей кожи!)
- Кожаные доспехи (studded leather)
- Мешки, сумки
- Барабаны
- Переплёты книг (позднее)
**Технологические цепочки**: корова → забой → свежевание → мездровка → дубление (квасцы/дубовая кора) → сушка → кожа
**Особые свойства**:
- Самая массовая кожа (коров много)
- Исторически — основа римских легионов (скутум, калига)
**Источники»: FAO

### Овечья шкура / Овчина (Sheepskin)

**Биом**: где разводят овец (умеренный, горный, степь)
**География**: повсеместно
**Свойства**:
- Тёплая (с мехом)
- Мягкая кожа
- Меньше коровьей
**Где используется**:
- Тулупы (овчинные шубы)
- Шапки (боярские — из овчины)
- Покрывала, коврики
- Пергамент (нелёгкая обработка — см. ниже)
**Особые свойства**:
- Сельский, доступный материал
- Историческая основа одежды в холодных регионах
**Источники»: FAO

### Козлина (Goatskin)

**Биом**: где разводят коз
**География**: повсеместно (особенно горные регионы)
**Свойства**:
- Мягкая, эластичная
- Тоньше коровьей, прочнее овечьей
- Водонепроницаемая (после обработки)
**Где используется**:
- Меха (кожаные), одежда
- Мешки для воды/вина (water skin)
- Перчатки
- Сёдла
- Пергамент (Pergamena — название от Пергама!)
**Особые свойства**:
- **Пергамент** — самый важный писчий материал до бумаги (заменил папирус)
- Водонепроницаемость → идеальна для мехов
**Источники»: FAO

### Свиной кожи (Pigskin)

**Биом**: где разводят свиней
**География**: повсеместно
**Свойства**:
- Жёсткая, плотная
- Толстая
- Меньше, чем у коровы
**Где используется**:
- Подошвы обуви (дешёвая альтернатива коровьей)
- Сёдла
- Мебель (обивка)
- Кожаные мячи
**Особые свойства**:
- Кожа с подкожным жиром → нужно特别 обработка
- Дешёвая, массовая
**Источники»: FAO

### Кожа лошади / Конина (Horsehide)

**Биом**: где разводят лошадей (степь, кочевники)
**География**: Степь, кочевые народы
**Свойства**:
- Грубая, толстая
- Прочная
**Где используется**:
- Сёдла
- Ремни
- Кожаные доспехи (азиатские lamellar)
- Лук без тетивы (кобура)
**Особые свойства**:
- У кочевников — побочный продукт забоя лошадей
- Стратегический материал азиатских армий
**Источники»: FAO

## 🔴 Специальные кожи

### Кожа аллигатора / Крокодила (Crocodile leather)

**Биом**: тропические реки и побережья
**География**: Африка, ЮВ Азия, Австралия, Америка
**Свойства**:
- Очень прочная, с характерной текстурой
- Дорогая
- Статусная
**Где используется**:
- Элитная обувь, сумки (Lux)
- Чемоданы, кошельки
**Особые свойства**:
- Исторически — элитный материал (египетские фараоны)
- Сейчас — охраняется CITES
**Источники»: IUCN, CITES

### Змеиная кожа (Snakeskin)

**Биом**: тропический
**География**: ЮВ Азия, Африка, Америка
**Свойства**:
- Тонкая, с чешуйчатой текстурой
- Эластичная
**Где используется**:
- Элитная обувь, сумки
- Пояса
**Особые свойства**:
- Элитный материал
**Источники»: IUCN, CITES

## Кожевенное дело — отдельная отрасль

### Технологии обработки

| Стадия | Что делается | Инструменты/химикаты |
|---|---|---|
| 1. Свежевание | Снятие шкуры с туши | Ножи |
| 2. Мездровка | Очистка от подкожного жира | Тупые ножи, скребки |
| 3. Мочение | Замачивание в воде/моче | Чаны (моча — аммиак) |
| 4. Золение | Обработка золой/известью (NaOH) | Чаны со щёлочью |
| 5. Дубление | Закрепление структуры | Квасцы, дубовая кора (танин), рыжий мох |
| 6. Жирование | Пропитка жиром/маслом | Жир животных, рыбий жир |
| 7. Сушка | Сушка и растягивание | Рамы |
| 8. Отделка | Полировка, покраска | Красители (см. 07_dyes_pigments.md) |

### Виды кожи (по типу обработки)

| Тип | Обработка | Свойства |
|---|---|---|
| Сыромятная | Только сушка | Жёсткая, недолговечная |
| Замша (Suede) | Без дубления, мездровая | Мягкая, впитывает воду |
| Дублёная (Tanned) | С дубильными веществами | Мягкая, прочная, водостойкая |
| Лайка (Limings) | Со сливовым маслом | Очень мягкая (перчатки) |
| Велюр | С лицевой стороны | Бархатистая |
| Сафьян (Morocco) | С сумахом (танин) | Эластичная, цветная |
| Юфть (Russian) | С берёзовым дёгтем | Водостойкая, ароматная |
| Шагрень (Shagreen) | С семенами горчицы | Шероховатая (декор) |
| Пергамент (Parchment) | С石灰ом, растянутая | Тонкая, для письма |

## Цикл развития кожевенного дела

```
1. 🟢 Сыромятная кожа (просто сушка)
   ↓ позволяет: простая одежда, навесы
   
2. 🟢 Мездровка + жирование (механическая обработка)
   ↓ позволяет: замша, мягкая одежда
   
3. 🟡 Дубление с танином (кора дуба)
   ↓ позволяет: стойкая кожа, доспехи, ремни
   
4. 🟡 Дубление с квасцами
   ↓ позволяет: светлая кожа, пергамент (Пиргамум, 200 до н.э.)
   
5. 🔴 Сафьян (с сумахом), шагрень (со семенами)
   ↓ позволяет: элитная кожа, премиум-товары
   
6. 🔴 Крокодил/змея (тропические)
   ↓ позволяет: элитные материалы (только для элиты)
```

## Принципы для дизайна

### 1. Кожа — второй текстиль (после льна)

В регионах без земледелия (кочевники, севера) — кожа главный материал одежды. Это даёт кочевым племенам альтернативу.

### 2. Без дубления — нет стойкости

Сыромятная кожа гниёт через месяц. Дубление (с танином или квасцами) делает её вековой. Исторически — критическая технология.

### 3. Пергамент — критический писчий материал

Козлиная/овечья кожа → пергамент → книги. Без пергамента — только папирус (растёт в Египте). Это делает регионы без папируса зависимыми от кожевенного дела.

### 4. Доспехи — критичны для армии

Кожаные доспехи (studded, lamellar, scale) — основной доспех до железа. Без хорошей кожи — плохая пехота. Это делает кожевенное дело военной технологией.

### 5. Статусный символ

Шкуры диких животных (соболь, медведь, бобр, волк) — статусные. В игре: одежды вождя и элиты = редкие шкуры.

### 6. Истощение популяций

Вырубка бобров ради шапок в Европе (16-17 вв.) → почти полное истребление. В игре: моделировать истощение диких животных при перерубке.
