## Принципы каталога (всё важно для дизайна)

### Принцип 1: Реальное расположение

Каждый ресурс привязан к реальной геологии/географии. Используются достоверные научные источники (см. ниже). Историческая достоверность — приоритет.

### Принцип 2: Все ресурсы в технологических цепочках

Ни один ресурс не «висит». Каждый имеет:
- Где встречается (география/биом)
- Как добывается (инструмент/технология)
- Где используется (технология/здание/предмет)
- Альтернативы (если есть)

### Принцип 3: Слоистая доступность (см. `06_technology/prerequisites.md`)

Каждый ресурс помечен категорией доступности:
- 🟢 Поверхностные — доступны с первого дня
- 🟡 Подповерхностные — нужны базовые инструменты и опыт
- 🔴 Глубокие — требуют развитой металлургии, шахт, специализации

### Принцип 4: Кросс-технологические зависимости

Многие ресурсы — это «бутылочные горлышки» для технологий. Например:
- Без огнеупорной глины — нет плавки железа (1500°C)
- Без олова — нет бронзы
- Без песчаника — нет качественных точильных камней
- Без конкретных видов дерева — нет длинных луков

### Принцип 5: Уникальность региона

В разных регионах — разные ресурсы. Это создаёт стимул к торговле и экспансии:
- Касситерит (олово) — Корнуолл, Боливия, Малайя
- Самородная медь — Верхнее озеро (США), Корнуолл, Урал
- Лазурит — только Афганистан
- Шёлк — только Китай (исторически)

### Принцип 6: Доступность для изменений

Структура каталога — плоская, каждый ресурс в таблице. Легко добавить/удалить/изменить. Версионирование через git.

## Достоверные источники (использованные для каталога)

### Минералы и руды

- **USGS Mineral Commodity Summaries** (ежегодные обзоры минерального сырья США) — https://www.usgs.gov/centers/national-minerals-information-center
- **Mindat.org** — крупнейшая база данных минералов и месторождений — https://www.mindat.org/
- **Webmineral.com** — детальные данные о минералах
- **British Geological Survey (BGS) World Mineral Statistics** — https://www.bgs.ac.uk/
- **IMA-CNMNC** (International Mineralogical Association — Commission on New Minerals, Nomenclature and Classification) — официальный список одобренных минералов
- **ВСЕГЕИ** (Всероссийский научно-исследовательский геологический институт) — геология РФ/СНГ
- **USGS MRDS** (Mineral Resources Data System) — база месторождений

### Почвы

- **WRB (World Reference Base for Soil Resources)** 2014, обновление 2022 — международная классификация почв FAO
- **USDA Soil Taxonomy** — американская классификация
- **SoilGrids 250m (ISRIC)** — глобальные почвенные данные — https://www.isric.org/
- **FAO Soil Map of the World** — историческая карта почв
- **Harmonized World Soil Database (HWSD)** v1.2 — глобальная база почв

### Флора

- **GBIF (Global Biodiversity Information Facility)** — https://www.gbif.org/
- **IUCN Red List of Threatened Species** — https://www.iucnredlist.org/
- **FAO** (Food and Agriculture Organization) — статистика по культурам — http://www.fao.org/
- **Plants of the World Online (POWO)** — Royal Botanic Gardens, Kew — http://powo.science.kew.org/
- **CABI Invasive Species** — инвазивные виды
- **World Flora Online** — современный список всех растений

### Фауна

- **IUCN Red List** — охраняемые виды
- **GBIF** — биоразнообразие
- **CITES Appendices** — международная торговля видами
- **Mammal Species of the World** (3rd ed., 2005) + **ASM Mammal Diversity Database** — современная таксономия млекопитающих
- **BirdLife International** — данные по птицам
- **FishBase** — данные по рыбам

### Исторические данные по одомашниванию

- **Vavilov Centers of Origin** — центры происхождения культурных растений
- **Braudel, Fernand** «The Mediterranean and the Mediterranean World in the Age of Philip II» — историческая география
- **Diamond, Jared** «Guns, Germs, and Steel» — географические факторы развития цивилизаций
- **Smith, Bruce D.** «The Emergence of Agriculture» — история одомашнивания
- **FAO Domestic Animal Diversity Information System (DAD-IS)** — породы дом. животных

## Структура записи ресурса (шаблон)

Каждый ресурс в каталоге описывается по шаблону:

```
### Название ресурса

**Категория доступности**: 🟢/🟡/🔴
**Виды/сорта**: ...
**Где встречается**: ...
**Реальные месторождения**: ...
**Как добывается**: ...
**Инструменты/технологии для добычи**: ...
**Где используется**: ...
**Технологические цепочки**: ...
**Альтернативы**: ...
**Особые свойства**: ...

**Игровые поля** (P5, v0.31+):
- [питательность ккал/кг — для пищевых] | [содержание металла % — для руд] | [урожайность кг/гектар/год — для растений]
- [трудоёмкость добычи: чел-ч/кг]
- [требуемый инструмент: из каталога items/02_tools.md]
- [прочность/качество: 0-100 — для материалов]

**Источники**: ...
```

> ⚠️ **Игровые поля обязательны (P5, v0.31+)**: СУЩЕСТВОВАНИЕ полей — обязательно сейчас. Значения — на плейтестах (можно заглушка `TBD: плейтесты`). Без числовых полей каталог остаётся энциклопедией, а не игрой. См. [decision_log.md → "Игровые поля каталогов"](../_meta/decision_log.md).

## Как использовать каталог

### При проектировании технологий
1. Для каждой технологии проверь, какие ресурсы нужны
2. Если ресурс редкий в стартовом регионе → стимул к торговле/захвату
3. Если ресурс недоступен → можно построить «обходной путь» через альтернативы

### При проработке деревьев племён
1. Стартовая локация определяет доступные ресурсы
2. Разные племена имеют разные стартовые ресурсы
3. Это создаёт реиграбельность

### При балансировке экономики
1. Цены ресурсов зависят от редкости в регионе
2. Длинные технологические цепочки дороже
3. «Бутылочные горлышки» — особенно ценные ресурсы

## Принцип 7: Версионирование и изменяемость

Каталог — это «снимок» концепции на текущий момент. Если пользователь захочет изменить — достаточно отредактировать соответствующий файл. Все изменения — через git-коммиты.

Принятые решения фиксируются в `_meta/decision_log.md`. Если изменяем что-то концептуальное (например, удаляем категорию ресурсов) — пишем обоснование в decision_log.
