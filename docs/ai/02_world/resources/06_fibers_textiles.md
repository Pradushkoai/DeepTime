# Волокна и ткани

> Текстиль — вторая (после керамики) древнейшая технология обработки материалов. Разные волокна дают разные ткани с разными свойствами. Исторически критично для одежды, парусов, верёвок, бумаги.

---

## 🟢 Растительные волокна (легкодоступные)

### Лён (Flax / Linum usitatissimum)

**Биом**: умеренный пояс
**География**: Египет (Нил —最早的 льняные ткани), Европа, Россия, Канада
**Свойства**: 
- Волокно: длинное, прочное, гладкое, блестящее
- Ткань: лёгкая, прохладная, впитывает влагу, мнётся
**Как производится**:
1. Посев, выращивание (90-120 дней)
2. Уборка (выдёргивание с корнем — для длинного волокна)
3. Замочка (роса/вода — отделение волокна от стебля)
4. Мятьё, трепание, чесание
5. Прядение (нити)
6. Ткачество (ткань)
**Где используется**:
- **Одежда** (главная до хлопка в Европе!)
- Паруса (корабельные — критично!)
- Веревки (прочные)
- Полотно для картин (живопись)
- Масло (семена)
**Технологические цепочки**: лён → сушка → мочка → трепание → прядение → ткачество → льняное полотно
**Особые свойства**: 
- Самая древняя текстильная культура (Гёбекли-Тепе, 9000 до н.э.)
- Ткани Египетских мумий — лён
- Бо́льшая прочность мокрого (уникально!)
- "Льняная ксения" — в Европе лён был главной тканью до XII в.
**Источники**: FAO, Vavilov Centers, «Flax» (Marshall, 1989)

### Конопля (Hemp / Cannabis sativa)

**Биом**: умеренный, boreal
**География**: Центральная Азия (родина), повсеместно
**Свойства**: 
- Волокно: очень прочное, грубое, длинное
- Ткань: грубая, прочная
**Как производится**: как лён, но грубее обработка
**Где используется**:
- **Верёвки** (самые прочные!)
- **Паруса** (прочнее льна)
- Канаты корабельные
- Мешки, рогожа
- Одежда (для бедных — грубая)
- Бумага (позднее — лучшая!)
**Технологические цепочки**: конопля → сушка → мочка → трепание → прядение → верёвки/рогожа
**Особые свойства**: 
- Самая прочная растительная нить (после кендыря)
- Исторически — основной материал для морских верёвок и парусов
- Венеция и Генуя выращивали коноплю массово для флота
- Психоактивный сорт (Cannabis indica) — отдельный продукт (медицина/религия)
**Источники**: FAO, «Hemp» (Bouloc, 2013)

### Крапива (Nettle / Urtica dioica)

**Биом**: умеренный, вездесущая
**География**: повсеместно
**Свойства**: 
- Волокно: похожее на лён, но тоньше и мягче
- Ткань: тонкая, блестящая
**Как производится**: как лён
**Где используется**:
- Одежда (бедных — в трудные времена)
- Мешки, рогожа
- Нити для шитья
**Особые свойства**: 
- Дикое растение → можно собирать без посева
- В средние века — основной материал бедных (когда лён дорог)
- В WWI в Германии — стратегический материал из-за блокады
**Источники**: POWO, FAO

### Хлопок (Cotton / Gossypium spp.)

**Биом**: тропический и субтропический
**География**: 
- G. herbaceum — Африка (родина)
- G. arboreum — Индия
- G. hirsutum — Мезоамерика (Перу, Мексика)
**Свойства**: 
- Волокно: мягкое, короткое, пушистое
- Ткань: мягкая, лёгкая, дышащая, впитывает влагу
**Как производится**:
1. Выращивание (180-200 дней, много солнца и воды)
2. Сбор коробочек
3. Джиннирование (отделение волокна от семян — критичная машина!)
4. Чесание, прядение
5. Ткачество
**Где используется**:
- **Одежда** (главная после античности!)
- Постельное бельё
- Полотно для картин
- Фитили свечей
- Бумага (хлопковая — премиум)
**Технологические цепочки**: хлопок → джиннирование → чесание → прядение → ткачество → хлопковая ткань
**Особые свойства**: 
- Нужна «хлопко-очистительная машина» (cotton gin) для массового производства
- Без джиннирования — ручной труд, очень медленно
- Исторический скачок: Эли Уитни (1793) — хлопковая революция
- В игре: переход от ручного хлопка (только элита) к массовому через джинн
**Источники**: FAO, Vavilov Centers

### Ютта / Джут (Jute / Corchorus)

**Биом**: тропический
**География**: Индия, Бангладеш
**Свойства**: 
- Волокно: грубое, длинное, коричневатое
- Ткань: грубая, дешёвая
**Где используется**:
- Мешки (бочки для зерна)
- Рогожа, циновки
- Верёвки (дешёвые)
**Особые свойства**: 
- Дешевле и грубее конопли
- В Индии — главный материал для упаковки
**Источники**: FAO, POWO

### Рами / Крапива китайская (Ramie / Boehmeria nivea)

**Биом**: тропический/субтропический
**География**: Восточная Азия (родина), ЮВ Азия
**Свойства**: 
- Волокно: очень длинное, прочное, блестящее
- Ткань: тонкая, прочная, белая
**Где используется**:
- Одежда (тонкая, для элиты в Азии)
- Ткани для художников
**Особые свойства**: 
- Одно из самых прочных растительных волокон
- Не мнётся
- Исторически: «китайская трава» — стратегический экспорт Китая
**Источники**: FAO, POWO

### Сизаль (Sisal / Agave sisalana)

**Биом**: полусухой тропический
**География**: Мексика (родина), Вост. Африка, Бразилия
**Свойства**: 
- Волокно: очень прочное, грубое
- Ткань: не используется, но канаты/верёвки — да
**Где используется**:
- Верёвки (особенно морские — не гниют в солёной воде)
- Канаты
- Мешки
- Щётки
**Особые свойства**: 
- Американское происхождение
- Морские канаты (особенно важны для полинезийцев)
**Источники**: FAO, POWO

### Кенаф / Кендырь (Kenaf / Hibiscus cannabinus)

**Биом**: тропический
**География**: Африка, Индия
**Свойства**: 
- Волокно: грубое, длинное
- Использование: верёвки, мешки, бумага
**Особые свойства**: 
- Альтернатива конопле в Африке
- Быстрорастущее
**Источники**: FAO, POWO

### Луб (Bast — внутренняя кора деревьев)

**Биом**: любой с деревьями
**География**: повсеместно
**Свойства**: 
- Волокно: мягкое, гибкое, недолговечное
**Где встречается**: внутренний слой коры (липа, ива, дуб)
**Где используется**:
- Верёвки (простые)
- Циновки
- Корзины
- Мочало (мочало из липы)
**Особые свойства**: 
- Не требует посева — собирается с растущих деревьев
- Дикий материал → для самых бедных
**Источники**: —

## 🟡 Животные волокна

### Шерсть (Wool)

**Биом**: где разводят овец (умеренный, горный, степной)
**География**: 
- Овцы одомашнены в Месопотамии (~11000 лет назад)
- Сейчас: Австралия, Новая Зеландия, Россия, Великобритания
**Свойства**: 
- Волокно: мягкое, извитое, чешуйчатое
- Ткань: тёплая, дышащая, эластичная, впитывает влагу
**Как производится**:
1. Разведение овец (пастбище)
2. Стрижка (1-2 раза в год)
3. Сортировка, мойка
4. Чесание
5. Прядение
6. Ткачество
7. Валяние (для войлока)
**Виды тканей**:
- Шерстяная ткань (тёплая)
- Сукно (валёное, плотное)
- Войлок (нетканое, плотное)
- Кашемир (мягкий подшёрсток кашмирских коз)
**Где используется**:
- **Одежда** (главная в Европе до хлопка!)
- Одеяла
- Палатки (кочевники — юрты из войлока!)
- Ковры
- Паруса (позднее — шерстяные паруса викингов)
**Технологические цепочки**: овца → стрижка → мойка → чесание → прядение → ткачество → шерстяная ткань / валяние → войлок
**Особые свойства**: 
- Множество пород овец → разная шерсть
- Валяние — простой процесс, доступный кочевникам
- Исторически — основа экономики Англии (XIII-XV вв.)
**Источники**: FAO, Vavilov Centers

### Шёлк (Silk)

**Биом**: где разводят тутовый шелкопряд (умеренный, субтропический)
**География**: 
- Китай (родина — Хэнань, ~3000 до н.э.)
- Позже: Корея, Япония, Индия, Византия (после 552 н.э.)
- Европа (Италия, Франция — средние века)
**Свойства**: 
- Волокно: длинная непрерывная нить (до 1 км!)
- Ткань: очень прочная, блестящая, лёгкая, дышащая
**Как производится**:
1. Тутовые деревья (Morus alba)
2. Разведение гусениц шелкопряда (Bombyx mori)
3. Кормление листьями (40 дней)
4. Коконы (3-5 дней прядения)
5. Разматывание коконов в горячей воде
6. Скручивание нитей
7. Ткачество
**Виды**:
- Шёлк-сырец (натуральный)
- Дутин (тонкая ткань)
- Атлас, парча, газ
**Где используется**:
- Одежда (только элита — очень дорого!)
- Знамёна, штандарты
- Парашюты (позднее)
- Шёлковая бумага
- Нити для шитья
**Технологические цепочки**: тутовое дерево → листья → шелкопряд → коконы → разматывание → нити → шёлковая ткань
**Особые свойства**: 
- Историческая монополия Китая (до 552 н.э.)
- Контрабанда коконов в Византию (монахи-контрабандисты)
- Великий Шёлковый путь — назван в честь
- В игре: китайский игрок имеет стратегическое преимущество (монополия)
**Источники**: FAO, Vavilov Centers, «Silk» (Kuhn, 1988)

### Кашемир (Cashmere)

**Биом**: горный
**География**: Кашмир (Индия), Тибет, Монголия, Иран
**Свойства**: 
- Очень тонкий подшёрсток кашмирских коз
- Ткань: очень мягкая, тёплая, лёгкая
**Где используется**: премиум одежда (элита)
**Особые свойства**: 
- Сбор: вычёсывание (не стрижка)
- Очень дорогой — 1 коза = 150 г волокна в год
- Исторический экспорт Кашмира → весь мир
**Источники**: FAO, POWO

### Мохер (Mohair)

**Биом**: полусухой
**География**: Турция (Ангора), ЮАР, США
**Свойства**: 
- Длинные блестящие волокна ангорских коз
- Ткань: блестящая, тёплая
**Где используется**: премиум одежда, мебель
**Особые свойства**: 
- Турция имела историческую монополию (ангорские козы)
- В 19 веке вывезены в ЮАР и США
**Источники**: FAO, POWO

### Верблюжья шерсть (Camel hair)

**Входящие связи**: верблюд (одомашненный) → [fauna/README.md](../fauna/README.md)
**Исходящие связи**: одежда кочевников → [items/03_buildings.md](../06_technology/items/03_buildings.md)
**Роль**: стратегический материал кочевых империй

**Биом**: степь, пустыня
**География**: Центральная Азия, Монголия, Ближний Восток
**Свойства**: 
- Тёплая, грубая
- Ткань: пальто, одеяла (для кочевников)
**Особые свойства**: 
- Стратегический материал кочевых империй
- Юрты монголов — из верблюжьей шерсти
**Источники**: FAO, POWO

## 🔴 Специальные волокна (редкие)

### Паучий шёлк (Spider silk)

**Биом**: где есть пауки (везде)
**Свойства**: 
- Самое прочное волокно (5x прочнее стали по весу!)
- Очень тонкое
**Использование**: 
- Исторически — редкие ткани (Паучий шёлк Франции)
- Сейчас — оптика, медицина (только в индустриальную эпоху)
**Особые свойства**: 
- Нельзя массово произвести (пауки каннибалы)
- Только ручной сбор — нереально дорогой
**Источники**: IUCN

### Asbestos (Асбест)

**Биом**: metamorphic зоны
**География**: 
- Кипр (древнейшие разработки)
- Урал (Россия)
- Квебек (Канада)
- ЮАР
**Свойства**: 
- Минеральное волокно (не органическое!)
- Огнестойкое (использовали как «вечный фитиль»)
**Где использовался в древности**:
- Ткань для фильтрации (Греция)
- Неразрушаемые фитиля для ламп
- Одежда пожарных (позднее)
**Особые свойства**: 
- Минеральное волокно → «каменная ткань»
- Огнестойкость
- Токсичность (асбестоз — современная проблема)
**Источники**: USGS, Mindat.org

## Цикл развития текстиля

```
1. 🟢 Луб, крапива, шерсть (дикие овцы) → примитивная одежда
   
2. 🟢 Лён (одомашнен в Месопотамии ~9000 до н.э.)
   ↓ позволяет: тонкая одежда, паруса
   
3. 🟡 Шерсть (одомашненные овцы) → валяние → войлок
   ↓ позволяет: кочевое скотоводство (юрты), палатки
   
4. 🟡 Конопля (Центральная Азия) → верёвки, паруса
   ↓ позволяет: мореплавание (нужны прочные канаты)
   
5. 🟡 Хлопок (Индия, Мезоамерика) → мягкая одежда
   ↓ позволяет: тропическая одежда (лён не подходит)
   
6. 🔴 Шёлк (Китай, 3000 до н.э.) → премиум элита
   ↓ позволяет: уникальные ткани + монополия торговли
   
7. 🔴 Кашемир, мохер → премиум животноводство
   ↓ позволяет: товары элиты
   
8. 🔴 Асбест → огнестойкие изделия
   ↓ позволяет: «магические» ткани, не горят
```

## Принципы для дизайна

### 1. Географическая уникальность волокон

- Лён: Европа, Египет
- Конопля: Центральная Азия, Европа
- Хлопок: Индия, Мезоамерика
- Шёлк: только Китай (историческая монополия!)
- Кашемир: только горные регионы

### 2. «Бутылочные горлышки» текстиля

- **Без льна/конопли — нет парусов** → нет мореплавания
- **Без шерсти — нет кочевников** (юрты, войлок)
- **Без шёлка — нет премиум-товара для торговли на дальние расстояния**

### 3. Шёлк — стратегический ресурс

Историческая монополия Китая на шёлк → Великий Шёлковый путь → монополия на торговлю с Европой. В игре: игрок, контролирующий тутовое дерево + шелкопряда, имеет уникальный экспортный товар.

### 4. Джинн-революция

До хлопко-очистительной машины (1793) хлопок — редкий премиум. После — массовая дешёвая ткань. В игре: технологии джиннирования → бум производства хлопка.

### 5. Валяние vs ткачество

Валяние (войлок) — проще, доступно кочевникам. Ткачество — сложнее, требует станка. Кочевники могут делать войлок без станка → адаптация к мобильной жизни.

### 6. Парусная революция

Развитие мореплавания зависит от:
- Льна (тонкие паруса) — Средиземноморье
- Конопли (прочные паруса) — Северная Европа
- Сизаля (морские канаты) — Полинезия
