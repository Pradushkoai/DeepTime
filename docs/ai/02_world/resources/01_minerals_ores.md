# Минералы и руды (металлы)

> Самая большая и технологически важная категория ресурсов. Металлы — основа прогресса от медного века до железного.

---

## 🟢 Поверхностные (легкодоступные)

### Самородная медь (Native copper)

**Категория**: 🟢 Поверхностный
**Формула**: Cu (чистая медь)
**Виды**: самородки, налёты, вкрапления в породе
**Где встречается**: зоны окисления медных месторождений, базальты
**Реальные месторождения**:
- Верхнее озеро (США, Мичиган) — крупнейшие самородки до 10 тонн
- Корнуолл (Англия)
- Урал (Россия)
- Кирмана (Иран)
- Тимна (Израиль) — древнейшие медные рудники
**Как добывается**: сбор самородков с поверхности → примитивные шахты → штольни
**Инструменты**: каменные молоты, деревянные лопаты, позже — кирки
**Где используется**: медные орудия, ornaments, плавка → слитки
**Технологические цепочки**: самородная медь → холодная ковка → медные орудия; самородная медь + обжиг → медные слитки
**Альтернативы**: халькопирит (медный колчедан), малахит
**Особые свойства**: ковкая в холодном состоянии, первая металлургия — без плавки
**Источники**: USGS, Mindat.org, «The Ancient Copper Industry» (Wertime, 1973)

### Самородное золото (Native gold)

**Категория**: 🟢 Поверхностный
**Формула**: Au
**Виды**: самородки, россыпное (золотоносные пески), жильное
**Где встречается**: россыпи в реках, кварцевые жилы
**Реальные месторождения**:
- Долина Нила (Египет) — Нубия
- Лидия (Турция) — первые монеты
- Колхида (Грузия) — золотоносные реки
- Урал (Россия)
- Витватерсранд (ЮАР)
**Как добывается**: промывание россыпей, позже — подземные шахты
**Инструменты**: промывочные корыта, ковши, лотки
**Где используется**: украшения, монеты (позднее), религиозные предметы
**Технологические цепочки**: россыпное золото → промывка → самородки → плавка → слитки
**Альтернативы**: электрум (сплав золота с серебром, природный)
**Особые свойства**: не окисляется, ковкая
**Источники**: USGS, Mindat.org, «Gold in Antiquity» (Healy, 1999)

### Самородное серебро (Native silver)

**Категория**: 🟢 Поверхностный (редкий)
**Формула**: Ag
**Виды**: самородки, вкрапления
**Где встречается**: зоны окисления серебряных месторождений
**Реальные месторождения**:
- Лидия (Турция)
- Лаврион (Греция) — древнейшие серебряные рудники
- Потоси (Боливия) — крупнейшее месторождение в истории
**Как добывается**: сбор самородков → примитивные шахты
**Инструменты**: каменные/медные молоты, лопаты
**Где используется**: украшения, монеты (позднее), посуда
**Технологические цепочки**: самородное серебро → плавка → слитки → монеты/украшения
**Альтернативы**: аргентит (серебряный блеск), галенит с серебром
**Особые свойства**: ковкая, бактерицидная
**Источники**: USGS, Mindat.org

### Малахит (Malachite)

**Категория**: 🟢 Поверхностный
**Формула**: Cu₂(CO₃)(OH)₂ (карбонат меди)
**Виды**: зелёные натёки, почковидные агрегаты
**Где встречается**: зоны окисления медных месторождений
**Реальные месторождения**:
- Урал (Россия) — Меднорудянск
- Шабинаби (Конго)
- Тимна (Израиль)
**Как добывается**: сбор поверхностных натёков → шахты
**Инструменты**: молоты, лопаты
**Где используется**: декоративный камень, плавка → медь (важный источник!)
**Технологические цепочки**: малахит → обжиг 800°C → медь + CO₂ + H₂O
**Альтернативы**: азурит (синий аналог), хризоколла
**Особые свойства**: при обжиге даёт медь — критически важно для ранней металлургии
**Источники**: Mindat.org, USGS

### Азурит (Azurite)

**Категория**: 🟢 Поверхностный
**Формула**: Cu₃(CO₃)₂(OH)₂
**Виды**: синие кристаллы, натёки
**Где встречается**: с малахитом в зонах окисления
**Реальные месторождения**: как у малахита
**Как добывается**: сбор
**Где используется**: синий пигмент (важный!), плавка → медь
**Технологические цепочки**: азурит → помол → синяя краска; азурит → обжиг → медь
**Особые свойства**: первый «синий» пигмент древности
**Источники**: Mindat.org

### Самородная платина (Native platinum)

**Категория**: 🟢 Поверхностный (очень редкий)
**Формула**: Pt (с примесями других платиноидов)
**Где встречается**: россыпи в реках
**Реальные месторождения**:
- Чоко (Колумбия) — древнейшие находки
- Урал (Россия)
- Трансвааль (ЮАР)
**Как добывается**: промывание россыпей
**Где используется**: украшения (трудно плавится — Tплав=1768°C!)
**Технологические цепочки**: самородная платина → холодная ковка → украшения
**Особые свойства**: очень тугоплавкая, древние не могли её плавить → только ковали
**Источники**: USGS, Mindat.org

## 🟡 Подповерхностные (нужно исследовать + базовые инструменты)

### Халькопирит (медный колчедан)

**Категория**: 🟡 Подповерхностный
**Формула**: CuFeS₂
**Виды**: массивные руды, вкрапления
**Где встречается**: гидротермальные жилы, скарны
**Реальные месторождения**:
- Бингем (США)
- Чукикамата (Чили)
- Рио-Тинто (Испания) — древнейшие разработки
- Норильск (Россия)
**Как добывается**: подземные шахты → blasting → подъём руды
**Инструменты**: кирки, молоты, клинья, огневое разрушение породы
**Где используется**: плавка → медь (черновая) → рафинирование → чистая медь
**Технологические цепочки**: халькопирит → обжиг (sintering) → плавка → черновая медь → рафинирование → Cu
**Особые свойства**: основной источник меди в мире (50%+), но требует сложной плавки (сера!)
**Источники**: USGS, Mindat.org

### Касситерит (оловянный камень)

**Категория**: 🟡 Подповерхностный (но выходы есть на поверхности)
**Формула**: SnO₂
**Виды**: россыпное (вместе с самородным золотом), жильное
**Где встречается**: гранитные пегматиты, россыпи
**Реальные месторождения**:
- Корнуолл (Англия) — главный источник античности
- Бангка и Белитунг (Индонезия)
- Боливия (Ла-Пас)
- Малайя
- Приморье (Россия)
**Как добывается**: россыпное — промывка; жильное — шахты
**Инструменты**: кирки, промывочные корыта
**Где используется**: плавка → олово → сплав с медью = бронза
**Технологические цепочки**: касситерит + уголь → плавка ~1200°C → Sn → сплав с Cu = бронза
**Особые свойства**: **КРИТИЧЕСКИ ВАЖНЫЙ** — без олова нет бронзы. Исторический дефицит → торговые пути от Корнуолла до Средиземноморья
**Источники**: USGS, Mindat.org, Penhallurick, «Tin in Antiquity» (1986)

### Галенит (свинцовый блеск)

**Категория**: 🟡 Подповерхностный
**Формула**: PbS
**Виды**: массивный, вкрапленный
**Где встречается**: гидротермальные жилы
**Реальные месторождения**:
- Лаврион (Греция) — древнейшие
- Корнуолл (Англия)
- Бингем (США)
- Горная Шория (Россия)
**Как добывается**: шахты
**Инструменты**: кирки, клинья, огневое разрушение
**Где используется**: плавка → свинец; **источник серебра** (галенит с Ag)
**Технологические цепочки**: галенит + уголь → плавка ~1100°C → Pb + SO₂; рафинирование → серебро
**Особые свойства**: основной источник серебра в античности (cupellation process)
**Источники**: USGS, Mindat.org, «Silver in Antiquity» (Patterson, 1972)

### Сфалерит (цинковая обманка)

**Категория**: 🟡 Подповерхностный
**Формула**: ZnS
**Где встречается**: с галенитом
**Реальные месторождения**:
- Раммельсберг (Германия) — ср. века
- Бингем (США)
- Нерчинск (Россия)
**Как добывается**: шахты
**Где используется**: латунь (Cu + Zn), позже — цинк
**Технологические цепочки**: сфалерит → обжиг → ZnO → восстановление → Zn; Zn + Cu = латунь
**Особые свойства**: цинк летучий, древним сложно было получить чистым → только сплав латунь
**Источники**: USGS, Mindat.org

### Гематит (красный железняк)

**Категория**: 🟡 Подповерхностный (но много поверхностного)
**Формула**: Fe₂O₃
**Виды**: плотный, чешуйчатый (мичиковая руда), почковидный
**Где встречается**: осадочные месторождения, зоны окисления
**Реальные месторождения**:
- Эльба (Италия)
- Корнуолл (Англия)
- Кривбасс (Украина)
- Курская магнитная аномалия (Россия)
**Как добывается**: поверхностные сборы → шахты → карьеры
**Инструменты**: кирки, лопаты
**Где используется**: красный пигмент (древний!), позже — плавка → железо
**Технологические цепочки**: гематит → помол → охра (красная краска); гематит + уголь + воздух → плавка 1500°C → железо
**Особые свойства**: «кровавый камень» — использовался как краска за 70 000 лет до металлургии
**Источники**: USGS, Mindat.org

### Магнетит (магнитный железняк)

**Категория**: 🟡 Подповерхностный
**Формула**: Fe₃O₄
**Виды**: массивный, пески
**Где встречается**: магматические месторождения, россыпи
**Реальные месторождения**:
- Кируна (Швеция)
- Соколовско-Сарбайское (Казахстан)
- Магнитогорск (Россия) — название говорит
**Как добывается**: шахты, карьеры
**Где используется**: плавка → железо
**Технологические цепочки**: магнетит → обогащение → плавка → железо
**Особые свойства**: магнитные свойства (использовался для компасов в Китае)
**Источники**: USGS, Mindat.org

### Лимонит (бурый железняк)

**Категория**: 🟡 Подповерхностный
**Формула**: FeO(OH)·nH₂O (смесь гётита и др.)
**Виды**: землистые массы, конкреции, болотная руда
**Где встречается**: болота, зоны окисления
**Реальные месторождения**:
- Болотные руды Скандинавии
- Лотарингия (Франция)
**Как добывается**: сбор из болот,浅кие ямы
**Инструменты**: лопаты, корзины
**Где используется**: плавка → железо (низкого качества)
**Технологические цепочки**: лимонит → сушка → обжиг → плавка → железо
**Особые свойства**: доступен в северных регионах без крупных месторождений → «болотное железо» кельтских и скандинавских кузнецов
**Источники**: USGS, Mindat.org

### Сидерит (железный шпат)

**Категория**: 🟡 Подповерхностный
**Формула**: FeCO₃
**Виды**: массивный, конкреции
**Где встречается**: осадочные месторождения
**Реальные месторождения**:
- Штирия (Австрия)
- Эрцбергирге (Германия)
- Кривбасс (Украина)
**Как добывается**: шахты
**Где используется**: плавка → железо
**Технологические цепочки**: siderite → обжиг → оксид → восстановление → железо
**Особые свойства**: при обжиге выделяет CO₂, требуя дополнительной обработки
**Источники**: USGS, Mindat.org

### Куприт

**Категория**: 🟡 Подповерхностный
**Формула**: Cu₂O
**Виды**: кристаллы, землистые массы
**Где встречается**: зоны окисления медных месторождений
**Реальные месторождения**: Бисби (США), Чукикамата (Чили)
**Как добывается**: шахты
**Где используется**: красный пигмент, плавка → медь
**Технологические цепочки**: куприт → восстановление → Cu
**Источники**: Mindat.org

### Халькозин (медный блеск)

**Категория**: 🟡 Подповерхностный
**Формула**: Cu₂S
**Где встречается**: с халькопиритом
**Реальные месторождения**: Бутт (США), Норильск (Россия)
**Как добывается**: шахты
**Где используется**: плавка → медь
**Технологические цепочки**: халькозин → обжиг + плавка → Cu
**Особые свойства**: богатая медью руда (79.8% Cu)
**Источники**: Mindat.org

## 🔴 Глубокие (нужно дорасти: металлургия, шахты, специализация)

### Хромит

**Категория**: 🔴 Глубокий
**Формула**: FeCr₂O₄
**Где встречается**: ультраосновные породы
**Реальные месторождения**:
- Бушвельд (ЮАР)
- Кемпирсайское (Казахстан)
- Сараны (Россия, Урал)
**Как добывается**: глубокие шахты
**Где используется**: тугоплавкие сплавы, ювелирное дело (хром + Fe = нержавейка)
**Технологические цепочки**: хромит + Al → термитная реакция → Cr
**Особые свойства**: тугоплавкий — нужен для продвинутых металлургических процессов
**Источники**: USGS, Mindat.org

### Пентландит

**Категория**: 🔴 Глубокий
**Формула**: (Fe,Ni)₉S₈
**Где встречается**: сульфидные месторождения
**Реальные месторождения**: Садбери (Канада), Норильск (Россия)
**Как добывается**: глубокие шахты
**Где используется**: плавка → никель → сплав с медью (cupronickel) → монеты
**Технологические цепочки**: пентландит → плавка → Ni → сплав Cu+Ni = cupronickel
**Особые свойства**: основной источник никеля
**Источники**: USGS, Mindat.org

### Киноварь (Cinnabar)

**Категория**: 🔴 Глубокий (но выходы есть)
**Формула**: HgS (сульфид ртути)
**Где встречается**: гидротермальные жилы
**Реальные месторождения**:
- Альмаден (Испания) — крупнейшее в истории
- Идрия (Словения)
- Хайдаркан (Кыргызстан)
- Никитовка (Украина)
**Как добывается**: шахты
**Где используется**: красная краска (важнейшая!), → ртуть при обжиге
**Технологические цепочки**: киноварь → помол → vermilion (красная краска); киноварь → обжиг 500°C → Hg (ртуть)
**Особые свойства**: токсична (Hg!), но давала единственный ярко-красный пигмент в древности
**Источники**: USGS, Mindat.org, Gettens, «The Materials of Painting» (1942)

### Стибнит (Antimonite)

**Категория**: 🔴 Глубокий
**Формула**: Sb₂S₃
**Где встречается**: гидротермальные жилы
**Реальные месторождения**: Китай (Сычуань), Боливия, Россия
**Как добывается**: шахты
**Где используется**: чёрная краска для бровей/глаз (Древний Египет!), позже — сплав с Pb
**Технологические цепочки**: стибнит → помол → чёрная краска; стибнит → плавка → Sb
**Особые свойства**: древнейшее использование — косметика в Египте и Месопотамии
**Источники**: Mindat.org

### Барит

**Категория**: 🔴 Глубокий
**Формула**: BaSO₄
**Где встречается**: гидротермальные жилы
**Где используется**: утяжелитель, позже — краска (литопон)
**Технологические цепочки**: барит → помол → краска; барит → восстановление → Ba
**Источники**: USGS, Mindat.org

### Витерит

**Входящие связи**: продукт выветривания баритовых месторождений
**Исходящие связи**: источник бария → [13_salts_minerals_chem.md](13_salts_minerals_chem.md)
**Роль**: редкий минерал, источник Ba

**Категория**: 🔴 Глубокий
**Формула**: BaCO₃
**Особые свойства**: редкий, источник бария
**Источники**: Mindat.org

### Церуссит (свинцовые белила)

**Категория**: 🔴 Глубокий
**Формула**: PbCO₃
**Где встречается**: зоны окисления галенита
**Где используется**: белая краска (свинцовые белила), ювелирное стекло
**Технологические цепочки**: церуссит → помол → белила; церуссит → плавка → Pb
**Особые свойства**: токсичен, но тысячелетиями главный белый пигмент
**Источники**: Mindat.org

### Англезит

**Категория**: 🔴 Глубокий
**Формула**: PbSO₄
**Где встречается**: зоны окисления галенита
**Где используется**: источник свинца и серебра
**Источники**: Mindat.org

### Аргентит (серебряный блеск)

**Категория**: 🔴 Глубокий
**Формула**: Ag₂S
**Где встречается**: с галенитом
**Где используется**: источник серебра
**Технологические цепочки**: аргентит → плавка → Ag
**Особые свойства**: основной источник серебра в Испании и Мексике
**Источники**: Mindat.org

### Бернатит, урановая смолка (Pitchblende)

**Категория**: 🔴 Глубокий (очень глубокий, поздняя технология)
**Формула**: UO₂ (с примесями)
**Где встречается**: гидротермальные жилы
**Где используется**: только в поздние эпохи, для радиоактивных материалов
**Особые свойства**: радиоактивность — не нужна в древнем периоде
**Источники**: USGS, Mindat.org

### Алунит

**Категория**: 🔴 Глубокий
**Формула**: KAl₃(SO₄)₂(OH)₆
**Где встречается**: вулканические области
**Где используется**: источник квасцов (дубление кож, красители)
**Технологические цепочки**: алунит → обработка → квасцы → дубление шкур → кожа
**Особые свойства**: важен для кожевенного производства
**Источники**: USGS, Mindat.org

## Цикл развития металлургии (концептуальная сводка)

```
1. 🟢 Самородные металлы (Cu, Au, Ag, Pt)
   ↓ холодная ковка, простые орудия
   
2. 🟢 Карбонаты меди (малахит, азурит)
   ↓ обжиг 800-900°C → медь
   
3. 🟡 Оксиды железа (гематит, лимонит) — как краска
   ↓ помол → охра
   
4. 🟡 Сульфиды меди (халькопирит, халькозин)
   ↓ сложная плавка с обжигом → Cu
   
5. 🟡 Касситерит (олово)
   ↓ плавка 1200°C → Sn → бронза (Cu+Sn)
   
6. 🟡 Галенит (свинец + серебро)
   ↓ плавка 1100°C → Pb + Ag (cupellation)
   
7. 🔴 Оксиды железа (как металл)
   ↓ плавка 1500°C с огнеупорами → железо
   
8. 🔴 Сульфиды никеля (пентландит)
   ↓ сложная плавка → Ni → сплавы
   
9. 🔴 Киноварь → ртуть (токсичная, поздняя)
   ↓ обжиг 500°C → Hg
```
