# Пряности и лекарственные травы

> Пряности — стратегический товар древности, ценились на вес золота. Лекарственные травы — единственная «фармация» до синтетики. Многие вещества работают как и пряность, и лекарство (душистое + лечебное).

---

## 🟢 Европейские/средиземноморские (легкодоступные)

### Укроп (Dill / Anethum graveolens)

**Биом**: средиземноморский, умеренный
**География**: Средиземноморье (родина)
**Используемая часть**: листья, семена
**Применение**:
- Приправа (пища)
- Лекарство (от колик, газов)
- Эфирное масло
**Особые свойства**: древняя культура Египта и Рима
**Источники»: Vavilov Centers, POWO

### Тмин (Caraway / Carum carvi)

**Биом**: умеренный
**География**: Европа, Азия
**Используемая часть**: семена
**Применение**: приправа (хлеб, сыр), лекарство (от колик)
**Источники»: POWO

### Анис (Anise / Pimpinella anisum)

**Биом**: средиземноморский
**География**: Египет, Греция
**Используемая часть**: семена
**Применение**:
- Приправа
- Лекарство (откашляющее, от газов)
- Ароматизатор для алкоголя (anisette, ouzo, ракы, абсент — позднее)
**Особые свойства**: один из древнейших aromatиков
**Источники»: Vavilov Centers

### Фенхель (Fennel / Foeniculum vulgare)

**Биом**: средиземноморский
**География**: Средиземноморье
**Используемая часть**: листья, семена, корень
**Применение**:
- Приправа
- Лекарство (от газов, откашляющее)
- Овощ (корень)
**Особые свойства**: считался символом мужественности у греков
**Источники»: POWO

### Розмарин (Rosemary / Rosmarinus officinalis)

**Биом**: средиземноморский
**География**: Средиземноморье
**Используемая часть**: листья
**Применение**:
- Приправа (мясо, рыба)
- Лекарство (улучшение памяти, волосы)
- Религия (брачные венки)
**Особые свойства**: вечнозелёный → символ вечной любви
**Источники»: POWO

### Тимьян (Thyme / Thymus vulgaris)

**Биом**: средиземноморский
**География**: Средиземноморье
**Применение**:
- Приправа
- Лекарство (антисептик, откашляющее)
- Дезинфекция (тимол — антисептик)
**Особые свойства**: древние египтяне использовали для бальзамирования
**Источники»: POWO

### Шалфей (Sage / Salvia officinalis)

**Биом**: средиземноморский
**Применение**:
- Приправа (жирное мясо)
- Лекарство (от воспалений, антисептик)
- Религия (лат. «salvare» — спасать)
**Особые свойства**: «спасительный» — священное растение
**Источники»: POWO

### Мята (Mint / Mentha spp.)

**Биом**: умеренный
**География**: Европа, Азия
**Виды**: мята перечная, кудрявая, полевая
**Применение**:
- Приправа (чай)
- Лекарство (от газов, пищеварение)
- Эфирное масло
**Особые свойства**: упоминается в Библии как десятина
**Источники»: POWO

### Майоран (Marjoram / Origanum majorana)

**Биом**: средиземноморский
**Применение**: приправа, лекарство
**Источники»: POWO

### Орегано / Душица (Oregano / Origanum vulgare)

**Биом**: средиземноморский
**Применение**: приправа (главное для пиццы!), антисептик
**Источники»: POWO

### Лавр / Лавровый лист (Bay laurel / Laurus nobilis)

**Биом**: средиземноморский
**Применение**:
- Приправа (главное в средиземноморской кухне)
- Религия (венки для победителей — «лауреат»)
- Лекарство
**Особые свойства**:
- Символ победы (греческие/римские победители)
- Аполлон в лавровом венке
**Источники»: POWO

### Шафран (Saffron / Crocus sativus)

**Биом**: субтропический
**География**: Иран (главный сейчас), Греция (родина), Кашмир
**Используемая часть**: рыльца цветков (трудоёмкий сбор — 150 000 цветков = 1 кг!)
**Применение**:
- **Приправа** (главная для паэльи, ризотто)
- **Краситель** (жёлтый — самый дорогой)
- Лекарство (антидепрессант)
- Парфюм
**Особые свойства**:
- **Самый дорогой продукт на вес** (дороже золота!)
- Исторически: иранская/греческая монополия
- В игре: сверх-премиум товар
**Источники»: Vavilov Centers, POWO

### Асафетида (Asafoetida / Ferula assafoetida)

**Биом**: полусухой
**География**: Иран, Афганистан
**Используемая часть**: смола корня
**Применение**:
- Приправа (главная в индийской кухне — «хинг»)
- Лекарство (от газов, антисептик)
**Особые свойства**: сильный запах → «дьявольский навоз» в Европе, «божественная пища» в Индии
**Источники»: POWO

### Сумах (Sumac / Rhus coriaria)

**Биом**: средиземноморский
**География**: Ближний Восток
**Применение**: приправа (кислая), дубильное вещество (для кож)
**Источники»: POWO

## 🟡 Восточные пряности (требуют выращивания и торговли)

### Чёрный перец (Black pepper / Piper nigrum)

**Биом**: тропический влажный
**География**: Малабарское побережье Индии (родина)
**Используемая часть**: незрелые плоды (сушатся)
**Цвет**: чёрный (незрелый), белый (спелый без кожуры), зелёный (свежий)
**Применение**:
- **Приправа** (главная в Европе до 16 в.!)
- Лекарство (антисептик)
- Консервант
**Особые свойства**:
- **Историческая индийская монополия** → Великое открытие (Колумб, Васко да Гама) — ради перца!
- Ценился на вес золота (буквально)
- В игре: главный товар Дальнего Востока → Европы
- Торговые пути через Аравию → обогащение арабов
**Источники»: Vavilov Centers, FAO

### Кардамон (Cardamom / Elettaria cardamomum)

**Биом**: тропический горный
**География**: Гаты (Индия), Гватемала (позднее)
**Используемая часть**: семена в стручках
**Применение**:
- Приправа (индийская, скандинавская кухни)
- Лекарство (пищеварение)
- Парфюм
**Особые свойства**:
- Третья по дороговизне пряность (после шафрана и ванили)
- В игре: премиум-товар
**Источники»: Vavilov Centers

### Гвоздика (Clove / Syzygium aromaticum)

**Биом**: тропический остров
**География**: Молуккские острова (Индонезия) — «Острова пряностей»
**Используемая часть**: бутоны цветов
**Применение**:
- Приправа
- Лекарство (зубная боль — обезболивающее эвгенол)
- Консервант (антисептик)
**Особые свойства**:
- **Монополия Молуккских островов** (до 18 в.)
- Голландцы монополизировали торговлю → насильственное уничтожение плантаций на других островах
- В игре: сверх-премиум, монополия Островов Пряностей
**Источники»: Vavilov Centers

### Мускатный орех / Мускатный цвет (Nutmeg / Mace / Myristica fragrans)

**Биом**: тропический остров
**География**: Банда (Молуккские острова)
**Используемая часть**: семя (мускат) и присемянник (масис/мускатный цвет)
**Применение**:
- Приправа (европейская кухня, индийская)
- Лекарство (галлюциноген в больших дозах!)
- Консервант
**Особые свойства**:
- **Монополия островов Банда** (до 18 в.)
- Исторически — голландская монополия → кровавые войны
- В игре: стратегический товар Островов Пряностей
**Источники»: Vavilov Centers

### Корица (Cinnamon / Cinnamomum verum)

**Биом**: тропический
**География**: Шри-Ланка (Цейлон, родина)
**Используемая часть**: кора (снимается слой)
**Применение**:
- Приправа (сладкая, европейская кухня)
- Лекарство (антисептик, пищеварение)
- Бальзамирование (Древний Египет — для мумий!)
**Особые свойства**:
- **Монополия Шри-Ланки** (античность)
- Позже: кассия (Cinnamomum cassia) из Китая — заменитель
- В игре: стратегический товар Цейлона
**Источники»: Vavilov Centers, POWO

### Имбирь (Ginger / Zingiber officinale)

**Биом**: тропический
**География**: ЮВ Азия (родина), Индия
**Используемая часть**: корневище
**Применение**:
- Приправа (азиатская кухня, европейская — для пряников)
- Лекарство (от тошноты, антиоксидант)
**Особые свойства**:
- Древний торговый товар (через Шёлковый путь)
- Исторически: арабская торговля в Европу
**Источники»: Vavilov Centers

### Куркума (Turmeric / Curcuma longa)

**Биом**: тропический
**География**: Индия (родина)
**Используемая часть**: корневище
**Применение**:
- Приправа (главная в индийском карри)
- **Краситель** (жёлтый — пищевая окраска)
- Лекарство (куркумин — противовоспалительное)
- Религия (индуизм — ритуалы)
**Особые свойства**:
- Исторически: индийская монополия
- В игре: двойное применение (пряность + краситель)
**Источники»: Vavilov Centers

### Калган / Галанга (Galangal / Alpinia galanga)

**Биом**: тропический
**География**: ЮВ Азия
**Применение**: приправа (тайская кухня), лекарство
**Источники»: POWO

### Тамаринд (Tamarind / Tamarindus indica)

**Биом**: тропический
**География**: Африка (родина), Индия (главное применение)
**Используемая часть**: плоды (кислые)
**Применение**:
- Приправа (кислая — индийские чатни, вустерский соус)
- Напиток (тамариндовый сок)
- Лекарство (слабительное)
**Источники»: Vavilov Centers

### Чили / Острый перец (Chili / Capsicum spp.)

**Биом**: тропический, субтропический
**География**: Мезоамерика (родина)
**Виды**: Capsicum annuum (сладкий), C. frutescens (табаско), C. chinense (хабанеро)
**Применение**:
- Приправа (главная в Мезоамерике, Азии после Колумба)
- Лекарство (антибактериальное, обезболивающее)
- Защитное средство (перцовый баллончик — позднее)
**Особые свойства**:
- Американское происхождение → после Колумба распространился в Азии
- Стал главной острой пряностью Азии (заменил чёрный перец)
- В игре: только в Мезоамерике на старте
**Источники»: Vavilov Centers

### Ваниль (Vanilla / Vanilla planifolia)

**Биом**: тропический
**География**: Мексика (родина — только там растёт опылитель — пчела Melipona)
**Используемая часть**: стручки (ферментированные)
**Применение**:
- Ароматизатор (премиум — после шафрана по цене)
- Парфюм
- Лекарство
**Особые свойства**:
- Историческая монополия Мексики (только там опылитель!)
- Без пчелы — нужно ручное опыление (открыто в 1841 г.)
- В игре: монополия мезоамериканских цивилизаций
**Источники»: Vavilov Centers

## 🟡 Лекарственные травы (отдельная категория)

### Алоэ (Aloe / Aloe vera)

**Биом**: полусухой тропический
**География**: Аравия (родина), повсеместно
**Применение**:
- Лекарство (ожоги, раны — гель из листьев)
- Косметика
**Особые свойства**: антибактериальное, заживляющее
**Источники»: POWO

### Опиумный мак (Opium poppy / Papaver somniferum)

**Биом**: умеренный
**География**: Средиземноморье (родина)
**Используемая часть**: млечный сок (опиум), семена (пищевые)
**Применение**:
- **Лекарство** (обезболивающее — морфин, кодеин)
- **Наркотик** (опиум, героин — позднее)
- Пищевое масло (маковое)
- Семена (выпечка)
**Особые свойства**:
- Древнейшее обезболивающее (4000 до н.э. — Шумер)
- Исторически: критический медицинский препарат
- В игре: критически важно для медицины → стратегическое растение
**Источники»: Vavilov Centers, IUCN

### Эфедра / Ма-хуан (Ephedra / Ephedra sinica)

**Биом**: полусухой
**География**: Центральная Азия, Китай
**Применение**: лекарство (от астмы, насморка — эфедрин)
**Особые свойства**: стимулятор, использовался в шаманизме
**Источники»: POWO

### Белладонна (Belladonna / Atropa belladonna)

**Биом**: умеренный
**География**: Европа
**Применение**:
- Лекарство (атропин — расширяет зрачки, антиспазматическое)
- Яд (тропаны — токсичны)
**Особые свойства**:
- Исторически: «ведьмин трава» (содержит галлюциногены)
- В игре: критическое лекарство, но требует осторожности
**Источники»: POWO

### Наперстянка (Foxglove / Digitalis purpurea)

**Биом**: умеренный
**География**: Европа
**Применение**: лекарство (сердечные гликозиды — дигоксин)
**Особые свойства**:
- Критически важное для сердечных болезней
- Открытие Уильяма Уизеринга (1785)
- В игре: только в поздние эпохи (требует развития фармации)
**Источники»: POWO

### Хинное дерево (Cinchona)

**Биом**: тропический горный
**География**: Анды (родина)
**Применение**: лекарство (хинин — против малярии)
**Особые свойства**:
- Критически важное для колонизации Африки (малярия!)
- Историческая монополия Перу/Боливии (до 17 в.)
- В игре: монополия Андского региона
**Источники»: Vavilov Centers

### Полынь (Wormwood / Artemisia absinthium)

**Биом**: умеренный
**География**: Европа, Азия
**Применение**:
- Лекарство (антипаразитическое)
- Алкоголь (абсент — позднее)
**Особые свойства**: антигельминтное действие
**Источники»: POWO

### Валериана (Valeriana officinalis)

**Биом**: умеренный
**Применение**: успокоительное, седативное
**Источники»: POWO

### Женьшень (Panax ginseng)

**Биом**: boreal, горный
**География**: Маньчжурия, Корея (родина), Китай, Восточная Россия
**Применение**: адаптоген, тоник, лекарство
**Особые свойства**:
- «Корень жизни» в китайской медицине
- Историческая монополия Маньчжурии/Кореи
- Очень дорогой (дикий женьшень)
**Источники»: Vavilov Centers

### Ромашка (Chamomile / Matricaria chamomilla)

**Биом**: умеренный
**Применение**: лекарство (успокоительное, противовоспалительное), чай
**Источники»: POWO

### Эвкалипт (Eucalyptus)

**Биом**: субтропический
**География**: Австралия (родина)
**Применение**:
- Лекарство (эфирное масло — от кашля, антисептик)
- Дерево (древесина, смола)
**Особые свойства**: 
- Австралийское растение
- В игре: стратегический товар аборигенов
**Источники**: POWO

### Аконит / Борец (Aconitum napellus)

**Биом**: горный
**География**: Европа, Азия
**Применение**: 
- Яд (стрелы — у древних германцев и монголов)
- Лекарство (в гомеопатии)
**Особые свойства**: 
- Один из самых ядовитых растений Европы
- Использовался для отравленных стрел
**Источники»: POWO

### Кока (Coca / Erythroxylum coca)

**Биом**: горный тропический
**География**: Анды (родина)
**Применение**:
- Лекарство (кокаин — местная анестезия)
- Стимулятор (листья жевать — для работы на высоте)
**Особые свойства**:
- Историческая монополия Андов
- Основа инкского ритуала и труда
- В игре: стратегическое растение Андского региона
**Источники»: Vavilov Centers

### Чай (Tea / Camellia sinensis)

**Биом**: субтропический горный
**География**: Китай (Юньнань, родина)
**Используемая часть**: листья (ферментированные или нет)
**Виды**: зелёный (неферментированный), чёрный (ферментированный), улун (полуферментированный)
**Применение**:
- Напиток (главный в Восточной Азии)
- Лекарство (антиоксидант)
- Стимулятор (кофеин)
**Особые свойства**:
- Историческая китайская монополия (до 19 в.)
- Чайный путь (через Россию — караванами)
- В игре: стратегический экспорт Китая
**Источники»: Vavilov Centers

### Кофе (Coffee / Coffea arabica)

**Биом**: горный тропический
**География**: Эфиопия (родина — Каффа), Йемен (первое выращивание)
**Используемая часть**: семена (бобы)
**Применение**:
- Напиток (главный стимулятор мира)
- Лекарство
**Особые свойства**:
- Историческая монополия Йемена (Мокко) в 15-17 вв.
- Контрабанда в Европу → голландские плантации на Яве
- В игре: стратегический товар Эфиопии/Йемена
**Источники»: Vavilov Centers

### Какао (Cocoa / Theobroma cacao)

**Биом**: тропический влажный
**География**: Мезоамерика (родина)
**Используемая часть**: семена (бобы)
**Применение**:
- Напиток (главный в Мезоамерике — шоколад!)
- Валюта (ацтеки — бобы какао = деньги!)
- Лекарство (стимулятор)
**Особые свойства**:

## Цикл развития пряностей

```
1. 🟢 Европейские травы (укроп, тмин, анис, фенхель, мята, лавр)
   ↓ позволяет: средиземноморская кухня
   
2. 🟡 Восточные пряности через Шёлковый путь (перец, корица, имбирь)
   ↓ позволяет: элитная европейская кухня, монополия арабов
   
3. 🟡 Лекарственные травы (опиум, белладонна, наперстянка)
   ↓ позволяет: фармация, обезболивающее
   
4. 🔴 Молуккские пряности (гвоздика, мускат) → морская революция
   ↓ позволяет: поиск морского пути в Индию (Колумб, Васко да Гама)
   
5. 🔴 Американские растения (ваниль, чили, какао, кока, хинин)
   ↓ позволяет: новые монополии, новая медицина
   
6. 🔴 Чай и кофе (стимуляторы) → социальная революция
   ↓ позволяет: кофейни, новые общественные места
```

## Принципы для дизайна

### 1. Монополии пряностей = монополии торговли

- Чёрный перец → Малабар (Индия)
- Гвоздика → Молуккские острова
- Мускат → острова Банда
- Корица → Шри-Ланка
- Шафран → Иран/Греция

В игре: контроль этих мест = контроль стратегической торговли.

### 2. Пряности как деньги

- Бобы какао = валюта ацтеков
- Шафран = вес золота в Европе

В игре: пряности могут быть «твёрдой валютой» в торговле.

### 3. Медицинские растения — стратегический ресурс

- Опиум (Шумер, Египет) — обезболивающее
- Хинин (Анды) — противомалярийное (критично для колонизации Африки!)
- Кока (Анды) — стимулятор для работы на высоте

В игре: наличие конкретных лекарств → расширение возможностей (колонизация тропиков без хинина — невозможна).

### 4. Колониальная революция через пряности

Европа искала путь в Индию ради перца и гвоздики → открыла Америку (Колумб) и морской путь в Индию (Васко да Гама). В игре: мотивация для морской экспансии.

### 5. Чай и кофе — социальные революции

Кофейни в Европе 17 в. → места политической дискуссии → Столетняя революция, Просвещение. Чай в Англии → викторианская культура. В игре: стимуляторы → социальные изменения.

### 6. Бутылочные горлышки

- Без опиума → нет обезболивающего → нет серьёзной хирургии
- Без хинина → нельзя колонизировать тропики (малярия)
- Без перца → нет острой европейской кухни (и нет стимула к мореплаванию!)
