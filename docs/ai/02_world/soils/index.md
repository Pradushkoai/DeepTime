# Почвы — Индекс связей (Принцип 10: обязательная связность)

> 📋 **Этот файл — структурированный индекс всех 32 Reference Soil Groups (RSG) по WRB**. Каждый элемент имеет ID, категорию, входящие/исходящие связи, альтернативы, роль. Содержит все связи, необходимые для валидации (Принцип 11).

---

## 🎯 Принципы индекса

1. **ID-система**: S-001 ... S-032 (S = Soil)
2. **Категория**: по плодородию — 🟢 (высокое), 🟡 (среднее), 🔴 (низкое)
3. **Входящие связи**: биом → климат → материнская порода → почва
4. **Исходящие связи**: → ресурсы (пища, торф, соль, глина), → процессы (осушение, известкование, террасирование), → технологии (земледелие T-015, ирригация T-016)
5. **Альтернативы**: какие почвы заменяют данную в её функциях
6. **Роль**: бутылочное горлышко? критично для региона? рядовой?

## 🔗 Карточки почв со связями

### S-001: Histosols (торфяные)

**Категория**: 🔴 → 🟢 (после осушения)
**Состав**: 100% органика (торф), без минеральной основы
**Процесс**: накопление неразложившейся органики в условиях переувлажнения

**Входящие связи** (из чего формируется):
- биом → [тундра, болота] (../geography.md)
- климат → холодный/влажный (замедляет разложение)
- материнская порода → органика (растения)

**Исходящие связи** (для чего нужен):
- ресурс: [торф](../resources/04_organic_fuels.md) ⭐ (топливо — основной до угля)
- процесс: осушение → [рисовые поля](../resources/08_food_resources.md) (после осушения — высокоурожайные)
- технология: → [T-015 Земледелие](../../06_technology/tech_tree.md) (после осушения)

**Альтернативы**:
- как топливо: [древесина](../resources/05_wood_timber.md), [древесный уголь](../02_world/processed_materials/01_fuel_products.md), [каменный уголь](../resources/04_organic_fuels.md) (S-001 → S-018, S-019 при высыхании)
- как поле: [Gleysols S-003](#s-003-gleysols-глеевые) (тоже рисовые поля после дренажа)

**Роль**: **бутылочное горлышко для топлива** в тундре/субарктике (без леса → торф = единственное топливо)

---

### S-002: Cryosols (мерзлотные)

**Категория**: 🔴
**Состав**: почвы с вечной мерзлотой
**Процесс**: мёрзлые, низкое плодородие

**Входящие связи**:
- биом → [Арктика, тундра] (Сибирь, Канада, Аляска)
- климат → вечная мерзлота

**Исходящие связи**:
- технология: → охота/собирательство (с/х невозможен)
- ресурс: → [северный олень](../fauna/README.md) (пастбища)

**Альтернативы**: НЕТ — единственная почва Арктики. Заменяется через [T-032 Кочевое скотоводство](../../06_technology/tech_tree.md) (оленеводство)

**Роль**: критично для арктических племён — без оленеводства нет выживания

---

### S-003: Gleysols (глеевые)

**Категория**: 🟡 → 🟢 (после дренажа)
**Состав**: глей (Fe²⁺ — голубой), заболоченные
**Процесс**: постоянное переувлажнение

**Входящие связи**:
- биом → [поймы рек, низины]
- процесс → [дождевые осадки, грунтовые воды]

**Исходящие связи**:
- культура: → [рис](../resources/08_food_resources.md) (затопляемые поля)
- культура: → [тростник](../resources/06_fibers_textiles.md) (для кровли, корзин)
- процесс: → дренаж (T-016 Ирригация — обратная сторона)
- технология: → [T-015 Земледелие](../../06_technology/tech_tree.md) (после дренажа)

**Альтернативы**:
- как рисовое поле: [Fluvisols S-014](#s-014-fluvisols-аллювиальные) (речные поймы), [Planosols S-020](#s-020-planosols-сезонно-заболоченные)

**Роль**: рядовой — основные рисовые поля Азии

---

### S-004: Andosols (вулканические)

**Категория**: 🟢🟢 (очень высокое)
**Состав**: почвы на вулканическом пепле
**Процесс**: выветривание вулканического пепла

**Входящие связи**:
- биом → [зоны вулканизма] (Япония, Исландия, Камчатка, Анды, Италия)
- материнская порода → [вулканический пепел](../resources/02_stone_construction.md)
- ресурс → [пуццолан](../02_world/processed_materials/02_chemical_products.md) (вулканическая зола — побочный продукт)

**Исходящие связи**:
- культура: → любые (высокая урожайность)
- материал: → [пуццолан](../02_world/processed_materials/02_chemical_products.md) (для римского бетона T-071)
- технология: → [T-015 Земледелие](../../06_technology/tech_tree.md), → [T-071 Римский бетон](../../06_technology/tech_tree.md) (через пуццолан)

**Альтернативы**:
- как «золотые» почвы: [Chernozems S-007](#s-007-чernozems-чернозёмы) (степи), [Fluvisols S-014](#s-014-fluvisols-аллювиальные) (речные долины)

**Роль**: **бутылочное горлышко для пуццолана** → римский бетон → акведуки. Без Andosols нет пуццолана.

---

### S-005: Vertisols (текстурные)

**Категория**: 🟡
**Состав**: глинистые, сильное набухание/усадка
**Процесс**: трещины при высыхании (50 см глубиной)

**Входящие связи**:
- биом → [саванны, субтропики] (Австралия, Индия, Техас, Судан)
- климат → сезонные дожди/засуха

**Исходящие связи**:
- культура: → [хлопок](../resources/06_fibers_textiles.md), [пшеница](../resources/08_food_resources.md), [рис](../resources/08_food_resources.md)
- процесс: → самовзрыхление (выгодно для обработки без плуга)
- технология: → [T-017 Плуг](../../06_technology/tech_tree.md) (трудно пахать, но урожайно)

**Альтернативы**: [Kastanozems S-006](#s-006-kastanozems-каштановые-почвы), [Chernozems S-007](#s-007-чernozems-чернозёмы) (легче пахать)

**Роль**: рядовой — хлопковые поля Индии/Техаса

---

### S-006: Kastanozems (каштановые почвы)

**Категория**: 🟡
**Состав**: средний гумус, нейтральный pH
**Процесс**: степное почвообразование

**Входящие связи**:
- биом → [степи] (Украина, Россия, Великие Равнины, Аргентина)
- климат → умеренно-засушливый

**Исходящие связи**:
- культура: → [пшеница](../resources/08_food_resources.md), [ячмень](../resources/08_food_resources.md), [подсолнечник](../resources/08_food_resources.md)
- технология: → [T-015 Земледелие](../../06_technology/tech_tree.md), → [T-017 Плуг](../../06_technology/tech_tree.md)

**Альтернативы**: [Chernozems S-007](#s-007-чernozems-чернозёмы) (лучше, но реже), [Phaeozems S-008](#s-008-phaeozems-серые-лесные)

**Роль**: рядовой — степное земледелие

---

### S-007: Chernozems (чернозёмы)

**Категория**: 🟢🟢 (очень высокое — самые плодородные)
**Состав**: 7-15% гумус, нейтральный pH, мощный горизонт
**Процесс**: степное почвообразование (многолетние травы)

**Входящие связи**:
- биом → [Великая Степь] (Украина, Россия, Казахстан, Велик. Равнины, Пампасы)
- климат → умеренно-континентальный

**Исходящие связи**:
- культура: → [пшеница](../resources/08_food_resources.md) (главный «житница»!), [кукуруза](../resources/08_food_resources.md), [подсолнечник](../resources/08_food_resources.md), [сахарная свёкла](../resources/08_food_resources.md)
- технология: → [T-015 Земледелие](../../06_technology/tech_tree.md), → [T-017 Плуг](../../06_technology/tech_tree.md), → [T-084 Трёхполье](../../06_technology/tech_tree.md)
- эффект: урожай 3000-5000 кг/га (vs 1000-2000 на других)

**Альтернативы**: [Andosols S-004](#s-004-andosols-вулканические) (вулканические — равноценны), [Fluvisols S-014](#s-014-fluvisols-аллювиальные) (речные — восстанавливаются)

**Роль**: **бутылочное горлышко для «житницы»** — лучшие стартовые локации для земледелия. Украина = 30% чернозёмов мира.

### S-008: Phaeozems (серые лесные)

**Категория**: 🟢

**Процесс**: лесостепное почвообразование

**Входящие связи**:
- биом → [лесостепи] (Европа, Сев. Америка, Россия)

**Исходящие связи**:
- культура: → [пшеница](../resources/08_food_resources.md), [ячмень](../resources/08_food_resources.md), [овёс](../resources/08_food_resources.md)
- технология: → [T-015 Земледелие](../../06_technology/tech_tree.md)

**Альтернативы**: [Chernozems S-007](#s-007-чernozems-чернозёмы), [Luvisols S-026](#s-026-luvisols-серые-лесные)

**Роль**: рядовой

### S-009: Gypsisols (гипсовые)

**Категория**: 🔴
**Состав**: гипс в профиле, щелочные
**Процесс**: засушливое почвообразование

**Входящие связи**:
- биом → [засушливые регионы] (Испания, Иран, Австралия)
- материнская порода → [гипс](../resources/13_salts_minerals_chem.md)

**Исходящие связи**:
- ресурс: → [гипс](../resources/13_salts_minerals_chem.md) ⭐ (минерал — парижский гипс!)
- материал: → [парижский гипс](../02_world/processed_materials/02_chemical_products.md) (CaSO₄·0.5H₂O — для литья T-051)
- культура: → пастбища (засушливые)
- технология: → [T-051 Литьё в формы](../../06_technology/tech_tree.md) (через парижский гипс)

**Альтернативы**:
- как гипс: [Mineral gypsum](../resources/13_salts_minerals_chem.md) (добыча из пород)

**Роль**: **бутылочное горлышко для гипса** → парижский гипс → литьё. Без Gypsisols нет природного гипса.

### S-011: Calcisols (карбонатные)

**Категория**: 🟡
**Состав**: карбонат кальция, щелочные, средний гумус
**Процесс**: засушливое субтропическое почвообразование

**Входящие связи**:
- биом → [Средиземноморье, Ближний Восток] (засушливые субтропики)

**Исходящие связи**:

- материал: → [известь CaO](../02_world/processed_materials/02_chemical_products.md) (через обжиг T-070a)
- технология: → [T-015 Земледелие](../../06_technology/tech_tree.md), → [T-070a Производство извести](../../06_technology/tech_tree.md)

**Альтернативы**:

**Роль**: рядовой — средиземноморское земледелие (оливки/виноград)

### S-012: Solonchaks (солончаки)

**Категория**: 🔴
**Состав**: очень солёные, токсичные для растений
**Процесс**: засушливое прибрежное/континентальное

**Входящие связи**:
- биом → [засушливые прибрежные и континентальные] (Мёртвое море, Аральское море, Такла-Макан)
- ресурс → [соль](../resources/12_water_salt.md) ⭐ (выкристаллизованная на поверхности)

**Исходящие связи**:
- ресурс: → [соль NaCl](../resources/12_water_salt.md) ⭐ (добыча — стратегический ресурс!)
- культура: → солянка (солеустойчивая)
- материал: → [сода](../02_world/processed_materials/02_chemical_products.md) (через выщелачивание)
- технология: → [T-081 Порох](../../06_technology/tech_tree.md) (селитра из солончаков!), → сода для стекла (T-056)

**Альтернативы**:
- как соль: [морская соль](../resources/12_water_salt.md) (выпаривание), [каменная соль](../resources/12_water_salt.md) (добыча)

**Роль**: **бутылочное горлышко для селитры** → порох. Селитра (KNO₃) образуется в старых солончаках.

### S-014: Fluvisols (аллювиальные)

**Категория**: 🟢
**Состав**: ежегодно обновляются илом
**Процесс**: речной нанос

**Входящие связи**:
- биом → [долины рек] (Нил, Месопотамия, Ганг, Янцзы, Миссисипи)
- процесс → [разлив рек] (ежегодный ил)

**Исходящие связи**:
- культура: → любые (особенно рис в затопляемых долинах)
- технология: → [T-015 Земледелие](../../06_technology/tech_tree.md), → [T-016 Ирригация](../../06_technology/tech_tree.md) (естественная)
- эффект: восстанавливается каждый год (ил Нила!)

**Альтернативы**: [Chernozems S-007](#s-007-чernozems-чернозёмы) (степные, не восстанавливаются), [Andosols S-004](#s-004-andosols-вулканические)

**Роль**: **бутылочное горлышко для древних цивилизаций** — Египет, Месопотамия, Китай, Индия — все на Fluvisols. Без речных долин нет ранних цивилизаций.

### S-024: Acrisols (выщелоченные тропические)

**Категория**: 🔴 (тропический парадокс — густые джунгли, но бедные почвы)
**Состав**: сильно выщелоченные, кислые
**Процесс**: тропическое выщелачивание

**Входящие связи**:
- биом → [тропические влажные леса] (Амазония, Конго, ЮВ Азия)

**Исходящие связи**:
- культура: → подсечно-огневое земледелие (быстро истощается)
- технология: → [T-015 Земледелие](../../06_technology/tech_tree.md) (только подсечно-огневое)
- эффект: после вырубки джунглей — почвы быстро истощаются → переключение участков

**Альтернативы**: [Anthrosols S-030](#s-030-anthrosols-искусственные) (terra preta — искусственно улучшенные)

**Роль**: **бутылочное горлышко для тропиков** — иллюзия богатых джунглей, реально бедные почвы. Майя вырубили леса → истощение → коллапс.

## 🎯 Ключевые «бутылочные горлышки» среди почв

| Почва | Что блокирует | Где | Альтернатива |
|---|---|---|---|
| **S-004 Andosols** | Пуццолан → римский бетон → акведуки | зоны вулканизма | НЕТ (нужен импорт) |
| **S-007 Chernozems** | Житница (массовое земледелие) | Великая Степь | Fluvisols, Andosols |
| **S-009 Gypsisols** | Гипс → парижский гипс → литьё | засушливые | минеральный гипс |
| **S-012 Solonchaks** | Селитра → порох | засушливые прибрежные | навоз (медленно) |
| **S-014 Fluvisols** | Древние цивилизации (Нил, Месопотамия) | долины рек | НЕТ (география = судьба) |
| **S-017 Arenosols** | Кварцевый песок → стекло | песчаные регионы | речной/морской песок |
| **S-024 Acrisols** | Тропический парадокс (бедные джунгли) | тропики | Anthrosols (terra preta) |
