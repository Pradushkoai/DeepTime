# Почвы — классификация и свойства

> Почва — основа земледелия. От её типа зависит урожайность, набор культур, агротехника. В игре используем международную классификацию WRB (World Reference Base for Soil Resources), но с упрощениями для геймплея.

> ⚠️ **Для валидации связей (Принцип 10) см. [index.md](index.md)** — структурированные карточки всех 32 почв (ID S-001...S-032) с входящими/исходящими связями, альтернативами, ролями.

---

## Источники классификации

- **WRB (World Reference Base for Soil Resources)** 2014/2022 — международная классификация FAO
- **USDA Soil Taxonomy** — американская альтернатива
- **SoilGrids 250m (ISRIC)** — глобальные почвенные данные
- **Harmonized World Soil Database (HWSD)** v1.2 — глобальная база
- **FAO Soil Map of the World** — историческая карта 1:5M

---

## Принципы подхода для игры

### Принцип 1: Реалистичная классификация, но не избыточная

WRB определяет **32 Reference Soil Groups (RSGs)**. В игре используем все 32 (это не избыточно), но агрегируем подкатегории — иначе будет 500+ типов (не играбельно).

### Принцип 2: Каждая почва имеет ключевые свойства

- **Плодородие** (0-100) — насколько хорошие урожаи без обработки
- **Дренированность** (песок → глина)
- **рН** (кислотность) — какая культура растёт
- **Органическое вещество** (гумус) — питательность
- **Структура** (от камней до чернозёма)

### Принцип 3: Географическое распределение

Каждая почва характерна для конкретных биомов/регионов. В игре — по реальным данным SoilGrids.

## 32 Reference Soil Groups (по WRB 2014)

> Краткое описание каждой группы с географией, свойствами и применением в игре.

### Histosols — Гистозёмы (торфяные)

**Описание**: почвы из неразложившегося органического вещества (торфа)
**География**: болота, тундра, зоны вечной мерзлоты
**Свойства**: 100% органика, без минеральной основы
**Плодородие**: низкое (после осушения — высокое)
**Применение**:
- Торф (топливо — см. 04_organic_fuels.md)
- После осушения — высокоурожайные поля (но разрушается быстро)
- В игре: топливо + рисовые поля после осушения
**Источники**: WRB, SoilGrids

### Cryosols — Криозёмы (мерзлотные)

**Описание**: почвы с вечной мерзлотой
**География**: Арктика, тундра (Сибирь, Канада, Аляска)
**Свойства**: мёрзлые, низкое плодородие
**Применение**: охота, собирательство (сельхоз невозможен)
**Источники**: WRB

### Gleysols — Глеезёмы (глеевые)

**Описание**: почвы с постоянным переувлажнением
**География**: поймы рек, низины
**Свойства**: глей (Fe²⁺ — голубой), заболоченные
**Плодородие**: после дренажа — высокое
**Применение**: рис (затопляемые поля!), тростник
**Источники**: WRB

### Andosols — Андозёмы (вулканические)

**Описание**: почвы на вулканическом пепле
**География**: зоны вулканизма (Япония, Исландия, Камчатка, Анды, Италия)
**Свойства**: очень плодородные, богатые минералами
**Плодородие**: очень высокое
**Применение**: высокая урожайность любых культур
**Особые свойства**: 
- Лёгкая обработка
- Высокая водозадерживающая способность
- В игре: «золотые» почвы рядом с вулканами
**Источники»: WRB

### Vertisols — Вертозоли (текстурные)

**Описание**: глинистые почвы с сильным набуханием/усадкой
**География**: саванны, субтропики (Австралия, Индия, Техас, Судан)
**Свойства**: трещины при высыхании (50 см глубиной!)
**Плодородие**: высокое (но трудная обработка)
**Применение**: хлопок, пшеница, рис
**Особые свойства**:
- Самовзрыхление → выгодно для обработки без плуга
- Но «тяжёлые» для орудий
- В игре: трудно пахать, но урожайно
**Источники»: WRB

### Kastanozems — Каштановые почвы (каштанозёмы)

**Описание**: тёмно-каштановые почвы степей
**География**: степи (Украина, Россия, Великие Равнины, Аргентина)
**Свойства**: средний гумус, нейтральный pH
**Плодородие**: среднее-высокое
**Применение**: пшеница, ячмень, подсолнечник
**Источники»: WRB

### Chernozems — Чернозёмы (чёрнозёмы)

**Описание**: самые плодородные почвы мира (тучные чернозёмы)
**География**: Великая Степь (Украина, Россия, Казахстан, Велик. Равнины, Аргентина — Пампасы)
**Свойства**: 7-15% гумус, нейтральный pH, мощный горизонт
**Плодородие**: **очень высокое** — самые плодородные
**Применение**: 
- Пшеница (главный «житница» Европы!)
- Кукуруза, подсолнечник
- Сахарная свёкла
**Особые свойства**:
- Урожай 3000-5000 кг/га (vs 1000-2000 на других)
- Историческая основа «житниц» (Украина = 30% чернозёмов мира!)
- В игре: лучший стартовый регион для земледелия
**Источники»: WRB, FAO

### Phaeozems — Феозёмы (серые лесные)

**Описание**: тёмные почвы лесостепей (между чернозёмами и серыми лесными)
**География**: Европа, Сев. Америка, Россия
**Свойства**: высокий гумус (но меньше чернозёмов), слабокислые
**Плодородие**: высокое
**Применение**: пшеница, ячмень, овёс
**Источники»: WRB

### Gypsisols — Гипсозёмы

**Описание**: почвы с гипсом
**География**: засушливые регионы (Испания, Иран, Австралия)
**Свойства**: гипс в профиле, щелочные
**Плодородие**: низкое
**Применение**: пастбища (засушливые)
**Источники»: WRB

### Durisols — Дурозёмы

**Описание**: почвы с кремнезёмным горизонтом (дюрит)
**География**: засушливые субтропики
**Свойства**: каменистый горизонт
**Плодородие**: низкое
**Источники»: WRB

### Calcisols — Кальцизёмы (карбонатные)

**Описание**: почвы с карбонатом кальция
**География**: засушливые субтропики (Средиземноморье, Ближний Восток)
**Свойства**: щелочные, средний гумус
**Плодородие**: среднее
**Применение**: оливки, виноград, пшеница (в Средиземноморье)
**Источники»: WRB

### Solonchaks — Солончаки (солёные)

**Описание**: почвы с высоким содержанием солей
**География**: засушливые прибрежные и континентальные (Мёртвое море, Ара-кое море, Такла-Макан)
**Свойства**: очень солёные, токсичные для растений
**Плодородие**: очень низкое
**Применение**: только солеустойчивые (солянка) или добыча соли
**Источники»: WRB

### Solonetz — Солонцы

**Описание**: щелочные почвы с натрием
**География**: засушливые степи
**Свойства**: токсичные для большинства культур
**Плодородие**: низкое
**Применение**: пастбища (солеустойчивые травы)
**Источники»: WRB

### Gleysols — см. выше

### Fluvisols — Флювизоли (аллювиальные)

**Описание**: почвы речных пойм (наносные)
**География**: долины рек (Нил, Месопотамия, Ганг, Янцзы, Миссисипи)
**Свойства**: ежегодно обновляются илом, очень плодородные
**Плодородие**: высокое (восстанавливается каждый год)
**Применение**: 
- Главные почвы древних цивилизаций (Египет, Месопотамия!)
- Любые культуры
- Рис (затопляемые долины)
**Особые свойства**:
- **Ил Нила** = основа египетской цивилизации
- В игре: лучший старт для речных цивилизаций
**Источники»: WRB

### Leptosols — Лептозоли (скелетные)

**Описание**: мелкие почвы на скальной основе
**География**: горы, скалы (Альпы, Гималаи, Анды, Сахара)
**Свойства**: тонкий горизонт, много камней
**Плодородие**: низкое
**Применение**: пастбища, леса (не земледелие)
**Источники»: WRB

### Regosols — Регозоли

**Описание**: рыхлые почвы без развитого профиля
**География**: склоны, пески
**Свойства**: слабый горизонт
**Плодородие**: низкое
**Применение**: пастбища, леса
**Источники»: WRB

### Arenosols — Аренозоли (песчаные)

**Описание**: песчаные почвы
**География**: дюны, пески (Сахара, Калахари, Австралия)
**Свойства**: очень дренированные, низкое плодородие
**Плодородие**: низкое
**Применение**: арахис, просяные (на песках)
**Источники»: WRB

### Cambisols — Камбизоли (бурозёмы)

**Описание**: почвы с начальным профилем (изменённый горизонт B)
**География**: умеренный пояс (Европа, Сев. Америка)
**Свойства**: средний гумус, среднее плодородие
**Плодородие**: среднее
**Применение**: пшеница, ячмень, овёс, рожь
**Источники»: WRB

### Umbrisols — Умбризоли

**Описание**: тёмные кислые почвы
**География**: горы, влажные регионы
**Свойства**: высокий гумус, кислый pH
**Применение**: пастбища, картофель
**Источники»: WRB

### Planosols — Планозоли

**Описание**: почвы с резко меняющейся водопроницаемостью
**География**: плоские территории с сезонным переувлажнением
**Свойства**: сезонные заболачивания
**Применение**: рис
**Источники»: WRB

### Plinthosols — Плинтозоли

**Описание**: почвы с железистым твёрдым горизонтом (плинфит)
**География**: тропики (тропическая Африка, Бразилия)
**Свойства**: при высыхании — цементируется
**Применение**: ограниченное
**Источники»: WRB

### Stagnosols — Стагнозоли

**Описание**: почвы с сезонным переувлажнением
**География**: умеренный пояс (Зап. Европа)
**Свойства**: глей в верхних горизонтах
**Применение**: пастбища, овёс
**Источники»: WRB

### Alisols — Ализоли

**Описание**: кислые глинистые почвы с высоким обменным Al
**География**: тропики, субтропики
**Свойства**: токсичный алюминий
**Плодородие**: низкое
**Применение**: рис (после известкования)
**Источники»: WRB

### Acrisols — Акризоли

**Описание**: сильно выщелоченные тропические почвы
**География**: тропические влажные леса (Амазония, Конго, ЮВ Азия)
**Свойства**: кислые, низкое плодородие
**Плодородие**: **низкое** — тропические почвы бедны!
**Применение**: подсечно-огневое земледелие (быстро истощается)
**Особые свойства**:
- **Парадокс тропиков**: густые джунгли — но почвы бедные
- После вырубки джунглей — почвы быстро истощаются
- Исторически: подсечно-огневое → переключение участков
- В игре: иллюзия богатых джунглей → на самом деле бедные почвы
**Источники»: WRB

### Lixisols — Ликсизоли

**Описание**: менее выщелоченные тропические
**География**: сухие саванны
**Свойства**: лучше акризолей
**Плодородие**: среднее
**Применение: просо, сорго
**Источники»: WRB

### Luvisols — Лювизоли (серые лесные)

**Описание**: лесные почвы умеренного пояса
**География**: Европа, Сев. Америка
**Свойства**: средний гумус, нейтральный pH
**Плодородие**: высокое
**Применение**: пшеница, ячмень, фрукты, овощи
**Источники»: WRB

### Nitisols — Нитизоли

**Описание**: глубокие тропические почвы с глинистой структурой
**География**: Вост. Африка, Бразилия
**Свойства**: глубокий профиль
**Плодородие**: среднее (для тропиков — высокое)
**Применение**: кофе, какао, банан
**Источники»: WRB

### Ferralsols — Ферралозоли (латериты)

**Описание**: глубоко выветренные тропические почвы
**География**: Амазония, Конго, ЮВ Азия
**Свойства**: Fe и Al оксиды, очень старые
**Плодородие**: низкое (как акрисоли)
**Применение**: подсечно-огневое
**Особые свойства**:
- Бедные, но стабильные
- Латерит (твёрдый Fe-горизонт) → строительный материал (Ангкор-Ват!)
- В игре: фундамент для строек (как камень)
**Источники»: WRB

### Anthrosols — Антропозоли (искусственные)

**Описание**: почвы, изменённые человеком (terrace, terra preta)
**География**: Амазония (terra preta), Китай, Япония (terraces)
**Свойства**: обогащённые углём/компостом
**Плодородие**: высокое (искусственно улучшенное)
**Применение**: высокая урожайность
**Особые свойства**:
- **Terra preta** в Амазонии — «индейская земля» (густо чёрная, очень плодородная)
- Исторический пример искусственного улучшения
- В игре: можно создать улучшая другие почвы
**Источники»: WRB, «Terra Preta» (Lehmann, 2003)

### Technosols — Технозоли

**Описание**: почвы из техногенных материалов (золы, шлак, кирпич)
**География**: антропогенные зоны (древние свалки, развалины)
**Свойства**: смешанный состав
**Плодородие**: переменное
**Источники»: WRB

## Принципы для дизайна

### 1. Географическое распределение

Игрок в Европе получит Luvisols и Cambisols. Игрок в Украине — Chernozems (очень выгодно!). Игрок в Египте — Fluvisols (Нил). Игрок в Амазонии — Acrisols (трудности).

### 2. Историческая связь почв и цивилизаций

- Древний Египет — Fluvisols Нила → земледелие
- Месопотамия — Fluvisols Тигра/Евфрата
- Украина — Chernozems → житница Европы
- Китай — Luvisols Янцзы/Хуанхэ
- Мезоамерика — тера прета (Anthrosols в Амазонии) → майя

### 3. «Тропический парадокс»

Густые джунгли = бедные почвы (Acrisols, Ferralsols). После вырубки — почвы быстро истощаются. Это создаёт в игре:
- Иллюзию богатых джунглей (для игрока)
- Подсечно-огневое земледелие (нужно переключать участки)
- Реальная история: майя вырубили леса → истощение → коллапс

### 4. Улучшение почв

- Известкование (на кислых почвах — Alisols, Acrisols)
- Орошение (на засушливых — Solonchaks, Arenosols)
- Дренаж (на заболоченных — Gleysols, Histosols)
- Удобрение (на бедных — все)
- Террасирование (на горных — Leptosols)
- Terra preta (искусственно создавать Anthrosols)

### 5. Эрозия

- На горных почвах (Leptosols) — террасирование обязательно
- На степных (Chernozems) — ветровая эрозия (пыльные бури)
- На лесных после вырубки — водная эрозия
- В игре: моделировать эрозию при неправильной обработке

### 6. Ключевые стартовые локации

Лучшие старты для земледелия:
- Долины рек (Fluvisols)
- Степи с чернозёмами (Chernozems)
- Вулканические зоны (Andosols)

Худшие:
- Тропические леса (Acrisols, Ferralsols)
- Засушливые пустыни (Arenosols, Solonchaks)
- Горы (Leptosols)
