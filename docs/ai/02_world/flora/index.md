# Флора — Индекс связей (Принцип 10: обязательная связность)

> 📋 **Этот файл — структурированный индекс ключевых растений** (~150-200 видов, агрегированных в 80+ карточек). Каждый элемент имеет ID, категорию, входящие/исходящие связи, альтернативы, роль. Содержит все связи, необходимые для валидации (Принцип 11).

---

## 🎯 Принципы индекса

1. **ID-система**: F-001 ... F-080 (F = Flora)
2. **Категории**: 🌲 деревья (древесина), 🌾 культурные (пища), 🌿 пряные/лекарственные, 🧵 волокнистые, 🎨 красильные
3. **Входящие связи**: биом → почва → климат → растение
4. **Исходящие связи**: → ресурсы (древесина, пища, волокно, краситель, лекарство), → процессы (помол, ферментация, дубление), → технологии (ткачество, красители, фармацевтика)
5. **Альтернативы**: какие растения заменяют данное
6. **Роль**: бутылочное горлышко? критично для цепочки? рядовой?

## 🔗 Карточки ключевых растений со связями

> Подробно описаны только **бутылочные горлышки** и **стратегические** растения. Остальные — в сводной таблице выше + в [README.md](README.md).

### F-005: Дуб черешчатый (Quercus robur)

**Категория**: 🌲 дерево (умеренный лес)
**Состав**: твёрдая древесина, кора с танином, жёлуди
**Процесс**: вырубка + сушка (для древесины); дубление (для коры)

**Входящие связи**:
- биом → [умеренный лес] (Европа, Сев. Америка)
- почва → [Luvisols S-026](../soils/index.md#s-026-luvisols-серые-лесные), [Cambisols S-018](../soils/index.md#s-018-cambisols-бурозёмы)

**Исходящие связи**:
- ресурс: → [древесина дуба](../resources/05_wood_timber.md) ⭐ (корабли, бочки, мебель, балки)
- ресурс: → [кора (танин)](../resources/11_spices_medicinal.md) (дубление кож!)
- ресурс: → [жёлуди](../resources/08_food_resources.md) (еда свиней, бедняков в голод)
- материал: → [дублёная кожа](../02_world/processed_materials/08_hygiene_textile_products.md) (через танин)
- технология: → [T-020 Деревообработка](../../06_technology/tech_tree.md), → дубление кож (через T-030)

**Альтернативы**:
- как древесина: [Бук F-006](#f-006-бук-лесной-fagus-sylvatica), [Каштан F-012](#f-012-каштан-castanea-sativa)
- как танин: каштан, ель (хуже)

**Роль**: **бутылочное горлышко для кораблей** — дубовые кили/доски = основа кораблестроения до стали. Без дуба нет океанских кораблей.

### F-009: Тис ягодный (Taxus baccata)

**Категория**: 🌲 дерево (умеренный лес)
**Состав**: очень упругая древесина (самая лучшая для луков!)
**Процесс**: вырубка + сушка (1-2 года)

**Входящие связи**:
- биом → [умеренный лес] (редкий!)
- география → ограниченные ареалы (Британия, Кавказ, Средиземноморье)

**Исходящие связи**:
- ресурс: → [древесина тиса](../resources/05_wood_timber.md) ⭐ (для длинных луков!)
- технология: → [T-005 Лук](../../06_technology/tech_tree.md) (тис = лучший длинный лук)

**Альтернативы**: [Ясень F-008](#f-008-ясень-fraxinus-excelsior), [Граб F-007](#f-007-граб-carpinus-betulus), [Бамбук F-021](#f-021-бамбук-bambusoideae) (тропики), [Берёза F-010](#f-010-берёза-betula-pendula)

**Роль**: **бутылочное горлышко для длинных луков** (английский longbow). Без тиса — композитный лук (рог+сухожилия) или короткий (ясень/граб). Британия = историческая монополия на тисовые луки.

### F-013: Олива (Olea europaea)

**Категория**: 🌲 дерево (средиземноморье)

**Входящие связи**:

- почва → [Calcisols S-011](../soils/index.md#s-011-calcisols-карбонатные)

**Исходящие связи**:
- ресурс: → [оливковое масло](../resources/08_food_resources.md) ⭐ (пища, освещение, мыло!)

- материал: → [олифа](../02_world/processed_materials/08_hygiene_textile_products.md) (масляная краска T-090)
- технология: → [T-034 Красители](../../06_technology/tech_tree.md), → [T-090 Масляная живопись](../../06_technology/tech_tree.md)

**Альтернативы**:

**Роль**: **бутылочное горлышко для средиземноморской экономики** — оливковое масло = стратегический ресурс (пища + освещение + мыло + краска).
