# Флора — растения по биомам и категориям

> В игре не нужны все 350 000 видов растений. Нужно ~150-200 ключевых видов: деревья (для древесины), культурные (для пищи), пряные/лекарственные, волокнистые, красильные. Каждый — с реальным биомом и географией.

---

## Источники

- **GBIF (Global Biodiversity Information Facility)** — биоразнообразие
- **Plants of the World Online (POWO)** — Royal Botanic Gardens, Kew
- **IUCN Red List** — охраняемые виды
- **FAO** — статистика по культурам
- **Vavilov Centers of Origin** — центры происхождения культурных растений
- **World Flora Online** — полный список растений
- **CABI Invasive Species** — инвазивные виды

---

## Принципы подхода

1. **Реалистично, но не избыточно**: ~150-200 видов (vs 350 000 в реальности)
2. **Привязка к биомам**: каждое растение в своём биоме
3. **Дикие vs культурные**: дикие виды → источник одомашнивания
4. **Множественное использование**: одно растение = дерево + пища + лекарство
5. **Географическая уникальность**: не все растения есть везде

## Культурные растения (с детализацией по Vavilov Centers)

### Центр 1: Южно-Азиатский тропический (Индия, ЮВ Азия)

**Злаки**: рис, просо
**Бобовые**: соя, нут
**Волокна**: хлопок, ютта, рами
**Пряности**: чёрный перец, кардамон, имбирь, куркума, гвоздика, мускат
**Другое**: сахарный тростник, чай, кофе (после Эфиопии), кокос, банан, манго, цитрус

**Злаки**: рис, просо
**Бобовые**: соя
**Волокна**: конопля
**Другое**: чай, шелковица (Morus), мандарин, личи

**Злаки**: пшеница (эммер, эйнкорн), ячмень

**Плодовые**: олива, инжир, виноград, гранат, яблоко, груша, слива, вишня, миндаль, фисташка, грецкий орех

### Центр 4: Средиземноморский

**Злаки**: твёрдая пшеница (дурум), овёс
**Бобовые**: нут, бобы
**Плодовые**: олива, виноград, инжир
**Овощи**: капуста, репа, морковь, свёкла, лук, чеснок
**Пряности**: розмарин, тимьян, шалфей, мята, лавр, орегано, майоран

### Центр 6: Центрально-Американский (Мезоамерика)

## Принципы для дизайна

### 1. Vavilov Centers — основа для старта племён

Игрок в каждой локации имеет доступ к разным культурам. Игрок в Плодородном полумесяце → эммер, ячмень, лён. Игрок в Китае → рис, соя, шелковица. Игрок в Мезоамерике → кукуруза, бобы, какао.

### 2. Дикие предки нужно искать

Для одомашнивания культуры нужно:
- Найти дикого предка в регионе
- Иметь нужные инструменты/знания
- Накопить опыт выращивания

В игре: дикий рис в ЮВ Азии → нужно открыть технологию выращивания → получить культурный рис.

### 3. Несколько центров → несколько путей

- Злаки: Плодородный полумесяц (пшеница/ячмень), Китай (рис/просо), Мезоамерика (кукуруза), Африка (сорго/тэфф)
- Волокна: Европа (лён), Индия (хлопок), Китай (шёлк/конопля)
- Пряности: Индия (перец), Молукки (гвоздика), Цейлон (корица), Мексика (ваниль, чили)

### 4. Тропический парадокс

Богатые джунгли = бедные почвы → подсечно-огневое земледелие → частая миграция. Это создаёт в игре уникальный геймплей для тропических племён.

### 5. Множественное использование растений

- Дуб: древесина + жёлуди (еда свиней) + кора (танин для кож) → 3 продукта
- Кокосовая пальма: молоко + мякоть + масло + волокно + скорлупа + древесина → 6+ продуктов
- Олива: масло + плоды + древесина + мыло → 4 продукта

### 6. Зависимость культур от почв

- Рис → Fluvisols, Gleysols (затопляемые)
- Пшеница → Chernozems, Phaeozems, Luvisols
- Виноград → Calcisols, хорошо дренированные
- Картофель → Umbrisols, Andosols (кислые)
- Просо/сорго → Arenosols, Lixisols (засушливые)

### 7. Культуры как «бутылочные горлышки» племён

Без специфических культур — нет специализации. Например, без риса → нет рисоводческой цивилизации. Без винограда → нет средиземноморского виноделия. Это создаёт географическую уникальность племён.
