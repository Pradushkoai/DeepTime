# Нефтепродукты

> Продукты переработки нефти. От древнего битума (Вавилон) до современного пластика. Демонстрирует принцип «бесконечного развития» — от простого к сложному.

---

## 🛢️ Нефть → фракционная перегонка

### Битум / Асфальт (Bitumen) ⭐

**Сырьё**: нефть (естественные выходы — Мёртвое море, Месопотамия)
**Процесс**: естественное испарение лёгких фракций ИЛИ примитивная перегонка
**Условия**: солнечная сушка или нагрев 100°C
**Эпоха**: с древности (Месопотамия — Хит, ~3000 до н.э.)
**Применения**:
- **Строительный раствор** (Вавилон!) — кирпичи скреплялись битумом
- **Гидроизоляция**: корабли, корзины, бассейны, акведуки
- **Герметизация**: амфоры, бочки
- **Консервант**: мумификация (Египет)
- **Дороги** (Вавилон — первые асфальтовые)
- **Клей и цемент**
**Технологические цепочки**:
- нефть → испарение → битум → + кирпич → водостойкая кладка (Вавилон)
- битум → + корзина → водонепроницаемая амфора
**Особые свойства**: критически важен для месопотамской цивилизации (нет леса/камня, есть битум)
**Источники»: USGS, «Bitumen in Antiquity» (Connan, 1999)

### Греческий огонь (Greek fire) ⭐

**Сырьё**: нефть + смолы + сера (для усиления)
**Процесс**: примитивная перегонка нефти → лёгкие фракции + добавки
**Условия**: медный котёл, нагрев 100-200°C, секретная смесь
**Эпоха**: Византия, 7 в. н.э. (Каллиник из Гелиополя)
**Применения**:
- **Военное дело**: зажигательные снаряды (горшки), насос-сифон на кораблях
- Защита Константинополя от арабов (674-678)
**Технологические цепочки**:
- нефть → перегонка → лёгкие фракции → + смолы + сера → греческий огонь → + насос-сифон → огнемётный корабль
**Особые свойства**: 
- Секретная технология Византии (держали в тайне 5 веков)
- Горит даже на воде → морское оружие
- В игре: технологическое «секретное оружие» для одного государства
**Источники»: «Greek Fire» (Haldon, 2003)

### Керосин (Kerosene)

**Сырьё**: нефть
**Процесс**: фракционная перегонка (собрать фракцию 150-250°C)
**Условия**: медный котёл, перегонка
**Эпоха**: античность (известен), массово — 19 в. (Дарвин, 1854)
**Применения**:
- **Освещение** (масляные лампы — замена оливкового масла)
- Отопление
- Топливо (позднее — ракетное, турбины)
**Технологические цепочки**:
- нефть → перегонка → керосин → + лампа → освещение (дешевле масла)
**Особые свойства**: первый массовый продукт нефтепереработки
**Источники»: Ullmann's Encyclopedia

### Парафин / Воск нефтяной (Paraffin wax)

**Сырьё**: нефть (тяжёлые фракции)
**Процесс**: перегонка + очистка
**Эпоха**: 19 в. (1850-е)
**Применения**:
- **Свечи** (замена пчелиного воска — дешевле!)
- Герметизация (консервация)
- Косметика
- Медицина (парафинотерапия)
- Упаковка (позднее)
**Технологические цепочки**:
- нефть → перегонка тяжёлых фракций → парафин → + фитиль → свеча (дешевле воска)
**Особые свойства**: демократизировало освещение — свечи стали доступны всем
**Источники»: Ullmann's Encyclopedia

### Нефтяные смолы (Petroleum resins)

**Сырьё**: нефть (тяжёлые фракции)
**Процесс**: перегонка + очистка
**Эпоха**: 19 в.
**Применения**:
- Лак, краски
- Клей
- Герметизация
- Резина (модификатор, позднее)
**Источники»: Ullmann's Encyclopedia

### Мазут (Mazut / Heavy fuel oil)

**Сырьё**: нефть (остаток после перегонки лёгких фракций)
**Процесс**: перегонка (побочный тяжёлый остаток)
**Эпоха**: 19 в.
**Применения**:
- **Топливо** для котлов (паровые машины, корабли)
- Сжигание в печах (металлургия)
- Сырьё для крекинга → бензин (позднее)
**Особые свойства**: дешёвое топливо для промышленности
**Источники»: Ullmann's Encyclopedia

### Бензин (Gasoline / Petrol) ⭐

**Сырьё**: нефть (или мазут через крекинг)
**Процесс**: фракционная перегонка (фракция 30-200°C) ИЛИ крекинг тяжёлых фракций
**Условия**: перегонка при атмосферном давлении
**Эпоха**: 19 в. (известен), массово — 20 в. (ДВС — Бенц, 1886)
**Применения**:
- **Топливо ДВС** (главное!)
- Растворитель
- Химическое сырьё (этилен → полиэтилен, и т.д.)
**Технологические цепочки**:
- нефть → перегонка → бензин → + ДВС → автомобиль
- нефть → крекинг мазута → бензин
**Предпосылки**: 
- Знание перегонки
- Крекинг (Бартон, 1913) — для увеличения выхода бензина
- ДВС (Ленуар 1860, Отто 1876, Бенц 1886)
**Особые свойства**: критическое топливо для индустриальной эпохи
**Источники»: Ullmann's Encyclopedia

### Дизельное топливо (Diesel)

**Сырьё**: нефть (тяжёлые фракции)
**Процесс**: перегонка (фракция 200-350°C)
**Эпоха**: 20 в. (Дизель, 1892)
**Применения**:
- Дизельные двигатели (Корабли, локомотивы, грузовики)
- Топливо для тяжёлой техники
**Предпосылки**: 
- Двигатель Дизеля (1892)
- Перегонка нефти
**Источники»: Ullmann's Encyclopedia

## ⛽ Продукты глубокой переработки (поздняя индустриальная)

### Асфальт (Asphalt / Asphalt concrete)

**Сырьё**: битум + песок/щебень
**Процесс**: смешивание
**Эпоха**: античность (Вавилон), массово — 19-20 в.
**Применения**:
- **Дороги** (главное! — современный «асфальт»)
- Кровля
- Гидроизоляция
**Технологические цепочки**:
- битум + песок + щебень → асфальт → + дорога → автомобильная сеть
**Особые свойства**: основа дорожной инфраструктуры 20 в.
**Источники»: USGS

### Нефтяной кокс (Petroleum coke)

**Сырьё**: нефть (тяжёлые остатки)
**Процесс**: коксование нефтяных остатков
**Эпоха**: 19-20 в.
**Применения**:
- Электроды (критично для электролиза алюминия!)
- Топливо (высококалорийное)
- Тигли (позднее)
**Технологические цепочки**:
- нефть → коксование → нефтяной кокс → + бокситы → электролиз → алюминий
**Особые свойства**: критично для производства алюминия (нужны угольные электроды)
**Источники»: USGS

### Пластмассы (Plastics) ⭐

**Сырьё**: нефть (через этилен, пропилен и др.)
**Процесс**: 
- Крекинг нефти → этилен (C₂H₄)
- Полимеризация → полиэтилен (PE), полипропилен (PP), ПВХ, и др.
**Эпоха**: 20 в. (Бакелит — 1907, полиэтилен — 1933)
**Применения**:
- Упаковка, контейнеры
- Трубы
- Ткани (полиэстер)
- Изоляция (электричество)
- Корпуса приборов
- 3D-печать (позднее)
**Предпосылки**: 
- Крекинг нефти (Бартон, 1913)
- Полимеризация (знание химии)
- Очень сложная технологическая цепочка
**Технологические цепочки**:
- нефть → крекинг → этилен → полимеризация → полиэтилен → изделие
**Особые свойства**: 
- КРИТИЧНО для современной цивилизации
- В игре: «последняя» технология перед пластиком — много предпосылок
**Источники»: «Plastics» (American Chemistry Council)

### Синтетический каучук (Synthetic rubber)

**Сырьё**: нефть
**Процесс**: полимеризация изопрена/бутадиена
**Эпоха**: 20 в. (массово — WW2, США)
**Применения**:
- Шины (главное!)
- Уплотнения
- Резина
**Предпосылки**: 
- Натуральный каучук (из гевеи — Мезоамерика)
- Химия полимеров
- Знание вулканизации (Goodyear, 1839)
**Источники»: Ullmann's Encyclopedia

## Цикл развития нефтепереработки

```
1. Античность: естественные выходы нефти → битум (Вавилон, Египет)
   ↓ (только лёгкое использование)
   
2. Поздняя античность: примитивная перегонка → греческий огонь (Византия)
   ↓ (военное применение)
   
3. 19 в.: фракционная перегонка → керосин + парафин (освещение)
   ↓ (массовое освещение)
   
4. 19-20 в.: мазут → котлы паровых машин
   ↓ (промышленное топливо)
   
5. 20 в.: бензин → ДВС → автомобиль (Бенц, 1886)
   ↓ (транспортная революция)
   
6. 20 в.: крекинг → больше бензина
   ↓ (массовая автомобилизация)
   
7. 20 в.: этилен → полимеризация → пластик (Бакелит, 1907)
   ↓ (пластмассовая революция)
   
8. 20 в.: нефтяной кокс → электроды → электролиз → алюминий
   ↓ (производство лёгких металлов)
```

## Принципы для дизайна

### 1. Нефть — топливо «бесконечного развития»

От античности (битум) до 20 в. (пластик) — одна и та же нефть даёт всё больше продуктов по мере развития. Это эталонный пример принципа «эпохи определяются технологиями».

### 2. Каждая ступень требует новых технологий

- Битум — нужна только нефть (выходы)
- Греческий огонь — нужна перегонка
- Керосин — нужна фракционная перегонка (продвинутая)
- Бензин — нужен крекинг (Бартон, 1913)
- Пластик — нужна химия полимеров (Бакеланд, 1907)

### 3. Географическая уникальность

- Месопотамия, Египет — нефть на выходах (раннее развитие)
- Баку, Техас, Венесуэла — огромные месторождения (поздняя индустриализация)
- В игре: государство с нефтью + знание перегонки → монополия

### 4. Греческий огонь — секретное оружие

Исторически — секрет Византии. В игре: можно сделать технологию, которую сложно украсть (только через шпионов или дип. отношения).

### 5. Битум — критичен для Месопотамии

Без леса и камня (Месопотамия) — битум заменяет и раствор, и дерево, и герметик. Это делает Месопотамию играбельной в ранней стадии.

### 6. Пластик — «последняя» индустриальная технология

Требует: нефть + крекинг + химию полимеров. Очень много предпосылок. В игре: «финишная прямая» индустриализации.
