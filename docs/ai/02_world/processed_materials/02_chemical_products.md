# Химические продукты

> Продукты, получаемые термической/химической обработкой минерального сырья. Главные — известь, поташ, парижский гипс, сера, серная кислота.

---

## 🪨 Карбонаты → обжиг

### Известь / Негашёная известь (Quicklime, CaO) ⭐

**Сырьё**: известняк (CaCO₃)
**Процесс**: обжиг при 900°C
**Условия**: 900-1100°C, печь с тягой
**Эпоха**: с неолита (~10000 до н.э. — Иерихон), массово — античность
**Применения**:
- **Строительный раствор** (главное! — с песком → известковый раствор)
- Штукатурка
- Дезинфекция (посыпать ран, могилы)
- Кожевенное дело (золение — снятие шерсти)
- Производство стекла (флюс)
- Сельское хозяйство (известкование кислых почв)
- Очистка воды
- Производство аммиака (с N₂ и H₂ — позднее)
**Технологические цепочки**:
- известняк → обжиг 900°C → CaO → + H₂O → Ca(OH)₂ (гашёная) → + песок → строительный раствор
- CaO + Na₂CO₃ → NaOH (щёлочь) + CaCO₃
- CaO + песок + пуццолан → римский цемент (водостойкий!)
**Особые свойства**: 
- **КРИТИЧЕСКИ ВАЖНО** для монументальной архитектуры
- Римский бетон (CaO + пуццолан) водостойкий → акведуки, гавани
- Источник CO₂ при обжиге
**Источники**: «Roman Concrete» (Lancaster, 2005)

### CO₂ (Углекислый газ)

**Сырьё**: побочный продукт обжига известняка, брожения спирта
**Процесс**: 
- Из CaCO₃: CaCO₃ → CaO + CO₂ (900°C)
- Из брожения: C₆H₁₂O₆ → 2C₂H₅OH + 2CO₂
**Применения**:
- Брожение хлеба (дрожжи выделяют CO₂ → тесто поднимается)
- Газация напитков (позднее)
- Сухой лёд (позднее)
- Тушение пожаров (позднее)
- Парниковый эффект (химия атмосферы — позднее)
**Особые свойства**: можно использовать в игре как «побочный продукт» — собирать или выбрасывать
**Источники**: Ullmann's Encyclopedia

### Парижский гипс / Полугидрат (Plaster of Paris, CaSO₄·0.5H₂O) ⭐

**Сырьё**: гипс (CaSO₄·2H₂O)
**Процесс**: обжиг при 150°C
**Условия**: 150-180°C, в печи
**Эпоха**: античность (Париж, Монмартр)
**Применения**:
- **Штукатурка** (быстро твердеет)
- **Скульптура** (лёгкая обработка)
- **Формы для литья металла** (медали, статуэтки)
- **Стяжка пола**
- **Маски для мумий** (Египет)
- **Медицинские повязки** (позднее — гипс)
**Технологические цепочки**:
- гипс → обжиг 150°C → полугидрат → + вода → твердеет → форма для литья Cu/бронзы/золота
**Особые свойства**: 
- Быстро твердеет при добавлении воды (3-5 минут)
- Критично для **форм литья металла** — раньше создания сложных отливок
**Источники**: Mindat.org

### Ангидрит (CaSO₄)

**Сырьё**: гипс (или природный ангидрит)
**Процесс**: обжиг при 300-500°C (выше парижского)
**Применения**:
- Огнеупор
- Цемент (при помоле + активатор)
**Особые свойства**: гидратируется медленно, не так популярен как парижский
**Источники**: Mindat.org

## 🌿 Зола → выщелачивание

### Поташ / Карбонат калия (Potash, K₂CO₃) ⭐

**Сырьё**: древесная зола (см. [../resources/13_salts_minerals_chem.md](../resources/13_salts_minerals_chem.md))
**Процесс**: 
1. Сжечь древесину → зола
2. Залить водой → растворить
3. Отфильтровать раствор
4. Выпарить → поташ
**Условия**: комнатная температура выщелачивания, 100°C выпаривание
**Эпоха**: с античности (массово — средние века, Россия — главный экспортёр)
**Применения**:
- **Стекло** (флюс — понижает T плавления песка с 1700°C до 1200°C) — критично!
- **Мыло** (с жиром)
- **Удобрение** (K — калий для растений)
- **Красители** (протрава)
- **Кожевенное дело**
- **Лекарство**
- **Порох** (с серой и селитрой)
**Технологические цепочки**:
- дерево → сжигание → зола → выщелачивание водой → поташ → + песок + CaO → стекло (1200°C)
- дерево → зола → поташ → + жир → омыление → мыло
**Альтернативы**: сода (натрон) — лучше, но только в натронных озёрах
**Особые свойства**:
- **КРИТИЧНО** для массового производства стекла в Европе (без натронных озёр)
- Исторически: Россия и Германия — крупные производители поташа
- Бутылочное горлышко — без дерева нет поташа, без поташа нет стекла
**Источники**: USGS, «Potash» (Crow, 1929)

### Натрон / Природная сода (Na₂CO₃)

**Сырьё**: натронные озёра (Египет — Вади-Натрун)
**Процесс**: добыча + очистка
**Применения**:
- Стекло (как поташ — флюс)
- Мумификация (Египет)
- Мыло
- Красители
- Медицина
**Особые свойства**: историческая монополия Египта → критично для египетского стекла
**Источники**: Mindat.org

### Зольная щёлочь / Щёлок (Lye, KOH)

**Сырьё**: древесная зола
**Процесс**: выщелачивание водой (без выпаривания)
**Применения**:
- Мыло (с жиром)
- Клей
- Удобрение
- Красители
**Особые свойства**: доступна с неолита, простейшая щёлочь
**Источники**: —

## 🟡 Сера и её производные

### Сера (Sulfur)

**Сырьё**: самородная сера (сицилийская) ИЛИ побочный продукт обжига пирита/галенита
**Процесс**: добыча + плавка (113°C)
**Эпоха**: с античности
**Применения**:
- **Порох** (с селитрой + уголь) — критично!
- Фумигация (дезинфекция)
- Медицина (кожа, антисептик)
- Вулканизация резины (позднее)
- Красители (ультрамарин)
**Технологические цепочки**: S + KNO₃ + C → помол → порох
**Особые свойства**: сицилианская монополия в античности
**Источники**: USGS, Mindat.org

### Серная кислота (H₂SO₄)

**Сырьё**: SO₂ (из обжига пирита/галенита/киновари)
**Процесс**: 
- Контактный процесс (позднее): SO₂ + O₂ → SO₃ (V₂O₅ катализатор) → + H₂O → H₂SO₄
- Свинцовый процесс (18 в.)
**Эпоха**: 18 в. (массово), известна с 13 в. (алхимия)
**Применения**:
- Химическое сырьё (критично для многих процессов)
- Удобрения (с фосфатами → суперфосфат)
- Аккумуляторы (позднее)
- Очистка металлов
- Нейтрализация щелочей
**Особые свойства**: один из главных продуктов химической промышленности (поздняя эпоха)
**Источники**: Ullmann's Encyclopedia

### Сернистый газ / SO₂ (Sulfur dioxide)

**Сырьё**: побочный продукт обжига сульфидов (пирит, галенит, киноварь, халькопирит)
**Процесс**: обжиг MeS + O₂ → MeO + SO₂
**Применения**:
- → серная кислота (позднее)
- Фумигация (дезинфекция — древний способ)
- Консервант (SO₂ для вина)
- Отбеливатель (текстиль, бумага — позднее)
**Особые свойства**: токсичен, но исторически использовался как антисептик
**Источники**: Ullmann's Encyclopedia

## 🧪 Минералы → обработка

### Боракс / Бура (Borax, Na₂B₄O₇·10H₂O)

**Сырьё**: боратные месторождения (Тибет, США)
**Процесс**: добыча + очистка
**Применения**:
- **Флюс для металлургии** (понижает T плавления, очищает металл)
- **Стекло** (термостойкое — боросиликатное, позднее)
- **Керамика** (глазури)
- **Мыло** (как сода)
- **Лекарство** (антисептик)
- **Консервант**
**Особые свойства**: критический флюс — понижает температуру плавления металлов
**Источники**: USGS

### Пуццолан / Вулканическая зола

**Сырьё**: вулканический пепел (зоны вулканизма)
**Процесс**: добыча + помол
**Применения**:
- **Римский цемент** (CaO + пуццолан + H₂O → водостойкий бетон)
- Водостойкий раствор → акведуки, гавани, мосты
**Особые свойства**: 
- Затвердевает под водой (в отличие от обычного раствора)
- Историческая итальянская монополия → римское строительство
- В игре: без пуццолана — нет водостойких акведуков и портов
**Источники**: Mindat.org, «Roman Concrete» (Lancaster, 2005)

### Флюорит / Плавиковый шпат (CaF₂)

**Сырьё**: флюорит (гидротермальные жилы)
**Процесс**: добыча + помол
**Применения**:
- **Флюс для металлургии** (как боракс)
- **Стекло** (особое оптическое)
- **Эмаль** (керамика)
- Плавиковая кислота (HF) — позднее (травление стекла)
**Особые свойства**: улучшение металлургических процессов
**Источники**: USGS

### Асбест (Asbestos)

**Сырьё**: асбест (см. [../resources/06_fibers_textiles.md](../resources/06_fibers_textiles.md))
**Процесс**: добыча + разделение волокон
**Применения**:
- **Огнестойкие ткани** («вечный фитиль» ламп)
- Строительный материал (плиты)
- Фильтры (позднее)
**Особые свойства**: единственный минерал, из которого делают ткань
**Источники**: USGS

## Принципы для дизайна

1. **Известь — фундамент строительства**. Без неё — нет монументальной архитектуры.
2. **Поташ — бутылочное горлышко стекла в Европе**. Без дерева — нет поташа, без поташа — нет стекла.
3. **Парижский гипс — критичен для литья металла**. Без гипсовых форм — нет сложных отливок (медали, статуэтки, инструменты).
4. **Пуццолан — римский секрет**. Без него — нет водостойких конструкций (акведуки, гавани, мосты).
5. **Сера → SO₂ → H₂SO₄** — пример «бесконечного развития»: от фумигации (античность) до серной кислоты (18 в.).
6. **CO₂ как «побочный продукт»** — в игре можно собирать для брожения или выпускать.
