# Сельскохозяйственные продукты

> Удобрения, костяная мука, зола, гуано — продукты для повышения плодородия почвы. Критичны для роста урожайности → роста населения.

---

## 🦴 Костяная мука (Bone meal) ⭐

**Сырьё**: кости животных (побочный продукт забоя скота)
**Процесс**: 
1. Кости → варить (удалить жир и желатин)
2. Сушка
3. Помол → порошок
**Состав**: Ca₃(PO₄)₂ (трикальцийфосфат), ~30% P₂O₅, ~15% CaO
**Эпоха**: античность (известна), массово — 19 в.
**Применения**:
- **Удобрение** (критично! — фосфор для растений)
- Костяной уголь (для обесцвечивания сахара — позднее)
- Источник P
**Технологические цепочки**:
- кости животных → варка + сушка + помол → костяная мука → + поле → +урожайность зерновых
**Особые свойства**:
- **КРИТИЧНО** — фосфор — важнейший элемент для растений (нуклеиновые кислоты, АТФ)
- В игре: открытие костяной муки → рост урожайности на 20-30%
**Источники**: «Bone Fertilizer» (Hall, 1933)

### Костяной уголь (Bone char)

**Сырьё**: кости животных (предварительно обезжиренные)
**Процесс**: обжиг костей без воздуха (карбонизация)
**Состав**: Ca₃(PO₄)₂ + C
**Применения**:
- **Обесцвечивание сахара** (главное — 18-19 в.)
- Очистка воды (фильтр)
- Чёрная краска
**Особые свойства**: фильтрующий материал
**Источники**: «Bone Char» (Hesse, 1910)

## 🌿 Зола древесная (Wood ash)

**Сырьё**: зола от сжигания древесины
**Состав**: ~30% K₂CO₃, ~30% CaO, микроэлементы (P, Mn, Fe)
**Процесс**: сбор золы после сжигания
**Эпоха**: с неолита (известна)
**Применения**:
- **Удобрение** (калий + кальций + фосфор)
- **Щёлок** (для мыла)
- **Поташ** (после выщелачивания)
- **Лекарство** (древний антисептик)
- **Порошок для золения кож**
**Технологические цепочки**:
- дерево → сжигание → зола → + поле → +урожайность
- зола → выщелачивание → поташ → + песок → стекло
**Особые свойства**: 
- Возобновляемое удобрение (зола возвращается в почву)
- Но: вырубка лесов истощает
**Источники**: FAO

## 🐦 Гуано (Guano) ⭐

**Сырьё**: помёт морских птиц ( накопленные тысячелетиями)
**Состав**: ~10-15% N (азот), ~10% P₂O₅, ~2% K₂O — идеально NPK
**География**: побережья Перу, Чили (острова Чинча), Намibia
**Процесс**: добыча + помол
**Эпоха**: известен с античности, массово — 19 в. (Перу)
**Применения**:
- **Суперудобрение** (NPK в высокой концентрации)
- Источник нитратов (для пороха, и взрывчатки)
**Технологические цепочки**:
- гуано → добыча → удобрение → +урожайность
**Особые свойства**:
- **КРИТИЧНО** — лучшее природное удобрение
- Историческая монополия Перу → войны (Гуановая война 1865-66)
- В игре: контроль месторождения гуано = преимущество в с/х
**Источники**: «Guano» (Skaggs, 1994)

## 🧪 Синтетические удобрения (поздняя индустриализация)

### Аммиачная селитра / NH₄NO₃

**Сырьё**: воздух (N₂) + водород (из метана) → NH₃ → NH₄NO₃
**Процесс**: 
1. **Процесс Габера-Боша** (1909): N₂ + 3H₂ → 2NH₃ (катализатор Fe, 500°C, 200 атм)
2. + HNO₃ → NH₄NO₃
**Эпоха**: 20 в.
**Применения**:
- **Массовое удобрение** (азот — главное!)
- Взрывчатка (NH₄NO₃ + топливо — ANFO)
**Предпосылки**:
1. Электричество (для H₂ из воды)
2. Знание катализа
3. Химическая инженерия (высокие давления)
4. Источник метана (природный газ) или уголь
**Технологические цепочки**:
- N₂ (воздух) + H₂ (CH₄ → водород) → Габер-Бош → NH₃ → + HNO₃ → NH₄NO₃ → удобрение → рост урожайности в 3-5 раз
**Особые свойства**:
- **КРИТИЧНО** — без синтеза аммиака нет массового удобрения → нет зелёной революции → нет современного населения
- Источник H₂: природный газ, уголь, или электролиз воды (дорого)
- В игре: «финишная прямая» для населения — без Габер-Боша планета может прокормить ~3 млрд (мы сейчас 8)
**Источники**: «Haber-Bosch Process» (Smil, 2001)

### Суперфосфат (Superphosphate)

**Сырьё**: фосфорит (Ca₃(PO₄)₂) + серная кислота
**Процесс**: Ca₃(PO₄)₂ + 2H₂SO₄ → Ca(H₂PO₄)₂ + 2CaSO₄
**Эпоха**: 19 в. (Лоуз, 1842)
**Применения**:
- **Удобрение** (фосфор)
**Предпосылки**: серная кислота (H₂SO₄)
**Технологические цепочки**:
- фосфорит + H₂SO₄ → суперфосфат → удобрение
**Особые свойства**: водорастворимый фосфор → лучше усваивается растениями
**Источники**: «Fertilizer Industry» (Sauchelli, 1960)

### Фосфорная кислота (H₃PO₄)

**Сырьё**: фосфорит + серная кислота (или термический путь)
**Применения**: 
- Удобрения (тройной суперфосфат, аммофос)
- Пищевая промышленность (Cola — фосфорная кислота!)
- Лекарства
**Источники**: Ullmann's Encyclopedia

## 🧪 NPK — триада удобрений

Современная агрономия строится на трёх элементах:

| Элемент | Источник | Функция для растений |
|---|---|---|
| **N (Азот)** | Гуано, навоз, аммиачная селитра (Габер-Бош) | Листья, белки |
| **P (Фосфор)** | Костяная мука, фосфорит, суперфосфат | Корни, цветы, семена |
| **K (Калий)** | Зола, поташ, калийные соли | Стебли, устойчивость к болезням |

## Принципы для дизайна

### 1. Историческое «бутылочное горлышко» населения

Без удобрений — урожайность 800-1500 кг/га (древний мир → 8 млрд максимум 3 млрд). С удобрениями (Габер-Бош) → 3000-5000 кг/га → современное население.

В игре: открыть Габер-Бош → демографический взрыв.

### 2. Костяная мука — древний способ повышения урожайности

Открытие костяной муки → +20-30% урожайности. Это первый «удобрительный» шаг.

### 3. Гуано — стратегический ресурс

Историческая монополия Перу → войны. В игре: контроль гуано = экономическое преимущество.

### 4. Габер-Бош — индустриальная революция с/х

Требует: электричество + метан + хим. инженерия. Это «финишная прямая» для демографии.

### 5. NPK — триада

Три элемента (N, P, K) — основа растительного роста. В игре: разные удобрения дают разные эффекты (листья / корни / стебли).

### 6. Зола — двойное применение

Зола = удобрение + сырьё для поташа (стекло, мыло). Это создаёт дилемму для игрока: пустить золу в поле или в стекловарение.
