## Принципы каталога

### 1. Чёткое разделение от ресурсов

Продукт переработки — это НЕ ресурс. Он не лежит в земле, его нужно произвести. Это критично для логики игры.

### 2. Бесконечное развитие (Принцип 9 в `ai_working_principles.md`)

Нет верхней границы по эпохам. Если игрок хочет алюминий или электричество — пусть, но это потребует пройти ВСЕ предпосылки (бокситы → глинозём → электричество → электролиз → алюминий). Эпохи — это описание текущего уровня, не временные рамки.

### 3. Кросс-технологические зависимости

Многие продукты — «бутылочные горлышки»:
- Без кокса — нет домны → нет чугуна → нет стали
- Без поташа — нет стекла (или нужна сода из натрона)
- Без графита — нет тиглей → нет плавки железа
- Без костяной муки / селитры — низкая урожайность → голод

### 4. Все продукты в технологических цепочках

Ни один продукт не «висит». Каждый имеет:
- Что является сырьём (исходный ресурс)
- Какой процесс нужен (обжиг, перегонка, плавка, омыление, ферментация, электролиз)
- Где используется (какая технология, изделие, здание)

### 5. Историческая достоверность

Все процессы описаны по реальной истории (см. [../../06_technology/processes.md](../../06_technology/processes.md)).

## Источники (использованные)

- **USGS Mineral Commodity Summaries** — минералы
- **Mindat.org** — минералогия
- **Vavilov Centers** — одомашнивание растений/животных
- **FAO** — сельское хозяйство
- **POWO** (Plants of the World Online) — растения
- **IUCN Red List, GBIF** — животные
- **WRB 2014/2022** — почвы
- **Kirk-Othmer Encyclopedia of Chemical Technology** — химические процессы
- **Ullmann's Encyclopedia of Industrial Chemistry** — промышленная химия
- **«The Materials of Painting» (Gettens, 1942)** — пигменты
- **«Roman Concrete» (Lancaster, 2005)** — пуццолан и римский цемент
- **«Pitch and Tar» (Needham, 1971)** — смолы
- **«Salt» (Kurlansky, 2002)** — соль
- **«Indigo» (Balfour-Paul, 1998)** — красители
- **«Coal: A Human History» (Freese, 2003)** — уголь

## Принципы для дизайна

1. **Каждый продукт = «точка ветвления»** — может идти в несколько изделий
2. **Сырьё → продукт → изделие** — всегда трёхзвенная цепочка
3. **Географическая уникальность сохраняется** — без сырья нет продукта (нет дерева → нет поташа → нет стекла массово)
4. **Процессы описаны отдельно** — в `06_technology/processes.md`, чтобы не дублировать
5. **Бесконечное развитие** — включаем даже «поздние» продукты (алюминий, пластик), но с правильными предпосылками
