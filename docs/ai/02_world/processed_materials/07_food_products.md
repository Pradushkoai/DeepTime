# Пищевые продукты

> Продукты ферментации и обработки пищевого сырья. От уксуса (античность) до этанола и сыра.

---

## 🍶 Этанол и его производные

### Этанол / Спирт этиловый (C₂H₅OH) ⭐

**Сырьё**: крахмал (зерно, картофель) или сахар (мёд, фрукты, сахарный тростник)
**Процесс**: 
1. **Осахаривание** (для крахмала): солод (фермент амилаза) → крахмал → сахара
2. **Брожение** (дрожжи Saccharomyces): C₆H₁₂O₆ → 2C₂H₅OH + 2CO₂
3. **Перегонка** (для крепости): ~10% → ~40-95%
**Условия**: 25-35°C, анаэробные условия
**Эпоха**: пиво ~10000 до н.э. (Гёбекли-Тепе), вино ~6000 до н.э. (Грузия), дистилляция ~12 в. (Италия)
**Применения**:
- **Алкогольные напитки** (главное! — пиво, вино, водка, виски, ром, коньяк)
- **Антисептик** (медицина — античность)
- **Растворитель** (красители, парфюм)
- **Топливо** (этанол, биоэтанол — 20 в.)
- **Консервант** (маринование)
**Технологические цепочки**:
- зерно → солод → осахаривание → брожение → пиво (~5-8%)
- фрукты (виноград) → отжим → брожение → вино (~10-15%)
- вино → перегонка → коньяк/бренди (~40%)
- зерно → солод → осахаривание → брожение → перегонка → виски (~40-50%)
- сахарный тростник → отжим → брожение → перегонка → ром (~40%)
**Альтернативы**: метанол (токсичен!), синтетический этанол (этилен + вода — 20 в.)
**Особые свойства**:
- Самое древнее «лекарство» и обезболивающее
- Дезинфицирует раны
- Источник «спирта-ректификата» (96%)
- В игре: алкоголь = социальный клей + антисептик + товар для торговли
**Источники**: «The History of Alcohol» (McGovern, 2009)

### Уксус / Уксусная кислота (CH₃COOH)

(см. [01_fuel_products.md](01_fuel_products.md) — там описано как топливный побочный продукт)
**Пищевое применение**:
- Маринование (мясо, овощи — критично для хранения зимой)
- Соусы (горчица, кетчуп)
- Приправа
**Эпоха**: древность (Египет, ~3000 до н.э.)
**Особые свойства**: консервант → критично для зимнего рациона в холодных регионах
**Источники**: «Vinegar» (Hubbard, 1977)

## 🧀 Молочные продукты

### Сыр (Cheese) ⭐

**Сырьё**: молоко (коровье, овечье, козье, буйволиное)
**Процесс**: 
1. Сквашивание молока (молочнокислые бактерии)
2. Свертывание (фермент реннин из желудка телёнка, или растительные ферменты)
3. Отделение сыворотки от творога
4. Формовка + прессование
5. Созревание (от нескольких дней до нескольких лет)
**Условия**: 25-35°C для сквашивания, прохладное место для созревания
**Эпоха**: ~5500 до н.э. (Польша, кости с молочным жиром)
**Применения**:
- **Пища** (главное! — высокобелковая, концентрированная)
- **Консервация молока** (критично! — молоко быстро портится, сыр хранится месяцами)
- Торговля (хорошо перевозится)
**Технологические цепочки**:
- молоко → + бактерии + реннин → творог → прессование → созревание → сыр → хранение месяцев
**Особые свойства**:
- **КРИТИЧНО** — без сыра нельзя хранить молоко
- Историческая основа монгольской, швейцарской, французской, итальянской кухни
- В игре: открытие сыра → снижение риска голода зимой (стратегический резерв)
**Источники**: «Cheese and Culture» (Kindstedt, 2012)

### Масло сливочное (Butter)

**Сырьё**: молоко (сливки)
**Процесс**: взбивание сливок → отделение жира от пахты
**Эпоха**: ~6500 до н.э. (Месопотамия)
**Применения**:
- Жир для готовки (замена растительному маслу в северных регионах)
- Консервант (топлёное масло — гхи в Индии, хранится месяцами)
- Ритуальное (Индия — бог Кришна, ведический огонь)
**Особые свойства**: 
- Замена оливкового масла в холодных регионах (где нет оливы)
- Гхи — топлёное масло без воды, хранится без холодильника
**Источники**: «Butter» (McGee, 2004)

### Казеин (Casein)

**Сырьё**: молоко (белковая фракция)
**Процесс**: 
- Кислотное осаждение (уксусом)
- Ферментативное (реннин)
**Эпоха**: древность (как побочный продукт сыроварения)
**Применения**:
- **Клей** (казеиновый клей — древний)
- **Краска** (казеиновая темпера — древняя)
- **Пластик** (галалит — 19 в.)
- Пищевой белок (позднее)
**Особые свойства**: универсальный белок → клей, краска, пластик
**Источники**: «Casein» (Fox, 1996)

## 🍯 Сладости и сахар

### Сахар (Sugar, C₁₂H₂₂O₁₁) ⭐

**Сырьё**: сахарный тростник (Индия) или сахарная свёкла (Европа, 18 в.)
**Процесс**: 
- **Тростник**: отжим → уваривание сока → кристаллизация
- **Свёкла**: экстракция → уваривание → кристаллизация
- **Очистка**: через костяной уголь (обесцвечивание)
**Эпоха**: ~5000 до н.э. (Новая Гвинея), массово — античность (Индия), Европа — 16 в.
**Применения**:
- **Подсластитель** (главное — дорогой в античности)
- **Консервант** (варенье — критично для хранения фруктов)
- **Алкоголь** (ром, после брожения)
- **Ферментация** (хлебное тесто)
**Технологические цепочки**:
- сахарный тростник → отжим → уваривание → кристаллизация → сырец → очистка → белый сахар → варенье
- + фрукты → варенье → хранение на зиму
**Особые свойства**:
- Историческая монополия Индии → сахарный путь (через арабов)
- После Колумба — сахар в Америке → колониальная экономика
- В игре: сахар = стратегический товар для хранения фруктов зимой
**Источники**: «Sugar» (Mintz, 1985)

### Патока (Molasses)

**Сырьё**: побочный продукт производства сахара
**Применения**:
- Пищевая (печенье, соусы — барбекю)
- **Ром** (ферментация патоки → дистилляция → ром)
- Корм для скота
- Биотопливо (позднее)
**Особые свойства**: историческая основа ромовой индустрии Карибских островов
**Источники**: «Rum» (Curtin, 1990)

## 🐟 Консервированная пища

### Солонина / Харан (Salted meat / cured) ⭐

**Сырьё**: мясо (говядина, свинина, рыба) + соль
**Процесс**: 
1. Засолка в рассоле (крепкий раствор NaCl) или сухая соль
2. Сушка
**Условия**: прохладное место, до 1 года хранения
**Эпоха**: античность (массово)
**Применения**:
- **Стратегический резерв** (критично для зимы, для армии, для флота)
- Торговля (главный мясной товар до холодильников)
- Военное снабжение (римские легионы, флоты)
**Технологические цепочки**:
- мясо + соль → засолка → солонина → хранение 6-12 месяцев
- рыба + соль → сушка → харан (треска, сельдь) — путь викингов
**Особые свойства**:
- **КРИТИЧНО** — без соли нет стратегического запаса пищи
- Историческая основа торговли треской (Норвегия, Канада)
- В игре: критично для выживания зимой
**Источники**: «Salt» (Kurlansky, 2002)

### Копчёное мясо / рыба

**Сырьё**: мясо/рыба + дым (от костра с опилками)
**Процесс**: копчение — медленное окуривание дымом
**Условия**: низкая температура, 2-7 дней
**Эпоха**: древность
**Применения**:
- Консервант (антибактериальное действие фенолов из дыма)
- Аромат
- Традиционная пища (копчёная рыба, ветчина)
**Технологические цепочки**:
- мясо/рыба + дым (опилки) → копчение → копчёности → хранение
**Особые свойства**: фенольные соединения из древесного дыма — антисептик
**Источники**: «Smoking of Foods» (Tauscher, 1995)

### Сыровяленая колбаса / Бастурма

**Сырьё**: мясо + соль + специи
**Процесс**: засолка + сушка
**Эпоха**: древность (Турция, Армения)
**Применения**: консервированное мясо без холодильника
**Источники**: «Cured Meats» (Cassens, 1990)

## 🍞 Ферментированные продукты

### Хлеб (дрожжевой) ⭐

**Сырьё**: мука (пшеничная, ржаная) + вода + дрожжи + соль
**Процесс**: 
1. Замес теста
2. Брожение (дрожжи выделяют CO₂ → тесто поднимается)
3. Выпекание (200-250°C)
**Условия**: тёплое место для брожения, печь для выпечки
**Эпоха**: ~6000 до н.э. (Египет — первый дрожжевой хлеб)
**Применения**:
- **Основной продукт** (главная пища в Европе, Ближнем Востоке)
- Социальный символ («хлеб насущный»)
**Технологические цепочки**:
- зерно → помол → мука → + вода + дрожжи + соль → брожение → выпечка → хлеб
**Особые свойства**:
- **КРИТИЧНО** — без дрожжей нет кислого хлеба (только пресные лепёшки)
- Исторический символ цивилизации
- В игре: дрожжи → кислый хлеб → калорийнее, легче усваивается
**Источники**: «The History of Bread» (Jacob, 2007)

### Квас / Пиво (древнее)

**Сырьё**: зерно (ячмень, рожь) + вода + дрожжи
**Процесс**: соложение → осахаривание → брожение
**Эпоха**: ~10000 до н.э. (Гёбекли-Тепе — древнейшие свидетельства)
**Применения**:
- Питательный слабый алкоголь (1-3%) — древний « безопасный напиток» (кипячёная вода с бактериями)
- Социальный напиток
- Религиозное (Божество пива — Нинкаси в Шумере)
**Особые свойства**: 
- Слабое пиво было безопаснее воды в древних городах (т.к. кипячение убивало бактерии)
- В игре: пиво = стратегический напиток, повышающий мораль + безопасность воды
**Источники**: «A History of Beer and Brewing» (Hornsey, 2003)

### Вино (см. [../resources/08_food_resources.md](../resources/08_food_resources.md))

(уже описано как природный продукт)
**Дополнительно**: 
- Ферментированный виноградный сок → алкоголь 10-15%
- Стратегический товар в античности (Греция, Рим)
- Религиозное (христианство, Дионис)

### Кумыс / Кефир

**Сырьё**: кобылье/козье/коровье молоко
**Процесс**: молочнокислое + спиртовое брожение
**Эпоха**: древность (степные народы)
**Применения**: 
- Кисломолочный напиток с лёгким алкоголем (1-3%)
- Основа рациона кочевников
- Лекарство (туберкулёз — 19 в., лечение в Башкирии)
**Особые свойства**: кочевая альтернатива вину/пиву
**Источники**: «Kumys» (Leitz, 1980)

## Принципы для дизайна

### 1. Этанол — самый древний продукт
Алкоголь = медицина + обезболивающее + антисептик + социальный клей. Все культуры имели.

### 2. Сыр — критическая консервация молока
Без сыра нельзя использовать молоко стратегически. Открытие сыра = снижение риска голода зимой.

### 3. Солонина — стратегический резерв
Без солонины нет армий (провиант) и нет выживания зимой в холодных регионах. Соль = критична.

### 4. Сахар — стратегический товар
Историческая монополия Индии → колониальная экономика → рабство в Америке. В игре: сахар = поздний стратегический товар.

### 5. Хлеб — основа цивилизации
Дрожжи → кислый хлеб → +калорийность → +население. В игре: открытие дрожжей = демографический буст.

### 6. Пиво — «безопасный напиток»
В древних городах вода была опасной (бактерии). Слабое пиво (кипячёное при соложении) — безопасно. В игре: пиво снижает риск эпидемий.
