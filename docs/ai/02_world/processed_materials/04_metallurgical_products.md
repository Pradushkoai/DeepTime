# Металлургические продукты

> Сплавы, амальгамы, черновые металлы и продукты глубокой переработки руд. От бронзы (медь+олово) до алюминия (электролиз бокситов).

---

## 🥉 Сплавы (комбинирование металлов)

### Бронза (Bronze) ⭐

**Состав**: Cu + Sn (медь + олово), обычно 88% Cu + 12% Sn
**Сырьё**: медь (халькопирит или самородная) + олово (касситерит)
**Процесс**: раздельная плавка → смешивание расплавов
**Условия**: 950°C (выше Cu), нужна огнеупорная глина
**Эпоха**: ~3500 до н.э. (Ближний Восток), широко ~3000 до н.э.
**Применения**:
- **Оружие**: мечи, копья, кинжалы (главное — твёрже меди!)
- **Орудия**: топоры, серпы, ножи
- **Доспехи**: шлемы, нагрудники
- **Скульптура**: статуи (Греция)
- **Зеркала** (полированная бронза)
- **Монеты** (Рим — сестерций)
- **Колокола** (позднее)
**Технологические цепочки**:
- медь + олово → плавка → бронза → отливка → меч/топор/статуя
**Альтернативы**: 
- Мышьяковая бронза (Cu + As) — древнее, но токсична
- Свинцовая бронза — для подшипников (позднее)
**Особые свойства**:
- **КРИТИЧЕСКИ ВАЖНО** — без олова нет бронзы. Это создавало торговые пути (Корнуолл → Средиземноморье)
- Твёрже чистой меди, лучше льётся, не так быстро ржавеет
- Исторический «бронзовый век» — от 3500 до 1200 до н.э.
- «Бронзовый коллапс» 1200 г. до н.э. — разрушение торговых путей олова → упадок
**Источники**: «Tin in Antiquity» (Penhallurick, 1986)

### Латунь (Brass)

**Состав**: Cu + Zn (медь + цинк), обычно 70% Cu + 30% Zn
**Сырьё**: медь + цинк (сфалерит) — но цинк летучий, древним сложно
**Процесс**: 
- Цементация: медь + ZnO (восстановление) → латунь (прямо в Cu)
- Позднее: плавка раздельная
**Условия**: 950-1100°C
**Эпоха**: античность (римляне знали)
**Применения**:
- **Монеты** (Рим — сестерций, дупондий — жёлтый блеск)
- **Украшения**
- **Латунные инструменты** (музыкальные — позднее)
- **Водопроводные фитинги** (позднее)
**Особые свойства**:
- Жёлтый цвет → имитация золота (римские монеты)
- Цинк трудно получить отдельно → только как сплав
**Источники**: «The Metallurgy of Brass» (Day, 1973)

### Купроникель (Cupronickel)

**Состав**: Cu + Ni (медь + никель)
**Сырьё**: медь + пентландит (никель)
**Процесс**: раздельная плавка → смешивание
**Эпоха**: ~17 в. до н.э. (Китай — «белая медь»), Европа — 19 в.
**Применения**:
- **Монеты** (главное!) — современные «серебристые» монеты
- Подшипники
- Коррозионностойкие сплавы
**Особые свойства**:
- Серебристый цвет → имитация серебра
- Коррозионностойкая
- Историческая китайская монополия («packfong»)
**Источники**: USGS

### Типографский сплав / Гарт (Type metal) ⭐

**Состав**: Pb + Sn + Sb (свинец + олово + сурьма), ~75% Pb + 5% Sn + 20% Sb
**Сырьё**: свинец (галенит) + олово (касситерит) + сурьма (стибнит)
**Процесс**: плавка трёх металлов в определённой пропорции
**Эпоха**: 15 в. (Гутенберг, 1440)
**Применения**:
- **Шрифты для печати** (критично для книгопечатания!)
- Припой (олово + свинец — мягкий сплав)
**Особые свойства**:
- Расширяется при затвердевании → точная отливка шрифта (важно для качества печати)
- Без стибнита не получить правильного расширения
- В игре: критическое «бутылочное горлышко» для книгопечатания
**Технологические цепочки**:
- свинец + олово + сурьма → плавка → типографский сплав → + пресс Гутенберга → книгопечатание → массовое распространение знаний
**Источники**: «Gutenberg and the Technology of Printing» (Pollard, 2000)

### Баббит / Подшипниковый сплав (Babbitt)

**Состав**: Sn + Cu + Sb (базовый) ИЛИ Pb + Sn + Sb (дешёвый)
**Сырьё**: олово + сурьма + медь
**Процесс**: плавка
**Эпоха**: 19 в. (Бэббит, 1839)
**Применения**:
- **Подшипники** для механизмов (критично для индустриальной эпохи)
- Антифрикционные свойства
**Особые свойства**: мягкая поверхность → скольжение вала без износа
**Источники**: «Babbitt Bearings» (Berry, 1955)

## 🥈 Амальгамы и разделение

### Амальгама золота (Gold amalgam) ⭐

**Состав**: Au + Hg (золото + ртуть)
**Сырьё**: золото + ртуть (из киновари)
**Процесс**: 
1. Растворить золото в ртути → амальгама (паста)
2. Нагрев → ртуть испаряется (424°C) → остаётся чистое золото
**Эпоха**: античность (известна), массово — 16 в. (патер — для извлечения Au из руды)
**Применения**:
- **Извлечение золота из руды** (критично! — амальгамация)
- Золочение (огонь + амальгама → золочение серебра/меди)
**Технологические цепочки**:
- руда с золотом + Hg → амальгамация → паста → нагрев → Hg испаряется → чистое Au
**Особые свойства**:
- Источник золота в рудах с низкой концентрацией (где не получается промывкой)
- Токсична (Hg пары!) — историческая проблема ртутью
- В игре: критично для эффективности золотодобычи
**Источники**: «Amalgamation Process» (Rickard, 1907)

### Амальгама серебра (Silver amalgam)

**Состав**: Ag + Hg
**Аналогично амальгаме золота**, но для серебра
**Процесс**: патер процесс (Мексика, 16 в.) — извлечение Ag из руды с помощью ртути
**Применения**:
- Извлечение серебра из бедных руд (историческая проблема испанских рудников в Америке)
**Особые свойства**: патер процесс — критическая технология для испанской колониальной экономики
**Источники**: «Patio Process» (Whitaker, 1938)

### Серебро из галенита (cupellation) ⭐

**Сырьё**: галенит (PbS) с примесью серебра
**Процесс**: cupellation
1. Обжиг галенита → черновой свинец (с Ag внутри)
2. Окисление свинца в печи с тягой (cupel) → PbO испаряется, Ag остаётся
**Условия**: 1100°C, печь с тягой
**Эпоха**: ~3000 до н.э. (Лидия, Лаврион)
**Применения**:
- **Серебро массовое** (критично для античной экономики — Афины, Рим)
**Технологические цепочки**:
- галенит (PbS + Ag) → обжиг → Pb + Ag (черновой) → cupellation → Ag чистое + PbO
**Особые свойства**:
- **КРИТИЧНО** — основной источник серебра в античности
- Афины разбогатели на серебре Лавриона
- «Lydian» (лидийские) серебряные монеты — первые в мире (~600 до н.э.)
- Историческая монополия Лидии / Лавриона / Потоси
**Источники**: «Silver in Antiquity» (Patterson, 1972)

## 🥇 Сплавы железа

### Чугун (Cast iron / Pig iron)

**Состав**: Fe + 2-4% C (высокоуглеродистый сплав)
**Сырьё**: железная руда (гематит/магнетит) + кокс + известняк (флюс)
**Процесс**: доменная плавка
**Условия**: 1500°C (нужна домна с шамотной футеровкой!)
**Эпоха**: ~500 до н.э. (Китай), Европа — 14 в. (массово — 18 в.)
**Применения**:
- **Отливка**: котлы, пушки, трубы, станки, радиаторы
- Сырьё для стали (через декарбуризацию)
**Особые свойства**:
- Хрупкий, но льётся (сталь нельзя отлить — только ковать)
- В Китае — рано (имели домны), в Европе — поздно
**Источники**: «Iron and Steel in China» (Needham, 1958)

### Сталь (Steel) ⭐⭐ КРИТИЧЕСКИ ВАЖНО

**Состав**: Fe + 0.1-2% C (низко-среднеуглеродистый сплав)
**Сырьё**: 
- Чугун (через декарбуризацию)
- Или железо + карбюризация (цементация)
**Процесс**: 
- **Сыродутный процесс** (древний): железо + уголь в горне → губка → ковать
- **Тигельная плавка** (Индия, ~300 до н.э.): в тигле с добавками
- **Домна + конвертер** (Бессемер, 1856): чугун → воздух → сталь
- **Мартеновская печь** (Сименс-Мартин, 1864): сталь + чугун → сталь
- **Кислородный конвертер** (LD, 1952): современный основной метод
**Условия**: 1500-1700°C (нужна огнеупорная футеровка — шамот, магнезит)
**Эпоха**: 
- Древняя сталь (Индия, Дамаск): ~300 до н.э. (вуц)
- Массовая сталь: 19 в. (Бессемер)
- Современная: 20 в.
**Применения**:
- **Всё**: инструменты, оружие, механизмы, станки, корабли, поезда, автомобили, небоскрёбы
**Технологические цепочки**:
- Fe-руда + кокс + CaO → домна 1500°C → чугун → + O₂ → сталь (Бессемер) → всё современное
- Fe + углерод → тигель 1500°C → тигельная сталь (Дамаск) → клинки
**Особые свойства**:
- **КРИТИЧНО** — без стали нет индустриализации
- Без домны — только мелкие количества (Дамасск)
- Кокс (←каменный уголь) — критическое «бутылочное горлышко»
- Без огнеупоров (шамот, магнезит) — нет домны
- В игре: переход в индустриальную эпоху требует стали → домны → кокса → огнеупоров
**Источники**: «A History of Ironworking» (Tylecote, 1992)

### Нержавеющая сталь (Stainless steel)

**Состав**: Fe + 0.1% C + 13-18% Cr (хром)
**Сырьё**: сталь + хром (хромит)
**Процесс**: легирование стали хромом
**Эпоха**: 20 в. (Бреарли, 1913)
**Применения**:
- Посуда
- Инструменты (медицинские)
- Конструкции (не ржавеет)
**Особые свойства**: стойкость к коррозии
**Источники**: «Stainless Steel» (Carpenter, 1968)

## 🥂 Драг. металлы — очистка

### Чистое золото (Refined gold)

**Сырьё**: самородное золото (с примесями Ag, Cu)
**Процесс**: 
- Хлорирование (позднее — Miller process)
- Электролитическое (Wohlwill, 1878)
**Применения**: чистое Au (99.99%)
**Источники**: «Gold Refining» (Rose, 1937)

### Чистое серебро (Refined silver)

**Сырьё**: черновое серебро (с примесями Pb, Cu)
**Процесс**: электролитическое (Moebius, 1882)
**Применения**: чистое Ag (99.9%)
**Источники**: «Silver Refining» (Hamilton, 1925)

## ⚡ Лёгкие металлы (поздняя индустриализация)

### Алюминий (Aluminium) ⭐⭐ КРИТИЧНО (поздняя эпоха)

**Состав**: чистый Al
**Сырьё**: бокситы (Al₂O₃·nH₂O) → глинозём (Al₂O₃)
**Процесс**: электролиз расплава глинозёма в криолите (процесс Холла-Эру, 1886)
**Условия**: 950°C + электричество + криолит (Na₃AlF₆ — флюс)
**Эпоха**: 19 в. (открыт 1825, массово — 1886)
**Применения**:
- **Лёгкие конструкции**: самолёты, рамы, банки, посуда, провода
- Сплавы (дюраль, силумин)
- Электрические провода (замена Cu — дешевле)
**Технологические цепочки**:
- бокситы → обработка (Байер, 1887) → глинозём (Al₂O₃) → электролиз (Холл-Эру) + нефтяной кокс (электроды) → Al
**Предпосылки**:
1. Бокситы (география)
2. Знание химии глинозёма (19 в.)
3. Электричество (Фарадей, 1831 → генератор)
4. Криолит (Гренландия)
5. Нефтяной кокс (электроды)
6. Дешёвая энергия (ГЭС)
**Особые свойства**:
- В 19 в. дороже золота (до открытия процесса Холл-Эру)
- Самый распространённый металл в земной коре (8%), но очень энергоёмкий
- КРИТИЧНО для современной цивилизации
- В игре: «финишная прямая» для перехода в электронную эпоху
**Источники**: «Aluminium» (Kirk-Othmer)

### Хром (Chromium)

**Состав**: чистый Cr
**Сырьё**: хромит (FeCr₂O₄)
**Процесс**: 
- Термитная реакция: хромит + Al → Cr + Al₂O₃ (термит — Гольдшмидт, 1894)
- Электролиз (позднее)
**Эпоха**: 19 в.
**Применения**:
- **Нержавеющая сталь** (легирование)
- Хромирование (защитное покрытие)
- Суперсплавы (турбины — позднее)
**Особые свойства**: критично для нержавейки
**Источники**: USGS

### Никель (Nickel)

**Состав**: чистый Ni
**Сырьё**: пентландит ((Fe,Ni)₉S₈)
**Процесс**: 
- Обжиг + плавка → черновой Ni
- Электролитическое рафинирование
**Эпоха**: 18 в. (открыт), массово — 19 в.
**Применения**:
- Легирование (купроникель, нержавейка, суперсплавы)
- Покрытия (никелирование)
- Монеты
**Источники**: USGS

## Цикл развития металлургии

```
1. Самородная медь (ковка) → простые орудия
   ↓
2. Малахит → обжиг → медь → плавка → медные орудия
   ↓
3. Бронза (Cu + Sn) ⭐ — нужна медь И олово (критическое горлышко!)
   ↓
4. Свинец + серебро (cupellation галенита) ⭐
   ↓
5. Железо (сыродутное) — ранняя сталь (Дамаск)
   ↓
6. Чугун (Китай, 500 до н.э.) — домна
   ↓
7. Сталь (Бессемер, 1856; мартен; LD) ⭐⭐ — индустриализация
   ↓
8. Нержавеющая сталь (Cr + сталь) — 20 в.
   ↓
9. Алюминий (электролиз) ⭐⭐ — электронная эпоха
   ↓
10. Суперсплавы (Cr, Ni, Co + Fe) — турбины, реактивные двигатели
```

## Принципы для дизайна

### 1. Бронза — историческое бутылочное горлышко

Без олова нет бронзы. Это создавало торговые пути и империи. «Бронзовый коллышок» 1200 г. до н.э. — разрушение торговли → упадок цивилизаций.

### 2. Cupellation — критическая технология серебра

Без cupellation нет массового серебра → нет денег → нет экономики. Афины и Лидия богатели именно на этом.

### 3. Сталь требует домну → кокс → огнеупоры

Тройное «бутылочное горлышко» индустриализации. Без любого из трёх — нет стали.

### 4. Алюминий — самая требовательная технология

Нужны: бокситы + электричество + криолит + нефтяной кокс + дешёвая энергия. Это «финишная прямая» для перехода в электронную эпоху.

### 5. Книгопечатание требует типографского сплава

Pb + Sn + Sb — без сурьмы (стибнит) нет качественной печати. Это делает месторождения стибнита стратегическими.

### 6. Амальгамация — позднее золото/серебро

Только в 16 в. Испанцы использовали в Америке. Это дало колоссальный рост добычи серебра.

### 7. Принцип «бесконечного развития»

Каждый шаг в металлургии требует больше технологий. От самородной меди (~10000 до н.э.) до алюминия (1886 н.э.) — путь в 12000 лет. Игрок сам решает, как далеко идти.
