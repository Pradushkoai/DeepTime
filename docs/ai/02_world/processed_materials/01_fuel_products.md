# Топливные продукты

> Продукты, получаемые при термической обработке органического сырья (древесины, угля, торфа, нефти). Главные — кокс, древесный уголь, дёготь, газы.

---

## 🪵 Древесина → сухая перегонка (пиролиз ~400°C без воздуха)

### Древесный уголь (Charcoal)

**Сырьё**: древесина (см. [../resources/05_wood_timber.md](../resources/05_wood_timber.md))
**Процесс**: сухая перегонка без доступа воздуха (угольная куча/яма)
**Условия**: ~400-500°C, без O₂, 5-7 дней
**Эпоха**: с неолита (~7000 до н.э. — Шумер)
**Применения**:
- **Металлургия**: плавка меди (700°C), бронзы (950°C), ранняя плавка железа (нужен + воздух)
- Безопасное топливо (без дыма в кухне)
- Порох (компонент с серой и селитрой)
- Фильтрация (активированный уголь — позднее)
**Технологические цепочки**:
- дерево → углежжение → древесный уголь → + руда → плавка → металл
- дерево → углежжение → уголь → + сера + селитра → помол → порох
**Альтернативы**: каменный уголь (после коксования), торфяной уголь (хуже)
**Особые свойства**: даёт температуру 1100-1300°C (выше дерева). Историческая проблема — вырубка лесов вокруг медных рудников
**Источники»: «The Charcoal Forests of the Mediterranean» (Thirgood, 1981)

### Дёготь древесный (Wood tar)

**Сырьё**: кора и древесина хвойных (сосна, ель, лиственница)
**Процесс**: сухая перегонка (выделение жидкой фракции)
**Эпоха**: с античности
**Применения**:
- **Герметизация**: корабли, амфоры, бочки (критично для мореплавания)
- **Консервант**: кожи, канаты
- **Медицина**: антисептик (раны), дёгтярное мыло
- **Клей**: стрелы, орудия
- **Косметика**: мыло (с золой)
- **Защита дерева**:防腐
**Технологические цепочки**: живица/кора → сухая перегонка → дёготь → герметизация корабля
**Особые свойства**: антибактериальное. Критично для финикийского и греческого мореплавания
**Источники»: «Pitch and Tar» (Needham, 1971)

### Метанол / Древесный спирт (Methanol, CH₃OH)

**Сырьё**: древесина (любая)
**Процесс**: сухая перегонка + конденсация летучих фракций
**Эпоха**: древность (известен с античности, массово — 17 в.)
**Применения**:
- **Растворитель**: красители, смолы
- **Антисептик**: медицина
- **Топливо** (позднее)
- **Защита дерева** (как дёготь)
**Особые свойства**: токсичен (вызывает слепоту при приёме внутрь)
**Источники»: Ullmann's Encyclopedia

### Уксусная кислота (Acetic acid, CH₃COOH)

**Сырьё**: древесина (через перегонку) ИЛИ ферментация этанола (главный путь)
**Процесс**: 
- Древесная: сухая перегонка + окисление
- Биологическая: ферментация этанола бактериями Acetobacter
**Эпоха**: древность (Египет, ~3000 до н.э.)
**Применения**:
- **Пищевая**: уксус (маринование, консервация)
- **Медицина**: антисептик
- **Протрава**: красители (с Fe — чёрные цвета)
- **Растворитель**
**Технологические цепочки**: 
- этанол + Acetobacter → ферментация → уксус
- зерно → солод → брожение → этанол → окисление → уксус

### Древесный газ (Wood gas, CO + H₂ + CH₄)

**Сырьё**: древесина
**Процесс**: сухая перегонка (газовая фракция)
**Эпоха**: античность (использовался в печах), массово — 19-20 в. (гогенолеты)
**Применения**:
- Топливо печей
- Восстановитель в металлургии (CO)
- Синтез-газ (позднее — для аммиака по Габеру-Бошу)
**Особые свойства**: в игре — можно использовать в доменной печи как восстановитель
**Источники»: Ullmann's Encyclopedia

## ⚫ Каменный уголь → коксование (~1000°C без воздуха)

### Кокс (Coke) ⭐ КРИТИЧНО

**Сырьё**: каменный уголь (битуминозный)
**Процесс**: коксование — нагрев без доступа воздуха
**Условия**: ~1000-1200°C, без O₂, 15-30 часов
**Эпоха**: античность (редко — Спарта), массово — 17-18 в. (Англия)
**Применения**:
- **Сталь** (главное!): в доменной печи с железной рудой + известняк (флюс) → чугун → + кокс + воздух → сталь
- Топливо (выше угля — чище, без серы)
- Химическое сырьё (источник углерода)
- Электроды (позднее)
**Технологические цепочки**:
- каменный уголь → коксование → кокс → + руда + CaO → домна 1500°C → чугун → + кокс + воздух → сталь
**Альтернативы**: древесный уголь (но нужен лес!), нефтяной кокс
**Особые свойства**: 
- **КРИТИЧЕСКИ ВАЖНО** — без кокса нет домны, без домны нет стали, без стали нет индустриализации
- Исторический «водораздел» между органической и индустриальной экономикой
- В игре: «бутылочное горлышко» для перехода в индустриальную эпоху
**Источники»: «Coal: A Human History» (Freese, 2003)

### Каменноугольная смола (Coal tar)

**Сырьё**: каменный уголь (побочный продукт коксования)
**Процесс**: коксование → конденсация смолы
**Эпоха**: 17-19 в. (массовое применение)
**Применения**:
- **Креозот** (антисептик для дерева, медицина)
- **Красители** (анилин, фуксин — Мов, 1856)
- **Лекарства** (аспирин — Гофман, 1897, из каменноугольной смолы)
- **Дёготь** (кровля, дороги)
- Нафталин (нафталиновые шарики)
- Бензол, толуол, ксилол (растворители, красители)
**Технологические цепочки**:
- каменный уголь → коксование → смола → фракционная перегонка → креозот + бензол + нафталин
**Особые свойства**: источник первой синтетической краски (анилиновый фуксин)
**Источники»: Ullmann's Encyclopedia

### Коксовый газ (Coke oven gas, H₂ + CH₄)

**Сырьё**: каменный уголь (побочный продукт коксования)
**Процесс**: коксование → сбор газа
**Эпоха**: 19 в. (освещение городов)
**Применения**:
- **Освещение городов** (газовые фонари — Лондон, 1807)
- Топливо (печи, котлы)
- Химическое сырьё (H₂ для аммиака — процесс Габера-Боша)
**Особые свойства**: первый «городской газ» до природного газа
**Источники»: Ullmann's Encyclopedia

## 🌾 Торф → сухая перегонка

### Торфяной уголь (Peat char)

**Сырьё**: торф
**Процесс**: сухая перегонка (аналог углежжения)
**Условия**: ~400-500°C без воздуха
**Эпоха**: древность (Нидерланды, Ирландия)
**Применения**:
- Низкокачественное топливо (между торфом и древесным углём)
- Источник углерода
**Особые свойства**: только для северных регионов без дерева
**Источники»: IPS (International Peat Society)

### Торфяной дёготь (Peat tar)

**Сырьё**: торф
**Процесс**: сухая перегонка
**Применения**:
- Герметизация (как древесный)
- Медицина
**Особые свойства**: низкое качество, только локальное использование
**Источники»: IPS

## Принципы для дизайна

1. **Кокс — критическое «бутылочное горлышко» индустриализации**. Без кокса нет домны → нет стали → нет паровой машины → нет электричества.
2. **Древесный уголь — альтернатива коксу** для ранней металлургии, но требует много дерева.
3. **Дёготь — основа мореплавания** (герметизация кораблей). Без дёгтя нет финикийцев/викингов.
4. **Побочные продукты коксования** (смола, газ) — отдельная статья дохода в индустриальную эпоху.
5. **Истощение лесов** при углежжении — модель экоупадка в игре.
