# Гигиена, текстиль и бытовые продукты

> Мыло, олифа, стеарин, клей, краски — продукты для повседневной жизни и ремесленного производства.

---

## 🧼 Гигиена

### Мыло (Soap) ⭐

**Состав**: соль жирной кислоты (Na- или K-oleate/stearate)
**Сырьё**: 
- Жир животный (говяжий, бараний) ИЛИ масло растительное (оливковое, кокосовое, касторовое)
- Щёлочь: поташ (K₂CO₃) из древесной золы ИЛИ сода (Na₂CO₃) из натрона
**Процесс**: 
1. Нагрев жира/масла
2. Добавление щёлочи
3. Омыление: жир + щёлочь → мыло + глицерин
4. Добавки: ароматизаторы (лаванда, розмарин), абразивы (песок, зола)
**Условия**: 60-100°C, 2-3 часа
**Эпоха**: ~2800 до н.э. (Вавилон — первые рецепты), массово — 7 в. н.э. (арабы)
**Применения**:
- **Гигиена** (тело, руки, посуда)
- **Медицина** (антибактериальное)
- **Стирка одежды**
- **Бритьё** (пена)
- Косметика
**Технологические цепочки**:
- жир + поташ → омыление → мыло (K-oleate, мягкое)
- жир + сода → омыление → мыло (Na-oleate, твёрдое)
- + ароматизаторы → парфюмированное мыло
**Особые свойства**:
- **КРИТИЧНО** для гигиены → снижение эпидемий
- Историческая проблема: в Европе мыло было роскошью до 19 в.
- В игре: открытие мыла = снижение смертности от инфекций
**Источники**: «Soap» (Kuntz, 1928)

### Глицерин (Glycerol, C₃H₅(OH)₃)

**Сырьё**: побочный продукт омыления жиров
**Процесс**: выщелачивание мыльного раствора → отделение глицерина
**Эпоха**: 18 в. (Шеель, 1779)
**Применения**:
- **Увлажнитель** (косметика, медицина)
- **Сладкий сироп** (пищевая промышленность — позднее)
- **Нитроглицерин** (взрывчатка — 19 в., Нобель)
- Антифриз
**Особые свойства**: побочный продукт мыловарения → стратегический ресурс (нитроглицерин)
**Источники**: «Glycerol» (Harris, 1949)

### Стеарин (Stearin)

**Состав**: смесь стеариновой (C₁₇H₃₅COOH) и пальмитиновой кислот
**Сырьё**: животные жиры (говяжий, бараний)
**Процесс**: 
1. Омыление жира → мыло + глицерин
2. Кислотное разложение мыла → стеарин
**Эпоха**: 19 в. (Шеврёль, 1825)
**Применения**:
- **Свечи стеариновые** (главное! — замена воска)
- Резина (модификатор, позднее)
- Косметика
**Технологические цепочки**:
- жир животный → омыление → мыло → кислота → стеарин → + фитиль → свеча
**Особые свойства**: 
- Твёрже жира, не плавится в руках
- Дешевле воска → свечи для всех
- В игре: «демократизация освещения»
**Источники**: «Candles and Candlemaking» (Bright, 1978)

## 🎨 Текстиль и живопись

### Олифа / Льняное масло (Linseed oil / Drying oil)

**Сырьё**: лён (см. [../resources/06_fibers_textiles.md](../resources/06_fibers_textiles.md))
**Процесс**: 
1. Отжим семян льна → масло
2. Кипячение (полимеризация) → олифа (густая, тёплая)
**Условия**: 100-200°C с добавлением свинцового сурика (катализатор)
**Эпоха**: античность (известна), живопись — 12 в. (Ян ван Эйк усовершенствовал, 15 в.)
**Применения**:
- **Масляная живопись** (главное! — для художников)
- Лак (защитное покрытие)
- Замазка (оконная)
- Олифа для дерева (защита)
**Технологические цепочки**:
- лён (семена) → отжим → льняное масло → кипячение + сурик → олифа → + пигменты → масляная краска
**Особые свойства**: 
- Полимеризуется на воздухе → твёрдая плёнка → долговечная краска
- Основана масляная живопись (Ренессанс!)
- В игре: критично для искусства поздней эпохи
**Источники**: «Oil Painting» (Mayer, 1940)

### Масляная краска / Масляная живопись ⭐

**Состав**: олифа + пигмент
**Сырьё**: олифа (←лён) + пигменты (охра, лазурит, индиго, и т.д.)
**Процесс**: перетирание пигмента с олифой → паста
**Эпоха**: 15 в. (Ян ван Эйк, ~1410-1440)
**Применения**:
- **Живопись** (главное! — Ренессанс, Барокко, и т.д.)
- Декоративная отделка
**Технологические цепочки**:
- пигмент + олифа → перетирание → масляная краска → + холст (лён) → картина
**Особые свойства**: 
- Долговечная (столетия)
- Возможность лессировки (прозрачные слои)
- В игре: открывает искусство живописи (бонус культуре/счастью)
**Источники**: «Materials of Painting» (Feller, 1986)

### Декстрин / Клейстер (Dextrin / Starch paste)

**Сырьё**: крахмал (зерно, картофель)
**Процесс**: 
- Нагрев крахмала с водой → клейстер
- Сухой нагрев крахмала → декстрин (порошок)
**Эпоха**: древность (клейстер), 19 в. (декстрин)
**Применения**:
- **Клей** (бумага, дерево — древний)
- **Аппретура** (текстиль — крахмаление)
- Пищевое (загуститель)
- Почтовые марки (позднее)
**Особые свойства**: простейший клей → критично для бумажной индустрии
**Источники**: «Adhesives» (Skeist, 1977)

### Казеиновый клей (Casein glue)

**Сырьё**: казеин (из молока)
**Процесс**: осаждение казеина + обработка щёлочью
**Эпоха**: древность (Египет, Греция)
**Применения**:
- **Клей для дерева** (главное! — мебель, иконы)
- Краска (казеиновая темпера)
- Пластик (галалит — 19 в.)
**Особые свойства**: водостойкий после высыхания → мебель
**Источники**: «Casein» (Fox, 1996)

## 🕯️ Освещение и уют

### Свеча восковая (Beeswax candle)

**Сырьё**: пчелиный воск (см. [../resources/08_food_resources.md](../resources/08_food_resources.md))
**Процесс**: расплавить воск → + фитиль → формовка
**Эпоха**: античность
**Применения**:
- Освещение (дорогое! — для церквей и элиты)
- Религиозное (христианство, буддизм)
- Косметика
**Особые свойства**: 
- Без дыма (в отличие от сальных)
- Дорогие → только для элиты
**Источники**: «Candles» (Bright, 1978)

### Свеча стеариновая (Stearin candle) ⭐

**Сырьё**: стеарин (← животный жир)
**Процесс**: формовка
**Эпоха**: 19 в. (Шеврёль, 1825)
**Применения**:
- **Освещение для всех** (дешевле воска!)
- Дома, мастерские, фабрики (до электричества)
**Особые свойства**: 
- «Демократизация освещения»
- В игре: переход от элитных свечей (воск) к массовым (стеарин) → +продуктивность труда вечером
**Источники**: «Candles» (Bright, 1978)

### Свеча парафиновая (Paraffin candle)

**Сырьё**: парафин (←нефть)
**Процесс**: формовка
**Эпоха**: 19 в. (1850-е)
**Применения**:
- Освещение (дешевле стеарина)
- Косметика
- Консервация
**Особые свойства**: самый дешёвый вид свечей → полное освещение масс
**Источники**: «Candles» (Bright, 1978)

### Сальная свеча (Tallow candle)

**Сырьё**: животный жир (говяжий/бараний)
**Процесс**: расплавить жир → + фитиль → формовка
**Эпоха**: античность
**Применения**:
- Дешёвое освещение (для бедных)
- Дымная, неприятный запах
**Особые свойства**: 
- Дешёвая альтернатива воску
- Дымит, коптит → снижение гигиены
**Источники**: «Candles» (Bright, 1978)

## 🌸 Косметика и парфюмерия

### Помада / Белила / Грим

**Сырьё**: 
- Белила: свинцовые белила (PbCO₃) или мел
- Румяна: охра, кошениль, краппа
- Чёрная (глаза): сажа, стибнит
- Красная (губы): кошениль, марена
**Процесс**: помол + смешивание с жиром/маслом
**Эпоха**: Египет (~3000 до н.э.)
**Применения**:
- Косметика (декоративная)
- Защита от солнца (Египет)
- Ритуальное (погребальное)
**Особые свойства**: 
- Свинцовые белила токсичны → историческая проблема со здоровьем
- В игре: элитный спрос
**Источники**: «Cosmetics» (Corson, 1972)

### Парфюм / Эфирные масла

**Сырьё**: 
- Цветы (роза, лаванда, жасмин)
- Пряности (корица, гвоздика, имбирь)
- Смолы (ладан, мирра)
**Процесс**: 
- Дистилляция (с водой и маслом-носителем)
- Анфлёраж (извлечение жиром)
**Эпоха**: античность (массово — арабы, 9 в.)
**Применения**:
- Парфюм (главное!)
- Медицина (антисептик — эфирные масла)
- Религия (благовония)
- Косметика
**Особые свойства**: 
- Дистилляция — критическая технология (изобрёл Ибн Сина, 11 в.)
- В игре: открытие дистилляции эфирных масел → парфюм + медицина
**Источники**: «Perfume» (Classen, 1994)

## Принципы для дизайна

### 1. Мыло — критично для гигиены

Без мыла → выше смертность от инфекций. Открытие мыла = снижение эпидемий. Историческая связь: мыловарение в Европе 7 в. → снижение смертности.

### 2. Стеариновые свечи — «демократизация освещения»

До 19 в. — свечи для элиты (воск). Стеарин → свечи для всех. Это дало возможность работать вечером → индустриализация.

### 3. Масляная живопись — культурная революция

До 15 в. — темпера (яичная). Масляная живопись (Ян ван Эйк) → Ренессанс. В игре: бонус к культуре/искусству.

### 4. Глицерин → нитроглицерин

Побочный продукт мыловарения → взрывчатка (динамит, Нобель, 1867). В игре: «случайное» военное применение мыловарения.

### 5. Парфюм — побочный продукт дистилляции

Дистилляция (Ибн Сина) → парфюм + медицина (эфирные масла) + спирт (медицина). Одна технология → много продуктов.

### 6. Эволюция свечей

Воск (элита) → Сало (бедные, дымно) → Стеарин (массы) → Парафин (дешевле) → Электричество (позднее). Пример «бесконечного развития» в одной категории.
