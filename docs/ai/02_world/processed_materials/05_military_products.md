# Военные продукты

> Продукты военного применения: порох, яды, зажигательные смеси. Исторически часто были «секретными технологиями».

---

## 💥 Порох

### Чёрный порох (Black powder) ⭐

**Состав**: KNO₃ (селитра) + S (сера) + C (древесный уголь), обычно 75:10:15
**Сырьё**: 
- Селитра (KNO₃) — из навоза животных, старых копанок
- Сера (S) — самородная (Сицилия) или из пирита
- Древесный уголь (C) — из дерева
**Процесс**: 
1. Помол компонентов отдельно
2. Смешивание в правильной пропорции
3. Грануляция (для нужной скорости горения)
**Условия**: ручное производство, позже — водяные мельницы
**Эпоха**: ~9 в. (Китай, Бай Цзыяо), 13 в. (Европа — Роджер Бэкон)
**Применения**:
- **Огнестрельное оружие**: ружья, пушки (14 в. — Европа)
- **Взрывчатка**: мины, гранаты, бомбы
- **Ракеты** (позднее)
**Технологические цепочки**:
- селитра + сера + древесный уголь → помол → порох → + фитиль → граната/пушка
**Особые свойства**:
- **КРИТИЧНО** — три компонента, все нужны:
  - Селитра (трудно достать в Европе — старые копанки, Чили)
  - Сера (Сицилия — монополия в античности)
  - Древесный уголь (лес — возобновляемый)
- Исторически: открытие пороха — революция в военном деле
- В игре: переход от холодного к огнестрельному оружию
**Источники**: «Saltpeter» (Needham, 1985), «Gunpowder» (Kelly, 2004)

### Дымный порох / Заряд (Gunpowder charge)

**Та же смесь, но в виде гранул определённого размера** для пушек/ружей
**Особые свойства**: размер гранул влияет на скорость горения → разные применения
**Источники**: «Gunpowder» (Kelly, 2004)

## 🔥 Зажигательные смеси

### Греческий огонь (см. [03_petroleum_products.md](03_petroleum_products.md))

(подробное описание — в нефтепродуктах, так как сырьём является нефть)
**Военное применение**: насос-сифон → зажигательные корабли → защита от осады
**Особые свойства**: горит на воде → морское оружие

### Коктейль Молотова / Зажигательная бутылка

**Состав**: горючая жидкость (бензин/смола/мазут) + бутылка + фитиль
**Сырьё**: нефтяные продукты + стекло
**Эпоха**: 20 в. (финны — против СССР, 1939)
**Применения**: пехотное зажигательное оружие
**Особые свойства**: простое производство → партизанское оружие
**Источники**: «Incendiary Weapons» (Stockholm International Peace Research Institute)

## ☠️ Яды

### Акотинит / Акотин / Aconitine

**Источник**: аконит (Aconitum napellus) — растение
**Процесс**: экстракция корней
**Эпоха**: древность (Греция, Восточная Европа)
**Применения**:
- Ядовитые стрелы (древние германцы, монголы)
- Убийства (политика)
- Медицина (в малых дозах — сердечное)
**Особые свойства**: один из самых ядовитых растений Европы
**Источники**: «A History of Poisons» (Thompson, 1931)

### Мышьяк / Арсеник (As₂O₃) ⭐

**Источник**: самородный мышьяк (редко), побочный продукт плавки Cu/As минералов
**Процесс**: обжиг мышьяковых руд → As₂O₃ возгоняется → собирается
**Эпоха**: античность
**Применения**:
- **Яд**: «наследный порошок» (Borgia, 15-16 в.)
- **Краситель** (зелёный — «париковый зелёный» Scheele, 1775)
- **Стекло** (обесцвечивание зелёного оттенка)
- **Лекарство** (лечение сифилиса — 19 в.)
- Инсектицид
- Легирование меди (мышьяковая бронза)
**Особые свойства**:
- Исторически — «король ядов и яд королей»
- В игре: стратегическое применение для убийств/отравленных стрел
**Источники**: «Arsenic» (British Arsenic Company, 1910)

### Кураре (Curare)

**Источник**: Strychnos toxifera и др. (Южная Америка)
**Процесс**: экстракция коры + упаривание
**Эпоха**: аборигены Амазонии (древность)
**Применения**:
- Ядовитые стрелы для охоты (не убивает мясо — только нервную систему)
- Медицина (миорелаксант — 20 в.)
**Особые свойства**: действует только при попадании в кровь (не в желудок) → можно есть отравленную дичь
**Источники**: «Curare» (McIntyre, 1947)

### Ртуть (Hg)

(см. [../resources/01_minerals_ores.md](../resources/01_minerals_ores.md) — сырьё)
**Ядовитое применение**: пары ртути — нейротоксин
**Историческое**: «лечение» сифилиса (15-17 в.) — отравляли пациентов
**Особые свойства**: хроническое отравление — «безумие шляпника» (меркуриализм)
**Источники**: «Mercury Poisoning» (Goldwater, 1972)

## Принципы для дизайна

### 1. Порох — три компонента, все критичны

Селитра + сера + уголь. Все три нужны. Это создаёт три «бутылочных горлышка» для военной революции.

### 2. Греческий огонь — секретное оружие

В игре: можно сделать технологию, которую сложно украсть. Только через шпионов или дип. отношения.

### 3. Яды — стратегические для убийств/охоты

Аконит, мышьяк, кураре — каждый со своими свойствами. Можно использовать:
- Для отравленных стрел (акотин, кураре)
- Для политических убийств (мышьяк)
- Для охоты (кураре)

### 4. Химическое оружие — только в позднюю индустриальную эпоху

Если игрок идёт в современность, может разработать химическое оружие. Но это требует много предпосылок.

### 5. Холодное оружие → огнестрельное

Переход от холодного оружия (мечи, копья) к огнестрельному — историческая веха. В игре: открытие пороха → через 200-500 лет → первое ружьё.
