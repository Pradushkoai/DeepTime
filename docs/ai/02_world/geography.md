# Geography — Реальная география

## Источники данных

Мир игры строится не процедурно, а на основе реальных географических данных. Это означает, что игровой движок не «генерирует» карту, а импортирует её из научных баз данных. Один раз при сборке игры выполняется процесс конвертации: реальные геоданные в формате shapefile и raster преобразуются в гекс-сетку с предвычисленными атрибутами каждого гекса. Результат сериализуется в бинарный файл, который грузится в рантайме.

| Источник | Что предоставляет |
|---|---|
| **NASA SRTM** | Цифровая модель рельефа, разрешение 30 м. Высоты, горы, долины. |
| **ASTER GDEM** | Альтернативный источник высот, более свежий в полярных регионах. |
| **OpenStreetMap** | Реки, озёра, леса, болота. Импорт через osm2pgsql. |
| **GEBCO** | Батиметрия мирового океана. Глубины морей. |
| **Koppen-Geiger** | Классификация климатических зон. Биоклиматические пояса. |
| **MODIS (NASA)** | Спутниковая растительность. Типы лесов, саванн, пустынь. |
| **SoilGrids (ISRIC)** | Глобальные почвенные данные. Типы почв, плодородие. |
| **USGS MRDS** | Месторождения полезных ископаемых по всему миру. |
| **BGS** | Британская геологическая служба — европейская геология. |
| **ВСЕГЕИ** | Российская геологическая служба — месторождения на территории РФ/СНГ. |

## Пайплайн конвертации

```
Реальные данные (shapefile, raster)
        ↓
GDAL + QGIS — preprocessing
        ↓
Гекс-сетка с предвычисленными атрибутами
        ↓
Сериализация в бинарный файл
        ↓
Рантайм: грузится за секунды
```

## Отличие от GDD v0.1

Ранее в источниках были PaleoClim, NOAA NCEI Paleoclimatology, Paleo-DEM NOAA, BIOME 6000, PANGEA — все для палео-реконструкции. **Удалено в v0.2**, так как палео-реконструкция отменена. Используются современные источники данных, перечисленные выше.
