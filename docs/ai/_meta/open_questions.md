## Как пользоваться этим реестром

### Для ИИ в новой сессии

1. Прочитай **DASHBOARD** в начале (быстрый обзор)
2. Если нужен контекст по конкретному вопросу — прочитай соответствующий раздел ниже
3. Если пользователь спрашивает «что открыто?» — покажи DASHBOARD
4. Если пользователь спрашивает «что делать дальше?» — покажи «Рекомендуемый порядок проработки»

### При решении вопроса

1. Переведи вопрос в статус `RESOLVED` (в двух местах: DASHBOARD и полный список)
2. Добавь запись в `decision_log.md` с обоснованием
3. Добавь запись в `reasoning_log.md` с ходом рассуждений
4. При необходимости — создай доменный файл (например, `05_player/chief_role.md`)

### При добавлении нового вопроса

1. Присвой следующий Q-XXX (нумерация сквозная)
2. Добавь в DASHBOARD в нужный приоритетный блок
3. Добавь детальный раздел ниже
4. Если есть зависимости — обнови диаграмму зависимостей
5. Обнови сводку по приоритетам
