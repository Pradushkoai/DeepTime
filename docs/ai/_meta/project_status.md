## Архитектура слоёв (v0.7-v0.8)

```
ПРИРОДА → МАТЕРИАЛЫ → ТЕХНОЛОГИИ → ИЗДЕЛИЯ
```

| Слой | Что это | Где в доках |
|---|---|---|
| **Природа** | Ресурсы, почвы, флора, фауна — что даёт мир | `02_world/{resources,soils,flora,fauna}/` |
| **Материалы** | Что производим из ресурсов при обработке | `02_world/processed_materials/` (v0.7) |
| **Технологии** | Процессы + дерево техов + граф зависимостей | `06_technology/` (включая processes.md, tech_tree.md, dependencies_graph.md) |
| **Изделия** | Готовые продукты | `06_technology/items/` (v0.8) ⭐ NEW |
