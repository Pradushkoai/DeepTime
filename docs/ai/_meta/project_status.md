## Система активации (создана в v0.4)

Для активации ИИ в новой сессии:
1. Пользователь копирует промпт-шаблон из `session_memory.md` → «Шаблон промпта для активации»
2. Вставляет GitHub токен в промпт
3. Отправляет в новую сессию
4. ИИ клонирует репо, читает `BOOT.md` в корне, следует процедуре активации (читает мета-файлы в порядке)
5. После прочтения ИИ готов продолжать работу

Файлы:
- `BOOT.md` (в корне репо) — точка входа
- `docs/ai/_meta/ai_working_principles.md` — Принцип 0: процедура активации
- `docs/ai/_meta/session_memory.md` — шаблон промпта для активации
