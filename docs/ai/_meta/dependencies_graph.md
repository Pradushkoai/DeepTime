# Dependencies Graph — Единый граф зависимостей

> 📊 Обзорный граф связей между всеми элементами игры: ресурсы → материалы → процессы → технологии → изделия. Помогает увидеть «бутылочные горлышки» и альтернативные пути.

---

## 🎯 Принципы (см. [ai_working_principles.md → Принцип 10](ai_working_principles.md))

1. **Обязательная связность** — каждый элемент связан с другими
2. **Никаких «висящих»** — у каждого есть применение
3. **Валидация** (Принцип 11) — периодически проверять

## 🔗 Ключевые цепочки (визуализация)

### Цепочка 1: Сталь (критично для индустриализации)

```
[ПРИРОДА]                    [МАТЕРИАЛ]              [ПРОЦЕСС]              [ТЕХНОЛОГИЯ]            [ИЗДЕЛИЕ]
──────────────────────────────────────────────────────────────────────────────────────────────────────────
Железная руда ──────────┐
Каменный уголь ─────────┤
Глина (огнеупорная) ────┤   → Шамот ──────────→ Обжиг 1400°C ─→ Огнеупор. футеровка
Графит ─────────────────┤   → Графитовый тигль  → Формовка+обжиг → Тигель для плавки
                        │
                        ├──→ Кокс ─────────→ Коксование 1000°C → [Бутылочное горлышко!]
                        │
                        └──→ Чугун ────────→ Домна 1500°C (Fe+кокс+CaO) → Сталь → Меч/Топор/Плуг/Паровоз
```

**Бутылочные горлышки**:
- ⚠️ Шамот (нужен каолин/огнеупорная глина)
- ⚠️ Графит (для тиглей)
- ⚠️ Кокс (нужен каменный уголь + герметичная печь)
- ⚠️ Домна (нужна шамотная футеровка)

**Альтернатива** (без кокса): сыродутное железо → только мягкое железо (не сталь)

---

### Цепочка 2: Серебро (критично для денег/экономики)

```
[ПРИРОДА]              [МАТЕРИАЛ]              [ПРОЦЕСС]              [ИЗДЕЛИЕ]
───────────────────────────────────────────────────────────────────────────
Галенит (PbS) ────→ Черновой свинец ────→ Cupellation 1100°C ──→ Серебро ──→ Монеты/Украшения
                  (Pb + Ag примесь)        (PbO испаряется,        ⭐
                                          остаётся Ag)
```

**Бутылочное горлышко**: ⚠️ Знание cupellation (нужна развитая металлургия)

**Альтернатива**: самородное серебро (редко), амальгамация (16 в.)

---

### Цепочка 3: Стекло (критично для окон/линз)

```
[ПРИРОДА]                    [МАТЕРИАЛ]              [ПРОЦЕСС]              [ИЗДЕЛИЕ]
──────────────────────────────────────────────────────────────────────────
Кварцевый песок ─────────┐
Древесина ───────────────┤
(для золы) ──────────────┤  → Поташ ───────────→ Выщелачивание ─→ Флюс для стекла
                         │
Натронные озёра ─────────┤  → Натрон ──────────→ Добыча ──────→ Флюс (альтернатива)
                         │
Известняк ───────────────┤  → Известь ─────────→ Обжиг 900°C ─→ CaO (стабилизатор)
                         │
Огнеупорная глина ───────┤  → Шамот ───────────→ Стенки печи ──→ Стекловаренная печь
                         │
Древесный уголь ────────┘  → Топливо ─────────→ Плавка 1200°C ─→ Стекло → Окна/Линзы/Бутылки
```

**Бутылочные горлышки**:
- ⚠️ Поташ (нужно много дерева) ИЛИ натрон (только натронные озёра!)
- ⚠️ Огнеупор (для печи)
- ⚠️ 1200°C (нужен древесный уголь + меха)

**Альтернатива**: плавка без щёлочи — 1700°C (почти невозможно в древности)

---

### Цепочка 4: Порох (3 бутылочных горлышка!)

```
[ПРИРОДА]                    [МАТЕРИАЛ]              [ПРОЦЕСС]              [ИЗДЕЛИЕ]
──────────────────────────────────────────────────────────────────────────
Селитра (KNO₃) ─────────┐
  (из навоза, копанок,  │  → Селитра очищенная ─→ Помол
   Чили) ────────────────┤
                         │
Сера самородная ────────┤  → Сера ───────────────→ Помол
  (Сицилия, вулканы) ────┤
                         │
Древесина ──────────────┘  → Древесный уголь ───→ Помол → Порох → Ружьё/Пушка/Граната
                            (← Сухая перегонка)              ⭐
```

**Бутылочные горлышки** (3 сразу!):
- ⚠️ Селитра (редко, нужна старая органика/Калийные копи)
- ⚠️ Сера (Сицилия — географическая монополия)
- ⚠️ Древесный уголь (нужно много дерева)

### Цепочка 5: Печать (книгопечатание)

```
[ПРИРОДА]              [МАТЕРИАЛ]              [ПРОЦЕСС]              [ИЗДЕЛИЕ]
──────────────────────────────────────────────────────────────────────
Галенит (Pb) ─────→ Свинец ──────┐
Касситерит (Sn) ──→ Олово ───────┤  → Типографский сплав ─→ Плавка → Шрифты
Стибнит (Sb) ─────→ Сурьма ──────┘   (Pb+Sn+Sb) ⭐            │
                                                              │
Пергамент/Бумага ──────────────────────────────────────→ Печатный пресс → Книга ⭐
                                                              │
                                                              └→ (распространение знаний)
```

**Бутылочные горлышки**:
- ⚠️ Сурьма (стибнит — редкий минерал)
- ⚠️ Знание механики (печатный пресс)

---

### Цепочка 6: Алюминий (критично для электронной эпохи)

```
[ПРИРОДА]              [МАТЕРИАЛ]              [ПРОЦЕСС]              [ИЗДЕЛИЕ]
──────────────────────────────────────────────────────────────────────
Бокситы ──────→ Глинозём (Al₂O₃) ──→ Обжиг 1200°C ──→ Сырьё для электролиза
                                              │
Криолит (Гренландия) ─────────────────→ Флюс ─┤
                                              │
Нефть ──→ Нефтяной кокс ──→ Электроды ──→ ┐   │
                                          │   │
Электричество (←генератор←пар.машина) ───→ Электролиз ──→ Алюминий ⭐⭐
                                              │
                                              └→ Самолёт/Авто/Провода
```

**Бутылочные горлышки**:
- ⚠️ Бокситы (география)
- ⚠️ Криолит (Гренландия — монополия)
- ⚠️ Нефтяной кокс (нужна переработка нефти)
- ⚠️ Электричество (нужна паровая машина → генератор)
- ⚠️ Много энергии (нужна ГЭС или уголь)

### Цепочка 7: Демография (Габер-Бош — критично для 20 в.)

```
[ПРИРОДА]              [МАТЕРИАЛ]              [ПРОЦЕСС]              [ЭФФЕКТ]
──────────────────────────────────────────────────────────────────────
Воздух (N₂) ──┐
              │
Метан/Уголь ──→ H₂ ──→ Габер-Бош ──→ NH₃ ──→ NH₄NO₃ ──→ Удобрение ──→ +Урожайность ──→ +Население
              │      (катализатор    ⭐⭐    (массовый азот)                    (8 млрд)
              │       Fe, 500°C,                                               
              │       200 атм)                                                 
              │
Катализатор Fe ─┘
```

**Бутылочное горлышко**: ⚠️ Высокое давление + катализатор Fe + H₂ источник

## 🛠 Как поддерживать граф в актуальном состоянии

### При добавлении нового элемента

1. Описать элемент в соответствующем каталоге
2. Указать **входящие и исходящие связи** (Принцип 10)
3. Обновить `dependencies_graph.md` (этот файл) — добавить в соответствующий раздел
4. Обновить `tech_tree.md` — если это новая технология
5. Проверить, что элемент не «висит»

### При валидации (Принцип 11)

1. Пройти по всем каталогам
2. Для каждого элемента проверить наличие раздела «Связи»
3. Если связи отсутствуют → добавить или удалить элемент
4. Записать отчёт в `_meta/validation_log.md` (будет создан)
