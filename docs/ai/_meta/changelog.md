### 4. Принят Принцип 9: «Бесконечное развитие»
Нет верхней границы по эпохам. Игрок играет столько, сколько хочет. Эпохи — описание текущего уровня, не временные рамки. Все исторически возможные технологии включаются с правильными предпосылками.

### 5. Ключевые «бутылочные горлышки» зафиксированы:
- Без кокса нет домны → нет стали → нет индустриализации
- Без поташа/соды нет стекла массово
- Без галенита и cupellation нет серебра массово
- Без селитры + серы + угля нет пороха (3 горлышка!)
- Без типографского сплава (Pb+Sn+Sb) нет книгопечатания
- Без графитовых тиглей + шамотной футеровки нет плавки железа
- Без костяной муки/селитры/гуано нет удобрений → низкий урожай
- Без электричества + бокситов + криолита + нефтяного кокса нет алюминия
- Без Габер-Боша нет массового азота → нет демографии 20 в.
