> 📋 **Спецификация D-005** — соседние цивилизации (AI) и торговля с ними. Двухслойный AI с границей при контакте, готовая диффузия из GDD, перенасыщение от скорости.
>
> **Основано на**: Q-006 (AI соседей). См. `discussions/consensus.md` → Вопрос 04.

## 🎯 Обзор

Соседние цивилизации (AI) играют по тем же правилам, что и игрок — те же предпосылки, та же география, тот же дефицит. Но для производительности используется **двухслойная архитектура**: AI «живёт» упрощённо (макро-агрегаты), но «играет» на полных правах при контакте с игроком.

**Принцип**: мы не знаем, как жил каждый римлянин, но знаем, что Рим действовал по институтам. Честность сохраняется в точке контакта, нагрузка — только там.

## 🏗 Двухслойный AI

### Слой 1: Макро-симуляция (упрощённый)

> AI-цивилизация «живёт» агрегатами, не по 30 000 агентов.

**Что считается в слое 1:**

| Параметр | Как | Пример |
|---|---|---|
| Население | Рост/падение по формуле | 5000 → 5200 (+4%) |
| Ресурсы | Добыча по региону | Медь: 50/год |
| Технологии | Список открытых | [T-001, T-004, T-010, T-050] |
| Фракции | Сила по фракциям (агрегат) | Жречество: 65, Военные: 30 |
| Богатство | Сумма казны + складов | 1200 единиц |
| Армия | Численность + качество | 300 воинов, качество 5/10 |
| Отношение к игроку | Числовая шкала (−100..+100) | +15 (нейтрально-положительное) |

**Что НЕ считается в слое 1:**
- Отдельные граждане и их решения
- Внутренняя политика (реформы, эдикты)
- Детальная экономика (вакансии, миграция)
- UI — AI не имеет интерфейса

### Слой 2: Полная симуляция (при контакте)

> ⚠️ **Граница слоёв** (уточнена B в round_04): слой 2 включается **только** для AI-цивилизации, у которой в данный момент есть активное взаимодействие с игроком.

**Когда включается:**

| Триггер | Что активируется | Длительность |
|---|---|---|
| Дипломатические переговоры | Фракции AI, повестки, внутренние расчёты | На время переговоров |
| Война | Тактика, армия, ресурсы, фракции | На время боевых действий |
| Торговая сделка | Экономика, ресурсы, фракции | На время сделки |
| Шпионаж | Внутренние связи, секреты | На время операции |

**Что происходит при включении:**

```
1. AI-цивилизация "разворачивается" из агрегатов в полную симуляцию
2. Фракции получают повестки, обиду, связи (как у игрока — D-004)
3. Экономика считается детально (вакансии, ресурсы)
4. Армия получает тактические параметры
5. AI принимает решения на полных правах (те же эдикты, реформы)
6. После разрешения взаимодействия → сворачивание обратно
```

**Что пишется обратно в слой 1 (только агрегированное):**

| Параметр | Что сохраняется | Что НЕ сохраняется |
|---|---|---|
| Состояние договора | ✅ Тип + срок | — |
| Состояние войны | ✅ Активна/нет + потери | — |
| Технологический дельта | ✅ Что перенял/передал | — |
| Отношение фракций к игроку | ✅ Шкала −100..+100 | Детальные связи |
| Потери/прибыли | ✅ Числовые значения | — |

> **Потоковая симуляция не сохраняется.** Между контактами AI «спит» в слое 1.

## 📊 5 уровней контакта

| Уровень | Название | Что доступно | Условие |
|---|---|---|---|
| 0 | ❓ Неизвестно | Ничего | Нет контакта |
| 1 | 👁️ Знают о вас | Видят на карте | Встреча (разведчик/торговец достиг границы) |
| 2 | 🤝 Дипломатия | Переговоры, обмен информацией | Посольство (эдикт + ресурсы) |
| 3 | 💰 Торговля | Обмен ресурсами | Торговый путь (дорога/корабль) |
| 4 | 🛡️ Союз | Военная помощь, технологии | Договор о союзе |
| 5 | ⚔️ Вассал / Сюзерен | Дань, протекторат | Война (победа) или дипломатия |

### Переходы между уровнями

```
0 → 1: Разведка достигла границы AI
1 → 2: Игрок построил посольство (эдикт)
2 → 3: Игрок открыл торговый путь (дорога/корабль + мир)
3 → 4: Военный союз (общий враг + договор)
4 → 5: Война → победа → вассалитет

Любой → ниже: Нарушение договора, война, шпионаж раскрыт
```

### Палеолитный тест (Принцип 13)

| Уровень | В 10 000 до н.э.? | Условие |
|---|---|---|
| 0 Неизвестно | ✅ | Старт |
| 1 Знают | ✅ | Разведка пешком |
| 2 Дипломатия | ✅ | Посольство = старейшина идёт к соседям |
| 3 Торговля | ✅ | Караванный путь (T-022 колесо + T-030 лошадь) или пеший |
| 4 Союз | ✅ | Договор = клятва (устная) |
| 5 Вассал | ✅ | Война = бой |

## 🛤️ 3 типа торговых путей

| Тип | Что | Технология | Скорость | Вместимость |
|---|---|---|---|---|
| 🛤️ **Караванный** | Сухопутный (лошадь/верблюд/вол) | T-022 (колесо) + T-030 (скотоводство) | Медленно | Средняя |
| ⛵ **Морской** | Через море (корабль с парусом) | T-060b (парусное мореплавание) | Быстро | Большая |
| 🔄 **Через посредника** | Третья цивилизация перевозит | Любой путь + посредник на уровне 3+ | Зависит | Зависит |

### Механика торгового пути

```
1. Игрок открывает торговый путь (строит дорогу / открывает морской маршрут)
2. Проверка: AI на уровне ≥1 (знают о вас)
3. Если AI на уровне ≥2 (дипломатия) → можно предложить торговлю
4. Если AI соглашается → уровень 3 (торговля)
5. Торговый путь активен → ресурсы + информация (вакансии) + диффузия
```

### Что переносят торговые пути

| Что | Механика | Связь |
|---|---|---|
| 📦 Ресурсы | Обмен: медь ↔ зерно ↔ оружие | Q-012 (собственность) |
| 📰 Информация | Вакансии распространяются | D-003 (миграция) |
| 🔬 Технологии | Культурный шок → диффузия | GDD (см. §5 ниже) |
| 🦠 Болезни | Эпидемии через торговлю | (Q-016 убран, но болезни как событие) |

## 🔬 Диффузия технологий (готовая механика GDD)

> ⚠️ **Принцип 14 (Тест на один справочник)**: НЕ создаём новую механику диффузии. Подключаем **готовую** из GDD — культурный шок с 4 реакциями.

### Культурный шок (из GDD, подтверждено в `glossary.md`)

> **Культурный шок** — событие, когда цивилизация впервые видит продвинутую технологию. Игрок выбирает реакцию: **любопытство, страх, имитация, сопротивление**.

### 4 реакции культурного шока

| Реакция | Что происходит | Эффект |
|---|---|---|
| 🔍 **Любопытство** | «Хотим узнать больше» | +шанс перенять технологию, +наука |
| 😨 **Страх** | «Это опасно» | −отношения с источником, +традиция |
| 📋 **Имитация** | «Хотим такое же» | +шанс перенять, но −качество (копия) |
| 🚫 **Сопротивление** | «Это запрещено» | −шанс перенять, +традиция, −инновации |

### Механика диффузии

```
1. Игрок торгует с AI, у которого есть технология X
2. Событие: «Культурный шок — ваша цивилизация видит [X]»
3. Игрок выбирает реакцию (любопытство/страх/имитация/сопротивление)
4. Если любопытство или имитация → шанс перенять:
   - Проверка: есть ли предпосылки у игрока? (Принцип 12 — нельзя обойти)
   - Если да → шанс 5-15%/год перенять через торговлю
   - Если нет → «недостаточно предпосылок» (нельзя перенять)
5. Если страх или сопротивление → шанс минимален
```

### Условие: предпосылки обязательны

> ⚠️ Диффузия **ускоряет** открытие, но НЕ обходит бутылочные горлышки (Принцип 9).

- Нет олова → нет бронзы, даже если сосед торгует бронзовыми изделиями
- Нет шамота → нет домны, даже если сосед строит домны
- Нет письменности → нет книгопечатания, даже если сосед печатает книги

### Связь с research_system.md (Q-004)

Механизм 4 «Торговая диффузия» из `research_system.md` = применение культурного шока:
- Торговый путь → шанс 5%/год перенять (если предпосылки есть)
- Покупка технологии за ресурсы → гарантированный перенос (если предпосылки есть)
- Без предпосылок → penalty ×0.5 (медленнее, дороже)

## 🏰 Институциональное перенасыщение (Тёрчин, уточнённое)

> ⚠️ **Уточнено B в round_06**: действует от **скорости роста**, не от размера. Институты расширяют ёмкость. Потолок смещается, но не исчезает.

### Принцип

> Слишком быстрая экспансия → много претендентов на элитные позиции → мало позиций → кризис. Рим при Августе был огромен и стабилен (медленный рост). Александр — стремителен и распался сразу после смерти (быстрый рост).

### Формула перенасыщения

```
перенасыщение = скорость_роста / ёмкость_институтов

где:
  скорость_роста = прирост территории/населения за период (например, за 10 лет)
  ёмкость_институтов = базовая_ёмкость + бонус_от_институтов

Если перенасыщение > порог → кризис (мятежи, распад, гражданская война)
```

### Институты, расширяющие ёмкость

| Институт | Что | Технология | Бонус к ёмкости |
|---|---|---|---|
| Бюрократия | Чиновники управляют территорией | T-043 (города) | +20 |
| Ценз / перепись | Учёт населения | T-036 (клинопись) / T-037 (алфавит) | +15 |
| Экзамены | Отбор элиты по заслугам | T-085 (университеты) | +25 |
| Федеральная система | Автономия регионов | T-041 (религия) + T-043 | +30 |
| Дороги | Связь территории | T-020 (деревообработка) | +10 |

### Потолок смещается, но не исчезает

> ⚠️ **Ключевое уточнение B**: институты, расширяющие ёмкость, **сами порождают новый элитный класс**. Экзамены создают чиновничество, бюрократия — свой аппарат. За каждой реформой лестницы приходит новая группа претендентов.

```
1. Игрок быстро расширяет территорию → перенасыщение растёт
2. Игрок строит институты (бюрократия, экзамены) → ёмкость растёт
3. Перенасыщение снижается → стабилизация
4. НО: новые институты = новые элитные классы = новые претенденты
5. Потолок смещается, но не исчезает → цикл продолжается
```

### Связь с GDD (вырождение)

> «Бюрократическое разбухание» — одна из причин вырождения (GDD, глава 12 «Динамика цивилизаций»). Мы не добавляем новое правило — подключаем существующее.

### Применяется и к AI, и к игроку

Перенасыщение действует **симметрично**:
- Игрок быстро расширяется → кризис
- AI быстро расширяется → кризис (виден в слое 2 при контакте)

Это создаёт **естественный потолок доминированию** без анти-чита:
- Римский сценарий (одна цивилизация захватывает всех) ограничен перенасыщением
- Слишком быстрая экспансия → внутренний кризис → распад

## 🤝 Дипломатия (8 действий)

| # | Действие | Что | Условие | Эффект |
|---|---|---|---|---|
| 1 | 🕊️ **Мир** | Прекращение войны | Война активна | +отношения, конец боевых действий |
| 2 | 📜 **Торговый договор** | Снижение пошлин | Уровень ≥2 | +торговля, +отношения |
| 3 | 🛡️ **Военный союз** | Совместная война | Уровень ≥2 + общий враг | +армия, −самостоятельность |
| 4 | 💰 **Дань** | Одна сторона платит | Сила (война/угроза) | −казна, +мир |
| 5 | 💍 **Брак** | Династический союз | Наследники есть | +отношения, +легитимность |
| 6 | ⚖️ **Требование возмещения** | «Ты убил торговца 150 лет назад, плати» | Память племени (D-001) | +казна ИЛИ −отношения (отказ) |
| 7 | 🏛️ **Культурный протекторат** | «Позволь строить храмы на твоей земле» | Уровень ≥2 + религия | +мягкая экспансия, −традиция AI |
| 8 | 🏃 **Приём беженцев** | Принять изгнанников от AI | Событие (война/голод у AI) | +технологии, +население, +внутреннее давление |

### Убранное действие

> ~~Обмен технологиями~~ — **отклонено**. Технологии уходили с людьми и товарами, не по «соглашению об обмене». Это следствие торгового договора (через культурный шок), не отдельный акт.

### Требование возмещения (особое)

> Связь с D-001 (память племени): обиды переживают вождя. «Ты убил торговца 150 лет назад» — это **память племени** (внешний домен обиды, см. D-004).

```
1. AI убил торговца игрока (событие войны/пиратства)
2. Запись в «памяти племени» (хроника — D-001)
3. Через 150 лет игрок требует возмещения
4. AI выбирает: заплатить (−казна AI, +отношения) или отказаться (−отношения, риск войны)
5. Если отказ → игрок может объявить войну с casus belli
```

### Приём беженцев (особое)

> Рискованный обмен: технологии + население, но +внутреннее давление.

```
1. У AI кризис (война/голод/преследования)
2. Событие: «Беженцы из [AI] просят убежища»
3. Игрок выбирает: принять / отказать
4. Если принять:
   + Население (+100-500 человек)
   + Технологии (диффузия — беженцы приносят знания)
   + Внутреннее давление (новая культура → +обида фракций Q-005)
   + Отношения с AI (−100, если беженцы политические)
5. Исторический аналог: гиксы в Египте, варяги на Руси
```

## 📊 Структура данных AI-цивилизации

### Слой 1 (макро)

```yaml
ai_civilization:
  id: "ai_egypt"
  name: "Египет"
  layer: 1                    # макро-симуляция
  
  # Агрегаты (считаются в слое 1)
  population: 5000
  wealth: 1200
  technology: [T-001, T-004, T-010, T-015, T-050, T-100]
  army_size: 300
  army_quality: 5             # 1-10
  
  # Фракции (агрегат — сила по фракциям)
  factions:
    priesthood: 65
    military: 30
    farmers: 50
  
  # Отношение к игроку
  attitude: +15               # −100..+100
  
  # Контакт с игроком
  contact_level: 3            # 0-5
  
  # Торговые пути
  trade_routes:
    - type: "caravan"
      target: "player"
      active: true
      established: "year_1200"
  
  # Договоры
  treaties:
    - type: "peace"
      signed: "year_1205"
      duration: 50
  
  # Память племени (внешний домен обиды)
  tribal_memory:
    - event: "killed_merchant"
      year: "year_1100"
      severity: 80
      resolved: false
  
  # Перенасыщение
  oversaturation: 0.6         # 0.0-1.0 (при >0.8 → кризис)
  institutional_capacity: 45  # базовая + бонусы институтов
  growth_rate: 0.08           # за 10 лет
```

## 📊 Сводка спецификации

| Элемент | Решение |
|---|---|
| Архитектура AI | Двухслойный (макро + полный при контакте) |
| Граница слоёв | Слой 2 = только при активном взаимодействии, на время разрешения |
| Обратно в слой 1 | Только агрегированное (договор, война, дельта, отношение) |
| Уровни контакта | 5 (неизвестно → знают → дипломатия → торговля → союз → вассал) |
| Торговые пути | 3 типа (караванный, морской, через посредника) |
| Диффузия | Готовая механика GDD (культурный шок, 4 реакции) — НЕ дублировать |
| Перенасыщение | От скорости роста (не размера); институты расширяют ёмкость; потолок смещается |
| Дипломатия | 8 действий (5 стандартных + требование возмещения + культурный протекторат + беженцы) |
| Обмен технологиями | ❌ Убран (следствие торговли, не отдельный акт) |
| Память племени | Внешний домен обиды, переживает вождя, «требование возмещения» через 150 лет |
