# AI Documentation Index — DeepTime

> Этот каталог — **память проекта** для ИИ-ассистента. Структура оптимизирована для поиска, цитирования, обновления и отслеживания зависимостей между системами.

---

## Правила работы с этой документацией

1. **Метаданные в начале каждого файла** — статус, дата последнего обновления, зависимости от других файлов.
2. **Кросс-ссылки** — `[См. → 02_world/hex_grid.md]` указывают на связанные разделы.
3. **Статусы** — `DRAFT` (черновик), `REVIEW` (на ревизии), `RESOLVED` (согласовано), `OPEN` (открытый вопрос).
4. **Файлы с открытыми вопросами** лежат в `99_open_tasks/` и связаны с `open_questions.md`.
5. **Каждое концептуальное решение** должно быть зафиксировано в `_meta/decision_log.md` с обоснованием.
