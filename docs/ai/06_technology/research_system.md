# Система исследований и бронирования технологий (Q-004)

> Как игрок ускоряет конкретное исследование. Лучшие практики + авторская концепция.

---

## 🎯 Принцип

Технологии в игре открываются **эмерджентно** — через:
- Накопление опыта жителей (автоматически)
- Случайные озарения (стохастически)
- Контакты с соседями (через торговлю)

Это **медленно** — может занять 500-1000 лет на технологию.

**Бронирование** = рычаги игрока для **ускорения** конкретных технологий. Не «по щелчку», а через создание условий и выделение ресурсов.

---

## 📋 8 механизмов ускорения

### 1. Приоритет исследования (основной) ⭐

**Как работает**:
- Игрок выбирает **1-3 технологии** для приоритета (из доступных — предпосылки выполнены)
- Приоритет даёт **×2-×3** к скорости исследования
- Чем больше приоритетных технологий — тем **меньше бонус** каждой (разделение ресурсов)

**Пример**:
- 1 технология в приоритете → ×3 к скорости
- 2 технологии → ×2 к каждой
- 3 технологии → ×1.5 к каждой
- 0 приоритетов → ×1 (базовая скорость, медленно)

**Цена**:
- Приоритет отвлекает граждан от других задач (производство, торговля)
- Чем больше приоритет → тем меньше производство

**Лучшие практики**:
- Stellaris: 3 ветки исследований, игрок выбирает фокус
- RimWorld: приоритет проекта → исследователи работают над ним

---

### 2. Финансирование из казны

**Как работает**:
- Игрок выделяет **ресурсы** (зерно/металл/деньги) на конкретное исследование
- Больше ресурсов → быстрее
- Ресурсы «тратятся» (не возвращаются)

**Пример**:
- 100 единиц зерна → +10% к скорости на 1 год
- 1000 единиц зерна → +50% к скорости на 1 год
- 0 → базовая скорость

**Цена**:
- Отвлекает ресурсы от других задач (еда → голод, металл → оружие)
- Нужна казна (накопление через налоги/торговлю)

**Лучшие практики**:
- Civilization 6: «бонусы технологий» — здания дают +науку
- Endless Legend: «эрционаж» — покупка технологии за влияние

---

### 3. Чемпионы реформ (через граждан) ⭐

**Как работает**:
- Конкретные граждане-адвокаты **появляются случайно** (событие «Молодой кузнец Дром предлагает реформу металлургии»)
- Игрок может **выдвинуть** чемпиона → +бонус к конкретной технологии
- Чемпион — конкретная личность (имя, черты, навыки)
- Чемпион может быть **устранён** оппозицией (потеря бонуса)

**Пример**:
- Событие: «Молодой гражданин Карл предлагает реформу плавки железа»
- Игрок: выдвигает Карла → +×2 к скорости T-055 (плавка железа)
- Оппозиция (традиционалисты): может устранить Карла → −бонус

**Цена**:
- Чемпион требует ресурсов (зарплата, лаборатория)
- Может быть устранён → потеря бонуса + недовольство

**Лучшие практики**:
- Crusader Kings 3: «Lifestyle» — выбор направления персонажа
- Victoria 3: «Агитаторы» — конкретные личности, продвигающие реформы

---

### 4. Торговая диффузия (через соседей)

**Как работает**:
- Если у соседа есть технология → торговый путь даёт **шанс перенять**
- Чем больше торговых путей → выше шанс
- Можно **закупать** технологии через дипломатию (плата ресурсами)

**Пример**:
- Сосед (AI) открыл T-056 (стекло)
- Игрок торгует с соседом → шанс 5%/год перенять
- Игрок может «купить» технологию за 1000 единиц ресурсов

**Цена**:
- Нужны торговые пути (дороги, корабли)
- Нужны дипломатические отношения (мир, не война)
- Можно купить — но дорого

**Лучшие практики**:
- Civilization 6: «торговля технологиями» — обмен между цивилизациями
- EU4: «институты» — распространение через соседей

---

### 5. Реверс-инжиниринг (через товары)

**Как работает**:
- Захват/покупка товара (например, железный меч) → шанс **скопировать** технологию
- Без полных предпосылок — с **penalty** (медленнее, дороже)
- С полными предпосылками — быстрее

**Пример**:
- Игрок покупает железный меч у соседа
- Шанс 10%/год открыть T-057 (сыродутный процесс) — если есть Fe-руда + древесный уголь
- Без древесного угля → штраф ×0.5

**Цена**:
- Нужно купить/захватить товар
- Без предпосылок → penalty

**Лучшие практики**:
- EU4: «шпионаж» — кража технологий
- Stellaris: «обратный инжиниринг» — анализ обломков

---

### 6. Образование (через университеты) ⭐

**Как работает**:
- T-085 (университеты) → **+скорость всех исследований**
- T-082 (книгопечатание) → **+распространение знаний** (ускоряет диффузию)
- T-037 (алфавит) → базовая письменность → +скорость

**Пример**:
- Без университетов → базовая скорость ×1
- 1 университет → ×1.2
- 5 университетов → ×1.5
- + книгопечатание → ×1.8
- + алфавит → ×1.1

**Цена**:
- Университеты требуют: пергамент/бумагу + учёных + здание + финансирование

**Лучшие практики**:
- Civilization 6: «кампусы» — здания дают +науку
- CK3: «образование» — навыки через наставников

---

### 7. Кризисы как окна возможностей

**Как работает**:
- Голод/поражение/эпидемия → **временное снижение сопротивления** реформам
- В этот момент можно быстрее провести реформу (через фракции — см. Q-005)
- Окно длится 1-5 лет → потом закрывается

**Пример**:
- Голод → «Аграрная реформа» (T-015 земледелие) доступна с ×2 скорости на 3 года
- Поражение → «Военная реформа» (T-005 лук) с ×2 на 2 года

**Цена**:
- Кризис — это плохо (гибель граждан, потеря ресурсов)
- Использовать кризис для реформы — цинично, но эффективно

**Лучшие практики**:
- Victoria 3: «кризисы» — окна для реформ
- CK3: «фракции» — давление во время кризиса

---

### 8. Случайные озарения (стохастически)

**Как работает**:
- **Стохастические события** → небольшой шанс открытия технологии
- Без приоритета — медленно, но **бесплатно**
- Шанс зависит от:
  - Количества граждан (больше → больше шансов)
  - Образования (университеты)
  - Культуры (ценность «знание»)

**Пример**:
- Базовый шанс: 0.1%/год на технологию
- + 100 граждан → ×2
- + университет → ×3
- + ценность «знание» > 50 → ×2

**Цена**:
- Бесплатно (но медленно)
- Нельзя контролировать

**Лучшие практики**:
- RimWorld: «случайные исследования» — события дают бонусы
- Dwarf Fortress: «странные настроения» — артефакты

## 🎮 Как это ощущается в игре

### Пример: игрок хочет открыть T-055 (плавка железа)

**Без бронирования**:
- Базовая скорость → 500-1000 лет → слишком медленно

**С бронированием**:
1. Ставит **приоритет** на T-055 → ×3 скорости
2. **Финансирует** из казны (1000 зерна) → +50%
3. **Выдвигает чемпиона** (кузнец Карл) → ×2
4. **Торгует** с соседом, у которого есть → шанс 5%/год
5. **Покупает** железный меч у соседа → реверс-инжиниринг
6. Строит **университет** → ×1.5

**Итого**: ~50-100 лет вместо 500-1000

### Пример: игрок хочет открыть T-082 (книгопечатание)

1. Ставит приоритет → ×3
2. Финансирует → +30%
3. Нужен типографский сплав (Pb+Sn+Sb) → если нет стибнита → **бутылочное горлышко** → нельзя!
4. Торговля с соседом → шанс перенять

**Итог**: если нет стибнита → невозможно (бутылочное горлышко), даже с бронированием

## 🎯 Принципы для дизайна

### 1. Бронирование — не «по щелчку»

Игрок **создаёт условия** (приоритет, финансирование, чемпион), а не «нажимает кнопку». Это органично.

### 2. Бутылочные горлышки — не обходятся

Если нет олова → нет бронзы, даже с приоритетом. Бронирование **ускоряет**, но не **обходит** предпосылки.

### 3. Кумулятивный эффект

Механизмы **складываются**: приоритет ×3 + финансирование ×1.5 + чемпион ×2 = ×9 к скорости. Но:
- Финансирование отвлекает ресурсы
- Чемпион может быть устранён
- Приоритет отвлекает граждан

### 4. Риск-вознаграждение

Чем больше ресурсов на исследование → тем меньше на другое (еда, армия, стройка). Игрок балансирует.

### 5. Историческая достоверность

Все механизмы основаны на реальной истории:
- Приоритет → «королевское покровительство» (Средние века)
- Чемпион → «Хаммурапи, Солон, Пётр I»
- Диффузия → «Финикийцы разнесли алфавит»
- Реверс-инжиниринг → «Римляне копировали карфагенские корабли»
