# Processes — Технологические процессы

> Описание физико-химических процессов, применяемых для переработки ресурсов в материалы. Это — связующее звено между ПРИРОДОЙ и МАТЕРИАЛАМИ.

---

## 📐 Концепция

Процессы — это **действия**, которые применяются к сырью для получения продуктов. Каждый процесс:
- Требует знаний (как выполнять)
- Требует инструментов/оборудования (печи, перегонные кубы, и т.д.)
- Имеет физико-химические условия (температура, давление, катализатор)
- Может иметь несколько предпосылок (знания + материалы + оборудование)

## 🌡 Термические процессы

### Обжиг / Кальцинация (Calcination)

**Описание**: нагрев минералов без доступа воздуха (или с ограниченным) → разложение
**Типичные применения**:
- CaCO₃ (известняк) → CaO (известь) + CO₂, при 900°C
- CaSO₄·2H₂O (гипс) → CaSO₄·0.5H₂O (парижский гипс), при 150°C
- MgCO₃ (магнезит) → MgO (периклаз), при 1500°C
- Бокситы → глинозём (Al₂O₃), при 1200°C (промышленно — Байер)
**Требует**: 
- Знание контроля огня
- Печь с тягой
- Знание нужной температуры
**Эпоха**: с неолита (~10000 до н.э. — Иерихон)
**Связанные материалы**: [известь, парижский гипс, магнезит](../02_world/processed_materials/02_chemical_products.md)
**Источники»: Ullmann's Encyclopedia

### Обжиг с окислением (Roasting)

**Описание**: нагрев минералов в потоке воздуха → окисление сульфидов
**Типичные применения**:
- FeS₂ (пирит) → Fe₂O₃ + SO₂ (источник серы)
- CuFeS₂ (халькопирит) → CuO + Fe₂O₃ + SO₂
- PbS (галенит) → PbO + SO₂ (для cupellation)
- HgS (киноварь) → Hg (ртуть возгоняется) + SO₂
- ZnS (сфалерит) → ZnO + SO₂
**Требует**: 
- Знание обжига
- Печь с тягой (высокая вентиляция)
- Сбор SO₂ (опционально — позднее)
**Эпоха**: античность
**Связанные материалы**: [сера, SO₂, ртуть, черновые металлы](../02_world/processed_materials/02_chemical_products.md)
**Источники»: «Pyrometallurgy» (Rosenqvist, 1983)

### Коксование (Carbonization / Coking) ⭐

**Описание**: нагрев угля/нефти/дерева без доступа воздуха → сухая перегонка + кокс
**Типичные применения**:
- Каменный уголь → кокс + каменноугольная смола + коксовый газ (1000-1200°C)
- Древесина → древесный уголь + дёготь + метанол + уксус + древесный газ (400-500°C)
- Торф → торфяной уголь + торфяной дёготь + торфяной газ (400-500°C)
- Нефтяные остатки → нефтяной кокс (800°C)
**Требует**: 
- Знание контроля воздуха (герметичная печь)
- Высокая температура (для угля — 1000°C+)
- Сбор продуктов (газ, смола — позднее)
**Эпоха**: 
- Углежжение (дерево → уголь) — неолит
- Коксование (уголь → кокс) — 17 в. (Дад Дадли, Англия), массово — 18 в.
**Связанные материалы**: [кокс, древесный уголь, дёготь, смола](../02_world/processed_materials/01_fuel_products.md)
**Особые свойства**: **КРИТИЧЕСКИ ВАЖНО** — без кокса нет домны → нет стали → нет индустриализации
**Источники»: «Coal Carbonization» (Reerink, 1982)

### Плавка / Восстановительная плавка (Smelting)

**Описание**: нагрев руды с восстановителем (C, CO) → металл + шлак
**Типичные применения**:
- Cu-руды + C → Cu + CO₂ (медь)
- Sn-руды + C → Sn (олово)
- Fe-руды + C → Fe (сыродутное, губка)
- PbS → обжиг → PbO + C → Pb
**Требует**: 
- Знание плавки
- Печь с высокой температурой
- Восстановитель (уголь/кокс)
- Флюс (известняк — для удаления примесей)
- Тигель (для железа)
**Эпоха**: ~5000 до н.э. (медь)
**Связанные материалы**: [медь, олово, свинец, железо, черновые металлы](../02_world/processed_materials/04_metallurgical_products.md)
**Источники»: «A History of Ironworking» (Tylecote, 1992)

### Доменная плавка / Доменный процесс (Blast furnace) ⭐

**Описание**: непрерывная плавка железной руды с коксом + флюсом + дутьём воздуха → чугун
**Типичные применения**:
- Fe-руда + кокс + CaO → домна 1500°C → чугун (Fe + 2-4% C)
**Требует**: 
- **Кокс** (критично! — без кокса домна не работает)
- **Огнеупорная футеровка** (шамот, магнезит, доломит)
- Печь высотой 10-30 м с дутьём воздуха
- Источник воздуха (меха — древние, паровые машины — позднее)
**Эпоха**: ~500 до н.э. (Китай), Европа — 14 в. (массово — 18 в.)
**Связанные материалы**: [чугун, сталь](../02_world/processed_materials/04_metallurgical_products.md)
**Особые свойства**: **КРИТИЧЕСКИ ВАЖНО** — без домны нет чугуна массово → нет стали → нет индустриализации
**Источники»: «Blast Furnace» (Wagner, 2008)

### Cupellation (Купелирование) ⭐

**Описание**: окисление чернового свинца → свинец окисляется (PbO возгоняется) → остаётся серебро
**Типичные применения**:
- Pb + Ag (черновой) + O₂ → PbO (испаряется) + Ag (чистое)
**Требует**: 
- Печь с сильной тягой (cupel — плоская чаша)
- Источник воздуха
- Высокая температура (~1100°C)
**Эпоха**: ~3000 до н.э. (Лидия, Лаврион)
**Связанные материалы**: [серебро (главное!)](../02_world/processed_materials/04_metallurgical_products.md)
**Особые свойства**: **КРИТИЧНО** — основной источник серебра в античности. Афины и Лидия богатели на этом.
**Источники»: «Silver in Antiquity» (Patterson, 1972)

### Конвертерный процесс / Бессемерование (Bessemer process) ⭐

**Описание**: продувка воздуха через расплав чугуна → выгорание C, Si, Mn → сталь
**Типичные применения**:
- Чугун + O₂ (воздух) → сталь (бессемеровская)
**Требует**: 
- Конвертер (Бессемер, 1856)
- Знание химии Fe-C
- Воздух под давлением
**Эпоха**: 19 в. (Бессемер, 1856)
**Связанные материалы**: [сталь](../02_world/processed_materials/04_metallurgical_products.md)
**Особые свойства**: **КРИТИЧНО** — первое массовое производство стали → индустриализация
**Источники»: «The Bessemer Process» (Bessemer, 1905)

## 💧 Жидкостные процессы

### Выщелачивание (Leaching)

**Описание**: растворение растворимых компонентов твердого сырья в воде/щёлочи
**Типичные применения**:
- Древесная зола + H₂O → раствор K₂CO₃ (поташ) + нерастворимый остаток
- Почва + вода (гравитационное выщелачивание) — для солей
- Руды с Cu + вода + кислота → CuSO₄ раствор (позднее — гидрометаллургия)
**Требует**: 
- Вода
- Контейнеры (чаши, бочки)
- Фильтры (ткань, песок)
**Эпоха**: с неолита (выщелачивание золы)
**Связанные материалы**: [поташ, щёлок, соли](../02_world/processed_materials/02_chemical_products.md)
**Источники»: «Leaching» (Habashi, 1969)

### Омыление (Saponification)

**Описание**: реакция жира (этиловый эфир жирной кислоты) со щёлочью → мыло + глицерин
**Химия**: триглицерид + 3NaOH → 3Na-oleate (мыло) + глицерин
**Типичные применения**:
- Животный жир + NaOH → Na-oleate (твёрдое мыло)
- Животный жир + KOH → K-oleate (мягкое мыло)
- Растительное масло + NaOH → мыло + глицерин
**Требует**: 
- Жир (животный или растительный)
- Щёлочь (поташ, сода, NaOH)
- Источник тепла (для растворения)
**Эпоха**: ~2800 до н.э. (Вавилон)
**Связанные материалы**: [мыло, глицерин, стеарин](../02_world/processed_materials/08_hygiene_textile_products.md)
**Особые свойства**: древнейшая химическая реакция (мыловарение)
**Источники»: «Soap» (Kuntz, 1928)

### Амальгамация (Amalgamation)

**Описание**: растворение золота/серебра в ртути → паста → нагрев → Hg испаряется → чистое Au/Ag
**Типичные применения**:
- Au-руда + Hg → амальгама → нагрев → Au чистое + Hg (испаряется, токсично!)
- Ag-руда + Hg → амальгама → нагрев → Ag чистое
**Требует**: 
- Ртуть (Hg) — из киновари (см. [../02_world/resources/01_minerals_ores.md](../02_world/resources/01_minerals_ores.md))
- Знание процесса
- Источник тепла
**Эпоха**: античность (известна), массово — 16 в. (патер процесс в Мексике)
**Связанные материалы**: [амальгама золота/серебра](../02_world/processed_materials/04_metallurgical_products.md)
**Особые свойства**: 
- Критично для извлечения Au/Ag из бедных руд
- Токсично (Hg пары → нейротоксичность)
- Историческая проблема в колониальной Америке
**Источники»: «Amalgamation Process» (Rickard, 1907)

## 🧪 Химические процессы

### Фракционная перегонка (Fractional distillation)

**Описание**: разделение смеси жидкостей по точкам кипения
**Типичные применения**:
- Нефть → фракции (бензин, керосин, дизель, мазут, битум) — 19 в.
- Спирт-сырец → этанол высокой концентрации (12 в.)
- Вода + эфирные масла → парфюм + вода (античность, Ибн Сина)
- Каменноугольная смола → бензол, толуол, нафталин, креозот (19 в.)
**Требует**: 
- Перегонный куб
- Знание температур кипения
- Конденсатор (змеевик)
**Эпоха**: античность (примитивная — Аристотель), современная — 12 в. (арабы)
**Связанные материалы**: [нефтепродукты, спирт, парфюм](../02_world/processed_materials/03_petroleum_products.md), [07_food_products.md](../02_world/processed_materials/07_food_products.md), [08_hygiene_textile_products.md](../02_world/processed_materials/08_hygiene_textile_products.md)
**Особые свойства**: 
- Критическая технология для нефтепереработки
- Ибн Сина изобрёл для парфюма → потом спирт
- В игре: «бесконечное развитие» — от примитивной перегонки до крекинга нефти
**Источники»: «Distillation» (Forbes, 1948)

### Крекинг (Cracking)

**Описание**: расщепление тяжёлых углеводородов на лёгкие (для увеличения выхода бензина)
**Типичные применения**:
- Тяжёлые фракции нефти → лёгкие (бензин) + газ
- Мазут → бензин + кокс (побочный)
**Требует**: 
- Знание крекинга (Бартон, 1913)
- Высокие температуры (500°C)
- Высокое давление (для термического крекинга)
- ИЛИ катализатор (для каталитического крекинга — 20 в.)
**Эпоха**: 20 в.
**Связанные материалы**: [бензин, крекинг-газ, нефтяной кокс](../02_world/processed_materials/03_petroleum_products.md)
**Особые свойства**: критично для массового автотранспорта (больше бензина из той же нефти)
**Источники»: «Cracking» (Kirk-Othmer)

### Полимеризация (Polymerization)

**Описание**: соединение множества малых молекул в большую полимерную цепь
**Типичные применения**:
- Этилен (C₂H₄) → полиэтилен (PE)
- Пропилен → полипропилен (PP)
- Винилхлорид → ПВХ
- Изопрен → синтетический каучук
- Фенол + формальдегид → бакелит (первый пластик, 1907)
- Стирол → полистирол
**Требует**: 
- Знание крекинга нефти (для этилена)
- Знание химии полимеров (20 в.)
- Катализаторы (Циглера-Натта — 1950-е)
- Высокое давление / температура
**Эпоха**: 20 в. (Бакеленд, 1907 — бакелит)
**Связанные материалы**: [пластмассы, синтетический каучук](../02_world/processed_materials/03_petroleum_products.md)
**Особые свойства**: «пластиковая революция» — последняя индустриальная технология
**Источники»: «Polymers» (American Chemistry Council)

### Электролиз (Electrolysis) ⭐

**Описание**: разложение вещества электрическим током
**Типичные применения**:
- Al₂O₃ (глинозём) в расплаве криолита → Al (катод) + O₂ (анод) — процесс Холла-Эру, 1886
- NaCl расплав → Na (катод) + Cl₂ (анод) — натрий
- H₂O + NaCl → NaOH + H₂ + Cl₂ (хлор-щёлок)
- H₂O → H₂ + O₂ (электролиз воды)
**Требует**: 
- **Электричество** (критично!)
- Знание электрохимии
- Специальные электроды (часто — нефтяной кокс)
- Расплав соли / раствора
**Эпоха**: 19 в. (Фарадей — основы, Холл-Эру — алюминий, 1886)
**Связанные материалы**: [алюминий, хлор, натрий, водород, кислород](../02_world/processed_materials/04_metallurgical_products.md)
**Особые свойства**: **КРИТИЧНО** — без электролиза нет алюминия (лёгкие металлы) и многих хим. продуктов
**Источники»: «Electrochemistry» (Kirk-Othmer)

### Процесс Габера-Боша (Haber-Bosch process) ⭐

**Описание**: синтез аммиака из азота и водорода
**Химия**: N₂ + 3H₂ → 2NH₃ (катализатор Fe, 500°C, 200 атм)
**Типичные применения**:
- Воздух (N₂) + водород (из CH₄ или угля) → NH₃ → удобрения → рост урожайности
- NH₃ → HNO₃ → взрывчатка
**Требует**: 
- Электричество (для H₂ из воды) или метан (для H₂ из CH₄)
- Знание катализа
- Химическая инженерия (высокие давления)
- Источник Fe (катализатор)
**Эпоха**: 20 в. (Габер, 1909; Бош, 1910)
**Связанные материалы**: [аммиачная селитра, NH₃](../02_world/processed_materials/06_agricultural_products.md)
**Особые свойства**: **КРИТИЧНО** — без этого процесса нет массовых удобрений → нет современного населения. «Зелёная революция» — основа демографии 20 в.
**Источники»: «Haber-Bosch Process» (Smil, 2001)

### Контактный процесс (Contact process)

**Описание**: производство серной кислоты из SO₂ + O₂
**Химия**: 2SO₂ + O₂ → 2SO₃ (катализатор V₂O₅, 450°C) → + H₂O → H₂SO₄
**Требует**: 
- SO₂ (из обжига пирита/галенита)
- Знание катализа (V₂O₅ — ванадат)
- Источник O₂
**Эпоха**: 19 в.
**Связанные материалы**: [серная кислота](../02_world/processed_materials/02_chemical_products.md)
**Особые свойства**: критично для современной химии (H₂SO₄ — главный продукт)
**Источники»: «Sulfuric Acid» (Sander, 1986)

## 🦠 Биологические процессы

### Брожение / Ферментация (Fermentation)

**Описание**: биохимическое преобразование микроорганизмами (дрожжи, бактерии)
**Типичные применения**:
- Сахар → этанол + CO₂ (дрожжи Saccharomyces)
- Лактоза → молочная кислота (бактерии Lactobacillus → йогурт, сыр)
- Крахмал → сахара (амилазы в солоде)
- Уксусная кислота из этанола (Acetobacter)
- Молоко → сыр (фермент реннин)
**Требует**: 
- Знание ферментации (древнее — наблюдение)
- Источник сырья (сахар, крахмал, молоко)
- Контроль температуры (25-35°C)
- Стерильные условия (позднее — Пастер, 19 в.)
**Эпоха**: пиво ~10000 до н.э. (Гёбекли-Тепе), вино ~6000 до н.э., сыр ~5500 до н.э.
**Связанные материалы**: [этанол, уксус, сыр, хлеб, пиво, вино](../02_world/processed_materials/07_food_products.md)
**Особые свойства**: древнейший «химический» процесс → основа всей пищевой промышленности
**Источники»: «Fermentation» (Hornsey, 2003)

### Гниение/Компостирование (Composting)

**Описание**: аэробное разложение органики бактериями → удобрение
**Типичные применения**:
- Органические отходы → компост → удобрение
- Навоз → перегной → удобрение
**Требует**: 
- Контроль влажности и аэрации
- Время (3-12 месяцев)
**Эпоха**: с неолита
**Связанные материалы**: [компост, удобрения](../02_world/processed_materials/06_agricultural_products.md)
**Особые свойства**: древнейшее удобрение → критично для земледелия
**Источники»: «Composting» (Hauck, 1993)

## ⚙ Механические процессы

### Помол (Milling)

**Описание**: измельчение твёрдых материалов механически
**Типичные применения**:
- Зерно → мука (главное!)
- Минералы → порошок (для красителей, металлов)
- Сахар-сырец → сахар
- Кости → костяная мука
**Требует**: 
- Жернов (каменный — базовый, или мельница — позднее)
- Источник энергии (мускульная, водяная, ветряная, паровая)
**Эпоха**: с неолита (~10000 до н.э. — ручные жернова)
**Связанные материалы**: [мука, костяная мука, красители](../02_world/processed_materials/07_food_products.md), [06_agricultural_products.md](../02_world/processed_materials/06_agricultural_products.md), [07_dyes_pigments.md](../02_world/resources/07_dyes_pigments.md)
**Особые свойства**: водяная мельница (1 в. до н.э.) → рост производительности ×100
**Источники»: «Milling» (Watts, 1952)

### Прессование / Отжим (Pressing)

**Описание**: выдавливание жидкости из твёрдого материала давлением
**Типичные применения**:
- Оливки → масло (главное! — тиски / каменный пресс)
- Виноград → сок → вино
- Семена льна → льняное масло
- Сахарный тростник → сок
**Требует**: 
- Пресс (деревянный, каменный, винтовой, гидравлический — позднее)
**Эпоха**: античность (массово)
**Связанные материалы**: [масла, оливковое масло, вино, сахар](../02_world/resources/08_food_resources.md), [олифа](../02_world/processed_materials/08_hygiene_textile_products.md)
**Особые свойства**: винтовой пресс (Гутенберг использовал для печати — 15 в.)
**Источники»: «Pressing» (David, 1980)

## Принципы для дизайна

### 1. Процессы — связующее звено
Каждый продукт в `processed_materials/` создаётся одним или несколькими процессами. Каждый процесс описан в этом файле.

### 2. Зависимости процессов
- **Простые** (неолит): обжиг, выщелачивание, помол, брожение
- **Средние** (античность): плавка, cupellation, омыление, дистилляция
- **Сложные** (19-20 в.): коксование, домна, электролиз, Габер-Бош, полимеризация

### 3. «Бутылочные горлышки»
- Без коксования нет домны → нет стали
- Без электричества нет электролиза → нет алюминия
- Без Габер-Боша нет массового азота → нет демографического взрыва

### 4. «Бесконечное развитие»
Каждый процесс — это шаг в дереве технологий. От обжига известняка (9000 до н.э.) до Габер-Боша (1909 н.э.) — путь в 11000 лет. Игрок сам решает, как далеко идти.

### 5. Кросс-зависимости
Многие процессы требуют нескольких предпосылок:
- **Электролиз** = электричество + химия + катализаторы + электроды
- **Габер-Бош** = катализаторы + высокие давления + H₂ (из CH₄ или электролиза)
