## ⚠️ Принцип 10: Обязательная связность (критический)

Каждое изделие **ОБЯЗАНО** иметь связи с другими элементами. **Никаких «висящих» изделий.**

### Шаблон записи изделия

```
### Название изделия

**Тип**: оружие/инструмент/здание/...
**Эпоха**: когда появилось
**Состав**: из каких материалов сделано

**Входящие связи** (из чего делается):
- материал1 → [путь к processed_materials/]
- материал2 → [путь к resources/]
- процесс → [путь к processes.md]
- предпосылка-технология → [путь к tech_tree.md]

**Исходящие связи** (для чего нужно):
- применение1 (какая польза: атака/защита/производство/и т.д.)
- какие технологии/здания требуют это изделие

**Альтернативы** (что можно использовать вместо):
- альтернатива1 → [путь]

**Игровые поля** (P5, v0.31+):
- [урон — для оружия] | [защита — для брони] | [эффективность × — для инструментов] | [вместимость — для зданий] | [скорость — для транспорта]
- [прочность: 0-100]
- [вес: кг]
- [требуемый навык: 0-100]
- [штраф к скорости: % — для брони]

**Роль**: критичное для эпохи? рядовое?
```

> ⚠️ **Игровые поля обязательны (P5, v0.31+)**: СУЩЕСТВОВАНИЕ полей — обязательно сейчас. Значения — на плейтестах (можно заглушка `TBD: плейтесты`). Без числовых полей каталог остаётся энциклопедией, а не игрой. См. [decision_log.md → "Игровые поля каталогов"](../_meta/decision_log.md).

### Правило

При добавлении нового изделия ИИ **обязан**:
1. Описать состав (материалы)
2. Указать входящие связи (из чего делается)
3. Указать исходящие связи (для чего нужно)
4. Указать альтернативы
5. Указать роль в дереве технологий

Если у изделия нет применения → либо создать, либо удалить.

## Принципы для дизайна изделий

### 1. Историческая прогрессия

Каждое изделие имеет «предшественника» (что использовали до него) и «преемника» (что придёт после). Например:
- Нож → Кинжал → Меч → Сабля → Шпага → Рапира
- Хижина → Глинобитный дом → Кирпичный дом → Каменный дом → Бетонное здание
- Лодка-долблёнка → Плот → Парусник → Галера → Каравелла

### 2. Технологические предпосылки

Каждое изделие требует:
- Определённые материалы (например, бронзовый меч → бронза → Cu + Sn + плавка)
- Определённые технологии (литьё, ковка, обработка)
- Определённые инструменты (например, для меча нужен молот, наковальня, точильный камень)

### 3. «Бутылочные горлышки» изделий

Некоторые изделия — критические для перехода в новую эпоху:
- Бронзовый меч → нужна бронза → нужно олово → нужна торговля (если нет олова локально)
- Железный меч → нужна плавка железа → нужны тигли + шамот
- Телега → нужно колесо → нужен токарный станок + древесина
- Парусник → нужны паруса → нужен лён/конопля + ткачество

### 4. Альтернативы — для реиграбельности

Если у изделия есть альтернатива, игрок может выбрать путь:
- Без олова → мышьяковая бронза (токсичнее, но доступнее)
- Без дерева → тростниковые лодки (Египет)
- Без железа → костяные орудия (север)
