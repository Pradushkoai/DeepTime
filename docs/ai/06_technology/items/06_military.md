# Военное снаряжение

> Доспехи, щиты, осадные машины — для обороны и нападения.

---

## 🛡 Доспехи

### Кожаный доспех (Leather armor)

**Тип**: защитный
**Эпоха**: палеолит/неолит
**Состав**: кожа (толстая — бычья/лось/медведь)

**Входящие связи**:
- Кожа → [../../02_world/resources/09_hides_leather.md]
- Процесс: дубление + шитьё → [../../02_world/processed_materials/09_hides_leather.md]
- Клей/нитки

**Исходящие связи**:
- Защита пехоты (дешёвый)
- Основа для усиленного доспеха (с пластинами)

**Альтернативы**: ламина́рный (с пластинами), тканевый (стёганый — heavier)

**Роль**: базовый доспех для всех эпох

---

### Ламина́рный / Ламинальный доспех (Lamellar / Laminar armor)

**Тип**: защитный
**Эпоха**: бронзовый век
**Состав**: кожа/ткань + металлические пластины (бронза/Fe/сталь)

**Входящие связи**:
- Кожа (основа)
- Металл (пластины) → [../../02_world/processed_materials/04_metallurgical_products.md]
- Канаты (для связывания)

**Исходящие связи**:
- Защита элитных войск
- Защита от стрел (более эффективная, чем у кожаного)

**Альтернативы**: кольчуга (более гибкая)

---

### Кольчуга (Chainmail)

**Тип**: защитный
**Эпоха**: 5 в. до н.э. (кельты), распространена в средние века
**Состав**: ~30000 железных/стальных колец

**Входящие связи**:
- Железо/сталь (много!) → [../../02_world/processed_materials/04_metallurgical_products.md]
- Процесс: ковка колец + клёпка/сварка
- Инструменты: клещи, молот

**Исходящие связи**:
- Защита пехоты/кавалерии (средние века)
- Гибкая (в отличие от ламинара)

**Альтернативы**: ламинарный, латный доспех

**Роль**: требует много металла → индикатор развитой металлургии

---

### Латный доспех / Полный латный (Plate armor)

**Тип**: защитный
**Эпоха**: 14-15 в. (расцвет)
**Состав**: стальные пластины (большой размер)

**Входящие связи**:
- Сталь (большое количество)
- Кузнечное дело (высокий уровень)
- Кузница + наковальня + молот + напильник

**Исходящие связи**:
- Защита аристократии (рыцари)
- Статус

**Роль**: элита → показатель индустриальной зрелости металлургии

---

### Шлем (Helmet)

**Тип**: защитный (голова)
**Эпоха**: бронзовый век
**Состав**: бронза/Fe/сталь (или кожа/кость)

**Входящие связи**: металл + кузня
**Исходящие связи**: защита головы (критично — удар в голову = смерть)

---

## 🛡 Щиты

### Деревянный щит (Wooden shield)

**Тип**: защитный
**Эпоха**: неолит
**Состав**: дерево + кожа/металл (обивка)

**Входящие связи**:
- Древесина
- Кожа (обивка) → [../../02_world/resources/09_hides_leather.md]
- Металл (умбон — центр, позднее)

**Исходящие связи**: защита от стрел/мечей

---

### Скутум / Римский щит (Scutum)

**Тип**: защитный (большой)
**Эпоха**: Рим (1 в. до н.э. — 4 в. н.э.)
**Состав**: дерево + кожа + металл (умбон + края)

**Входящие связи**:
- Древесина (многослойная)
- Кожа (толстая)
- Металл (умбон)
- Клей/заклёпки

**Исходящие связи**:
- Защита легионера (критично! — фаланга)
- Тактическое (черепаха — testudo)

---

### Баклер / Кулаковый щит (Buckler)

**Тип**: малый щит
**Эпоха**: средневековье
**Состав**: сталь

**Входящие связи**: сталь + кузня
**Исходящие связи**: защита дуэлянта/горожанина (маленький, лёгкий)

---

## ⚔ Осадные машины

### Таран (Battering ram)

**Тип**: осадная машина
**Эпоха**: античность
**Состав**: большое бревно (дуб) + металлический наконечник + подвес (канаты) + колёсная рама

**Входящие связи**:
- Большое дерево (дуб)
- Металл (наконечник)
- Канаты (конопля)
- Колёса → [04_transport.md]

**Исходящие связи**: пробивание стен/ворот

---

### Катапульта / Баллиста (Catapult / Ballista)

**Тип**: осадная машина (метательная)
**Эпоха**: античность (Греция, 4 в. до н.э.)
**Состав**: дерево + металл (пружины/оси) + канаты (торсион)

**Входящие связи**:
- Древесина (массивная)
- Металл (оси, крепления)
- Канаты (из сухожилий или конопли — для торсиона)
- Знание: механика (Архимед)

**Исходящие связи**:
- Бомбардировка стен
- Защита крепости
- Метание зажигательных смесей (греческий огонь)

**Роль**: требует знания механики → индикатор развитой инженерии

---

### Требушет (Trebuchet)

**Тип**: осадная машина (противовесная)
**Эпоха**: 12 в. (Китай), 13 в. (Европа)
**Состав**: дерево + противовес (камень/свинец) + рычаг + канаты

**Входящие связи**:
- Древесина (массивная)
- Большой камень/свинец (противовес)
- Канаты
- Знание: механика

**Исходящие связи**:
- Разрушение стен (эффективнее катапульты)
- Бомбардировка

**Роль**: последнее слово в осадной технике до пушек

---

## 🔫 Появление пороха (14-19 в.)

### Пушка (Cannon)

**Тип**: огнестрельное (осадное/военное)
**Эпоха**: 13 в. (Китай), 14 в. (Европа)
**Состав**: бронза/Fe ствол + порох + ядро (камень/Fe/свинец)

**Входящие связи**:
- Бронза/Fe (большое количество для ствола) → [../../02_world/processed_materials/04_metallurgical_products.md]
- Порох (селитра + сера + уголь) → [../../02_world/processed_materials/05_military_products.md]
- Ядро (камень/Fe/свинец)
- Кузнечное/литейное дело

**Исходящие связи**:
- Осада крепостей (конец замковой эпохи)
- Военное (полевая артиллерия)
- Морское (на кораблях)

**Роль**: КРИТИЧНО — пушка сделала замки устаревшими → конец феодализма

---

### Мушкет / Ружьё (Musket)

**Тип**: огнестрельное (ручное)
**Эпоха**: 16 в.
**Состав**: стальной ствол + деревянное ложе + порох + пуля

**Входящие связи**:
- Сталь (ствол)
- Древесина (ложе)
- Порох → [../../02_world/processed_materials/05_military_products.md]
- Свинец (пуля) → [../../02_world/resources/01_minerals_ores.md]
- Кремень (для искры — замок) → [../../02_world/resources/02_stone_construction.md]

**Исходящие связи**:
- Пехотное оружие (массовое)
- Кавалерийское
- Охота

**Роль**: КРИТИЧНО — пехота с мушкетами → конец кавалерии (как главной силы) → новая тактика

---

### Современное огнестрельное (Modern firearms)

**Тип**: автоматическое/нарезное
**Эпоха**: 19-20 в.
**Состав**: сталь + латунь (гильза) + порох + пуля

**Входящие связи**:
- Сталь (ствол)
- Латунь (гильза) → [../../02_world/processed_materials/04_metallurgical_products.md]
- Бездымный порох (нитроцеллюлоза) — позднее
- Пуля (свинец + оболочка — мельхиор/латунь)

**Исходящие связи**: военное, охотничье

## Принципы для дизайна

### 1. Доспех vs оружие — гонка технологий

Лучший меч → лучший доспех → ещё лучший меч → ... (гонка между атакой и защитой)

### 2. Кольчуга = индикатор развитой металлургии

~30000 колец требуют много металла. Если у племени есть кольчуги — у них развитая металлургия.

### 3. Порох — конец эпохи доспехов

Пушки пробивают любые стены → замки устаревают. Мушкеты пробивают доспехи → доспехи исчезают.

### 4. Осадные машины требуют механики

Катапульта/требушет — это механика (рычаги, торсион, противовес). Знание механики — критично.

### 5. Логистика военного дела

Армия требует:
- Оружие → кузницы
- Доспехи → много кожи/металла
- Провиант → стратегический запас (солонина)
- Транспорт → телеги для обоза
