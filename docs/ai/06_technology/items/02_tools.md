# Инструменты

> От каменного топора до доменной печи. Инструменты — основа производительной силы.

---

## 🪨 Каменные инструменты (палеолит/неолит)

### Каменный топор (Stone axe)

**Тип**: рубящий
**Эпоха**: палеолит
**Состав**: кремень/обсидиан + рукоять (дерево/кость) + клей/смола

**Входящие связи**:
- Кремень или обсидиан → [../../02_world/resources/02_stone_construction.md]
- Древесина (рукоять) → [../../02_world/resources/05_wood_timber.md]
- Смола/дёготь (крепление) → [../../02_world/processed_materials/01_fuel_products.md]
- Процесс: оббивка + шлифовка (неолит)

**Исходящие связи**:
- Рубка леса (главное!)
- Военное (как оружие — двойное)
- Строительство (заготовка древесины)

**Альтернативы**:
- Костяной топор
- Медный/бронзовый/железный (последовательно)

**Роль**: критичен для вырубки леса и строительства в ранней стадии

---

### Скребок (Scraper)

**Тип**: скоблящий
**Эпоха**: палеолит
**Состав**: кремень

**Входящие связи**:
- Кремень
- Процесс: оббивка

**Исходящие связи**:
- Обработка шкур (кожевенное дело) → [../../02_world/processed_materials/08_hygiene_textile_products.md]
- Обработка дерева
- Резка мяса

---

### Палка-копалка (Digging stick)

**Тип**: земледельческий
**Эпоха**: палеолит
**Состав**: твёрдое дерево (дуб, граб)

**Входящие связи**:
- Древесина
- Процесс: обтёсывание + обжиг (для твердости)

**Исходящие связи**:
- Земледелие (примитивное — для посадки семян)
- Сбор кореньев

**Альтернативы**:
- Мотыга (с каменным/металлическим лезвием)
- Лопата (позднее)

**Роль**: первый земледельческий инструмент

---

## 🥉 Медные/бронзовые инструменты

### Медный/бронзовый серп (Sickle)

**Тип**: земледельческий (жатва)
**Эпоха**: неолит (медь) → бронзовый век
**Состав**: медь/бронза + дерево (рукоять)

**Входящие связи**:
- Медь/бронза → [../../02_world/processed_materials/04_metallurgical_products.md]
- Древесина
- Процесс: литьё + заточка

**Исходящие связи**:
- Жатва зерновых (критично! — без серпа нет уборки урожая)
- Заготовка тростника

**Альтернативы**:
- Кремнёвый серп (вкладышевый — древний)
- Железный серп (прочнее)

**Роль**: критичен для урожайного земледелия

---

### Бронзовый нож (Knife)

**Тип**: режущий
**Эпоха**: бронзовый век
**Состав**: бронза + рукоять

**Входящие связи**: бронза + дерево + клей
**Исходящие связи**: бытовое, ремесло (резьба), война
**Альтернативы**: кремнёвый, медный, железный

---

### Бронзовая мотыга (Hoe)

**Тип**: земледельческий (обработка почвы)
**Эпоха**: неолит/бронзовый век
**Состав**: бронза + дерево

**Входящие связи**: бронза + древесина + крепление
**Исходящие связи**: обработка почвы (замена палки-копалки)
**Альтернативы**: палка-копалка, железная мотыга

---

## 🥇 Железные/стальные инструменты

### Железный/стальной серп

**Тип**: земледельческий
**Эпоха**: железный век
**Состав**: Fe/сталь + дерево

**Входящие связи**:
- Fe-руда → [../../02_world/resources/01_minerals_ores.md]
- Древесный уголь → [../../02_world/processed_materials/01_fuel_products.md]
- Шамот (огнеупор) + графит (тигель)
- Процесс: сыродутная плавка + ковка

**Исходящие связи**: жатва (более эффективная, чем бронзовым)

---

### Железный/стальной плуг (Plough)

**Тип**: земледельческий (пахота)
**Эпоха**: железный век
**Состав**: стальной лемех + деревянная рама + ось

**Входящие связи**:
- Сталь → [../../02_world/processed_materials/04_metallurgical_products.md]
- Древесина (дуб, граб — для рамы)
- Тягловое животное (корова/лошадь/буйвол) — одомашнено!

**Исходящие связи**:
- Пахота тяжёлых почв (чернозём, лесные почвы) — критично!
- Замена мотыги (массовое земледелие)
- Рост урожайности в 2-3 раза

**Альтернативы**:
- Деревянный плуг (без стального лемеха — не пашет тяжёлые почвы)
- Мотыга (ручная, медленнее)

**Роль**: КРИТИЧНО — без плуга нет массового земледелия в Европе

---

### Железный/стальной топор (Iron/steel axe)

**Тип**: рубящий
**Эпоха**: железный век
**Состав**: Fe/сталь + дерево

**Входящие связи**:
- Fe-руда + уголь + огнеупоры (тигель, шамот)
- Древесина (рукоять)

**Исходящие связи**:
- Рубка леса (эффективнее каменного в 5-10 раз)
- Строительство
- Военное (как оружие)

**Альтернативы**: каменный, бронзовый
**Роль**: революция в лесозаготовке → рост строительства

---

### Пила (Saw)

**Тип**: режущий (продольный)
**Эпоха**: бронзовый век (бронза), железный век (Fe/сталь)
**Состав**: бронза/Fe/сталь

**Входящие связи**:
- Бронза или Fe/сталь
- Процесс: ковка + заточка зубьев

**Исходящие связи**:
- Распиловка дерева (доски!)
- Резка кости/камня (медицинская)
- Столярное дело

**Роль**: критично для столярного дела (доски, мебель)

---

### Напильник (File)

**Тип**: абразивный
**Эпоха**: железный век
**Состав**: сталь с насечками

**Входящие связи**:
- Сталь
- Процесс: ковка + насечка + закалка

**Исходящие связи**:
- Обработка металла (заточка, шлифовка)
- Замок (слесарное дело — позднее)

---

### Молот/Кувалда (Hammer)

**Тип**: ударный
**Эпоха**: палеолит (камень) → бронзовый век (металл)
**Состав**: камень или металл + рукоять

**Входящие связи**:
- Камень или бронза/Fe
- Древесина
- Крепление

**Исходящие связи**:
- Кузнечное дело (главное!)
- Строительство
- Каменотёсное дело

---

### Наковальня (Anvil)

**Тип**: опора для ковки
**Эпоха**: бронзовый век
**Состав**: массивный металл (бронза/Fe/сталь)

**Входящие связи**:
- Большое количество металла
- Процесс: литьё + шлифовка

**Исходящие связи**:
- Кузнечное дело (критично — без наковальни нет кузни)
- Ювелирное дело

**Роль**: критичное оборудование кузницы

---

### Точильный камень (Whetstone)

**Тип**: абразивный (заточка)
**Эпоха**: палеолит
**Состав**: песчаник/кварц (твёрдый камень)

**Входящие связи**:
- Песчаник/кварц → [../../02_world/resources/02_stone_construction.md]
- Процесс: обтёсывание

**Исходящие связи**:
- Заточка орудий (ножи, серпы, мечи, топоры)
- Полировка изделий

**Роль**: критичен для поддержания остроты орудий

---

## ⚙ Механизмы (поздние)

### Жернов (Millstone)

**Тип**: помольный
**Эпоха**: неолит
**Состав**: базальт/песчаник (2 камня)

**Входящие связи**:
- Базальт или песчаник → [../../02_world/resources/02_stone_construction.md]
- Процесс: обтёсывание

**Исходящие связи**:
- Помол зерна (критично для муки → хлеба)
- Замена ручных жерновов → ×10 производительности

**Альтернативы**: ручной камень (метат), водяная мельница (позднее)

**Роль**: критичен для массового производства муки

---

### Токарный станок (Lathe)

**Тип**: вращающий (для дерева)
**Эпоха**: античность
**Состав**: дерево + металл (резец)

**Входящие связи**:
- Древесина
- Металл (резец)
- Процесс: сборка

**Исходящие связи**:
- Изготовление круглых деталей (колёса! bowls, мебель)
- Колесо → телега → транспорт

**Роль**: КРИТИЧНО — без токарного станка нет круглых колёс → нет телеги

---

### Водяная мельница (Water mill)

**Тип**: механический
**Эпоха**: 1 в. до н.э. (Витрувий)
**Состав**: жернов + водяное колесо + механизм (дерево + металл)

**Входящие связи**:
- Жернов
- Древесина (колесо, механизм)
- Металл (оси, шестерни)
- Река (источник энергии)

**Исходящие связи**:
- Помол зерна (×100 эффективности vs ручного)
- Лесопилка (позднее)
- Кузнечные меха (позднее)

**Альтернативы**: ручной помол, ветряная мельница

**Роль**: КРИТИЧНО — первый «механизированный» источник энергии → рост производительности

## Принципы для дизайна

### 1. Прогрессия инструментов = прогрессия цивилизации

Без плуга → нет тяжёлого земледелия → нет городов. Без пилы → нет столярного дела → нет мебели/досок. Без токарного станка → нет колёс → нет транспорта.

### 2. Двойное применение инструментов

Многие инструменты — и для гражданского, и для военного:
- Топор — рубка + оружие
- Нож — быт + война
- Молоток — стройка + оружие

### 3. Инструменты как предпосылки для других изделий

Меч требует: молот + наковальня + точильный камень. Это значит — кузница требует набор инструментов, а каждый инструмент — свои материалы.

### 4. «Бутылочные горлышки» инструментов

- Плуг → стальной лемех + тягловое животное (нужно одомашнить!)
- Жернов → базальт (географически ограничен)
- Токарный станок → первый шаг к колесу
