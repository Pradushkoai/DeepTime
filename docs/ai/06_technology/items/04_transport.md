# Транспорт

> От пешего ходока до автомобиля. Прогрессия: пешком → животное → колесо → парус → пар → ДВС → электричество.

---

## 🚶 Пешеходный транспорт (палеолит)

### Носилки / Вьюк (Carrying pole / Pack)

**Тип**: простой транспорт
**Эпоха**: палеолит
**Состав**: древесина (палка) + плетёная корзина/мешок

**Входящие связи**:
- Древесина (палка) → [../../02_world/resources/05_wood_timber.md]
- Корзина (лыко, лоза) → [../../02_world/resources/06_fibers_textiles.md]
- Труд человека

**Исходящие связи**:
- Переноска грузов (пешком)
- Переноска раненых

---

## 🐴 Транспорт с животными

### Вьючное животное (Pack animal)

**Тип**: животный транспорт
**Эпоха**: неолит
**Состав**: одомашненное животное (осёл, лошадь, мул, верблюд, лама)

**Входящие связи**:
- Одомашненное животное → [../../02_world/fauna/README.md]
- Седло/вьюк (кожа, дерево) → [../../02_world/resources/09_hides_leather.md]
- Корм (сено, зерно)

**Исходящие связи**:
- Торговля (караваны!)
- Транспорт в горах (вьючный — без дорог)

**Альтернативы**: человеческий носильщик (медленнее, дороже в долгосрочной перспективе)

**Роль**: критично для караванной торговли (Великий шёлковый путь, Сахара)

---

### Верховая лошадь (Riding horse)

**Тип**: верховая
**Эпоха**: ~3500 до н.э. (Ботай, Казахстан)
**Состав**: лошадь + узда/седло

**Входящие связи**:
- Лошадь (одомашненная) → [../../02_world/fauna/README.md]
- Уздечка (кожа, кость) → [../../02_world/resources/09_hides_leather.md]
- Седло (позднее — дерево + кожа, 5 в. до н.э. скифы)
- Подкова (Fe, позднее — 9 в. н.э.)

**Исходящие связи**:
- Кавалерия (критичное военное преимущество!)
- Транспорт (быстрый — 30-50 км/день)
- Связь (гонцы, почта)

**Альтернативы**: осёл, мул, верблюд, лама (по регионам)

**Роль**: КРИТИЧНО — без верховой лошади нет кавалерии → нет степных империй (монголы, скифы, гунны)

---

## 🛞 Колёсный транспорт

### Телега / Повозка (Cart / Wagon)

**Тип**: колёсный транспорт
**Эпоха**: ~3500 до н.э. (Месопотамия)
**Состав**: колёса + ось + кузов + животное (вол/лошадь)

**Входящие связи**:
- Колесо → [02_tools.md] (токарный станок — критично!)
- Древесина (дуб, граб для оси)
- Тяговое животное (вол/корова/лошадь) — одомашнено
- Кожа/канаты (крепления)
- Железные оси (позднее)

**Исходящие связи**:
- Транспорт грузов (×10 vs носильщика)
- Сельское хозяйство (вывоз урожая)
- Торговля

**Альтернативы**: сани (зимой), вьюк (в горах)

**Роль**: КРИТИЧНО — без колеса нет телеги, без телеги нет массового транспорта по земле

---

### Колесница (Chariot)

**Тип**: военный транспорт
**Эпоха**: ~2000 до н.э. (Месопотамия), расцвет — 1500-1200 до н.э.
**Состав**: колесо со спицами + лошадь + лёгкая рама + вооружение

**Входящие связи**:
- Колесо со спицами (нужна продвинутая деревообработка)
- Лошадь (одомашненная, обученная)
- Древесина (лёгкая — тис, ясень)
- Кожа/канаты
- Бронзовое/железное оружие (для бойца)

**Исходящие связи**:
- Военное (древняя «бронетехника»)
- Гонки (ритуально-спортивные — Рим)

**Альтернативы**: верховая лошадь (позже вытеснила)

**Роль**: КРИТИЧНО для бронзового века — без колесниц со спицами нет Хеттского/Египетского военного преимущества

---

## 🚢 Водный транспорт

### Плот (Raft)

**Тип**: водный
**Эпоха**: палеолит (~50000 до н.э.)
**Состав**: брёвна/тростник + канаты

**Входящие связи**:
- Древесина (лёгкая — бальза, тополь) ИЛИ тростник (папирус)
- Канаты (лыко, конопля)

**Исходящие связи**:
- Переправа рек
- Прибрежное плавание
- Рыболовство

**Альтернативы**: лодка-долблёнка

---

### Лодка-долблёнка (Dugout canoe)

**Тип**: водный
**Эпоха**: палеолит (~8000 до н.э.)
**Состав**: цельное дерево (долблёное)

**Входящие связи**:
- Большое дерево (дуб, липа, кедр)
- Инструменты: топор + долото + огонь (для выжигания) → [02_tools.md]

**Исходящие связи**:
- Речной транспорт
- Рыболовство
- Переправа

**Альтернативы**: каркасная лодка (кожа на каркасе)

---

### Парусное судно (Sailing ship)

**Тип**: морской транспорт
**Эпоха**: ~3000 до н.э. (Египет, Финикия)
**Состав**: корпус + мачта + парус + канаты + руль

**Входящие связи**:
- Древесина (кедр — для финикийцев, дуб — для киля)
- Парус (лён или конопля) → [../../02_world/resources/06_fibers_textiles.md]
- Канаты (конопля — прочнее)
- Смола/дёготь (герметизация) → [../../02_world/processed_materials/01_fuel_products.md]
- Металл (гвозди, якорь) — позднее
- Ткацкий станок (для паруса)

**Исходящие связи**:
- Морская торговля (критично! — без паруса нет финикийцев/греков/викингов)
- Колонизация
- Военное (галеры)
- Рыболовство (вдали от берега)

**Альтернативы**: вёсельная лодка (медленнее, требует людей)

**Роль**: КРИТИЧНО — без паруса (←лён/конопля) нет мореплавания → нет финикийской/греческой/викингской цивилизаций

---

### Галера (Galley)

**Тип**: военное/торговое судно
**Эпоха**: античность
**Состав**: корпус + вёсла + мачта + парус + таран (бронза/Fe)

**Входящие связи**:
- Большое дерево (кедр — мачта, дуб — киль)
- Вёсла (ясень)
- Парус (лён)
- Таран (бронза/Fe)
- Рабы/гребцы (труд)

**Исходящие связи**:
- Военное (Афины, Рим — критично!)
- Торговое
- Пиратство

---

### Каравелла / Галеон (Caravel / Galleon)

**Тип**: океанское судно
**Эпоха**: 15-16 в. (Португалия, Испания)
**Состав**: каравелла — 2 мачты, галеон — 3+ мачты

**Входящие связи**:
- Древесина (дуб, кедр, тик)
- Паруса (льняные, потом хлопковые)
- Канаты (конопля)
- Металл (гвозди, пушки)
- Компас (для навигации)
- Астролябия (для навигации)

**Исходящие связи**:
- Океанская торговля
- Колонизация (критично! — Америка, Индия)
- Военное (пушки)

**Роль**: КРИТИЧНО — океанская революция → Великие географические открытия

## 🚂 Современный транспорт (индустриальная)

### Паровоз (Steam locomotive)

**Тип**: рельсовый транспорт
**Эпоха**: 1804 (Тревисик), массово — 1830 (Стивенсон)
**Состав**: стальной котёл + цилиндр + поршень + колёса

**Входящие связи**:
- Сталь (критично! — котёл под давлением) → [../../02_world/processed_materials/04_metallurgical_products.md]
- Уголь/кокс
- Вода
- Знание: паровая машина (Ньюкомен 1712, Уатт 1769)

**Исходящие связи**:
- Железнодорожный транспорт (×100 эффективности)
- Логистика (массовый)
- Промышленная революция

**Роль**: КРИТИЧНО — без паровоза нет индустриализации транспорта

---

### Автомобиль (Automobile)

**Тип**: дорожный транспорт
**Эпоха**: 1886 (Бенц)
**Состав**: стальной кузов + ДВС + колёса + резина

**Входящие связи**:
- Сталь (кузов)
- Бензин → [../../02_world/processed_materials/03_petroleum_products.md]
- Резина (натуральный или синтетический каучук)
- ДВС (знание — Отто 1876, Бенц 1886)
- Электричество (для зажигания)

**Исходящие связи**:
- Индивидуальный транспорт
- Грузовой транспорт
- Логистика

---

### Самолёт (Airplane)

**Тип**: воздушный транспорт
**Эпоха**: 1903 (братья Райт)
**Состав**: алюминиевый корпус + ДВС (позднее — реактивный) + пропеллер/турбина

**Входящие связи**:
- Алюминий (критично — лёгкий!) → [../../02_world/processed_materials/04_metallurgical_products.md]
- ДВС (Отто, Бенц)
- (позднее): реактивный двигатель + керосин
- Знание аэродинамики

**Исходящие связи**:
- Воздушный транспорт
- Военное (бомбардировщики, истребители)
- Связь (быстрая почта)

## Принципы для дизайна

### 1. Три «бутылочных горлышка» транспорта

1. **Колесо со спицами** → колесница/телега (без токарного станка нет колеса)
2. **Парус** → мореплавание (без льна/конопли нет парусов)
3. **Сталь** → паровоз/авто/самолёт (без домны+кокса нет стали)

### 2. Прогрессия = рост скорости и грузоподъёмности

Носильщик (30 кг, 30 км/день) → Вьюк (100 кг, 40 км/день) → Телега (500 кг, 30 км/день) → Поезд (100 т, 500 км/день) → Самолёт (50 т, 10000 км/день)

### 3. Военное применение транспорта

Колесница → Кавалерия → Танк → Бомбардировщик. Транспорт = военная мощь.

### 4. Логистика как основа экономики

Без транспорта нет торговли. Без торговли нет специализации. Без специализации нет цивилизации.
