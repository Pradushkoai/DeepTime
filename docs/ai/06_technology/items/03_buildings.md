# Здания

> От шалаша до небоскрёба. Историческая прогрессия: дерево → глина → кирпич → камень → бетон → сталь/стекло.

---

## 🏕 Жилые здания

### Шалаш / Хижина из веток (Wattle shelter)

**Тип**: временное жильё
**Эпоха**: палеолит
**Состав**: ветки, листья, кора, шкуры

**Входящие связи**:
- Ветки/листья → [../../02_world/resources/05_wood_timber.md]
- Кора (берёста) → [../../02_world/resources/05_wood_timber.md] (берёза)
- Шкуры животных → [../../02_world/resources/09_hides_leather.md]

**Исходящие связи**:
- Жильё (первое для племени)
- Защита от непогоды

**Альтернативы**:
- Пещера (естественная)
- Юрта (кочевая — войлок + войлочная шерсть)

**Роль**: базовое жильё палеолита

---

### Глинобитный дом (Wattle and daub / Cob house)

**Тип**: постоянное жильё
**Эпоха**: неолит (~9000 до н.э.)
**Состав**: глина + солома + древесина (каркас)

**Входящие связи**:
- Глина → [../../02_world/resources/03_clays_refractories.md]
- Солома (злаки) → [../../02_world/resources/08_food_resources.md]
- Древесина (каркас) → [../../02_world/resources/05_wood_timber.md]
- Процесс: формовка + сушка

**Исходящие связи**:
- Постоянное жильё (оседлость!)
- Ремесленные мастерские

**Альтернативы**:
- Кирпичный дом (если есть обжиг)
- Каменный дом (если есть камень)

**Роль**: переход к оседлости — критично для неолитической революции

---

### Кирпичный дом (сырцовый/обожжённый) (Brick house)

**Тип**: постоянное жильё
**Эпоха**: неолит (адоб), бронзовый век (обожжённый кирпич)
**Состав**: кирпич-сырец или обожжённый кирпич + раствор

**Входящие связи**:
- Кирпич-сырец: глина + солома + сушка
- Обожжённый кирпич: глина + обжиг (нужна печь 800-900°C)
- Раствор: глина ИЛИ известь → [../../02_world/processed_materials/02_chemical_products.md]
- Древесина (перекрытия) → [../../02_world/resources/05_wood_timber.md]

**Исходящие связи**:
- Капитальное жильё (долговечнее глинобитного)
- Городское строительство
- Дворцы, храмы, административные здания

**Альтернативы**:
- Глинобитный (дешевле, но менее прочный)
- Каменный (прочнее, но дороже)

**Роль**: основа месопотамского, египетского строительства

---

### Каменный дом (Stone house)

**Тип**: капитальное жильё
**Эпоха**: бронзовый век/античность
**Состав**: камень (известняк, песчаник, гранит) + раствор

**Входящие связи**:
- Известняк/песчаник/гранит → [../../02_world/resources/02_stone_construction.md]
- Известковый раствор (CaO + песок) → [../../02_world/processed_materials/02_chemical_products.md]
- Железные инструменты (для обработки камня) → [01_weapons.md] + [02_tools.md]

**Исходящие связи**:
- Капитальное жильё (столетиями)
- Дворцы
- Храмы
- Оборонительные стены

**Альтернативы**: кирпичный, бетонный (позднее)

**Роль**: основа монументальной архитектуры античности

---

### Бетонное здание (Concrete building)

**Тип**: капитальное
**Эпоха**: античность (Рим), массово — 19-20 в.
**Состав**: римский бетон (CaO + пуццолан + заполнитель) ИЛИ современный цемент

**Входящие связи**:
- Известь → [../../02_world/processed_materials/02_chemical_products.md]
- Пуццолан (вулканическая зола) → [../../02_world/processed_materials/02_chemical_products.md]
- Заполнитель (песок, щебень)
- Вода
- (Позднее): портландцемент (19 в.) — CaO + SiO₂ + Al₂O₃

**Исходящие связи**:
- Акведуки (критично! — водостойкий бетон)
- Гавани
- Мосты
- Купольные конструкции (Пантеон)
- Небоскрёбы (позднее)

**Альтернативы**: камень, кирпич

**Роль**: КРИТИЧНО — без пуццолана нет римских акведуков/гаваней. Без современного цемента (19 в.) нет индустриальной архитектуры.

## 🏛 Общественные здания

### Храм (Temple)

**Тип**: религиозное
**Эпоха**: неолит (Стоунхендж, Гёбекли-Тепе)
**Состав**: камень (мегалиты) или кирпич + декор

**Входящие связи**:
- Камень/кирпич → [../../02_world/resources/02_stone_construction.md]
- Древесина (перекрытия, двери)
- Металл (декор, утварь)
- Скульптура → [07_cult_ritual.md]

**Исходящие связи**:
- Религиозный центр
- Социальный (община)
- Политический (теократия)

**Альтернативы**:
- Священная роща (природный храм)
- Капище (открытое место)

**Роль**: центр развития религии и социальной организации

---

### Дворец (Palace)

**Тип**: административно-жилое
**Эпоха**: бронзовый век (Кносский дворец, Микены)
**Состав**: кирпич/камень + дерево + декор (золото, бронза)

**Входящие связи**:
- Камень/кирпич
- Древесина (массивная — кедр, дуб)
- Металлы (Au, Ag, бронза — декор)
- Скульптура, фрески

**Исходящие связи**:
- Жильё вождя/царя
- Администрация
- Казна
- Хранилище

---

### Склад / Амбар (Storage / Granary)

**Тип**: складское
**Эпоха**: неолит
**Состав**: дерево, глина, камень

**Входящие связи**:
- Древесина
- Глина/камень (фундамент, стены)
- Солома (крыша)

**Исходящие связи**:
- Хранение зерна (критично! — без склада нет стратегического резерва)
- Хранение товаров

**Альтернативы**: зернохранилище (специальное)

**Роль**: КРИТИЧНО — без склада нет стратегического запаса → нет городов

## 🏭 Производственные здания

### Кузница (Smithy)

**Тип**: производственное
**Эпоха**: бронзовый век
**Состав**: печь (огнеупоры) + наковальня + меха + инструмент

**Входящие связи**:
- Огнеупорная глина/шамот (для печи) → [../../02_world/resources/03_clays_refractories.md]
- Наковальня → [02_tools.md]
- Молот, клещи, напильник
- Меха (кожа) → [../../02_world/resources/09_hides_leather.md]
- Топливо: древесный уголь → [../../02_world/processed_materials/01_fuel_products.md]

**Исходящие связи**:
- Производство металлических орудий и оружия
- Ремонт инструментов
- Декор (ювелирное дело)

**Альтернативы**: открытый костёр (только для меди/бронзы)

**Роль**: КРИТИЧНО — без кузницы нет металлургии

---

### Металлургическая печь (Smelter)

**Тип**: производственное
**Эпоха**: бронзовый век → железный век → домна
**Состав**: огнеупорная футеровка (шамот, магнезит, доломит) + меха + трубки

**Входящие связи**:
- Огнеупоры → [../../02_world/resources/03_clays_refractories.md]
- Меха (кожа)
- Древесный уголь / кокс
- Руда

**Исходящие связи**:
- Плавка меди/бронзы
- Плавка железа
- Плавка стали (домна + кокс)

**Роль**: КРИТИЧНО — без металлургической печи нет металлов массово

---

### Гончарная мастерская / Печь для обжига (Kiln)

**Тип**: производственное
**Эпоха**: неолит
**Состав**: глина/огнеупор + топливо

**Входящие связи**:
- Глина
- Древесина/уголь
- Процесс: обжиг (800-1200°C)

**Исходящие связи**:
- Керамика → [05_household.md]
- Кирпич
- Обжиг гипса/известняка → [../../02_world/processed_materials/02_chemical_products.md]
- Плавка стекла (позднее)

---

### Стекловаренная печь (Glass furnace)

**Тип**: производственное
**Эпоха**: античность
**Состав**: огнеупор (держит 1200°C+) + песок + сода/поташ + CaO

**Входящие связи**:
- Кварцевый песок → [../../02_world/resources/02_stone_construction.md]
- Сода (натрон) ИЛИ поташ → [../../02_world/processed_materials/02_chemical_products.md]
- Известь (CaO) → [../../02_world/processed_materials/02_chemical_products.md]
- Огнеупоры (для печи)
- Топливо (древесный уголь, позднее — каменный уголь)

**Исходящие связи**:
- Стеклянные изделия → [05_household.md]
- Окна (для зданий)
- Зеркала

**Альтернативы**: плавка только с песком (нужна 1700°C — почти невозможно в античности)

**Роль**: критично для стекла массово

## 🌾 Сельскохозяйственные здания

### Загон для скота (Livestock pen)

**Тип**: сельскохозяйственное
**Эпоха**: неолит
**Состав**: дерево/камень/ветки

**Входящие связи**: ветки/камень/жерди
**Исходящие связи**: содержание скота

---

### Конюшня/Коровник (Barn)

**Тип**: сельскохозяйственное
**Эпоха**: неолит
**Состав**: дерево (массивный каркас) + солома/дранка (крыша)

**Входящие связи**:
- Древесина (дуб, граб)
- Солома/дранка (крыша)
- Глина (утепление)

**Исходящие связи**:
- Содержание лошадей/коров/овец
- Защита скота зимой (критично в холодном климате)

---

### Мельница (Mill)

**Тип**: сельскохозяйственное/механическое
**Эпоха**: античность (водяная), 12 в. (ветряная)
**Состав**: жернов + механизм + источник энергии

**Входящие связи**:
- Жернов → [02_tools.md]
- Древесина (механизм)
- Металл (оси)
- Вода (для водяной) ИЛИ ветер (для ветряной)

**Исходящие связи**:
- Помол зерна (×100 vs ручного)
- Лесопилка (позднее)
- Кузнечные меха (позднее)

---

## 🏰 Оборонительные здания

### Оборонительная стена (Defensive wall)

**Тип**: оборонительное
**Эпоха**: неолит (Иерихон ~8000 до н.э.)
**Состав**: камень/кирпич/глинобит

**Входящие связи**:
- Камень/кирпич
- Раствор (глина/известь/цемент)
- Труд (много рабочих)

**Исходящие связи**:
- Защита поселения
- Статус (столица)

---

### Башня (Tower)

**Тип**: оборонительное/наблюдательное
**Эпоха**: неолит
**Состав**: камень/кирпич

**Входящие связи**: камень/кирпич + раствор
**Исходящие связи**: наблюдение + оборона

---

### Замок (Castle)

**Тип**: оборонительно-жилое
**Эпоха**: средневековье (9-15 в.)
**Состав**: камень + дерево + металл + ров + башни

**Входящие связи**:
- Камень (большое количество)
- Древесина (перекрытия, двери)
- Металл (двери, решётки, оси)
- Известь (раствор)

**Исходящие связи**:
- Жильё аристократии
- Оборона региона
- Административный центр

## Принципы для дизайна

### 1. Прогрессия материалов

Шалаш (ветки) → Глинобитный (глина) → Кирпичный (кирпич + раствор) → Каменный → Бетонный → Стальной/стеклянный. Каждый шаг требует новых материалов и технологий.

### 2. «Бутылочные горлышки» зданий

- Глинобитный дом → глина (легко)
- Кирпичный → обжиг (нужна печь 800°C)
- Каменный → железные инструменты (для обработки камня)
- Бетонный → пуццолан (вулканический пепел, географическая монополия)
- Стеклянный → стекло (печь 1200°C + сода/поташ)

### 3. Производственные здания — «фабрики»

Кузница, печь, стекловарня — это не просто здания, а производственные мощности. Каждое требует:
- Огнеупоры (для печи)
- Топливо (уголь/дерево)
- Инструменты
- Знание (какой материал загружать, при какой температуре)

### 4. Здания как предпосылки для технологий

- Без кузницы → нет металла → нет меча/топора/плуга
- Без стекловарни → нет стекла → нет окон/зеркал/линз
- Без амбара → нет стратегического запаса → нет городов
- Без храма → нет религии → нет легитимности вождя
- Без мельницы → нет массового муки → нет массового хлеба

### 5. Двойное назначение

Некоторые здания — и гражданские, и оборонительные:
- Замок — жильё + оборона
- Амбар — хранение + оборона (толстые стены)
- Храм — религия + укрепление (часто массивные стены)
