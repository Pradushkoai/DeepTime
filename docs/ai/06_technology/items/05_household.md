# Бытовые предметы

> Посуда, мебель, одежда, утварь. То, что окружает человека дома.

---

## 🏺 Посуда

### Глиняный горшок (Clay pot)

**Тип**: посуда
**Эпоха**: неолит (~20000 до н.э. — Япония, Дзёмон)
**Состав**: обожжённая глина

**Входящие связи**:
- Глина → [../../02_world/resources/03_clays_refractories.md]
- Процесс: формовка + обжиг (800-900°C) → [../processes.md]
- Топливо: древесина

**Исходящие связи**:
- Хранение продуктов (критично! — без горшка нет хранения жидкостей)
- Приготовление пищи (варка)
- Похоронные урны

**Альтернативы**: плетёная корзина (не для варки), каменная чаша (дороже)

**Роль**: КРИТИЧНО — без керамики нет варки/хранения → нет неолитического питания

---

### Амфора (Amphora)

**Тип**: посуда для жидкостей
**Эпоха**: античность (Греция, Рим)
**Состав**: обожжённая глина + смола/битум (для герметизации)

**Входящие связи**:
- Глина
- Древесный уголь (обжиг)
- Смола ИЛИ битум → [../../02_world/processed_materials/03_petroleum_products.md]

**Исходящие связи**:
- Хранение и транспорт вина/масла
- Торговля (главный торговый контейнер античности)

---

### Керамическая чаша / тарелка (Ceramic bowl/plate)

**Тип**: столовая посуда
**Состав**: глина + обжиг + глазурь (позднее)

**Входящие связи**: глина + обжиг + (позднее: глазурь — свинцовая/оловянная)

**Исходящие связи**: столовая посуда

---

### Стеклянная бутылка/чаша (Glass vessel)

**Тип**: посуда
**Эпоха**: ~1500 до н.э. (Египет)
**Состав**: стекло + декор

**Входящие связи**:
- Стекло → [../../02_world/processed_materials/02_chemical_products.md]
- Стекловаренная печь → [03_buildings.md]
- Песок + сода/поташ + CaO

**Исходящие связи**:
- Элитная посуда (дорого в античности)
- Хранение (если с пробкой)

**Роль**: элитная посуда (позднее — массовая)

---

### Металлическая посуда (Metal vessel)

**Тип**: посуда (бронза/Fe/сталь)
**Эпоха**: бронзовый век
**Состав**: металл (бронза/Fe/сталь)

**Входящие связи**:
- Металл → [../../02_world/processed_materials/04_metallurgical_products.md]
- Процесс: литьё/ковка

**Исходящие связи**: элитная посуда (для знати), котлы (для варки)

---

### Деревянная посуда (Wooden bowl)

**Тип**: посуда
**Эпоха**: неолит
**Состав**: дерево (выдолбленное)

**Входящие связи**: древесина + инструменты (долото, нож) → [02_tools.md]
**Исходящие связи**: дешёвая посуда для бедных

## 🪑 Мебель

### Стул / Скамья (Stool / Chair)

**Тип**: мебель
**Эпоха**: неолит
**Состав**: дерево (дуб, бук) + шпон/гвозди (позднее)

**Входящие связи**:
- Древесина
- Инструменты: пила, рубанок, долото → [02_tools.md]
- Клей (казеиновый) → [../../02_world/processed_materials/08_hygiene_textile_products.md]

**Исходящие связи**: меблировка жилища

---

### Стол (Table)

**Тип**: мебель
**Эпоха**: неолит
**Состав**: дерево

**Входящие связи**: древесина + инструменты + клей
**Исходящие связи**: меблировка + рабочее место

---

### Кровать (Bed)

**Тип**: мебель
**Эпоха**: неолит (каменная) → античность (деревянная)
**Состав**: дерево + матрас (солома, шерсть) + ткани (постельное)

**Входящие связи**:
- Древесина
- Солома (матрас)
- Шерсть (одеяло) → [../../02_world/resources/06_fibers_textiles.md]
- Льняное полотно (постельное)

## 👕 Одежда

### Туника (Tunic)

**Тип**: одежда
**Эпоха**: античность
**Состав**: лён/шерсть (ткань)

**Входящие связи**:
- Лён ИЛИ шерсть → [../../02_world/resources/06_fibers_textiles.md]
- Ткацкий станок → [02_tools.md] (станок — это инструмент/механизм)
- Нитки (пряжа)
- Игла (кость/медь/Fe — для шитья)

**Исходящие связи**:
- Одежда (базовая)

**Альтернативы**: меха (зимой), хлопок (тропики)

---

### Плащ (Cloak)

**Тип**: верхняя одежда
**Эпоха**: палеолит (шкуры) → античность (ткани)
**Состав**: шкуры животных ИЛИ ткань (шерсть)

---

### Сапоги / Сандалии (Footwear)

**Тип**: обувь
**Эпоха**: палеолит
**Состав**: кожа (сапоги) ИЛИ кожа + дерево (сандалии)

**Входящие связи**:
- Кожа → [../../02_world/processed_materials/09_hides_leather.md] (кожа — из resources/09_hides_leather.md)
- Нитки (сухожилия)
- Дерево (подошва, для сандалий)

**Исходящие связи**: защита ног

---

### Шапка (Hat)

**Тип**: головной убор
**Состав**: шерсть (войлок) ИЛИ меха

**Входящие связи**: шерсть + валяние → [../../02_world/resources/06_fibers_textiles.md]
**Исходящие связи**: защита от холода/солнца

## 🕯 Освещение

### Масляная лампа (Oil lamp)

**Тип**: освещение
**Эпоха**: палеолит
**Состав**: глина/камень/металл + фитиль + масло

**Входящие связи**:
- Глина/металл (корпус)
- Масло: оливковое (юг), животный жир (север), нефть (позднее)
- Фитиль: лён/конопля

**Исходящие связи**: освещение дома

**Альтернативы**: свеча (воск/стеарин/парафин), факел

---

### Свеча (Candle)

**Тип**: освещение
**Эпоха**: античность (воск), 19 в. (стеарин, парафин)
**Состав**: воск/стеарин/парафин + фитиль

**Входящие связи**: 
- Воск (пчела) ИЛИ стеарин (животный жир) ИЛИ парафин (нефть)
- → [../../02_world/processed_materials/08_hygiene_textile_products.md]

**Исходящие связи**: освещение (дорогое — элита; позднее — массовое)

## Принципы для дизайна

### 1. Посуда — прогрессия материалов

Глина → Бронза → Стекло → Фарфор → Пластик. Каждый шаг требует новых материалов и процессов.

### 2. Одежда — климатическая адаптация

В тропиках — хлопок/лён. На севере — шерсть/меха. В засушливых регионах — лён (холодный).

### 3. Освещение — «демократизация»

Факел → Масляная лампа → Восковая свеча (элита) → Стеариновая свеча (массово) → Парафиновая (ещё дешевле) → Электричество (позднее).

### 4. Мебель — прогрессия технологий

Без пилы — нет досок → нет стульев/столов. Без токарного станка — нет круглых ножек. Без гвоздей — нет сборной мебели (только цельная).

**Процесс**: формовка + обжиг (T-014 керамика)
**Назначение**: хранение праха после кремации (ритуал погребения)

**Входящие связи**:
- сырьё: глина → [02_world/resources/03_clays_refractories.md]
- процесс: обжиг → [06_technology/processes.md]
- технология: T-014 (керамика) → [06_technology/tech_tree.md]

**Исходящие связи**:
- ритуал погребения → [06_technology/items/07_cult_ritual.md]

**Роль**: ритуальное изделие анта/античности, индикатор уровня культуры
