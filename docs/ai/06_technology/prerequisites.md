# Prerequisites — Предпосылки технологий

## Принцип

Любое нововведение в игре (технология, общественный строй, экономическая форма) требует **комбинации предпосылок**. Если хотя бы одна категория не выполнена, нововведение не происходит, сколько бы лет ни прошло.

## Базовые четыре категории предпосылок

### 1. Знания (когнитивные)

Предшествующие технологии, накопленный опыт, передача через торговлю/захват.

**Пример**: для плавки меди нужно знание контроля огня + многократное наблюдение плавки в костре.

[См. → knowledge_types.md]

### 2. Ресурсы (материальные)

Доступ к конкретному ресурсу в регионе, достаточное количество для специализации, транспортная доступность.

**Пример**: для бронзы нужен одновременно источник меди И источник олова. Если в регионе нет олова — будет только медь, без бронзы.

### 3. Социальная сложность

Размер населения, плотность поселений, наличие городов, избыток еды (чтобы кормить спецов), специализация труда.

**Пример**: для «раннего государства» нужно 5000+ в одном городе. Если население не доросло, государство не возникает, даже если есть все остальные предпосылки.

### 4. Культурные ценности

Готовность общества принять новшество, приоритеты вождя, религиозные убеждения, этнические традиции.

**Пример**: при сильной «традиции» и слабом «знании» технологии открываются в 2-3 раза медленнее. Жречество может блокировать реформы, угрожающие его власти.

## ⚠️ Принцип: кросс-технологические зависимости ⭐ КЛЮЧЕВОЙ МЕХАНИЗМ

> **Главный принцип**: каждая технология может зависеть от **других технологий**, и эта зависимость — основа всего дерева развития. Это не «одна отдельная категория предпосылок», а **сквозной принцип**, пронизывающий все технологии.

### Что это значит

Когда мы рассматриваем любую технологию, нужно спрашивать: **«от развития каких других технологий зависит её открытие?»**. Это могут быть:

- **Материаловедческие зависимости** (нужен материал с определёнными свойствами)
- **Инструментальные зависимости** (нужен инструмент, который сам является продуктом другой технологии)
- **Инфраструктурные зависимости** (нужна дорога/склад/печь определённого типа)
- **Знаниевые зависимости** (нужно знание из другой области — например, геометрия для архитектуры)
- **Социально-институциональные зависимости** (нужен институт — например, письменность для банков)

### Примеры (концептуальные, не исчерпывающие)

**Пример 1: Плавка металлов** (физико-химические пороги как ЧАСТНЫЙ СЛУЧАЙ)

| Технология | Зависит от | Почему |
|---|---|---|
| Плавка меди (~700°C) | Кирпич из обычной глины (800-900°C) | Нужен материал для печи, держащий температуру |
| Плавка бронзы (~950°C) | Огнеупорная глина / обожжённый кирпич | Обычный кирпич не держит |
| Плавка железа (~1500°C) | Шамотный кирпич + меха для нагнетания воздуха | Нужен продвинутый материал + подача O₂ |
| Производство стекла (~1200°C) | Огнеупорная глина + кварцевый песок | Материал печи + сырьё |
| Обжиг извести (~900°C) | Обычный кирпич достаточен | Порог ниже, чем у кирпича |

> ⚠️ **ВАЖНО**: Это лишь ОДИН ПРИМЕР того, как работает принцип кросс-технологических зависимостей. Пользователь дал этот пример (медь/железо/печи) как концептуальную иллюстрацию, и я должен воспринимать его как модель того, как **все технологии** должны зависеть от других.

**Пример 2: Письменность**

| Технология | Зависит от | Почему |
|---|---|---|
| Пиктограммы | Краски/уголь, поверхность (камень/глина) | Носитель и средство |
| Клинопись | Глиняные таблички + стилос | Система записи требует инструмента |
| Алфавит | Знание «слоговость» речи + торговая необходимость | Культурная предпосылка |
| Папирус/пергамент | Технология обработки растения/кожи | Нужен носитель для массовой записи |
| Чернила | Сажа + клей + растворитель | Химическая рецептура |

**Пример 3: Земледелие**

| Технология | Зависит от | Почему |
|---|---|---|
| Сбор диких злаков | Знание сезонности + корзины | Необходимо собирать и хранить |
| Примитивное земледелие | Палка-копалка + знание о посеве | Инструмент + знание |
| Ирригация | Лопата + канал + социальная организация | Техника + коллектив |
| Плуг | Дерево/железо + тягловое животное (одомашненное) | Много зависимостей |
| Севооборот | Накопленные наблюдения + письменность (для учёта) | Знание + институт |

**Пример 4: Колесо и транспорт**

| Технология | Зависит от | Почему |
|---|---|---|
| Колесо | Токарный станок / резец + древесина | Инструмент + материал |
| Телега | Колесо + ось + упряжь | Сборка из частей |
| Колесница | Колесо со спицами + лошадь (одомашн.) + вооружение | Много зависимостей |
| Корабль с парусом | Парусина (ткань) + мачта + канаты + мореплавание | Несколько цепочек |

**Пример 5: Архитектура**

| Технология | Зависит от | Почему |
|---|---|---|
| Хижина | Стойки + крыша из листьев/коры | Базовые материалы |
| Глинобитный дом | Глина + форма + сушильная площадка | Технология обработки глины |
| Кирпичный дом | Обожжённый кирпич + раствор (известь/цемент) | Цепочка производства |
| Каменная кладка | Каменотёсные инструменты + подъёмный механизм | Инструменты + инженерия |
| Арка/свод | Геометрические знания + центрирование (временная конструкция) | Знание + техника |

### Как это работает в игре

Каждая технология в дереве имеет:
1. Базовые предпосылки (4 категории выше)
2. **Список технологий-зависимостей** — другие технологии, которые должны быть открыты раньше

Пример структуры технологии:
```
Технология: "Плавка железа"
- Базовые предпосылки:
  - Знания: знание металлов вообще, плавки меди/бронзы
  - Ресурсы: железная руда, огнеупорная глина, древесный уголь
  - Соц. сложность: 500+ населения, специализация горняков/металлургов
  - Культурные ценности: ценность «прогресс» > «традиция»
- Технологии-зависимости (кросс-тех):
  - "Плавка бронзы" (опыт металлургии)
  - "Огнеупорный кирпич" (материал для печи)
  - "Меха для нагнетания воздуха" (достичь 1500°C)
  - "Древесный уголь" (топливо с высокой температурой)
```

### Принцип для дизайна

При проектировании дерева технологий:
1. Каждая технология должна иметь **минимум 1-2 технологии-зависимости** (иначе она «висит»)
2. Сложные технологии (железо, письменность, плуг) — 3-5 зависимостей
3. Зависимости могут быть **из разных областей** (металлургия + материаловедение + инструмент)
4. Это создаёт **«бутылочные горлышки»** — технологии, без которых нельзя продвинуться
5. Игрок может преодолеть «бутылочное горлышко» через:
   - Целенаправленное исследование (приоритет, финансирование)
   - Торговую диффузию (купить/привезти)
   - Захват мастеров (завоевать город со спецами)
   - Случайное озарение

## Альтернативные пути

Для каждой ключевой технологии есть 2-3 альтернативных пути. Например, к деньгам можно прийти через зерно, через ракушки или через металл. Это зависит от архетипа и региона. [См. → alternative_paths.md] (TBD)

## Пример: цепочка открытия железа (концептуальный)

Игрок видит в своём гексе выходы железной руды с первого дня. Однако иконка затемнена — граждане не знают, что с ней делать.

```
1. Развитие металлургии меди (нужна печь 700°C → обычный кирпич)
        ↓
2. Открытие плавки меди → медные орудия
        ↓
3. Контакт с оловом (торговля/сосед) → плавка бронзы (нужна печь 950°C → огнеупорная глина)
        ↓
4. Через торговлю или контакт с соседями — культурный шок: видят железные изделия
        ↓
5. Развитие огнеупорных материалов (шамотный кирпич) + нагнетание воздуха (меха) + древесный уголь
   ↓ (это и есть «кросс-технологические зависимости» — нужно сначала открыть эти технологии)
        ↓
6. Открытие технологии плавки железа (нужна печь 1500°C)
        ↓
7. Граждане распознают железную руду как ресурс → организуют лагерь добычи
        ↓
8. Железные орудия
```

Весь процесс может занять 500-1000 лет игрового времени. Если игрок не создаст условия (контакт с металлом, приоритет исследований, финансирование, огнеупорная глина в радиусе), железо останется «красивым камнем» навсегда.
