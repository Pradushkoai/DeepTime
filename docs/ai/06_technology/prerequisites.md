# Prerequisites — Предпосылки технологий

## Принцип

Любое нововведение в игре (технология, общественный строй, экономическая форма) требует **комбинации предпосылок**. Если хотя бы одна категория не выполнена, нововведение не происходит, сколько бы лет ни прошло.

## Пять категорий предпосылок

### 1. Знания (когнитивные)

Предшествующие технологии, накопленный опыт, передача через торговлю/захват.

**Пример**: для плавки меди нужно знание контроля огня + многократное наблюдение плавки в костре.

[См. → knowledge_types.md]

### 2. Ресурсы (материальные)

Доступ к конкретному ресурсу в регионе, достаточное количество для специализации, транспортная доступность.

**Пример**: для бронзы нужен одновременно источник меди И источник олова. Если в регионе нет олова — будет только медь, без бронзы.

### 3. Социальная сложность

Размер населения, плотность поселений, наличие городов, избыток еды (чтобы кормить спецов), специализация труда.

**Пример**: для «раннего государства» нужно 5000+ в одном городе. Если население не доросло, государство не возникает, даже если есть все остальные предпосылки.

### 4. Культурные ценности

Готовность общества принять новшество, приоритеты вождя, религиозные убеждения, этнические традиции.

**Пример**: при сильной «традиции» и слабом «знании» технологии открываются в 2-3 раза медленнее. Жречество может блокировать реформы, угрожающие его власти.

### 5. Физико-химические пороги ⚡ NEW в v0.2

**Принцип**: Технологии, связанные с плавкой, обжигом, химической обработкой, имеют физико-химические пороги. Нельзя «открыть» технологию без материала, способного выдержать требуемые условия.

**Примеры**:

| Технология | Требует | Порог | Что нужно сначала |
|---|---|---|---|
| Плавка меди | Печь, держащую ≥700°C | 700°C | Кирпич из обычной глины (держит 800-900°C) → достаточно |
| Плавка бронзы | Печь, держащую ≥950°C | 950°C | Кирпич из огнеупорной глины |
| Плавка железа | Печь, держащую ≥1500°C | 1500°C | Шамотный кирпич / огнеупорная глина + меха для нагнетания воздуха |
| Обжиг керамики | Печь, держащую 800-1200°C | варьируется | Глиняная печь достаточна |
| Производство стекла | Печь, держащую ≥1200°C | 1200°C | Огнеупорная глина + кварцевый песок |
| Производство цемента/извести | Печь, держащую ≥900°C | 900°C | Обычный кирпич достаточен |

**Игровая механика**:
1. Игрок не может «исследовать плавку железа» без разработки огнеупорного материала и печи.
2. Чтобы разработать огнеупорный материал, нужен доступ к огнеупорной глине (источник + геология).
3. Это создаёт «бутылочное горлышко»: без нужного материала — нет технологии.
4. Исторически достоверно: древние цивилизации упирались именно в материалы печей.

**Дополнительные физико-химические параметры** (TBD — детальная проработка):
- Твёрдость материала (для орудий): кремень твёрже меди, медь твёрже золота, бронза твёрже меди, железо твёрже бронзы.
- Удельный вес (для металлов): влияет на вес оружия/орудий.
- Коррозионная стойкость: железо ржавеет, бронза — нет.
- Теплопроводность: для посуды, отопления.
- Прочность на разрыв: для волокон (лён vs шерсть vs шёлк).

## Альтернативные пути

Для каждой ключевой технологии есть 2-3 альтернативных пути. Например, к деньгам можно прийти через зерно, через ракушки или через металл. Это зависит от архетипа и региона. [См. → alternative_paths.md] (TBD)

## Пример: цепочка открытия железа

Игрок видит в своём гексе выходы железной руды с первого дня. Однако иконка затемнена — граждане не знают, что с ней делать.

```
1. Развитие металлургии меди (нужна печь 700°C → обычный кирпич)
        ↓
2. Открытие плавки меди → медные орудия
        ↓
3. Контакт с оловом (торговля/сосед) → плавка бронзы (нужна печь 950°C → огнеупорная глина)
        ↓
4. Через торговлю или контакт с соседями — культурный шок: видят железные изделия
        ↓
5. Развитие огнеупорных материалов (шамотный кирпич) + нагнетание воздуха (меха)
        ↓
6. Открытие технологии плавки железа (нужна печь 1500°C)
        ↓
7. Граждане распознают железную руду как ресурс → организуют лагерь добычи
        ↓
8. Железные орудия
```

Весь процесс может занять 500-1000 лет игрового времени. Если игрок не создаст условия (контакт с металлом, приоритет исследований, финансирование, огнеупорная глина в радиусе), железо останется «красивым камнем» навсегда.
