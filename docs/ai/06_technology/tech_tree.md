# Дерево технологий — Tech Tree

> Полное дерево технологий игры «Цивилизация Прадушко». Каждая технология имеет предпосылки (знания, ресурсы, материалы, процессы) и результаты (новые материалы, изделия, возможности).

---

## 🌳 Концепция дерева

### Принципы (см. [prerequisites.md](prerequisites.md) и [_meta/ai_working_principles.md → Принцип 9](../_meta/ai_working_principles.md))

1. **5 категорий предпосылок**: знания, ресурсы, социальная сложность, культурные ценности, физ-хим пороги (как пример кросс-тех зависимостей)
2. **Бесконечное развитие** (Принцип 9): нет верхней границы по эпохам
3. **Обязательная связность** (Принцип 10): каждая технология связана с другими
4. **Кросс-тех зависимости** (Принцип в prerequisites.md): технология A зависит от технологии B

### Структура технологии в дереве

```
ТЕХНОЛОГИЯ: Название
- Предпосылки:
  - Знания: (предыдущие технологии + опыт)
  - Ресурсы: (что должно быть в регионе/доступно)
  - Материалы: (что должно быть произведено)
  - Соц. сложность: (население, города, специализация)
  - Культура: (ползунки ценностей)
  - Физ-хим пороги: (температуры, давление — пример)
- Результаты:
  - Открывает материалы: (ссылки на processed_materials/)
  - Открывает изделия: (ссылки на items/)
  - Открывает процессы: (ссылки на processes.md)
  - Открывает следующие технологии: (ссылки на tech_tree.md)
```

### T-001: Контроль огня

**Эпоха**: Палеолит (~1 млн лет назад — Homo erectus)
**Стартовая**: да (известна с начала)

**Предпосылки**:
- Знания: наблюдение за природным огнем (молнии, вулканы)
- Ресурсы: древесина (топливо), кремень (огниво)
- Соц. сложность: минимальная (10-30 человек)
- Культура: нет требований

**Результаты**:
- Открывает процессы: [обжиг](processes.md), [сухая перегонка](processes.md) (пиролиз)
- Открывает изделия: [костёр](items/03_buildings.md) (как «здание»)
- Открывает технологии: T-002 (приготовление пищи), T-003 (обогрев жилища), T-005 (оббивка с обжигом)
- Открывает материалы: [древесный уголь](../02_world/processed_materials/01_fuel_products.md) (через пиролиз — позже)

**Бутылочное горлышко?**: нет — базовая технология
**Связи**: → T-002, T-003, T-005, T-010 (керамика), T-015 (плавка меди)

### T-005: Изготовление лука

**Эпоха**: Палеолит (~35000 до н.э.)
**Стартовая**: да

**Предпосылки**:
- Знания: T-004 (оббивка), упругость древесины
- Ресурсы: любое упругое дерево — [тис](../02_world/resources/05_wood_timber.md) (лучший!), [ясень](../02_world/resources/05_wood_timber.md), [граб](../02_world/resources/05_wood_timber.md), [берёза](../02_world/resources/05_wood_timber.md), [бамбук](../02_world/resources/05_wood_timber.md) (тропики)
- Материалы: [сухожилия](../02_world/resources/09_hides_leather.md) или [лён](../02_world/resources/06_fibers_textiles.md) (тетива)
- Соц. сложность: 10-30 человек
- Культура: воинственность > 0 (для охотничьего применения)

**Результаты**:
- Открывает изделия: [лук](items/01_weapons.md), [стрелы](items/01_weapons.md)
- Открывает технологии: T-006 (составные орудия → композитный лук из рога+сухожилий+дерева — мощнее!)

**Бутылочное горлышко?**: НЕТ — лук можно сделать из любого упругого дерева. Тис даёт лучший длинный лук, но ясень/граб/берёза/бамбук — тоже работают. Композитный лук (рог+сухожилия) — мощнее тисового, но сложнее.
**Связи**: → T-006; требует: любое упругое дерево + тетива (сухожилия/лён)

### T-010: Керамика (гончарное дело)

**Эпоха**: Неолит (~20000 до н.э. — Япония Дзёмон, массово ~10000 до н.э.)

**Предпосылки**:
- Знания: T-001 (контроль огня), наблюдение — глина твердеет при обжиге
- Ресурсы: [обычная глина](../02_world/resources/03_clays_refractories.md) (повсеместно)
- Соц. сложность: 30-100 человек (специализация гончара)
- Физ-хим: **800-900°C** (обычная глина держит — критично!)

**Результаты**:
- Открывает материалы: [керамика](../02_world/processed_materials/07_food_products.md) (как материал для посуды)
- Открывает изделия: [глиняный горшок](items/05_household.md), [амфора](items/05_household.md), [урна](items/07_cult_ritual.md)
- Открывает процессы: [обжиг](processes.md) (керамики)
- Открывает технологии: T-011 (варка пищи в горшке), T-012 (кирпич-сырец), T-013 (гончарный круг — позднее), T-014 (обожжённый кирпич — позднее)

**Бутылочное горлышко?**: **ДА** — без обжига 800°C нет керамики → нет хранения жидкостей → нет варки → нет стратегического запаса пищи
**Связи**: → T-011, T-012, T-013, T-014; требует: T-001, глина

### T-015: Земледелие (одомашнивание злаков)

**Эпоха**: Неолит (~10000 до н.э. — Плодородный полумесяц)

**Предпосылки**:
- Знания: T-002 (приготовление пищи), наблюдение сезонности растений, знание о посеве
- Ресурсы: **дикие злаки в регионе** (эммер, ячмень — [Vavilov Center 3](../02_world/flora/README.md)), [палка-копалка](items/02_tools.md)
- Соц. сложность: 30-100 человек
- Культура: ценность «прогресс» > 0 ИЛИ кризис (голод → необходимость)

**Результаты**:
- Открывает материалы: [мука](../02_world/processed_materials/07_food_products.md) (через помол)
- Открывает изделия: [серп](items/02_tools.md) (для жатвы), [жернов](items/02_tools.md) (для помола)
- Открывает технологии: T-016 (ирригация), T-017 (плуг — позднее), T-025 (хлеб), T-026 (пиво)

**Бутылочное горлышко?**: **КРИТИЧНО** — без земледелия нет избытка пищи → нет городов → нет цивилизации. Требует диких злаков в регионе (география = судьба).
**Связи**: → T-016, T-017, T-025, T-026; требует: дикие злаки (география)

### T-030: Скотоводство (одомашнивание животных)

**Эпоха**: Неолит (~10000 до н.э. — овца/коза, ~8500 — корова/свинья)

**Предпосылки**:
- Знания: T-007 (приручение собаки), наблюдение за поведением стадных животных
- Ресурсы: **дикие предки дом. животных в регионе** ([муфлон→овца, безоаровый козёл→коза, тур→корова, кабан→свинья](../02_world/fauna/README.md))
- Соц. сложность: 50-200 человек (пастухи)
- Культура: ценность «коллектив» > 0 (пастбища — общинные)

**Результаты**:
- Открывает материалы: [молоко](../02_world/resources/08_food_resources.md), [шерсть](../02_world/resources/06_fibers_textiles.md), [кожи](../02_world/resources/09_hides_leather.md), [мясо дом. животных](../02_world/resources/08_food_resources.md)
- Открывает изделия: [сыр](../02_world/processed_materials/07_food_products.md) (консервация молока!), [войлок](../02_world/processed_materials/08_hygiene_textile_products.md) (валяние шерсти)
- Открывает технологии: T-031 (ткачество — из шерсти), T-032 (кочевое скотоводство), T-033 (пахота на коровах)

**Бутылочное горлышко?**: **ДА** — без дом. животных нет молока, шерсти, тягловой силы. Требует диких предков в регионе (география).
**Связи**: → T-031, T-032, T-033; требует: дикие предки (география)

## 🎯 Ключевые «бутылочные горлышки» в дереве

| Переход | Нужно (критичные элементы) |
|---|---|
| Палеолит → Неолит | Земледелие + скотоводство + керамика |
| Неолит → Халколит | Плавка меди (нужен древесный уголь + глина) |

| Железо → Античность | Пуццолан + известь (римский бетон) |
| Античность → Средние века | Порох + книгопечатание |

| Ренессанс → Индустриальная | Кокс + сталь + паровая машина |
| Индустриальная → Современная | Электричество + ДВС + Габер-Бош |
| Современная → Электронная | Полупроводники + ИИ |

## 🔄 Альтернативные пути (Принцип 9 — бесконечное развитие)

Игрок может выбирать разные пути:

### Пример: путь к стеклу
- **Европа (без натрона)**: песок + **поташ** (←зола←дерево) + CaO → стекло 1200°C
- **Египет**: песок + **сода (натрон)** (←натронные озёра) + CaO → стекло 1200°C
- **Без огнеупоров**: песок без щёлочи → плавка 1700°C → почти невозможно (только элитное стекло)

### Пример: путь к стали
- **Дамасск (Древняя Индия)**: тигельная плавка → вуц (сталь) — медленно, дорого
- **Европа 19 в.**: домна + кокс + Бессемер → сталь массово
- **Без кокса**: древесный уголь + сыродутный процесс → только железо (не сталь)

### Пример: путь к освещению
- **Воск** (←пчёлы) — элита
- **Сало** (←животный жир) — бедные, дымно
- **Стеарин** (←животный жир, обработанный) — массово (19 в.)
- **Парафин** (←нефть) — ещё дешевле (19 в.)
- **Электричество** (←генератор) — массово (20 в.)
