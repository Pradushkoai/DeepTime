# Дерево технологий — Tech Tree

> Полное дерево технологий игры «Цивилизация Прадушко». Каждая технология имеет предпосылки (знания, ресурсы, материалы, процессы) и результаты (новые материалы, изделия, возможности).

---

## 🌳 Концепция дерева

#### Принципы (см. [prerequisites.md](prerequisites.md) и [_meta/ai_working_principles.md → Принцип 9](../_meta/ai_working_principles.md))

1. **5 категорий предпосылок**: знания, ресурсы, социальная сложность, культурные ценности, физ-хим пороги (как пример кросс-тех зависимостей)
2. **Бесконечное развитие** (Принцип 9): нет верхней границы по эпохам
3. **Обязательная связность** (Принцип 10): каждая технология связана с другими
4. **Кросс-тех зависимости** (Принцип в prerequisites.md): технология A зависит от технологии B

### Структура технологии в дереве

```
ТЕХНОЛОГИЯ: Название
- Предпосылки:
  - Знания: (предыдущие технологии + опыт)
  - Ресурсы: (что должно быть в регионе/доступно)
  - Материалы: (что должно быть произведено)
  - Соц. сложность: (население, города, специализация)
  - Культура: (ползунки ценностей)
  - Физ-хим пороги: (температуры, давление — пример)
- Результаты:
  - Открывает материалы: (ссылки на processed_materials/)
  - Открывает изделия: (ссылки на items/)
  - Открывает процессы: (ссылки на processes.md)
  - Открывает следующие технологии: (ссылки на tech_tree.md)
```

### T-032: Кочевое скотоводство (альтернативный путь к цивилизации)

**Эпоха**: Неолит (~4000 до н.э. — степи Евразии)

**Предпосылки**:
- Знания: T-030 (скотоводство — одомашненные животные), T-007 (собака — охрана стад), знание сезонных миграций
- Ресурсы: [степь/пастбища](../02_world/soils/README.md) (корм для животных), [дом. животные](../02_world/fauna/README.md) (лошадь, овца, коза, верблюд — одомашнены)
- Материалы: [войлок](../02_world/processed_materials/08_hygiene_textile_products.md) (←шерсть → валяние → юрта), [кожи](../02_world/resources/09_hides_leather.md), [конопля/лён](../02_world/resources/06_fibers_textiles.md) (канаты)
- Соц. сложность: 100-500 (роды/племена — кочевая организация)
- Культура: ценность «традиция» > 0, «коллектив» > 0 (общинное управление стадами)

**Результаты**:
- Открывает изделия: [юрта](items/03_buildings.md) (мобильное жильё — войлок + каркас), [кочевая упряжь](items/04_transport.md), [кумыc](../02_world/processed_materials/07_food_products.md) (ферментированное кобылье молоко)
- Открывает технологии: T-032a (кочевая конфедерация/империя — государство без городов), T-060a (вёсельное мореплавание — нет, это не связано)
- Эффект: **альтернативный путь к цивилизации** — без земледелия, без городов, но с государством (скифы, гунны, монголы)

**Бутылочное горлышко?**: НЕТ — но требует степь/пастбища (география — не везде есть). Альтернатива оседлому земледелию (T-015).
**Связи**: → T-032a; ← T-030; требует: степь + дом. животные (лошадь/овца/верблюд). **Параллелен T-015 (земледелие) — не требует оседлости!**

- Открывает технологии: T-060b (парусное мореплавание — нет, кочевники не плавают, но могут торговать через караваны)

**Бутылочное горлышко?**: НЕТ — но требует степь + лошадь. Без степи → нет кочевья.
**Связи**: ← T-032, T-058, T-022; требует: лошадь + степь + железо (оружие). **Альтернатива T-043/городам — кочевая империя без городов!**

### T-052: Плавка бронзы (Cu + Sn)

### T-052a: Мышьяковая бронза (альтернатива без олова)

**Эпоха**: Бронзовый век (~4000 до н.э. — раньше оловянной бронзы!)

## ⚔ Эпоха 5: Железный век (~1200 до н.э.)

> ⚠️ Важно: сыродутный процесс (T-057), домна (T-055a) и тигельная сталь (T-055b) — РАЗНЫЕ технологии. Сыродутный — восстановление при 1200-1300°C → губка → ковать. Домна — 1500°C → чугун → литьё (нужен шамот). Тигельная сталь — 1300-1500°C в графитовом тигле → сталь напрямую (без кокса/шамота, но медленнее).

### T-057: Сыродутный процесс (железная губка)

**Эпоха**: Железный век (~1200 до н.э. — Бронзовый коллапс; Африка — ~1500 до н.э. без предшествующей бронзы!)

**Предпосылки**:
- Знания: T-001 (контроль огня), T-040 (древесный уголь — высокая температура), наблюдение — Fe-руда восстанавливается углём при нагреве. **НЕ требует знания меди или бронзы!** (Африка перепрыгнула бронзовый век)
- Ресурсы: [Fe-руда](../02_world/resources/01_minerals_ores.md) (гематит/лимонит/магнетит — повсеместно!), [древесный уголь](../02_world/processed_materials/01_fuel_products.md)
- Материалы: [огнеупорная глина](../02_world/resources/03_clays_refractories.md) (держит 1300-1500°C — для стенок печи)
- Инструменты: меха (кожа) — для дутья воздуха (повысить температуру)
- Соц. сложность: 100+ (кузнецы — специализация)
- Физ-хим: **1200-1300°C** (нужна огнеупорная глина + дутьё воздуха)
- Культура: ценность «прогресс» > «традиция»

**Результаты**:
- Открывает материалы: [железная губка](../02_world/processed_materials/04_metallurgical_products.md) (губчатое Fe — не жидкое, а тестообразное)
- Открывает изделия: [железные орудия](items/02_tools.md), [железное оружие](items/01_weapons.md) (кованые, не литые)
- Открывает технологии: T-058 (ковка железа → инструменты/оружие), T-055a (домна → чугун → сталь массово), T-055b (тигельная сталь → элитное оружие)

**Бутылочное горлышко?**: НЕТ — Fe-руда повсеместна (в отличие от олова!). Нужна только огнеупорная глина + древесный уголь + меха. **Параллельна меди/бронзе — не требует их знания!**
**Связи**: → T-058, T-055a, T-055b; ← T-001, T-040; требует: Fe-руда (повсеместно) + огнеупорная глина + древесный уголь + меха. **НЕ требует: T-050 (медь), T-052 (бронза)!**

### T-058: Ковка железа (орудия и оружие)

**Эпоха**: Железный век (~1200 до н.э.)

**Предпосылки**:
- Знания: T-057 (сыродутный процесс → губка), знание ковки (молот + наковальня + нагрев — универсальный механический процесс, не зависит от материала)
- Материалы: [железная губка](../02_world/processed_materials/04_metallurgical_products.md) (←T-057)
- Инструменты: [молот](items/02_tools.md), [наковальня](items/02_tools.md), [клещи](items/02_tools.md), [точильный камень](items/02_tools.md)
- Соц. сложность: 500+ (кузнецы)

**Результаты**:
- Открывает изделия: [железный меч](items/01_weapons.md), [железный топор](items/02_tools.md), [железный серп](items/02_tools.md), [железный плуг](items/02_tools.md) (критично для земледелия!)
- Открывает технологии: T-055a (домна — нужно больше температуры + шамот), T-055b (тигельная сталь — параллельный путь, без кокса)

**Бутылочное горлышко?**: НЕТ — но железо мягче бронзы (если не сталь). Преимущество: Fe-руда повсеместна, не нужна торговля оловом.
**Связи**: → T-055a (домна), T-055b (тигельная сталь); ← T-057; требует: T-057 + кузнечные инструменты (молот, наковальня, клещи, точильный камень). **Не требует T-050 (ковка меди) — ковка универсальный механический навык**

### T-055a: Домна (чугун) — основной путь к массовой стали

**Эпоха**: Железный век → Античность (~500 до н.э. — Китай, Европа — 14 в. н.э.)

**Предпосылки**:
- Знания: T-057 (сыродутный процесс — знание Fe), знание дутья воздуха (меха — повышение температуры), знание высоких температур (от керамики T-010 ИЛИ металлургии — НЕ обязательно бронза!)
- Ресурсы: [Fe-руда](../02_world/resources/01_minerals_ores.md), [древесный уголь](../02_world/processed_materials/01_fuel_products.md) ИЛИ [кокс](../02_world/processed_materials/01_fuel_products.md) (позднее)
- Материалы: [шамот](../02_world/resources/03_clays_refractories.md) (огнеупор 1500-1700°C — критично!), [графит](../02_world/resources/01_minerals_ores.md) (тигель), [известняк](../02_world/resources/02_stone_construction.md) (флюс — CaO)
- Соц. сложность: 1000+ (домна — большое сооружение)
- Физ-хим: **1500°C** (нужен шамот!)
- Культура: ценность «прогресс» > «традиция»

**Цепочка огнеупоров** (проверка!):
```
Природная огнеупорная глина (держит 1300-1400°C — для сыродутного T-057)
  → печь 1400°C (на грани природной глины)
  → обжиг каолина
  → шамот (держит 1500-1700°C)
  → домна 1500°C
  → чугун
```
Без природной огнеупорной глины → нет печи 1400°C → нет шамота → нет домны → нет чугуна.

**Результаты**:
- Открывает материалы: [чугун](../02_world/processed_materials/04_metallurgical_products.md) (Fe + 2-4% C — литейный)
- Открывает изделия: [чугунные котлы](items/05_household.md), [чугунные пушки](items/06_military.md) (позднее)
- Открывает технологии: T-102 (сталь массово — Бессемер, нужны кокс + воздух), T-130 (паровая машина — нужны стальные котлы)

**Бутылочное горлышко?**: **КРИТИЧНО** — без шамота нет домны → нет чугуна → нет стали → нет индустриализации. Требует: природная огнеупорная глина → шамот + графит + 1500°C.
**Связи**: → T-102, T-130; ← T-057, T-010; требует: шамот (←природная огнеупорная глина→печь 1400°C→каолин→шамот), графит, Fe-руда. **НЕ требует: T-052 (бронза)!**

### T-055b: Тигельная сталь (вуц, Дамаск) — альтернативный путь без кокса

**Эпоха**: Железный век → Античность (~300 до н.э. — Индия, Дамаск)

**Предпосылки**:
- Знания: T-057 (сыродутный процесс — железная губка), T-058 (ковка железа), наблюдение — карбюризация Fe в тигле с углеродом
- Ресурсы: [Fe-руда](../02_world/resources/01_minerals_ores.md) (или губка из T-057), [древесный уголь](../02_world/processed_materials/01_fuel_products.md) (источник C), [графит](../02_world/resources/01_minerals_ores.md) (тигель — критично!)
- Материалы: [огнеупорная глина](../02_world/resources/03_clays_refractories.md) (тигель + печь), [графитовый тигель](../02_world/resources/01_minerals_ores.md)
- Соц. сложность: 500+ (кузнецы-специалисты)
- Физ-хим: **1300-1500°C** (достижимо с природной огнеупорной глиной + меха — не нужен шамот!)
- Культура: ценность «знание» > 0 (секрет ремесла)

**Цепочка** (проверка!):
```
Железная губка (←T-057) + древесный уголь (C) + добавки (растения — листья/кора)
  → герметичный графитовый тигель
  → нагрев 1300-1500°C (несколько часов — медленно)
  → карбюризация Fe + C → сталь (вуц)
  → ковка → клинок (Дамаск)
```

**Результаты**:
- Открывает материалы: [тигельная сталь](../02_world/processed_materials/04_metallurgical_products.md) (высокого качества, но **медленно и дорого**)
- Открывает изделия: [дамасский клинок](items/01_weapons.md), [булатные орудия](items/02_tools.md)
- Эффект: **качественная сталь без кокса** — альтернатива T-055a для регионов без каменного угля

**Бутылочное горлышко?**: НЕТ коксу — но требует графит (тигель) + железо + много времени (медленнее домны в 10-100×). Не масштабируется → только элитное оружие/инструменты.
**Связи**: ← T-057, T-058; требует: графит (тигель) + Fe + древесный уголь + природная огнеупорная глина. **Альтернатива T-055a (домна) — не требует кокса и шамота, но медленнее и дороже**

> ⚠️ **Принцип 9 (бесконечное развитие)**: T-055a и T-055b — параллельные пути к стали. T-055a (домна) — массово, требует кокс+шамот. T-055b (тигель) — малые объёмы, требует только графит + природная огнеупорная глина. Игрок выбирает по доступности ресурсов.

### T-056: Стекло

**Эпоха**: Железный век / Бронзовый век (~1500 до н.э. — Египет, Месопотамия)

**Предпосылки**:
- Знания: T-050 (плавка меди — знание высокой температуры), T-010 (керамика — обжиг)
- Ресурсы: [кварцевый песок](../02_world/resources/02_stone_construction.md) (повсеместно), [натрон](../02_world/processed_materials/02_chemical_products.md) (натронные озёра — Египет) ИЛИ [поташ](../02_world/processed_materials/02_chemical_products.md) (←зола←дерево — Европа)
- Материалы: [известь CaO](../02_world/processed_materials/02_chemical_products.md) (←обжиг известняка 900°C), [огнеупорная глина](../02_world/resources/03_clays_refractories.md) (для печи)
- Соц. сложность: 1000+ (стекловары — специализация)
- Физ-хим: **1200°C** (нужна огнеупорная глина для печи)

**Цепочка** (проверка!):

```
Песок + (натрон ИЛИ поташ) + CaO → плавка 1200°C (в огнеупорной печи) → стекло
Без щёлочи (натрон/поташ) → плавка 1700°C → почти невозможно в древности
```

**Результаты**:

### T-082: Книгопечатание (Гутенберг)

**Эпоха**: Средние века / Ренессанс (~1440 — Гутенберг, Майнц)

**Предпосылки**:
- Знания: T-037 (алфавит), T-020 (деревообработка — пресс), T-073 (механика — винтовой пресс)
- Ресурсы: [пергамент/бумага](../02_world/processed_materials/07_food_products.md), [чернила](../02_world/processed_materials/07_food_products.md) (сажа + масло)
- Материалы: [типографский сплав](../02_world/processed_materials/04_metallurgical_products.md) ⭐ (Pb + Sn + Sb — критично!)
- Соц. сложность: 5000+ (города, университеты)
- Культура: ценность «знание» > 0

**Цепочка типографского сплава** (проверка!):
```
Галенит (PbS) → cupellation (T-053) → свинец
Касситерит (SnO₂) → плавка → олово
Стибнит (Sb₂S₃) → плавка → сурьма
Pb + Sn + Sb → сплав → шрифты → печатный пресс → книги
```
Без сурьмы (стибнит — редкий!) → сплав Pb+Sn работает, но **не расширяется при затвердевании** → ниже чёткость отпечатка, выше износ шрифта. Со сурьмой — оптимально (расширение → точная отливка → долговечность шрифта).

**Результаты**:
- Открывает изделия: [печатная книга](items/07_cult_ritual.md) (массовое распространение знаний!)
- Эффект: ×1000 скорость распространения знаний vs ручного переписывания → +наука → +скорость исследования
- Открывает технологии: T-085 (университеты — массовое образование), T-090 (масляная живопись — нужна книга для рецептов)

**Бутылочное горлышко?**: **ЧАСТИЧНО** — без сурьмы (стибнит — редкий минерал) сплав Pb+Sn работает, но ниже качество и выше износ шрифта. С сурьмой — оптимально. **Альтернатива**: печать без Sb (Pb+Sn) — возможна, но шрифт изнашивается быстрее, тиражи меньше.
**Связи**: → T-085, T-090; ← T-037, T-020, T-073; требует: алфавит + типографский сплав (Pb+Sn+Sb) + пресс

> Если в тексте упоминается «T-060» без суффикса — имеется в виду мореплавание вообще (любой из двух вариантов).

### T-061: Колонизация (основание новых поселений)

**Эпоха**: Бронза → Античность (~800 до н.э. — греки, финикийцы)

**Предпосылки**:
- Знания: T-060b (парусное мореплавание — океан), T-043 (города — основание новых), T-015 (земледелие — выживание колонии)
- Ресурсы: [дерево](../02_world/resources/05_wood_timber.md) (корабли), [население](../02_world/fauna/README.md) (избыток → миграция)
- Соц. сложность: 5000+ (метрополия → колония)

**Результаты**:
- Эффект: +новые поселения → +ресурсы (из новых регионов), +торговля
- Открывает технологии: T-091 (каравелла — океанская колонизация)

**Бутылочное горлышко?**: НЕТ — но требует парусное мореплавание + избыток населения.
**Связи**: ← T-060b, T-043, T-015; → T-091; требует: корабли + избыток населения + новая земля

### T-075: Витражи (стеклянная мозаика)

**Эпоха**: Средние века (~12 в. — готика)

**Предпосылки**:
- Знания: T-056 (стекло), T-034 (красители — пигменты для стекла)
- Ресурсы: [стекло](../02_world/processed_materials/02_chemical_products.md), [пигменты](../02_world/resources/07_dyes_pigments.md) (оксиды металлов — Co, Cu, Mn, Au)
- Материалы: [цветное стекло](../02_world/processed_materials/02_chemical_products.md), [свинец](../02_world/processed_materials/04_metallurgical_products.md) (H-образные профили — крепление)
- Соц. сложность: 1000+ (мастера-витражисты)

**Результаты**:
- Открывает изделия: [витраж](items/03_buildings.md), [окно с витражом](items/03_buildings.md)

**Бутылочное горлышко?**: НЕТ — но требует стекло + пигменты.
**Связи**: ← T-056, T-034; требует: стекло + пигменты (оксиды металлов) + свинец (крепление)

## 🚧 Географические тупики и альтернативы

> Не везде на Земле есть все ресурсы. Вот что блокируется и какие альтернативы есть.

| Ресурс | Где есть | Что блокирует | Альтернатива? |
|---|---|---|---|
| **Олово (касситерит)** | Корнуолл, Боливия, Малайя | Бронза (T-052) | ✅ Мышьяковая бронза (T-052a) ИЛИ перепрыгнуть → железо (T-057) |
| **Каменный уголь** | Рур, Донбасс, Англия, Китай | Кокс (T-080) → сталь массово (T-102) → индустриализация | ✅ Тигельная сталь (Дамаск) — медленнее, дороже, но работает |
| **Бокситы** | Австралия, Гвинея, Бразилия | Алюминий (T-111) → авиация → электроника | ❌ Нет (нужен импорт) |
| **Криолит** | Только Гренландия | Алюминий (T-111) | ❌ Нет (нужен импорт; позже — синтетический) |
| **Медь** | Почти везде | Электричество (T-103) → компьютеры (T-120) | ✅ Серебро (провода — дорого) ИЛИ алюминий (но требует электричество — замкнутый круг!) |
| **Уран** | Очень редкий | Атомная энергия (T-113) | ❌ Нет (нужен импорт) |
| **Дикие злаки** | Плодородный полумесяц, Китай, Мезоамерика, Африка | Земледелие (T-015) → оседлость → города | ✅ Скотоводство (T-030) → кочевой путь (T-032) ИЛИ рыболовство (прибрежные города) |
| **Пуццолан** | Италия, Греция, Камчатка | Римский бетон (T-071) → акведуки | ⚠️ Обычный раствор (не водостойкий — нельзя акведуки) |
| **Селитра** | Чили, старые копанки, навоз | Порох (T-081) → огнестрел | ⚠️ Можно производить из навоза (медленно) |
| **Сера** | Сицилия, вулканы | Порох (T-081) | ⚠️ Из пирита (обжиг) |
| **Стибнит (сурьма)** | Редкий | Типографский сплав (T-082) → книгопечатание | ⚠️ Без сурьмы — хуже (сплав не расширяется), но можно пробовать |
| **Папирус** | Только Египет | Папирус (T-038) | ✅ Пергамент (T-039) — из кожи (повсеместно) |
| **Натрон** | Египет, Кения | Стекло (T-056) через натрон | ✅ Поташ (из золы дерева) — повсеместно |

### Принцип: «географический тупик = стимул к торговле/захвату»

Если у племени нет ресурса →:
1. **Торговать** с теми, у кого есть (если есть мир)
2. **Завоевать** территорию с ресурсом (если есть армия)
3. **Найти альтернативу** (если есть — см. таблицу выше)
4. **Остановиться** на текущем уровне (если нет альтернативы и торговли)

### Принцип: «параллельные пути, не последовательные»

Технологии — **не всегда** последовательные. Многие — **параллельные**:
- Медь и железо — **параллельны** (можно перепрыгнуть медь → сразу железо, как Африка)
- Земледелие и скотоводство — **параллельны** (кочевой путь без оседлости)
- Натрон и поташ — **альтернативы** для стекла
- Папирус и пергамент — **альтернативы** для письма
- Кокс и древесный уголь — **альтернативы** для топлива (но кокс даёт выше температуру)
- Водяная и ветряная мельница — **альтернативы** для энергии

**Правило**: если технология требует конкретный ресурс, у которого есть альтернатива — указать **обе**. Если альтернативы нет — указать как «географический тупик» (нужен импорт).

| Переход | Нужно (критичные элементы) |
|---|---|
| Палеолит → Неолит | Земледелие (T-015) + скотоводство (T-030) + керамика (T-010) |
| Неолит → Халколит | Плавка меди (T-050) — древесный уголь + глина + 700°C |

| Бронза → Железо | Сыродутный (T-057): природная огнеупорная глина + Fe + уголь + меха. Параллельные пути: T-055a (домна — шамот+кокс) ИЛИ T-055b (тигельная сталь — графит+уголь) |
| Железо → Античность | Пуццолан + известь → римский бетон (T-071). Альтернатива для акведуков — каменная кладка (T-070) |
| Античность → Средние века | Порох (T-081: селитра+сера+уголь — 3 горлышка) + книгопечатание (T-082: типографский сплав Pb+Sn+Sb) |
| Средние века → Ренессанс | Масляная живопись (T-090) + компас (T-093) |

| Индустриальная → Современная | Электричество (T-103) + ДВС (T-104) + Габер-Бош (T-112) |
| Современная → Электронная | Полупроводники (Si, Ge — T-120) + ИИ (T-122) |

## 🔄 Альтернативные пути (Принцип 9 — бесконечное развитие)

Игрок может выбирать разные пути:

### Пример: путь к стеклу
- **Европа (без натрона)**: песок + **поташ** (←зола←дерево) + CaO → стекло 1200°C
- **Египет**: песок + **сода (натрон)** (←натронные озёра) + CaO → стекло 1200°C
- **Без огнеупоров**: песок без щёлочи → плавка 1700°C → почти невозможно (только элитное стекло)

### Пример: путь к стали
- **Дамасск (Древняя Индия)**: тигельная плавка → вуц (сталь) — медленно, дорого
- **Европа 19 в.**: домна + кокс + Бессемер → сталь массово
- **Без кокса**: древесный уголь + сыродутный процесс → только железо (не сталь)

### Пример: путь к освещению
- **Воск** (←пчёлы) — элита
- **Сало** (←животный жир) — бедные, дымно
- **Стеарин** (←животный жир, обработанный) — массово (19 в.)
- **Парафин** (←нефть) — ещё дешевле (19 в.)
- **Электричество** (←генератор) — массово (20 в.)
