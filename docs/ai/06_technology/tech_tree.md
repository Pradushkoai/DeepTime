# Дерево технологий — Tech Tree

> Полное дерево технологий игры «Цивилизация Прадушко». Каждая технология имеет предпосылки (знания, ресурсы, материалы, процессы) и результаты (новые материалы, изделия, возможности).

---

## 🌳 Концепция дерева

### Принципы (см. [prerequisites.md](prerequisites.md) и [_meta/ai_working_principles.md → Принцип 9](../_meta/ai_working_principles.md))

1. **5 категорий предпосылок**: знания, ресурсы, социальная сложность, культурные ценности, физ-хим пороги (как пример кросс-тех зависимостей)
2. **Бесконечное развитие** (Принцип 9): нет верхней границы по эпохам
3. **Обязательная связность** (Принцип 10): каждая технология связана с другими
4. **Кросс-тех зависимости** (Принцип в prerequisites.md): технология A зависит от технологии B

### Структура технологии в дереве

```
ТЕХНОЛОГИЯ: Название
- Предпосылки:
  - Знания: (предыдущие технологии + опыт)
  - Ресурсы: (что должно быть в регионе/доступно)
  - Материалы: (что должно быть произведено)
  - Соц. сложность: (население, города, специализация)
  - Культура: (ползунки ценностей)
  - Физ-хим пороги: (температуры, давление — пример)
- Результаты:
  - Открывает материалы: (ссылки на processed_materials/)
  - Открывает изделия: (ссылки на items/)
  - Открывает процессы: (ссылки на processes.md)
  - Открывает следующие технологии: (ссылки на tech_tree.md)
```

## 🌳 Структура дерева по эпохам (группы, не ограничения)

> ⚠️ **Важно**: эпохи — это **описание текущего уровня**, не временные рамки (см. Принцип 9). Игрок может двигаться быстрее/медленнее истории.

### Эпоха 1: Палеолит / Мезолит (~10000 до н.э.)

**Стартовые технологии (известны с начала)**:
- 🔥 Контроль огня
- 🪨 Оббивка камня (кремнёвые орудия)
- 🏹 Изготовление лука (тис/ясень + сухожилия)
- 🏕 Постройка шалаша (ветки + шкуры)
- 🗣 Язык (базовая коммуникация)
- 🧠 Мифология (примитивная религия)

**Что открыть (палеолит → неолит)**:
- 🌾 Собирательство → Земледелие (нужны: знание о посеве, палка-копалка)
- 🐕 Приручение собаки (нужны: наблюдение за волками)
- 🏺 Керамика (нужны: глина, обжиг 800°C)
- 🪵 Древесный уголь (нужны: сухая перегонка)

---

### Эпоха 2: Неолит (~8000 до н.э.)

**Технологии**:
- 🌾 Земледелие (злаки — эммер, ячмень)
- 🐑 Скотоводство (овца, коза, корова, свинья)
- 🏺 Гончарное дело (формовка + обжиг)
- 🧺 Ткачество (лён/шерсть → ткацкий станок)
- 🏠 Глинобитное строительство
- 🪵 Древесный уголь (для плавки меди)
- 🪨 Шлифовка камня (полированные орудия)

**Что открыть (неолит → халколит)**:
- ⚒ Плавка меди (нужны: самородная медь ИЛИ малахит + древесный уголь + печь 700°C + обычная глина для печи)
- 📝 Пиктограммы (нужны: краски + поверхность)

---

### Эпоха 3: Халколит / Медный век (~5000 до н.э.)

**Технологии**:
- ⚒ Плавка меди → медные орудия/оружие
- 🏺 Литьё в формы (парижский гипс)
- 🪙 Начальная металлургия (медь + самородное Au/Ag)
- 📝 Пиктограммы → Клинопись (нужны: стилос + глиняные таблички)

**Что открыть (халколит → бронзовый век)**:
- ⚔ Плавка бронзы (нужны: медь + олово (касситерит!) + огнеупорная глина + обжиг 950°C)

---

### Эпоха 4: Бронзовый век (~3500 до н.э.)

**Технологии**:
- ⚔ Плавка бронзы → бронзовое оружие/доспехи
- 🔤 Алфавит (нужны: торговая необходимость + знания о слогах)
- 🚢 Мореплавание (нужны: паруса ←лён/конопля + кедр/тик для кораблей + дёготь для герметизации)
- 🏛 Монументальная архитектура (нужны: известняк + известь + много труда)
- 🪙 Чеканка монет (нужны: серебро (cupellation!) + сплавы для чеканки)
- 📜 Папирус (нужны: папирусное растение — Египет)

**Что открыть (бронза → железо)**:
- ⚔ Плавка железа (нужны: Fe-руда + древесный уголь + шамот (огнеупор) + графит (тигель) + 1500°C)

---

### Эпоха 5: Железный век (~1200 до н.э.)

**Технологии**:
- ⚔ Плавка железа → железное оружие
- 🏺 Стекло (нужны: песок + сода (натрон) ИЛИ поташ + CaO + 1200°C + огнеупоры)
- 🛞 Колесо со спицами (нужны: токарный станок + продвинутая деревообработка)
- 📜 Пергамент (нужны: козлиная/овечья кожа + обработка)
- ⚙ Механика (рычаги, шестерёнки — античная инженерия)

**Что открыть (Fe → индустриализация)**:
- 🏭 Коксование угля (нужны: каменный уголь + герметичная печь 1000°C)
- 📚 Книгопечатание (нужны: типографский сплав Pb+Sn+Sb + пресс)

---

### Эпоха 6: Античность (~500 до н.э.)

**Технологии**:
- 🏛 Древесное бетонирование (римский бетон — CaO + пуццолан)
- 🏛 Акведуки (нужны: водостойкий бетон)
- ⚙ Катапульта / Баллиста (нужны: знание механики)
- 📚 Библиотеки (нужны: пергамент/папирус)
- 🔬 Наука (Аристотель, Архимед)

---

### Эпоха 7: Средние века (5-15 в.)

**Технологии**:
- 🌾 Трёхполье (севооборот)
- ⚙ Ветряная мельница (нужны: жернов + механизм)
- 📚 Университеты
- 🏰 Замки/Крепости
- 🗡 Книгопечатание (Гутенберг, 1440)
- 💥 Порох (нужны: селитра + сера + уголь)

---

### Эпоха 8: Ренессанс / Раннее Новое время (15-18 в.)

**Технологии**:
- 🎨 Масляная живопись (нужны: олифа + пигменты)
- ⛵ Океанские корабли (каравеллы — 3 мачты)
- 🔭 Телескоп/Микроскоп (нужны: стекло + линзы)
- 🧭 Компас + астролябия
- 🗺 Картография
- 🏭 Первые фабрики (мануфактуры)

---

### Эпоха 9: Индустриальная (18-19 в.)

**Технологии**:
- 🏭 Паровая машина (Ньюкомен 1712, Уатт 1769)
- 🚂 Паровоз (Стивенсон, 1830)
- 🚢 Пароход (Фултон, 1807)
- ⚙ Сталь массово (Бессемер, 1856)

## 🎯 Ключевые «бутылочные горлышки» в дереве

| Переход | Нужно (критичные элементы) |
|---|---|
| Палеолит → Неолит | Земледелие + скотоводство + керамика |
| Неолит → Халколит | Плавка меди (нужен древесный уголь + глина) |
| Халколит → Бронза | Олово (касситерит!) + огнеупорная глина |
| Бронза → Железо | Шамот + графит (тигель) + 1500°C |
| Железо → Античность | Пуццолан + известь (римский бетон) |
| Античность → Средние века | Порох + книгопечатание |
| Средние века → Ренессанс | Масляная живопись + компас |
| Ренессанс → Индустриальная | Кокс + сталь + паровая машина |
| Индустриальная → Современная | Электричество + ДВС + Габер-Бош |
| Современная → Электронная | Полупроводники + ИИ |

## 🔄 Альтернативные пути (Принцип 9 — бесконечное развитие)

Игрок может выбирать разные пути:

### Пример: путь к стеклу
- **Европа (без натрона)**: песок + **поташ** (←зола←дерево) + CaO → стекло 1200°C
- **Египет**: песок + **сода (натрон)** (←натронные озёра) + CaO → стекло 1200°C
- **Без огнеупоров**: песок без щёлочи → плавка 1700°C → почти невозможно (только элитное стекло)

### Пример: путь к стали
- **Дамасск (Древняя Индия)**: тигельная плавка → вуц (сталь) — медленно, дорого
- **Европа 19 в.**: домна + кокс + Бессемер → сталь массово
- **Без кокса**: древесный уголь + сыродутный процесс → только железо (не сталь)

### Пример: путь к照明у
- **Воск** (←пчёлы) — элита
- **Сало** (←животный жир) — бедные, дымно
- **Стеарин** (←животный жир, обработанный) — массово (19 в.)
- **Парафин** (←нефть) — ещё дешевле (19 в.)
- **Электричество** (←генератор) — массово (20 в.)
