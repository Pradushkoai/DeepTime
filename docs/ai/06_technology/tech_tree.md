# Дерево технологий — Tech Tree

> Полное дерево технологий игры «Цивилизация Прадушко». Каждая технология имеет предпосылки (знания, ресурсы, материалы, процессы) и результаты (новые материалы, изделия, возможности).

---

## 🌳 Концепция дерева

#### Принципы (см. [prerequisites.md](prerequisites.md) и [_meta/ai_working_principles.md → Принцип 9](../_meta/ai_working_principles.md))

1. **5 категорий предпосылок**: знания, ресурсы, социальная сложность, культурные ценности, физ-хим пороги (как пример кросс-тех зависимостей)
2. **Бесконечное развитие** (Принцип 9): нет верхней границы по эпохам
3. **Обязательная связность** (Принцип 10): каждая технология связана с другими
4. **Кросс-тех зависимости** (Принцип в prerequisites.md): технология A зависит от технологии B

### Структура технологии в дереве

```
ТЕХНОЛОГИЯ: Название
- Предпосылки:
  - Знания: (предыдущие технологии + опыт)
  - Ресурсы: (что должно быть в регионе/доступно)
  - Материалы: (что должно быть произведено)
  - Соц. сложность: (население, города, специализация)
  - Культура: (ползунки ценностей)
  - Физ-хим пороги: (температуры, давление — пример)
- Результаты:
  - Открывает материалы: (ссылки на processed_materials/)
  - Открывает изделия: (ссылки на items/)
  - Открывает процессы: (ссылки на processes.md)
  - Открывает следующие технологии: (ссылки на tech_tree.md)
```

### T-001: Контроль огня

**Эпоха**: Палеолит (~1 млн лет назад — Homo erectus)
**Стартовая**: да (известна с начала)

**Предпосылки**:
- Знания: наблюдение за природным огнем (молнии, вулканы)
- Ресурсы: древесина (топливо), кремень (огниво)
- Соц. сложность: минимальная (10-30 человек)
- Культура: нет требований

**Результаты**:
- Открывает процессы: [обжиг](processes.md), [сухая перегонка](processes.md) (пиролиз)
- Открывает изделия: [костёр](items/03_buildings.md) (как «здание»)
- Открывает технологии: T-002 (приготовление пищи), T-003 (обогрев жилища), T-005 (оббивка с обжигом)
- Открывает материалы: [древесный уголь](../02_world/processed_materials/01_fuel_products.md) (через пиролиз — позже)

**Бутылочное горлышко?**: нет — базовая технология
**Связи**: → T-002, T-003, T-005, T-010 (керамика), T-015 (плавка меди)

### T-005: Изготовление лука

**Эпоха**: Палеолит (~35000 до н.э.)
**Стартовая**: да

**Предпосылки**:
- Знания: T-004 (оббивка), упругость древесины
- Ресурсы: любое упругое дерево — [тис](../02_world/resources/05_wood_timber.md) (лучший!), [ясень](../02_world/resources/05_wood_timber.md), [граб](../02_world/resources/05_wood_timber.md), [берёза](../02_world/resources/05_wood_timber.md), [бамбук](../02_world/resources/05_wood_timber.md) (тропики)
- Материалы: [сухожилия](../02_world/resources/09_hides_leather.md) или [лён](../02_world/resources/06_fibers_textiles.md) (тетива)
- Соц. сложность: 10-30 человек
- Культура: воинственность > 0 (для охотничьего применения)

**Результаты**:
- Открывает изделия: [лук](items/01_weapons.md), [стрелы](items/01_weapons.md)
- Открывает технологии: T-006 (составные орудия → композитный лук из рога+сухожилий+дерева — мощнее!)

**Бутылочное горлышко?**: НЕТ — лук можно сделать из любого упругого дерева. Тис даёт лучший длинный лук, но ясень/граб/берёза/бамбук — тоже работают. Композитный лук (рог+сухожилия) — мощнее тисового, но сложнее.
**Связи**: → T-006; требует: любое упругое дерево + тетива (сухожилия/лён)

## 🌾 Эпоха 2: Неолит (~8000 до н.э.)

---

### T-010: Керамика (гончарное дело)

**Эпоха**: Неолит (~20000 до н.э. — Япония Дзёмон, массово ~10000 до н.э.)

**Предпосылки**:
- Знания: T-001 (контроль огня), наблюдение — глина твердеет при обжиге
- Ресурсы: [обычная глина](../02_world/resources/03_clays_refractories.md) (повсеместно)
- Соц. сложность: 30-100 человек (специализация гончара)
- Физ-хим: **800-900°C** (обычная глина держит — критично!)

**Результаты**:
- Открывает материалы: [керамика](../02_world/processed_materials/07_food_products.md) (как материал для посуды)
- Открывает изделия: [глиняный горшок](items/05_household.md), [амфора](items/05_household.md), [урна](items/07_cult_ritual.md)
- Открывает процессы: [обжиг](processes.md) (керамики)
- Открывает технологии: T-011 (варка пищи в горшке), T-012 (кирпич-сырец), T-013 (гончарный круг — позднее), T-014 (обожжённый кирпич — позднее)

**Бутылочное горлышко?**: **ДА** — без обжига 800°C нет керамики → нет хранения жидкостей → нет варки → нет стратегического запаса пищи
**Связи**: → T-011, T-012, T-013, T-014; требует: T-001, глина

### T-015: Земледелие (одомашнивание злаков)

**Эпоха**: Неолит (~10000 до н.э. — Плодородный полумесяц)

**Предпосылки**:
- Знания: T-002 (приготовление пищи), наблюдение сезонности растений, знание о посеве
- Ресурсы: **дикие злаки в регионе** (эммер, ячмень — [Vavilov Center 3](../02_world/flora/README.md)), [палка-копалка](items/02_tools.md)
- Соц. сложность: 30-100 человек
- Культура: ценность «прогресс» > 0 ИЛИ кризис (голод → необходимость)

**Результаты**:
- Открывает материалы: [мука](../02_world/processed_materials/07_food_products.md) (через помол)
- Открывает изделия: [серп](items/02_tools.md) (для жатвы), [жернов](items/02_tools.md) (для помола)
- Открывает технологии: T-016 (ирригация), T-017 (плуг — позднее), T-025 (хлеб), T-026 (пиво)

**Бутылочное горлышко?**: **КРИТИЧНО** — без земледелия нет избытка пищи → нет городов → нет цивилизации. Требует диких злаков в регионе (география = судьба).
**Связи**: → T-016, T-017, T-025, T-026; требует: дикие злаки (география)

### T-030: Скотоводство (одомашнивание животных)

**Эпоха**: Неолит (~10000 до н.э. — овца/коза, ~8500 — корова/свинья)

**Предпосылки**:
- Знания: T-007 (приручение собаки), наблюдение за поведением стадных животных
- Ресурсы: **дикие предки дом. животных в регионе** ([муфлон→овца, безоаровый козёл→коза, тур→корова, кабан→свинья](../02_world/fauna/README.md))
- Соц. сложность: 50-200 человек (пастухи)
- Культура: ценность «коллектив» > 0 (пастбища — общинные)

**Результаты**:
- Открывает материалы: [молоко](../02_world/resources/08_food_resources.md), [шерсть](../02_world/resources/06_fibers_textiles.md), [кожи](../02_world/resources/09_hides_leather.md), [мясо дом. животных](../02_world/resources/08_food_resources.md)
- Открывает изделия: [сыр](../02_world/processed_materials/07_food_products.md) (консервация молока!), [войлок](../02_world/processed_materials/08_hygiene_textile_products.md) (валяние шерсти)
- Открывает технологии: T-031 (ткачество — из шерсти), T-032 (кочевое скотоводство), T-033 (пахота на коровах)

**Бутылочное горлышко?**: **ДА** — без дом. животных нет молока, шерсти, тягловой силы. Требует диких предков в регионе (география).
**Связи**: → T-031, T-032, T-033; требует: дикие предки (география)

## 🌳 Продолжение (эпохи 5-11 — заготовки для детализации)

## ⚔ Эпоха 5: Железный век (~1200 до н.э.)

> ⚠️ Важно: сыродутный процесс (T-057) и полная плавка железа (T-055) — РАЗНЫЕ технологии. Сыродутный — восстановление при 1200-1300°C → губка → ковать. Полная плавка — 1500°C → чугун → литьё. Исторически: сначала сыродутное железо (1200 до н.э.), потом — домна (Китай, 500 до н.э.).

---

### T-057: Сыродутный процесс (железная губка)

**Эпоха**: Железный век (~1200 до н.э. — Бронзовый коллапс, исчезновение олова → переход к железу)

**Предпосылки**:
- Знания: T-050 (плавка меди — знание металлургии), T-040 (древесный уголь)
- Ресурсы: [Fe-руда](../02_world/resources/01_minerals_ores.md) (гематит/лимонит/магнетит — повсеместно!), [древесный уголь](../02_world/processed_materials/01_fuel_products.md)
- Материалы: [огнеупорная глина](../02_world/resources/03_clays_refractories.md) (держит 1300-1500°C — для стенок печи), [графит](../02_world/resources/01_minerals_ores.md) (для тигля — опционально)
- Соц. сложность: 500+ (кузнецы — специализация)
- Физ-хим: **1200-1300°C** (нужна огнеупорная глина, НЕ шамот!)
- Культура: ценность «прогресс» > «традиция» (переход от бронзы к железу)

**Результаты**:
- Открывает материалы: [железная губка](../02_world/processed_materials/04_metallurgical_products.md) (губчатое Fe — не жидкое, а тестообразное)
- Открывает изделия: [железные орудия](items/02_tools.md), [железное оружие](items/01_weapons.md) (кованые, не литые)
- Открывает технологии: T-058 (ковка железа → инструменты/оружие), T-055 (полная плавка → чугун → сталь)

**Бутылочное горлышко?**: НЕТ — Fe-руда повсеместна (в отличие от олова!). Но нужна огнеупорная глина (1300°C) и древесный уголь. Это ДЕШЕВЛЕ бронзы (не нужно олово) → железо вытесняет бронзу после коллапса торговли оловом (1200 до н.э.)
**Связи**: → T-058, T-055; ← T-050, T-040; требует: Fe-руда (повсеместно) + огнеупорная глина + древесный уголь

### T-055: Полная плавка железа / Домна (чугун)

**Эпоха**: Железный век → Античность (~500 до н.э. — Китай, Европа — 14 в. н.э.)

**Предпосылки**:
- Знания: T-057 (сыродутный процесс), T-052 (плавка бронзы — знание высокой температуры), знание дутья воздуха (меха)
- Ресурсы: [Fe-руда](../02_world/resources/01_minerals_ores.md), [древесный уголь](../02_world/processed_materials/01_fuel_products.md) ИЛИ [кокс](../02_world/processed_materials/01_fuel_products.md) (позднее)
- Материалы: [шамот](../02_world/resources/03_clays_refractories.md) (огнеупор 1500-1700°C — критично!), [графит](../02_world/resources/01_minerals_ores.md) (тигель), [известняк](../02_world/resources/02_stone_construction.md) (флюс — CaO)
- Соц. сложность: 1000+ (домна — большое сооружение)
- Физ-хим: **1500°C** (нужен шамот! — каолин, обожжённый при 1400°C)
- Культура: ценность «прогресс» > «традиция»

**Цепочка огнеупоров** (проверка!):
```
Огнеупорная глина (природный материал, держит 1300-1500°C) → печь 1400°C → обжиг каолина → шамот (держит 1500-1700°C) → домна 1500°C → чугун
```
Без огнеупорной глины → нет печи 1400°C → нет шамота → нет домны → нет чугуна.

**Результаты**:
- Открывает материалы: [чугун](../02_world/processed_materials/04_metallurgical_products.md) (Fe + 2-4% C — литейный), затем [сталь](../02_world/processed_materials/04_metallurgical_products.md) (через декарбуризацию — T-102)
- Открывает изделия: [чугунные котлы](items/05_household.md), [чугунные пушки](items/06_military.md) (позднее)
- Открывает технологии: T-102 (сталь массово — Бессемер, нужны кокс + воздух), T-100 (паровая машина — нужны стальные котлы)

**Бутылочное горлышко?**: **КРИТИЧНО** — без шамота нет домны → нет чугуна → нет стали → нет индустриализации. Требует: огнеупорная глина → шамот + графит + 1500°C.
**Связи**: → T-102, T-100; ← T-057, T-052; требует: шамот (←огнеупорная глина→печь 1400°C→каолин→шамот), графит, Fe-руда

### T-056: Стекло

**Эпоха**: Железный век / Бронзовый век (~1500 до н.э. — Египет, Месопотамия)

**Предпосылки**:
- Знания: T-050 (плавка меди — знание высокой температуры), T-010 (керамика — обжиг)
- Ресурсы: [кварцевый песок](../02_world/resources/02_stone_construction.md) (повсеместно), [натрон](../02_world/processed_materials/02_chemical_products.md) (натронные озёра — Египет) ИЛИ [поташ](../02_world/processed_materials/02_chemical_products.md) (←зола←дерево — Европа)
- Материалы: [известь CaO](../02_world/processed_materials/02_chemical_products.md) (←обжиг известняка 900°C), [огнеупорная глина](../02_world/resources/03_clays_refractories.md) (для печи)
- Соц. сложность: 1000+ (стекловары — специализация)
- Физ-хим: **1200°C** (нужна огнеупорная глина для печи)
- Культура: ценность «прогресс» > 0

**Цепочка** (проверка!):
```
Песок + (натрон ИЛИ поташ) + CaO → плавка 1200°C (в огнеупорной печи) → стекло
Без щёлочи (натрон/поташ) → плавка 1700°C → почти невозможно в древности
```

**Результаты**:
- Открывает материалы: [стекло](../02_world/processed_materials/02_chemical_products.md)
- Открывает изделия: [стеклянная посуда](items/05_household.md), [окна](items/03_buildings.md), [зеркала](items/05_household.md), [бусины](items/07_cult_ritual.md)
- Открывает технологии: T-092 (телескоп/микроскоп — нужны линзы — позднее), T-075 (витражи — средние века)

**Бутылочное горлышко?**: НЕТ — но без щёлочи (натрон/поташ) нужно 1700°C (почти невозможно). С щёлочью — 1200°C (доступно). Натрон — географическая монополия Египта. Поташ — из золы дерева (возобновляемый, но нужен лес).
**Связи**: → T-092, T-075; ← T-050, T-010; требует: песок + щёлочь (натрон ИЛИ поташ) + CaO + огнеупор

### T-082: Книгопечатание (Гутенберг)

**Эпоха**: Средние века / Ренессанс (~1440 — Гутенберг, Майнц)

**Предпосылки**:
- Знания: T-037 (алфавит), T-020 (деревообработка — пресс), T-073 (механика — винтовой пресс)
- Ресурсы: [пергамент/бумага](../02_world/processed_materials/07_food_products.md), [чернила](../02_world/processed_materials/07_food_products.md) (сажа + масло)
- Материалы: [типографский сплав](../02_world/processed_materials/04_metallurgical_products.md) ⭐ (Pb + Sn + Sb — критично!)
- Соц. сложность: 5000+ (города, университеты)
- Культура: ценность «знание» > 0

**Цепочка типографского сплава** (проверка!):
```
Галенит (PbS) → cupellation (T-053) → свинец
Касситерит (SnO₂) → плавка → олово
Стибнит (Sb₂S₃) → плавка → сурьма
Pb + Sn + Sb → сплав → шрифты → печатный пресс → книги
```
Без сурьмы (стибнит — редкий!) → сплав не расширяется при затвердевании → нет качественной печати.

**Результаты**:
- Открывает изделия: [печатная книга](items/07_cult_ritual.md) (массовое распространение знаний!)
- Эффект: ×1000 скорость распространения знаний vs ручного переписывания → +наука → +скорость исследования
- Открывает технологии: T-085 (университеты — массовое образование), T-090 (Ренессанс — нужна книга)

**Бутылочное горлышко?**: **ДА** — без сурьмы (стибнит — редкий минерал) нет качественного типографского сплава. Pb+Sn+Sb — все три нужны.
**Связи**: → T-085, T-090; ← T-037, T-020, T-073; требует: алфавит + типографский сплав (Pb+Sn+Sb) + пресс

**Бутылочное горлышко?**: НЕТ — но нужен T-055 (домна → чугун) + T-080 (кокс). Это «вершина» металлургии.
**Связи**: → T-100, T-101, T-104, T-111; ← T-055, T-080; требует: чугун + кокс + воздух

**Цепочка алюминия** (проверка!):
```
Бокситы → глинозём (Al₂O₃, обжиг 1200°C) → электролиз (Холл-Эру, 950°C, криолит, нефтяной кокс-электроды) → алюминий
```

**Бутылочное горлышко?**: **КРИТИЧНО** — без алюминия нет лёгких самолётов. Алюминий требует: бокситы + криолит + нефтяной кокс + электричество (4 предпосылки!).
**Связи**: ← T-104, T-092; требует: алюминий (←бокситы + электричество + криолит + нефтяной кокс) + ДВС + аэродинамика

## 🎯 Ключевые «бутылочные горлышки» в дереве

| Переход | Нужно (критичные элементы) |
|---|---|
| Палеолит → Неолит | Земледелие + скотоводство + керамика |
| Неолит → Халколит | Плавка меди (нужен древесный уголь + глина) |
| Халколит → Бронза | Олово (касситерит!) + огнеупорная глина |
| Бронза → Железо | Шамот + графит (тигель) + 1500°C |
| Железо → Античность | Пуццолан + известь (римский бетон) |
| Античность → Средние века | Порох + книгопечатание |
| Средние века → Ренессанс | Масляная живопись + компас |
| Ренессанс → Индустриальная | Кокс + сталь + паровая машина |
| Индустриальная → Современная | Электричество + ДВС + Габер-Бош |
| Современная → Электронная | Полупроводники + ИИ |

## 🔄 Альтернативные пути (Принцип 9 — бесконечное развитие)

Игрок может выбирать разные пути:

### Пример: путь к стеклу
- **Европа (без натрона)**: песок + **поташ** (←зола←дерево) + CaO → стекло 1200°C
- **Египет**: песок + **сода (натрон)** (←натронные озёра) + CaO → стекло 1200°C
- **Без огнеупоров**: песок без щёлочи → плавка 1700°C → почти невозможно (только элитное стекло)

### Пример: путь к стали
- **Дамасск (Древняя Индия)**: тигельная плавка → вуц (сталь) — медленно, дорого
- **Европа 19 в.**: домна + кокс + Бессемер → сталь массово
- **Без кокса**: древесный уголь + сыродутный процесс → только железо (не сталь)

### Пример: путь к освещению
- **Воск** (←пчёлы) — элита
- **Сало** (←животный жир) — бедные, дымно
- **Стеарин** (←животный жир, обработанный) — массово (19 в.)
- **Парафин** (←нефть) — ещё дешевле (19 в.)
- **Электричество** (←генератор) — массово (20 в.)
