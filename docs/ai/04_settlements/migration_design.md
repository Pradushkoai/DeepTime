# D-003: Миграция рабочей силы — Спецификация

> 📋 **Спецификация D-003** — как жители выбирают работу и переезжают между поселениями. 3 слоя принятия решений + вакансии как информация + эдикты как рычаги.
>
> **Основано на**: Q-003 (миграция). См. `discussions/consensus.md` → Вопрос 02.

---

## 🎯 Обзор

Жители **сами выбирают** работу — игрок не назначает людей (как в RTS). Игрок влияет через **эдикты** (премии, налоги, общественные работы). Экономика сама балансируется: нехватка кузнецов → рост зарплат → приток.

**Принцип**: вождь не назначает каждого человека на работу. Вождь создаёт условия (премии, проекты, налоги), а люди сами решают.

## 📊 3 слоя принятия решений

> ⚠️ **Принцип 14 (Тест на один справочник)**: 3 слоя заменяют 5 личных приоритетов (которые дублировали 5 ценностей племени из GDD). Один справочник ценностей, не два.

### Слой 1: Нужды (что мне нужно сейчас)

Базовые потребности гражданина. Если не удовлетворены — всё остальное неважно.

| Нужда | Что | Эффект при неудовлетворённости |
|---|---|---|
| 🍞 Голод | Доступ к еде | Идёт на ЛЮБУЮ работу с зарплатой |
| 🛡️ Безопасность | Защита от угроз | Уезжает из опасного региона |
| ❤️ Семья | Близость к семье | Не уезжает от семьи без причины |

**Правило**: если голоден — все остальные слои игнорируются. Сначала еда, потом всё остальное.

### Слой 2: Ценности племени (что здесь принято)

> ⚠️ **Не создаём второй справочник** — используем 5 ползунков ценностей из GDD.

| Ползунок GDD | Влияние на выбор работы |
|---|---|
| Безопасность ↔ Изобилие | При «Изобилие» → идут в торговлю/ремесло; при «Безопасность» → в армию/земледелие |
| Воинственность ↔ Миролюбие | При «Воинственность» → военная карьера; при «Миролюбие» → торговля/наука |
| Знание ↔ Традиция | При «Знание» → исследования/ремесло; при «Традиция» → жречество/земледелие |
| Природа ↔ Прогресс | При «Прогресс» → новые отрасли; при «Природа» → охота/собирательство |
| Коллектив ↔ Индивидуализм | При «Индивидуализм» → частная практика; при «Коллектив» → общественные работы |

### Слой 3: Навык (что я умею) — ИНЕРЦИЯ, не порог

> ⚠️ Ключевое решение из дискуссии A+B (round_06): **навык = не порог входа, а стоимость переключения**.

**Принцип**: чем лучше гражданин в текущем деле, тем дороже ему уходить.

```
Utility_остаться = навык_текущий × вес_инерции
Utility_уйти = (зарплата_новая − зарплата_текущая) × ценности × нужды

Если Utility_остаться > Utility_уйти → остаётся
Если Utility_уйти > Utility_остаться → уходит
```

**Вход свободен**: новичок доступен к любой работе, навык = 0 не барьер. Круг разорван: чтобы пойти в кузницу, не нужен навык кузнеца; чтобы остаться — нужен.

**Первое распределение** (кто во что попробует в начале) — через **архетип племени** (уже существующий механизм GDD). Архетип определяет предрасположенность: степной → скотоводство/охота; речной → рыболовство/земледелие.

## 📋 Формула решения

```
Utility(работа) = Нужды × Ценности_племени × Вакансия × Эдикты

где:
  Нужды = 1.0 если базовые удовлетворены, иначе → приоритет еды/безопасности
  Ценности_племени = взвешенная сумма 5 ползунков GDD (0.0-1.0)
  Вакансия = 1.0 если есть, 0.0 если нет (гражданин не идёт на несуществующую работу)
  Эдикты = множитель от премий/налогов (0.5-2.0)

Для текущей работы дополнительно:
  Utility_остаться = навык_текущий × вес_инерции (0.01-1.0)

Решение:
  Если max(Utility_новая) > Utility_остаться → переход
  Иначе → остаётся
```

### Пример

```
Анна, кузнец, навык = 60

Ценности племени: Знание = 0.8, Прогресс = 0.7
Эдикт: +20% к зарплате в металлургии

Utility_остаться = 60 × 0.05 (вес инерции) = 3.0

Вакансия: исследователь (новая отрасль)
Utility_новая = 1.0 (нужды ок) × 0.8 (Знание) × 1.0 (вакансия есть) × 1.0 (нет эдикта) = 0.8

3.0 > 0.8 → Анна остаётся кузнецом

Но если эдикт «+50% к зарплате исследователей»:
Utility_новая = 1.0 × 0.8 × 1.0 × 1.5 = 1.2
3.0 > 1.2 → всё ещё остаётся (навык слишком высок)

Если Анна — новичок (навык = 5):
Utility_остаться = 5 × 0.05 = 0.25
0.25 < 1.2 → уходит в исследователи
```

## 📰 Вакансии как информация

### Принцип

> Вакансии распространяются **как информация по торговым путям**. Гражданин переезжает туда, где **знает о вакансии**, а не туда, где она теоретически есть.

### Механика

```
1. Работодатель (кузнец, поле, храм) создаёт вакансию
2. Вакансия = запись в «доске объявлений» региона
3. Вакансия распространяется:
   - Внутри поселения: мгновенно (все видят)
   - Между поселениями: через торговые пути (скорость = скорость каравана)
   - Через дипломатов: при посольстве (Q-006)
4. Гражданин видит только те вакансии, до которых дошла информация
5. Переезд = если Utility_новой > Utility_текущей + стоимость_переезда
```

### Связь с Q-006 (AI соседей)

Торговые пути выполняют **двойную функцию**:
1. Перевозка товаров (ресурсы)
2. Перевозка информации (вакансии + технологии через диффузию)

Это **не новая механика** — подключение существующей (Принцип 14). Торговля уже распространяет технологии (через культурный шок из GDD раздел 15). Теперь она же распространяет вакансии.

## 🏫 Институт-наборщик для исследователей

### Проблема

> Из Q-003 дискуссии: «Если в исследователи идут те, у кого случайно высокое "любопытство" — наука становится лотереей. В 10 000 до н.э. никто не выберет "исследователя" по зову сердца, когда надо охотиться».

### Решение

> Жречество / академия **сами приглашают** тех, у кого навык и склонность высокие. Склонность = шанс быть выбранным, а не путь по жизни.

### Механика

| Эпоха | Институт-наборщик | Что делает |
|---|---|---|
| Палеолит / Неолит | Жречество (T-009) | Жрецы замечают любопытных молодых → приглашают в храм |
| Бронза / Железо | Храм + писцы (T-036) | Писцы замечают способных → приглашают |
| Античность+ | Университет (T-085) | Университет набирает студентов |

### Процесс

```
1. Институт сканирует население на «склонность к знанию»
   (склонность = врождённая, не обучаемая — small random factor)
2. Если склонность > порог → институт делает предложение
3. Гражданин принимает (если ценности племени = «Знание» > 0.5)
4. Гражданин становится исследователем (навык = 0, растёт через практику)
```

> **Склонность = шанс быть выбранным, не путь по жизни.** Гражданин не выбирает «быть исследователем» — его выбирает институт. Это убирает «науку как лотерею».

## 🏗️ Общественные работы (основной механизм занятости)

### Принцип

> Игрок включает проект → безработные в нём задействуются → получают зарплату из казны → результат остаётся.

### Список проектов общественных работ

| Проект | Что даёт | Технология | Стоимость |
|---|---|---|---|
| 🛤️ Строительство дороги | +логистика, +миграция | T-020 | Дерево, камень, труд |
| 🏛️ Строительство храма | +легитимность, +жречество | T-041 | Камень, труд |
| 🧱 Строительство стены | +защита | T-013 | Кирпич, труд |
| 🌾 Расчистка полей | +сельхоз угодья | T-015 | Труд |
| 🏗️ Террасирование | +сельхоз на горах | T-015 + T-016 | Камень, труд |
| 🏗️ Ирригационный канал | +урожай | T-016 | Труд |
| 🏛️ Пирамида / монумент | +легитимность, +культура | T-070 | Камень, труд (много!) |

### Механика

```
1. Игрок выбирает проект из списка
2. Проверка: казна достаточна? Ресурсы есть?
3. Проект создаёт N вакансий (зависит от масштаба)
4. Безработные граждане региона направляются на проект
5. Зарплата = из казны (расход)
6. По завершении — результат остаётся (дорога, храм, стена)
```

### Историческое обоснование

> Античные общественные работы, строительство пирамид как механизм занятости. Уже упоминалось в GDD в списке мер перераспределения.

## 💰 Налог на безработицу (крайний случай)

### Принцип

> **Крайний рычаг** с тяжёлыми последствиями. Мягко → жёстко: общественные работы (основной) → налог (крайний).

### Механика

| Параметр | Значение |
|---|---|
| Эдикт | «Налог на безработицу» (вкл/выкл) |
| Эффект | −счастье безработных, +казна |
| Цена | **−счастье**, **+риск мятежа** (обида фракций Q-005) |
| Исторический аналог | Средневековые законы о бродяжничестве |

### Когда использовать

- Общественные работы **невозможны** (нет ресурсов / нет проектов)
- Безработица критическая (>30% населения)
- Игрок готов к риску мятежа

> **Принцип 9**: не закрываем путь. Налог существует как крайний рычаг — игрок может, но платит. (B откатила свой ❌ по этому вопросу в round_04, согласившись что спектр «мягко → жёстко» усиливает Принцип 9.)

## 🚫 3 якоря против вымирания городов

### Проблема

> Из Q-003: «как избежать вымирания городов (все уходят в столицу)?»

### Решение: 3 эмерджентных якоря (без запретов)

| Якорь | Механика | Эффект |
|---|---|---|
| 💰 **Стоимость переезда** | Переезд = деньги на дорогу + расстояние + потеря местной специализации | Если разница в привлекательности не покрывает стоимость — не едут |
| ⛏️ **Специализация у ресурса** | Кузнец не уедет от руды (ему негде работать в столице) | Ремесленники привязаны к ресурсам региона |
| 🌍 **География = судьба** | Если ресурсы региона истощились → столица пустеет сама | Это правильно — истощение = отток |

### Формула переезда

```
Переезд = Utility_новый_город − Utility_текущий_город − Стоимость_переезда

где:
  Стоимость_переезда = деньги_на_дорогу + расстояние × коэффициент + потеря_специализации

Если Переезд > 0 → гражданин переезжает
Если Переезд ≤ 0 → остаётся
```

### Дополнительные рычаги (из GDD)

| Эдикт | Эффект |
|---|---|
| «Ограничить отток из столицы» | +стоимость переезда (мягко) |
| «Поощрять освоение новых земель» | Премия за переезд в пустующий регион |

## 🧊 Палеолитный тест (Принцип 13)

| Элемент | Работает в 10 000 до н.э.? | Условие включения |
|---|---|---|
| 3 слоя (нужды × ценности × навык) | ✅ Да | С первого хода |
| Вакансии внутри поселения | ✅ Да | С первого хода (устно) |
| Вакансии между поселениями | ✅ Да | Через торговые пути (T-060a / караван) |
| Институт-наборщик | ✅ Да | T-009 (мифология → жречество) |
| Общественные работы | ✅ Да | С первого хода (расчистка полей, постройка хижин) |
| Налог на безработицу | ✅ Да | С первого хода (но крайний случай) |
| 3 якоря против вымирания | ✅ Да | С первого хода |

> **Палеолит**: жители сами выбирают между охотой и собирательством (по нуждам и ценностям племени). Вакансии = «нужен охотник на крупную дичь». Общественные работы = «расчистка стоянки». Без дорог между поселениями — миграция ограничена.
