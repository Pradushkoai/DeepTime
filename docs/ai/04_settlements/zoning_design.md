# D-002: Зонирование локальной карты — Спецификация

> 📋 **Спецификация D-002** — как работает размещение зданий в поселении. Игрок строит инфраструктуру (точечные объекты), здания кластеризуются вокруг автоматически.
>
> **Основано на**: Q-002 (зонирование). См. `discussions/consensus.md` → Вопрос 01.

---

## 🎯 Обзор

Игрок **НЕ рисует зоны**. Вместо этого:
1. Игрок строит **точечные объекты инфраструктуры** (дорога, колодец, причал, склад)
2. Здания **сами кластеризуются** вокруг инфраструктуры по правилам предпочтения
3. Игрок видит результат через **overlay-heatmap** (отображение, не черчение)

**Принцип**: вождь не размечал кварталы — он приказывал строить дорогу, порт, склад. Дальше город рос сам. Один рычаг (инфраструктура) вместо четырёх систем (зонирование + миграция + фракции + собственность).

---

## 📐 Три источника якорей

Якорь = точка притяжения для зданий. Здания кластеризуются вокруг якорей.

| Источник | Примеры | Доступ с | Как снимается |
|---|---|---|---|
| 🏞️ **Природный** | река, пещера, угодья, скала | Первый ход | ❌ Нельзя (рельеф) |
| ⛪ **Объявленный** | священная роща, некрополь, территория племени | Первый ход | Только игроком, с ценой |
| 🏗️ **Построенный** | дорога, колодец, причал, склад, стена | По технологиям | Физически разрушается |

### Ключевое различение

> **Объявление — социальный акт** (нужен авторитет вождя, не технология).
> **Постройка — инженерный акт** (нужна технология и ресурсы).

Племя всегда вправе объявить рощу священной — для этого не нужна ни одна технология, нужен авторитет. А дорогу построить нельзя, пока нет T-020 (деревообработка).

## 🏞️ Природные якоря

### Список природных якорей

| Якорь | Что притягивает | Радиус | Источник |
|---|---|---|---|
| 💧 Вода (река, ручей, озеро) | Жильё, кузница (нужна вода), гончарня, мельница | 3-5 гексов | `WaterAccess` поле гекса |
| 🕳️ Пещера / скальный навес | Жильё (укрытие), святилище | 2-3 гекса | `TerrainType` поле гекса |
| 🌳 Лес (строительный) | Деревообработка, лесопилка | 3-5 гексов | `Flora` поле гекса |
| 🪨 Выход камня | Каменотёсная мастерская, каменоломня | 2-3 гекса | `Minerals` поле гекса |
| 🐃 Охотничьи угодья | Охотничий лагерь, коптильня | 5-10 гексов | `Fauna` поле гекса |
| 🌾 Плодородная почва | Поля, сады | 3-5 гексов | `Fertility` поле гекса (см. `soils/index.md`) |
| 🏖️ Берег моря | Причал, рыболовная станция, солеварня | 2-3 гекса | `WaterAccess` + `Coastal` поле гекса |

### Как работают

- Природные якоря **существуют с первого хода** — их не нужно строить или объявлять
- Они **автоматически** притягивают здания по правилам предпочтения
- Их **нельзя убрать** — это рельеф местности
- В палеолите (10 000 до н.э.) природные якоря — **единственный** источник кластеризации (Принцип 13 ✅)

## ⛪ Объявленные якоря

### Список объявленных якорей

| Якорь | Что притягивает / отталкивает | Доступ | Цена объявления | Цена снятия |
|---|---|---|---|---|
| 🌲 Священная роща | Святилище, алтарь (притягивает); кузница, лесопилка (отталкивает) | Первый ход | Политический капитал | −легитимность, +обида жречества |
| ⚰️ Некрополь / захоронение | — (отталкивает жильё) | Первый ход | — | −легитимность, +обида всех |
| 🏕️ Территория племени | Граница поселения | Первый ход | — | Потеря территории |
| 🕯️ Святилище | Храм (притягивает); кузница (отталкивает) | T-009 (мифология) | — | −легитимность, +обида жречества |

### Механика объявления

1. Игрок выбирает точку на карте
2. Эдикт «Объявить священной рощей» (тратит политический капитал)
3. Точка становится **объявленным якорем** — защищена от застройки
4. AI-жители **не могут** строить на этой точке

### Механика снятия

1. Игрок выбирает объявленный якорь
2. Эдикт «Снять статус священной рощи»
3. Цена: **−легитимность** (вождь посягнул на святое) + **+обида жречества** (фракция Q-005)
4. Точка освобождается — AI может строить

> **Принцип**: защита по умолчанию. Игрок не получает popup «кузнец хочет снести святилище» — святилище просто защищено. Снос — осознанное решение игрока с ценой.

## 🏗️ Построенные якоря

### Список построенных якорей

| Якорь | Технология | Что притягивает | Радиус | Ресурсы для постройки |
|---|---|---|---|---|
| 🛤️ Дорога | T-020 (деревообработка) | Все (торговля, миграция, логистика) | Вдоль линии | Дерево, камень |
| 🕳️ Колодец | T-010 (керамика) + T-013 (кирпич) | Жильё (питьевая вода) | 2-3 гекса | Камень, кирпич |
| ⚓ Причал | T-060a (вёсельное мореплавание) | Рыболовство, торговля, верфь | 2-3 гекса | Дерево |
| 🏪 Склад | T-012 (глинобитное строительство) | Ремесло, торговля (хранение) | 2-3 гекса | Глина, дерево |
| 🧱 Стена | T-013 (обожжённый кирпич) | Жильё (защита), военные | Вдоль линии | Кирпич, камень |
| 🌉 Мост | T-020 (деревообработка) + T-022 (колесо) | Торговля, миграция | Через реку | Дерево |
| ⛴️ Переправа | T-060a (вёсельное мореплавание) | Торговля через реку | Через реку | Дерево |
| 🏛️ Рыночная площадь | T-043 (города) | Торговля, ремесло | 3-5 гексов | Камень, кирпич |

### Механика постройки

1. Игрок выбирает точку/линию на карте
2. Проверка: технология доступна? Ресурсы есть?
3. Если да — размещается **чертновик** (blueprint)
4. AI-строители берутся за работу по приоритету
5. Построенный якорь начинает притягивать здания

### Механика разрушения

- Построенные якоря можно **физически разрушить** (враг, пожар, эдикт сноса)
- При разрушении — здания вокруг теряют якорь → могут деградировать / заброситься
- Цена разрушения: только ресурсы (нет политической цены, в отличие от объявленных)

## 🏠 Правила предпочтения зданий

Каждый тип здания имеет **правила предпочтения** — где AI ставит его с наибольшим приоритетом.

### Структура правила

```yaml
building: "Кузница"
preferences:
  - condition: "near_water"        # у воды (охлаждение)
    weight: +5
  - condition: "near_ore"          # рядом с рудой
    weight: +8
  - condition: "near_road"         # у дороги (логистика)
    weight: +3
  - condition: "near_fuel"         # рядом с древесным углём
    weight: +5
  - condition: "not_near_housing"  # не у жилья (пожар, шум)
    weight: -5
  - condition: "not_near_shrine"   # не у святилища
    weight: -10
```

### Таблица правил для ключевых зданий

| Здание | Притягивается к | Избегает | Технология |
|---|---|---|---|
| 🏠 Жильё | Вода, склад, стена (защита), дорога | Кузница (пожар), некрополь | T-003 (обогрев) |
| 🔨 Кузница | Вода, руда, древесный уголь, дорога | Жильё (пожар), святилище | T-050 (медь) / T-058 (железо) |
| 🏺 Гончарня | Вода, глина, дорога | — | T-010 (керамика) |
| 🌾 Поле | Плодородная почва, вода | Тень леса | T-015 (земледелие) |
| 🐄 Пастбище | Трава (степь), вода | Лес (хищники) | T-030 (скотоводство) |
| ⛪ Храм | Святилище, высокая точка (холм) | Кузница, рынок (шум) | T-041 (религия) |
| 🏪 Рынок | Дорога, перекрёсток, причал | Святилище | T-043 (города) |
| ⚔️ Казарма | Стена, дорога, arsenал | Храм (мирное место) | T-073 (катапульта → военная специализация) |
| 🏥 Больница | Вода, дорога | Кузница (грязь) | T-092 (наука → медицина) |
| 📚 Школа / Университет | Храм (близость к знанию), дорога | Казарма (шум) | T-085 (университеты) |

### Алгоритм размещения

```
Для каждого нового здания:
  1. Определить тип здания
  2. Получить правила предпочтения для этого типа
  3. Для каждого свободного гекса в радиусе поселения:
     а. Вычислить score = сумма весов всех подходящих условий
     б. Учесть неприкосновенные объекты (объявленные якоря) — исключить
  4. Выбрать гекс с максимальным score
  5. Если score < порог → здание не строится (нет подходящего места)
  6. Разместить здание
```

## 📍 Черновики (Blueprints)

### Принцип

> Игрок может поставить **чертновик** здания — точечный контроль без рисования зон. Строители построят по приоритету, когда дойдут руки.

### Механика

1. Игрок выбирает тип здания (например, «казарма»)
2. Игрок выбирает точку на карте → размещается **чертновик** (полупрозрачная иконка)
3. AI-строители видят чертновик в очереди задач
4. Строят по приоритету (ресурсы + рабочая сила)
5. Когда построено — чертновик заменяется зданием

### Преимущества

- Игрок **не рисует зоны**, но может заказать конкретное здание
- Исторически достоверно: вождь приказывает «построить казарму у ворот»
- Не противоречит концепции вождя-тренда (директива, не микроконтроль)
- Из Dwarf Fortress — ровно тот микрокарман, который фанаты city-builder требуют

### Ограничения

- Черновик **не гарантирует** постройку — нужны ресурсы и рабочая сила
- AI-строители могут отложить чертновик, если есть более приоритетные задачи
- Игрок видит очередь чертновиков и может менять приоритет

## 🗺️ Визуальный Overlay

### Принцип

> Overlay = **отображение** сложившейся структуры, а не черчение. Игрок читает, но не рисует.

### Типы overlay

| Overlay | Что показывает | Когда включать |
|---|---|---|
| 🌡️ **Heatmap кластеров** | Где плотность кузниц / жилья / храмов | Для планирования инфраструктуры |
| 📍 **Якоря** | Все якоря (природные, объявленные, построенные) с радиусами | Для понимания притяжения |
| 🚫 **Неприкосновенные** | Защищённые точки (святилища, некрополи) | Перед сносом |
| 📋 **Чертновики** | Размещённые, но не построенные здания | Для управления очередью |
| 🔄 **Давление застройки** | Где AI хочет строить (где score высокий) | Для прогноза роста |

## ⚠️ Принудительное размещение (кузница в жилой зоне)

### Принцип

> Не запрещать, а **взимать цену**. Игрок может поставить кузницу в жилой зоне, но платит последствиями.

### Механика

1. Игрок размещает чертновик кузницы в жилой зоне (вопреки правилам предпочтения)
2. Система предупреждает: «⚠️ Кузница в жилой зоне: −довольство, +риск пожара»
3. Игрок подтверждает → здание строится
4. Эффекты:
   - **−довольство** жителей рядом (шум, дым)
   - **+риск пожара** (искры от кузницы)
   - Со временем — жители могут **переехать** (миграция Q-003)

### Историческое обоснование

> Средневековые города регулярно горели от кузнечных мастерских. Это исторически достоверно — игрок может, но платит.

## 🧊 Палеолитный тест (Принцип 13)

| Элемент | Работает в 10 000 до н.э.? | Условие включения |
|---|---|---|
| Природные якоря | ✅ Да | С первого хода |
| Объявленные якоря | ✅ Да | С первого хода (нужен авторитет, не технология) |
| Построенные якоря | ❌ Нет | По технологиям (T-010, T-012, T-013, T-020, T-060a, T-043) |
| AI-кластеризация | ✅ Да | С первого хода (вокруг природных + объявленных) |
| Черновики | ✅ Да | С первого хода (хижина, костёр) |
| Overlay | ✅ Да | С первого хода (минимальный — только природные якоря) |
| Принудительное размещение | ✅ Да | С первого хода |

> **Палеолит**: игрок видит природные якоря (река, пещера), может объявить священную рощу, ставит чертновики хижин. Здания кластеризуются у воды. Построенные якоря появляются с T-010/T-012/T-020.
