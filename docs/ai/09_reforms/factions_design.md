# D-004: Баланс фракций — Спецификация

> 📋 **Спецификация D-004** — социальные группы в обществе: эмерджентное появление, явные повестки, скрытые связи, сила от демографии, обида как накопитель.
>
> **Основано на**: Q-005 (фракции). См. `discussions/consensus.md` → Вопрос 03.

---

## 🎯 Обзор

В обществе есть группы (фракции) с собственными интересами. Они **появляются эмерджентно** по мере развития общества (3→5→7→9), имеют **явные повестки** (видны игроку) и **скрытые связи** (разведываются). Сила привязана к демографии и богатству. Обида копится, переживает вождя.

**Принцип**: драма рождается из **видимых конфликтов интересов**, которые игрок разведывает, а не из сюрпризов. Скрытые повестки = фрустрация (отклонено в round_02). Скрытые связи = заработанная драма (принято).

## 📊 Эмерджентное появление фракций

> ⚠️ **Принцип 13 (Палеолитный тест)**: в 10 000 до н.э. нет «торговцев» и «учёных» как института. Фракции появляются со специализацией.

### Шкала появления

| Эпоха | Фракции | Кол-во | Условие появления |
|---|---|---|---|
| 🪨 Палеолит | 🏹 Охотники / 🙏 Жречество / 👴 Старейшины | 3 | Старт (с первого хода) |
| 🌾 Неолит | + 🌾 Земледельцы / 🔨 Ремесленники | 5 | T-015 (земледелие) / T-020 (деревообработка) |
| ⛏️ Бронза | + 💰 Купцы / ⚔️ Военная элита | 7 | T-100 (монеты) / T-023 (колесница → военная специализация) |
| 🏛️ Античность | + 📋 Чиновники / 📚 Учёные | 9 | T-043 (города → бюрократия) / T-085 (университеты) |

### Механика появления

```
1. Игрок открывает технологию (например, T-015 Земледелие)
2. Часть населения начинает заниматься земледелием
3. Когда земледельцев > 10% населения → появляется фракция «Земледельцы»
4. Фракция получает базовую силу = доля населения × доля богатства
5. С этого момента игрок видит фракцию в UI
```

### Палеолитный старт

| Фракция | Кто входит | Повестка |
|---|---|---|
| 🏹 **Охотники** | Охотники, собиратели | +охотничьи угодья, +традиция, −земледелие |
| 🙏 **Жречество** | Шаманы, жрецы | +ритуалы, +традиция, −инновации |
| 👴 **Старейшины** | Пожилые, опытные | +стабильность, +традиция, −реформы |

## 🎯 Явные повестки

> Каждая фракция имеет **явную повестку** — видимую игроку с момента появления.

### Структура повестки

```yaml
faction: "Жречество"
overt_agenda:
  priorities:
    - issue: "ритуалы"
      stance: "increase"      # увеличить
      weight: 0.9
    - issue: "традиция"
      stance: "increase"
      weight: 0.8
    - issue: "инновации"
      stance: "decrease"      # уменьшить
      weight: 0.7
    - issue: "земля_храма"
      stance: "increase"      # больше земли храму
      weight: 0.6
  ultimatum_threshold: 80    # при силе >80 → ультиматум
```

### Таблица повесток (9 фракций)

| Фракция | Хочет | Против | Приоритетный ресурс |
|---|---|---|---|
| 🏹 Охотники | +угодья, +традиция | −земледелие, −прогресс | Охотничьи угодья |
| 🙏 Жречество | +ритуалы, +традиция, +земля_храма | −инновации, −светская власть | Священные места |
| 👴 Старейшины | +стабильность, +традиция | −реформы, −молодёжь | Совет/влияние |
| 🌾 Земледельцы | +земля, +ирригация, +стабильность | −налоги, −милитаризм | Плодородная земля |
| 🔨 Ремесленники | +заказы, +специализация, +прогресс | −традиция, −налоги | Ресурсы для ремесла |
| 💰 Купцы | +торговля, +мир, +прибыль | −война, −изоляция | Торговые пути |
| ⚔️ Военная элита | +война, +слава, +налог_на_войну | −мир, −торговля | Военная добыча |
| 📋 Чиновники | +бюрократия, +порядок, +налоги | −хаос, −коррупция | Административные посты |
| 📚 Учёные | +знание, +реформы, +просвещение | −традиция, −религия | Университеты/школы |

> **Принцип 14**: «приоритетный ресурс» — O(n), не O(n²). Каждая фракция имеет ОДИН приоритетный ресурс. Конфликт возникает там, где приоритеты двух фракций сталкиваются на одном объекте (например, жречество и купцы спорят за землю у храма — земля = приоритетный ресурс жречества, торговая точка = купцов).

## 🔍 Скрытые связи

> ⚠️ **Скрытые ПОВЕСТКИ отклонены** (фрустрация). **Скрытые СВЯЗИ приняты** (заработанная драма через разведку).

### Принцип

У каждой фракции:
- **Явная повестка** — видна сразу
- **Скрытые связи** — с другими фракциями и внешними силами. Игрок **разведывает** их.

### Типы скрытых связей

| Тип связи | Пример | Как разведать |
|---|---|---|
| 💰 **Финансовая** | «Жречество тайно получает золото от купцов» | Шпионаж (Q-006 уровень 2+) |
| 🤝 **Коалиция** | «Военные и жречество договорились о поддержке» | Дипломатия (посольство) |
| 🗡️ **Вендетта** | «Ремесленники ненавидят чиновников за налоги» | События (бунт → раскрытие) |
| 🌍 **Внешняя** | «Жречество получает поддержку от соседнего храма» | Разведка (Q-006 уровень 3+) |

### Механика разведки

```
1. Игрок видит явную повестку фракции (с первого хода)
2. Скрытые связи НЕ видны (показаны как «???»)
3. Игрок инвестирует в шпионаж/дипломатию → шанс раскрыть связь
4. При раскрытии → связь становится видимой → игрок может действовать
5. Действие: контр-дипломатия, подкуп, реформа, репрессии
```

## 💪 Сила фракции

### Принцип

> Сила **НЕ произвольный параметр**. Базовая сила = доля населения + доля богатства. Эдикты/события дают отклонение.

### Формула

```
базовая_сила = (доля_населения × 0.6) + (доля_богатства × 0.4)

фактическая_сила = базовая_сила + отклонение_от_эдиктов + отклонение_от_событий

где:
  доля_населения = население_фракции / общее_население (0.0-1.0) × 100
  доля_богатства = богатство_фракции / общее_богатство (0.0-1.0) × 100
  отклонение_от_эдиктов = ±5-15 (покровительство / репрессии)
  отклонение_от_событий = ±10-20 (война, голод, реформа)
```

### Шкала силы

| Сила | Статус | Эффект |
|---|---|---|
| 0-20 | Маргинальная | Влияет мало, игнорируется |
| 20-50 | Средняя | Учитывается в решениях |
| 50-80 | Сильная | Определяет политику |
| 80-100 | Доминирующая | Ультиматум (см. §6) |

### Источники изменения силы

| Источник | Эффект | Пример |
|---|---|---|
| **Покровительство** (эдикт) | +5-15 | «Поддержать ремесленников» → +10 |
| **Репрессии** (эдикт) | −10-20 | «Запретить жречество» → −15 |
| **Война** (событие) | +20 военным, −10 купцам | Война = усиление военных |
| **Голод** (событие) | +10 земледельцам, −10 всем | Кризис = усиление кормильцев |
| **Технология** | ±5-15 | Книгопечатание → +15 учёным, −10 жречеству |
| **Демография** | Автоматически | Рост населения фракции → рост силы |

## 😡 Обида как накопитель

### Принцип

> **Сила = способность действовать. Обида = готовность действовать ПРОТИВ тебя.** Слабая, но бешеная фракция опасна в кризис; сильная, но довольная — нет.

> **Обида переживает вождя** (не сбрасывается при смене — иначе порочный стимул). Обида убывает (покаяние, компенсация, время), но не сбрасывается.

### Разделение доменов

| Домен | Что | Переживает вождя? |
|---|---|---|
| **Обида фракций** (внутренний) | Между фракциями и вождём | ✅ Да (убывает, не сбрасывается) |
| **Память племени** (внешний) | Между цивилизациями | ✅ Да (вендетты 150 лет — Q-006) |

### Источники обиды

| Действие | Обида | Кого |
|---|---|---|
| Игнорирование фракции (10 лет) | +5/год | Игнорируемая фракция |
| Репрессии против фракции | +20-30 | Репрессируемая |
| Налог на фракцию | +10-15 | Налогоплательщик |
| Отстранение наследника (D-001) | +30 | Родовій клан |
| Снос священной рощи (D-002) | +20 | Жречество |
| Нарушение договора | +25 | Все |

### Источники убывания обиды

| Действие | Снижение | Цена |
|---|---|---|
| **Покаяние** (официальное извинение) | −20 | −легитимность |
| **Компенсация** (ресурсами/привилегиями) | −15 | Из казны |
| **Время** (без новых обид) | −2/год | Бесплатно (медленно) |
| **Смена вождя** | 0 (НЕ сбрасывается!) | — |
| **Реформа в пользу фракции** | −10 | Политический капитал |

### Шкала обиды

| Обида | Статус | Эффект |
|---|---|---|
| 0-20 | Довольна | Сотрудничает |
| 20-50 | Недовольна | Сопротивление реформам |
| 50-80 | Зла | Саботаж, скрытые интриги |
| 80-100 | В ярости | Мятеж в кризис (см. §7) |

> ⚠️ **Обида ≠ Сила**. UI обязан показывать их **раздельно** (условие из Q-003 дискуссии). Игрок видит:
> - Сила = ████░░ 65/100 (способность действовать)
> - Обида = ██░░░░ 30/100 (готовность против тебя)

## ⚠️ Ультиматум при силе >80

### Принцип

> При силе >80 фракция **доминирует** — выдвигает ультиматум. Игрок выбирает из 3 вариантов.

### 3 варианта

| Вариант | Что происходит | Цена |
|---|---|---|
| ✅ **Согласиться** | Фракция получает своё (повестка выполняется) | Остальные фракции −сила, −счастье |
| ⚔️ **Подавить** | Нужно суммарная поддержка остальных > доминирующей | Иначе мятеж |
| 🤝 **Разделить** | Эдикт, создающий конкурента (раскол) | −политический капитал, но решает проблему |

### «Разделить» — исторически самый богатый вариант

| Пример | Что | Эффект |
|---|---|---|
| Раскол церкви | Жречество → светское + духовное | Две фракции по 40 силы |
| Схизма | Жречество → ортодоксы + реформаторы | Две фракции, конфликт между ними |
| Реформа армии | Военные → регулярные + наёмники | Две фракции, разная лояльность |

### Механика ультиматума

```
1. Фракция достигает силы >80
2. Событие: «[Фракция] выдвигает ультиматум: [повестка]»
3. Игрок выбирает: Согласиться / Подавить / Разделить
4. Если Подавить и поддержка остальных < доминирующей → мятеж
5. Если Разделить → создаётся новая фракция-конкурент
6. Ультиматум снимается (сила снижается через раздел или реформу)
```

## 🔥 Мятеж в кризис

### Принцип

> Обида + кризис = мятеж. Фракция с обидой >80 и в момент кризиса (голод, поражение, давление вождя >90) → восстает.

### Механика

```
1. Проверка каждый год:
   IF обида_фракции > 80 AND кризис_активен THEN
     шанс_мятежа = (обида - 80) × кризис_множитель
   
2. Кризисные множители:
   - Голод: ×2.0
   - Поражение в войне: ×1.5
   - Давление вождя >90 (D-001): ×1.5
   - Смена вождя (кризис преемственности): ×3.0
   
3. Если мятеж →:
   - Фракция поднимает восстание
   - Часть населения уходит к мятежникам
   - Игрок: подавить (армия) или уступить (реформа)
```

### ⚠️ Предохранитель спиралей (R9, v0.29)

> 📋 **Из аудита Модели B (R9, И-6)**: смена вождя: наследник получает 50% давления × мятеж ×3.0 при смене вождя × реформы в эре DECLINING ослаблены = тройной удар по управляемости именно тогда, когда нужно проводить адаптацию. Произведение трёх множителей — фрустрация.

**Правило max вместо произведения** (паттерн уже принят в D-010 «правило min()»):

> При смене вождя кризисный множитель берётся как **max** всех активных, а не произведение.

```
Старый дизайн (❌ произведение):
  шанс_мятежа = (обида - 80) × ×3.0 (смена вождя) × ×2.0 (голод) × ×1.5 (давление вождя)
  = (обида - 80) × 9.0 — фрустрация

Новый дизайн (✅ max):
  шанс_мятежа = (обида - 80) × max(×3.0, ×2.0, ×1.5)
  = (обида - 80) × 3.0 — управляемо
```

**Обоснование**: тот же паттерн, что в D-010 «один множитель (максимальный), не произведение». Применяется только при смене вождя (т.к. именно тогда умножение создаёт спираль смерти). В обычных кризисах — множители складываются (как раньше), не умножаются.

**Связь**: D-001 (правки R9 — выбор при наследовании давления), D-016 (предохранители спиралей в генераторе событий).

## 📊 Сводка спецификации

| Элемент | Решение |
|---|---|
| Появление | Эмерджентное (3→5→7→9 по технологиям) |
| Повестки | Явные (видны сразу) |
| Скрытое | СВЯЗИ (разведываются), не повестки |
| Сила | От демографии (60%) + богатства (40%) + модификаторы |
| Обида | Накопитель, переживает вождя, убывает (не сбрасывается) |
| Домены | Обида = внутренний, память племени = внешний |
| Ультиматум >80 | 3 варианта (согласиться/подавить/разделить) |
| Мятеж | Обида >80 + кризис → восстание |
| Приоритетный ресурс | O(n) — одна фракция = один ресурс |
| UI | Сила и обида РАЗДЕЛЬНО |
