# D-011: Скорость перехода между стадиями — Спецификация

> 📋 **Спецификация D-011** — стадии развития общества. Стадия = отражение (не открывает, констатирует). 6 стадий от племени до индустриальной.
>
> **Основано на**: Q-015 (скорость перехода). См. `discussions/consensus.md` → Вопрос 12.
>
> ⚠️ **Проверено перед написанием**:
> - consensus.md → Вопрос 12 (стадия-отражение + 6 стадий + эмерджентность + пропуск невозможен + Q-017)
> - round_09: B предложила стадию-отражение (вместо рычага) — «Что открывает» дублирует дерево технологий
> - round_10: A принял полностью + подтвердил «пропуск невозможен»
> - Подтверждено: T-043 (города), T-041 (религия), T-130 (паровая машина) — открывают механики, не стадии

---

## 🎯 Обзор

Стадии развития общества — это **отражение**, а не рычаг. Стадия **ничего не открывает** — она констатирует факт. Открывают технологии и предпосылки. Стадия = подпись на панели прогресса: «Вы: Город».

> ⚠️ **B в round_09**: «В колонке "Что открывает" у тебя: специализация, администрация, законы/война, колонии, фабрики. Но всё это уже открывается деревом технологий. Две шкалы открывают одно и то же = двойная бухгалтерия.»

> ⚠️ **Принцип 14 (Тест на один справочник)**: не создаём вторую шкалу прогресса. Дерево технологий = единственный справочник того, что открыто. Стадия = подпись состояния.

## 📊 6 стадий

| # | Стадия | Подпись | Когда |
|---|---|---|---|
| 1 | 🏕️ **Племя** | «Вы: Племя» | Старт (10-30 человек) |
| 2 | 🏘️ **Поселение** | «Вы: Поселение» | 100+ человек + T-012 (глинобит) + земледелие/скотоводство |
| 3 | 🏛️ **Город** | «Вы: Город» | 1000+ + T-043 (города) + письменность |
| 4 | 🏰 **Государство** | «Вы: Государство» | 5000+ + T-041 (религия) + армия + налоги |
| 5 | 🏛️ **Империя** | «Вы: Империя» | 50000+ + T-070 (архитектура) + дороги |
| 6 | 🏭 **Индустриальная** | «Вы: Индустриальная цивилизация» | 100000+ + T-130 (паровая машина) |

### Стадия = отражение, НЕ рычаг

> ⚠️ **B в round_09**: «Стадия ничего не открывает — стадия отражает.»

| Что | Кто открывает | Стадия |
|---|---|---|
| Специализация (ремесло) | T-020 (деревообработка), T-050 (медь) | — |
| Администрация | T-041 (религия), T-043 (города) | — |
| Законы / война | T-043 + фракции (D-004) | — |
| Колонии | T-061 (колонизация) | — |
| Фабрики | T-130 (паровая машина) | — |
| Подпись «Вы: Город» | — | ✅ Это единственная функция стадии |

> Стадия = **этикетка** на панели прогресса. Не даёт ничего, кроме ощущения прогресса.

## 📋 Предпосылки для каждой стадии

> Стадия наступает **при выполнении всех предпосылок** — не по календарю (Принцип 9: эпохи = состояние, не время).

### Стадия 1: 🏕️ Племя (стартовая)

| Предпосылка | Значение |
|---|---|
| Население | 10-30 |
| Технологии | T-001..T-009 (стартовые) |
| Поселение | Стоянка (природные якоря) |

> Доступна с первого хода. Не требует выполнения — стартовая.

### Стадия 2: 🏘️ Поселение

| Предпосылка | Значение | Связь |
|---|---|---|
| Население | 100+ | D-003 (миграция / рост) |
| Технология | T-012 (глинобитное строительство) | D-002 (зонирование: построенный якорь) |
| Источник калорий | T-015 (земледелие) ИЛИ T-030 (скотоводство) | D-009 (альт. пути) |

> **Без земледелия ИЛИ скотоводства** → нет избытка пищи → нет постоянного поселения. Кочевое скотоводство (T-032) = альтернатива (стадия «Кочевая конфедерация», не «Поселение»).

### Стадия 3: 🏛️ Город

| Предпосылка | Значение | Связь |
|---|---|---|
| Население | 1000+ | Рост от избытка пищи |
| Технология | T-043 (города) | D-002 (зонирование: рыночная площадь) |
| Письменность | T-035 (пиктограммы) ИЛИ T-036 (клинопись) | D-001 (хроника с датами) |
| Собственность | Семья+ (D-006, ось КТО ≥ 1) | D-006 (переход от общины к семье) |

> **Без письменности** → нет учёта → нет администрации → нет города (только большое поселение).

### Стадия 4: 🏰 Государство

| Предпосылка | Значение | Связь |
|---|---|---|
| Население | 5000+ | Рост города |
| Технология | T-041 (религия → организованная) | D-004 (фракция жречества) |
| Армия | T-073 (катапульта → военная специализация) ИЛИ T-058 (ковка железа) | D-004 (фракция военных) |
| Налоги | T-100 (чеканка монет) ИЛИ зерновой налог | D-006 (собственность → институт) |
| Фракции | ≥5 (D-004: + купцы, + военная элита) | D-004 (эмерджентность) |

### Стадия 5: 🏛️ Империя

| Предпосылка | Значение | Связь |
|---|---|---|
| Население | 50000+ | Рост от государства |
| Технология | T-070 (монументальная архитектура) | D-002 (инфраструктура) |
| Дороги | T-020 (деревообработка) → дорожная сеть | D-002 (построенные якоря) |
| Территория | 2+ региона | D-005 (AI соседей: колонизация T-061) |
| Перенасыщение | <0.8 (D-005: институты держат) | D-005 (Тёрчин) |

### Стадия 6: 🏭 Индустриальная

| Предпосылка | Значение | Связь |
|---|---|---|
| Население | 100000+ | Рост от империи |
| Технология | T-130 (паровая машина) | D-001 (давление = адаптация) |
| Сталь | T-102 (Бессемер → массово) | D-006 (институт → фабрики) |
| Кокс | T-080 (коксование) | D-005 (торговля углём) |
| Институты | Бюрократия + экзамены (D-005) | D-005 (расширение ёмкости) |

## 🔄 Эмерджентность (не календарь)

> ⚠️ **Принцип 9**: эпохи = состояние, не календарь. Стадия наступает при выполнении предпосылок, не по расписанию.

### Принцип

```
Для каждой стадии:
  IF все_предпосылки_выполнены THEN
    стадия = новая
    событие: «Ваша цивилизация перешла к стадии: [название]»
  ELSE
    стадия = текущая (не меняется)
```

### Примеры

| Сценарий | Что происходит |
|---|---|
| 100 человек + T-012 + T-015 | → Стадия 2 (Поселение) ✅ |
| 100 человек + T-012, НО без T-015/T-030 | → Остаются Племенем (нет избытка пищи) |
| 5000 человек + T-043 + T-036, НО без армии | → Остаются Городом (нет Государства) |
| 50 человек + T-130 (читерство) | → Остаются Племенем (нет населения) |

> Рим стал империей при Августе — когда выполнились предпосылки, а не по календарю.

## 🚫 «Пропуск» невозможен

> ⚠️ **B в round_09**: «"Племя → сразу государство" нелогично: 5000 человек в одном месте с письменностью **и есть** город. Стадия — не веха, которую проходят, а факт, который констатируют. Пропустить факт нельзя.»

### Почему пропуск невозможен

```
Племя (10 чел.) → нужно 100+ для Поселения
  ↓ (рост населения — не может перескочить 100)
Поселение (100 чел.) → нужно 1000+ для Города
  ↓ (рост — не может перескочить 1000)
Город (1000 чел.) → нужно 5000+ для Государства
  ↓
Государство (5000 чел.) → ...
```

> Население растёт **постепенно**. Нельзя иметь 10 человек и вдруг 5000 — рост требует времени, еды, условий. Каждая стадия = **факт**, а не веха. Пропустить факт нельзя.

## ⚖️ Связь с Q-017 (давление вождя)

> ⚠️ **B**: «Переходы весят по-разному. Переход к городу и переход к индустрии — не одно давление на вождя. Ранжирование по значимости, числа — плейтестами (Принцип 2).»

### Веса переходов (направление, не числа)

| Переход | Значимость | Давление на вождя | Обоснование |
|---|---|---|---|
| Племя → Поселение | Среднее | +15 | Оседлость = изменение образа жизни |
| Поселение → Город | Высокое | +25 | Урбанизация = структурное изменение |
| Город → Государство | Высокое | +25 | Институализация = новая политическая система |
| Государство → Империя | Очень высокое | +35 | Экспансия = перенасыщение (D-005) |
| Империя → Индустриальная | Очень высокое | +40 | Индустриализация = переворот общества |

> ⚠️ **Принцип 2**: конкретные числа — на плейтестах. Сейчас фиксируем направление (среднее → очень высокое).

### Связь с D-001 (старение = непоглощённое изменение)

```
Переход стадии = изменение общества → +давление на вождя (D-001)

Если вождь провёл адаптацию (реформа 5 шагов) → давление поглощается
Если не провёл → давление растёт → вождь стареет → кризис

Пример:
  Переход Город → Государство (+25 давление)
  Реформа «учреждение администрации» → −15 (адаптация)
  Остаток: +10 давление (приемлемо)
```

## 🏘️ Альтернативная стадия: Кочевая конфедерация

> Из Q-005 (D-004) и D-009: кочевой путь развития не проходит через «Поселение» (нет оседлости).

| Стадия | Предпосылки | Что |
|---|---|---|
| 🐎 **Кочевая конфедерация** (вместо Поселения) | T-032 (кочевое скотоводство) + 100+ + лошадь | Государство без городов |

> Кочевая конфедерация = **альтернатива** Поселению. Скифы, гунны, монголы — государство без городов. Переход: Племя → Кочевая конфедерация → (далее может перейти к Государству через захват оседлого).
