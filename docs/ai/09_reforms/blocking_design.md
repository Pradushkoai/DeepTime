## 🎯 Обзор

«Блокировки эволюции» — это **НЕ отдельная механика**. Это **диагноз**: отображение причины замедления через уже существующие системы (фракции, ползунки, архетипы).

> ⚠️ **Принцип 14 (Тест на один справочник)**: у проекта уже есть 3 механизма, влияющих на скорость исследований — ползунки ценностей, архетипные модификаторы, сопротивление фракций. Добавлять 4-й = двойная бухгалтерия.

> ⚠️ **Паттерн «Диагноз, а не рычаг»** (от B): система объясняет, почему случилось замедление, а не создаёт новую механику. **Ограничение**: применяется только когда лечение дорогое.

## 🔍 Диагноз: как игрок видит замедление

> В слое видимости (D-007, категория «Прогресс») игрок видит:

### Структура диагноза

```
🔬 Прогресс
   Текущая технология: T-057 (сыродутный процесс)
   Скорость: ███░░░░ 30% от нормы ← ЗАМЕДЛЕНО

   ⚠️ Причины замедления:
      🙏 Жречество доминирует (сила 85) → −40%
      📜 Ползунок «Традиция» на 80 → −20%
      🏔️ Архетип «горно-долинный» → −10% к «чужому»

   Итоговый множитель: ×0.4 (максимальная причина)
   (НЕ ×0.6 × 0.8 × 0.9 = ×0.43 — см. §4)

   → [Реформа: ослабить жречество]
   → [Реформа: сдвинуть к Знанию]
```

### Принцип: подпись причины (из D-007)

> Каждый диагноз **обязан** показывать причину — не просто «замедлено», а «почему» и «что делать».

## 📊 3 случая снятия (B в round_11)

> ⚠️ **B**: «Выбор из двух вариантов (фракции или реформы) — ложная дилемма. Рычаг определяется причиной, а причина у диагноза всегда указана.»

| Диагноз (что видит игрок) | Где причина | Рычаг снятия | Цена |
|---|---|---|---|
| «Жречество доминирует, сила 85» | **Фракция** → D-004 | Ультиматум >80 → **разделить** | Политический капитал |
| «Ползунок Традиция на 80» | **Ценности** → D-001 | **Реформа** (5 шагов), НЕ слайдер | Коалиция ≥50% + время |
| «Архетип даёт −20% к чужому» | **Архетип** → GDD | **Не снимается — компенсируется** | 200 лет торговли + эдикты |

### Случай 1: Фракция доминирует

```
1. Игрок видит: «Жречество доминирует (сила 85) → −40% к науке»
2. Причина: фракция жречества (D-004) имеет силу >80
3. Рычаг: ультиматум >80 → «разделить» (D-004, §6)
4. Игрок разделяет жречество → две фракции по ~40 силы
5. Замедление снижается (нет доминанта >80)
```

### Случай 2: Ползунок смещён

> ⚠️ **B в round_11**: «Если ползунок — бесплатный слайдер, диагноз превращается в декорацию. Увидел → сдвинул → готово. Зачем диагноз?»

> ⚠️ **Разрешение B**: разделить **желаемое** и **достигнутое**.

```
1. Игрок видит: «Ползунок Традиция на 80 → −20% к науке»
2. Игрок задаёт ЦЕЛЬ: «Сдвигаем к Знанию» (прямой, дешёвый рычаг)
3. НО: фактический ползунок двигается С ЗАДЕРЖКОЙ:
   - Сопротивление фракций (жречество + старейшины против)
   - Архетип (горно-долинный = традиция по умолчанию)
4. Игрок проводит РЕФОРМУ (D-001, 5 шагов):
   - Идентификация → Коалиция ≥50% → Стратегия → Окно → Исход
5. После реформы → ползунок сдвигается (медленно, десятилетиями)
6. Приказ «будьте просвещёнными» ничего не меняет завтра
```

### Разделение «цель / достигнуто»

| Поле | Что | Игрок |
|---|---|---|
| **Цель** (желаемое) | Куда вождь хочет сдвинуть | Задаёт напрямую (дёшево) |
| **Текущее** (достигнутое) | Где общество реально находится | Двигается с задержкой (сопротивление) |
| **Разрыв** | Расстояние между целью и текущим | Виден в UI → причина замедления |

```
UI:
  Цель:     Знание ████████████░░░░ 80
  Текущее:  Знание ██████░░░░░░░░░░ 40
  Разрыв:   ████░░░░░░░░░░░░ 40 ← причина замедления

  «Общество сопротивляется сдвигу к Знанию:
   жречество (сила 65), архетип (горно-долинный = традиция)»
```

### Случай 3: Архетипная предрасположенность

> ⚠️ **B**: «Архетепную предрасположенность нельзя "устранить" — GDD: "через 200 лет торговли с приморскими соседями и через принудительные эдикты возможно сместить ценности". Это долгий путь, а не кнопка.»

```
1. Игрок видит: «Архетип горно-долинный → −20% к мореплаванию»
2. Причина: архетип (врождённый, не выбирается)
3. Рычаг: НЕ СНИМАЕТСЯ — компенсируется:
   - 200 лет торговли с приморскими соседями (D-005)
   - Принудительные эдикты (с сопротивлением фракций)
   - Реформы (D-001, 5 шагов)
4. Через 200 лет → ценности смещаются → штраф уменьшается
5. Полностью never не снимается — но компенсируется до приемлемого
```

> **Принцип 9**: нет неснимаемых блокировок. Но архетипные — **трудноснимаемые** (компенсируются, не снимаются). Сакоку длилась 220 лет, но снялась.

## 📐 Один множитель, не произведение

> ⚠️ **B в round_09**: «При 4 блокировках по −50%/−30% произведение ≈ −80% — наука встанет. Правило: одна причина — один множитель (берётся максимальный действующий), не произведение.»

### Правило

```
итоговый_множитель = min(все_действующие_множители)

НЕ: множитель1 × множитель2 × множитель3
ДА: max(замедление) — одна причина, один множитель
```

### Пример

```
Действующие причины:
  Жречество (сила 85) → ×0.6 (−40%)
  Ползунок Традиция 80 → ×0.8 (−20%)
  Архетип горно-долинный → ×0.9 (−10%)

❌ НЕПРАВИЛЬНО: 0.6 × 0.8 × 0.9 = 0.43 (−57% — наука почти встала)
✅ ПРАВИЛЬНО:   min(0.6, 0.8, 0.9) = 0.6 (−40% — замедлено, но работает)
```

> **Обоснование**: одна причина доминирует. Если жречество тормозит на 40%, ползунок на 20% не добавляет отдельного торможения — он уже учтён в силе жречества.

## 🚫 Нет неснимаемых блокировок

> ⚠️ **Принцип 9 (бесконечное развитие)**: нельзя закрывать путь.

| Тип блокировки | Снимаемость | Как |
|---|---|---|
| Фракция доминирует | ✅ Снимаема | Разделить (D-004) |
| Ползунок смещён | ✅ Снимаема | Реформа (D-001) |
| Архетипная | ⚠️ Трудноснимаема | Компенсируется (200 лет + эдикты + торговля) |

> Сакоку (изоляция Японии) длилась 220 лет — но снялась. Через цепочку реформ, не одним щелчком.

## ⚠️ Условие применения паттерна «Диагноз, а не рычаг»

> ⚠️ **B в round_11**: «Паттерн работает только там, где лечение дорогое. Если причина устранима бесплатно — диагноз не нужен, он станет украшением UI.»

### Когда применять

| Ситуация | Применять паттерн? | Почему |
|---|---|---|
| Лечение = реформа (5 шагов, ≥50% коалиции) | ✅ Да | Лечение дорогое → диагноз нужен |
| Лечение = разделить фракцию (политический капитал) | ✅ Да | Лечение дорогое → диагноз нужен |
| Лечение = 200 лет торговли | ✅ Да | Лечение очень дорогое → диагноз нужен |
| Лечение = сдвинуть ползунок (бесплатно) | ❌ Нет | Лечение бесплатное → диагноз = декорация |

> ⚠️ **Критическое правило**: ползунок НЕ бесплатный слайдер. Вождь задаёт **цель**, общество меняется с **задержкой** (сопротивление). Если лечение бесплатно — диагноз не нужен.
