# D-013: Туман войны и разведка — Спецификация

> 📋 **Спецификация D-013** — как игрок видит мир: туман войны, разведка территорий, обнаружение ресурсов.
>
> ⚠️ **Новая спецификация** — выявленная дыра (Принцип 12). В GDD описаны ресурсы (3 уровня) и иконки, но НЕ описаны туман войны, радиус видимости и механика разведки.
>
> **Основано на**: GDD (строки 126-175 — размер гекса, 3 уровня ресурсов, иконки) + D-005 (AI соседей, уровень 1 «Знают о вас»).
>
> ⚠️ **Проверено перед написанием**:
> - GDD: гекс = 50-100 км, сетка 360×180 = 64800 тайлов
> - GDD: ресурсы 3 уровней (поверхностные/подповерхностные/глубокие)
> - GDD: иконки затемнены без технологии, яркие с технологией
> - GDD: эмиссары/шпионы могут «разведать ресурсы»
> - D-005: уровень 1 «Знают о вас» = разведчик достиг границы

## 🎯 Обзор

Карта мира покрыта **туманом войны**. Игрок видит только то, что разведал. Радиус видимости — **маленький** (1-3 гекса), потому что гекс = 50-100 км.

Ресурсы открываются **поэтапно**: сначала поверхностные (при первом посещении), потом подповерхностные (геологическая разведка), потом глубинные (технологии).

**Принцип**: «ничто не появляется из воздуха» (GDD). Игрок не видит ресурсы в тумане. Граждане не трогают ресурс, пока не понимают, как его использовать.

---

## 🌫️ Туман войны — 3 состояния гекса

| Состояние | Что видно | Иконка | Как открыть |
|---|---|---|---|
| 🌫️ **Неизвестно** | Ничего — серый/чёрный гекс | — | Разведчик достигает гекса |
| 👁️ **Известно** | Рельеф, биом, реки, поверхностные ресурсы | Поверхностные — яркие; подповерхностные — скрыты | Разведчик побывал 1 раз |
| 🗺️ **Исследовано** | Все ресурсы (включая подповерхностные), фауна, флора, почвы | Все ресурсы видны (если технология позволяет) | Геологическая разведка + технологии |

### Переходы между состояниями

```
🌫️ Неизвестно
    ↓ Разведчик входит в гекс
👁️ Известно (поверхностные ресурсы видны)
    ↓ Геологическая разведка (эдикт + инструменты)
🗺️ Исследовано (все ресурсы видны)
```

> Возврата нет: однажды открытый гекс **не возвращается** в туман. Игрок мог забыть детали, но карта помнит.

## 📐 Радиус видимости

> ⚠️ **Гекс = 50-100 км.** Радиусы уменьшены — на такие расстояния не видно далеко.

### От поселений (пассивная видимость)

| Источник | Радиус | Обоснование |
|---|---|---|
| 🏕️ **Стоянка** (палеолит) | **1 гекс** | 50-100 км — уже далеко. С лагеря видно соседнюю территорию |
| 🏘️ **Поселение** (неолит) | **1-2 гекса** | Больше народа = больше разведки пешком |
| 🏛️ **Город** (бронза+) | **2-3 гекса** | Вышки, храмы, дальний обзор с высоты |
| 🏰 **Государство** | **2-3 гекса** | Стабильный обзор |
| 🏛️ **Империя** | **3 гекса** | Дороги + форпосты = дальше |

### От разведчиков (активная видимость)

| Разведчик | Радиус | Скорость | Технология |
|---|---|---|---|
| 🚶 **Пеший разведчик** | **1-2 гекса** | 1 гекс/ход | T-004 (оббивка — базовая) |
| 🐕 **С собакой** | **+1 гекс** | 1 гекс/ход | T-007 (собака — поиск) |
| 🐎 **Конный разведчик** | **2-3 гекса** | 2 гекса/ход | T-030 (скотоводство → лошадь) |
| ⛵ **Морская разведка (вёсельная)** | **2-3 гекса** | 2 гекса/ход (вдоль берега) | T-060a (вёсельное море) |
| ⛵ **Морская разведка (парусная)** | **3-4 гекса** | 3 гекса/ход (открытое море) | T-060b (парусное море) |
| 🧭 **Океанская экспедиция** | **4-5 гексов** | 3-4 гекса/ход | T-093 (компас) |

### Принцип радиуса

```
видимость_гекса = max(
  радиус_поселения (если гекс = или сосед поселения),
  радиус_разведчика (если разведчик в гексе или соседнем)
)

гекс = "Известно" если:
  - разведчик побывал в нём, ИЛИ
  - гекс в радиусе видимости поселения

гекс = "Исследовано" если:
  - геологическая разведка проведена (эдикт + время)
```

## 🔍 Обнаружение ресурсов

> ⚠️ **GDD (строка 160)**: ресурсы 3 уровней — поверхностные / подповерхностные / глубинные.

### 3 уровня + что нужно для видимости

| Уровень | Примеры | Что нужно для видимости | Что нужно для добычи |
|---|---|---|---|
| 🟢 **Поверхностные** | Кремень, обсидиан, самородная медь, дикие злаки, древесина, дичь, рыба | Гекс = 👁️ Известно | T-004 (оббивка) — базовая |
| 🟡 **Подповерхностные** | Глубокая глина, уголь (выходы), рудные жилы (обнажения), торф | Гекс = 🗺️ Исследовано + T-020 (инструменты) | T-020 (кирка, лопата) |
| 🔴 **Глубинные** | Железная руда, олово, свинец, цинк, драг. камни, глубокий уголь, нефть | Гекс = 🗺️ Исследовано + T-050+ (металлургия) | T-050/T-057 (шахты) + специализация |

### Принцип «технология = допуск к ресурсу» (GDD, строка 167)

> Граждане видят в локальной карте все ресурсы, которые там есть (визуально для игрока), но **доступны им только те, что они умеют использовать**.

### Иконки ресурсов (GDD, строка 169)

| Состояние иконки | Что значит | Когда |
|---|---|---|
| ⬜ **Затемнена/полупрозрачная** | Ресурс виден, но технология не открыта | Гекс исследован, технологии нет |
| 🟨 **Яркая, но «неизвестная»** | Ресурс виден, но граждане не знают, что это | Гекс известен, ресурс поверхностный |
| 🟩 **Яркая, активная** | Ресурс доступен — граждане добывают | Технология открыта + гекс исследован |
| ⬛ **Скрыта** | Ресурс не виден (туман или не исследовано) | Гекс в тумане ИЛИ не исследован |

### Цепочка открытия железа (пример из GDD)

```
1. Гекс в тумане → железо не видно
2. Разведчик входит в гекс → 👁️ Известно
   → Поверхностные ресурсы видны (кремень, дерево, вода)
   → Железная руда — подповерхностная → НЕ видна (нужно Исследовать)
3. Геологическая разведка → 🗺️ Исследовано
   → Железная руда видна, но иконка затемнена (нет T-057)
   → Граждане: «красивый камень»
4. Игрок открывает T-050 (медь) → T-052 (бронза) → T-057 (сыродутный процесс)
5. T-057 открыта → иконка железа становится яркой → граждане распознают руду
6. → Организуют лагерь добычи → плавят железо
```

## 🧭 Геологическая разведка

### Принцип

> Чтобы перейти от 👁️ Известно к 🗺️ Исследовано, нужна **геологическая разведка** — отдельное действие.

### Как работает

```
1. Гекс = 👁️ Известно (разведчик побывал)
2. Игрок даёт эдикт «Геологическая разведка [гекс]»
3. Назначает граждан (1-3 человека) → становятся «геологами»
4. Геологи идут в гекс → исследуют (1-5 игровых лет)
5. По завершении → гекс = 🗺️ Исследовано
   → Все ресурсы видны (если технология позволяет)
   → Фауна, флора, почвы catalogued
```

### Что нужно для геологической разведки

| Что | Технология | Зачем |
|---|---|---|
| Инструменты (кирка, лопата) | T-020 (деревообработка) | Копать, исследовать |
| Навык геологии | T-050 (медь → опыт работы с рудами) | Распознавать рудные жилы |
| Запас провизии | D-003 (миграция — еда) | Геологи в пути |

> ⚠️ **Палеолитный тест (Принцип 13)**: в 10 000 до н.э. геологической разведки НЕТ. Только поверхностные ресурсы видны при первом посещении (👁️ Известно). Геологическая разведка = с T-020 (неолит).

## 🌍 Разведка как действие

### Кого отправлять

| Юнит | Кто | Технология | Скорость |
|---|---|---|---|
| 🚶 **Разведчик-пешеход** | 1-3 гражданина | T-004 | 1 гекс/ход |
| 🐕 **С собакой** | 1-2 + собака | T-007 | 1 гекс/ход (+радиус) |
| 🐎 **Конный разведчик** | 1-2 всадника | T-030 (лошадь) | 2 гекса/ход |
| ⛵ **Морская экспедиция** | 3-5 моряков | T-060a/b | 2-3 гекса/ход |

### Что видит разведчик

| При входе в гекс | Что открывается |
|---|---|
| 🌫️ → 👁️ | Гекс становится «Известно» |
| Рельеф, биом, реки | Видно сразу |
| 🟢 Поверхностные ресурсы | Видно сразу |
| 🟡 Подповерхностные | Скрыты (нужно Исследовать) |
| 🔴 Глубинные | Скрыты |
| Фауна, флора | Базовая информация (виды) |
| Поселения других | Видно, если в гексе (D-005 уровень 1) |
| Армии других | Видно, если в гексе |

### Что НЕ видит разведчик

| Что | Почему |
|---|---|
| Подповерхностные ресурсы | Нужна геологическая разведка |
| Глубинные ресурсы | Нужна геологическая + технологии |
| Скрытые связи фракций (D-004) | Нужен шпионаж, не разведка |
| Силу AI-цивилизации | Нужен контакт (D-005 уровень 2+) |

## 🗺️ Масштабы видимости

### Глобальная карта (360×180 гексов)

```
┌───────────────────────────────────┐
│  🌫️🌫️🌫️  👁️👁️  🌫️🌫️🌫️🌫️  │
│  🌫️🌫️  🏘️👁️  🌫️🌫️🌫️  │
│  🌫️🌫️  👁️🗺️  🌫️🌫️🌫️🌫️  │
│  🌫️🌫️🌫️  🚶  🌫️🌫️🌫️  │
│  🌫️🌫️🌫️🌫️🌫️  🐎  🌫️  │
└───────────────────────────────────┘

🌫️ = Неизвестно (туман)
👁️ = Известно (поверхностные видны)
🗺️ = Исследовано (все ресурсы видны)
🏘️ = Поселение (радиус 1-2)
🚶 = Разведчик (радиус 1-2)
🐎 = Конный (радиус 2-3)
```

### Локальная карта (при зуме в гекс)

> GDD (строка 149): «При зуме в гекс разворачивается локальная карта 1×1 км с рельефом, реками, лесом, выходами ресурсов».

На локальной карте тумана войны **нет** — игрок видит всю локальную карту гекса (если гекс = 👁️ или 🗺️). Но ресурсы на локальной карте:
- 🟢 Поверхностные — видны сразу (если гекс 👁️)
- 🟡 Подповерхностные — видны только если гекс 🗺️
- 🔴 Глубинные — видны если гекс 🗺️ + технология

## 🧊 Палеолитный тест (Принцип 13)

| Элемент | Работает в 10 000 до н.э.? | Условие |
|---|---|---|
| Туман войны (3 состояния) | ✅ Да | С первого хода |
| Радиус стоянки (1 гекс) | ✅ Да | С первого хода |
| Пеший разведчик | ✅ Да | T-004 (стартовая) |
| Разведчик с собакой | ✅ Да | T-007 (стартовая) |
| 👁️ Известно → поверхностные ресурсы | ✅ Да | С первого хода |
| 🗺️ Исследовано → геологическая разведка | ❌ Нет | T-020 (деревообработка — неолит) |
| Конная разведка | ❌ Нет | T-030 (скотоводство → лошадь) |
| Морская разведка | ❌ Нет | T-060a (вёсельное море) |

| Эмиссары/шпионы | ❌ Нет | T-043 (города → специалисты) |

> **Палеолит**: стартовый гекс = 👁️ (стоянка, радиус 1). Остальное — туман. Разведчик-пешеход (T-004) открывает соседние гексы. Видны только поверхностные ресурсы (кремень, дичь, вода, дерево). Подповерхностные — скрыты (нет T-020). Конной/морской разведки нет.
