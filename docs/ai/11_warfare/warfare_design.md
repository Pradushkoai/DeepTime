| Параметр | Что |
|---|---|

| Дни без снабжения | Эффект | Боеспособность |
|---|---|---|
| 1-3 | Голод начинается, недовольство | 80% |
| 4-7 | Дезертирство, командиры теряют контроль | 50% |
| 8-14 | Болезни, падёж лошадей, развал | 25% |
| 15+ | Смерть от голода (если не ушла в грабёж) | 0% |

## ⚔️ Битва — автоматическое разрешение

> ✅ **B, round_14**: автоматическая — правильно. Тактический слой = другая игра и другой бюджет.

### Процесс битвы

```
1. Игрок выбирает: состав (юниты) + командир + стратегия + цель
2. Система показывает ПРОГНОЗ (точность = от D-013 разведки):
   - Враг в тумане → «???»
   - Разведчик видел → примерные числа
3. Игрок подтверждает → автоматический расчёт
4. Результат: победа / поражение / ничья + потери
5. Подпись причины: «Поражение: голод −25, река −15, командир-новичок −10»
```

### Стратегии (от состава)

| Стратегия | Условие | Эффект |
|---|---|---|
| Агрессивная | Любой состав | +атака, −защита |
| Оборонительная | Любой состав | +защита, −скорость |
| Фланговая | Кавалерия (T-030+седло) ИЛИ колесницы (T-023) | +прорыв, требует мобильность |
| Фаланга | Копья (каталог) + T-052 (бронза) + порог (плейтесты) | +защита, −скорость |
| Тестудо | Военная реформа (D-001) | +защита от стрел, −скорость |

> ⚠️ **B, round_16**: «фаланга/тестудо/клин = команды в списке стратегий битвы», не реформы и не экипировка. Реформа = условие разблокировки (годы), формация = тактический выбор в битве (мгновение).

### Подпись причины (паттерн Q-020)

> После боя игрок видит: «Поражение: голод −25, река −15, командир-новичок −10». Чёрный ящик = фрустрация; подпись = обучающая обратная связь.

### Битва = событие хроники (D-001)

> «Вождь Ур победил северян» — уже в формате хроники племени.

## 🚶 Видимая армия на карте (Д4, v0.29)

> 📋 **Из аудита Модели B (Д4)**: армии описаны как потоки/числа. Превратить в видимые движущиеся сущности на дорогах (D-002) в тумане войны (D-013). Армия = страх.

### Принцип

> Армия соседа, видимая на горизонте, — это драма. Дешёвая фича — огромный эффект присутствия.

### Реализация

| Параметр | Решение |
|---|---|
| **Где видна** | На дороге (D-002) в зоне видимости (D-013) |
| **Иконка** | Щит (по типу армии: пехота/конница/флот) |
| **Цвет** | Своя (зелёный), соседняя нейтральная (серый), вражеская (красный) |
| **Подсказка** | Командир, численность, цель (если известна разведкой) |
| **Анимация** | Движение между гексами со скоростью армии |

### События D-016

| Событие | Триггер | Выборы |
|---|---|---|
| «Разведчики видят армию [сосед]» | Вражеская армия вошла в наблюдаемый гекс | Мобилизация / переговоры / ожидание |
| «Армия [сосед] ушла на [направление]» | Вражеская армия покинула наблюдаемый гекс | Расслабиться / продолжить бдительность |
| «Наша армия вошла в [регион]» | Своя армия вошла в новый гекс | Подтвердить цель / изменить план |

### Связь с другими спецификациями

- **D-002 Зонирование** — армии движутся по дорогам
- **D-013 Туман войны** — видимость в наблюдаемом гексе
- **D-016 События** — армия как триггер событий (см. секцию «Видимые сущности» в D-013)

### Что лечит

- **Д-6 (Мир без движения)** — армии как видимый пульс угрозы
- **Д-4 (Нет генератора свежих решений)** — армия соседа = новое решение каждый ход
