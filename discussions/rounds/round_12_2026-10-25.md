## 📌 Вопрос 11 — подвопрос: механика снятия блокировки

### B: дилемма ложная + 3 случая вместо 2 + разделение «цель/достигнутое»

**Маркеры**: ✅ по ложной дилемме · ✅ по 3 случаям · ✅ по разделению цель/достигнутое · ✅ по условию применения паттерна

### ✅ Принимаю полностью — B разрешила противоречие с GDD

B: рычаг определяется **причиной диагноза**, а не выбирается игроком:

| Диагноз | Где причина | Рычаг снятия |
|---|---|---|
| «Жречество доминирует, сила 85» | Фракция → Q-005 | Ультиматум >80 → **разделить** |
| «Ползунок Знание↔Традиция смещён» | Ценности → Q-017 | **Реформа** (не слайдер) |
| «Архетип даёт −20% к чужому» | Архетип | **Не снимается — компенсируется** (долгий путь через 200 лет торговли) |

### ✅ Принимаю разделение «цель/достигнутое»

B нашла реальное противоречие с GDD: вождь задаёт ползунки напрямую, но если лечение бесплатное → диагноз = декорация.

**Решение B**:
- **Вождь задаёт цель** («сдвигаем к Знанию») — прямой, дешёвый рычаг
- **Фактический ползунок двигается с задержкой**, ограниченной сопротивлением фракций и архетипом

Приказ «будьте просвещёнными» ничего не меняет завтра — общество меняется десятилетиями. Это уже в проекте (GDD: «за изменение против наклонности платится усиленным сопротивлением фракций»).

### ✅ Принимаю условие применения паттерна «Диагноз»

B: «паттерн работает только там, где лечение дорогое. Если причина устранима бесплатно — диагноз не нужен, он станет украшением UI».

**Принимаю** — это критическое ограничение. Записываю вместе с паттерном в `consensus.md`.

### Итог: ✅ CONSENSUS (финальный)

- Блокировки = диагноз (не отдельная механика)
- 3 случая снятия (фракции / реформа / компенсация)
