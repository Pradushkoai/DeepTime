# 📌 Вопрос 14: Банковская система (Q-011)

> **ID в реестре**: Q-011 | **Приоритет**: 🟢 низкий | **Зависимости**: Q-012 (RESOLVED — собственность), T-100 (чеканка монет)

---

## 🎯 Суть вопроса

Банковская система должна быть, но без фанатизма. Проработать основу для поздних эпох.

---

## 🧠 Позиция Модели A (GLM) — начальная

### Предлагаемое решение

**1. Эволюция банков (4 стадии):**

| Стадия | Что | Технология |
|---|---|---|
| 🏛️ **Храмовые ссуды** | Жречество выдаёт ссуды зерном/металлом | T-041 религия + T-100 монеты |
| 💰 **Ростовщичество** | Частные лица дают в долг под % | T-100 монеты + Q-012 (частная собственность) |
| 🏦 **Гильдейские банки** | Гильдии объединяют капитал | T-085 университеты + гильдии |
| 🏦 **Государственные банки** | Центральный банк, эмиссия | T-130 паровая машина (индустриальная) |

**2. Механика:**
- **Кредит** — игрок/гражданин берёт в долг под % (деньги сейчас → больше потом)
- **Вклад** — игрок/гражданин отдаёт деньги в банк под % (меньше сейчас → больше потом)
- **Банкротство** — если не может вернуть → конфискация имущества (связь с Q-012 — закладывать)
- **Финансовые кризисы** — при плохой экономике → паника → обвал

**3. Связь с Q-012 (собственность):**
- Банковская система требует **оси «закладывать»** (T-100 чеканка → можно закладывать)
- Без частной собственности — нет банков (только храмовые ссуды)

### Аргументация

- Исторически: Вавилон (храмовые ссуды), Средние века (ростовщичество), Италия (гильдейские банки), Англия (государственный банк)
- Связь с Q-012 (собственность — ось «закладывать»)
- Принцип 13 (палеолитный тест): банков нет в палеолите, появляются с T-100 (монеты)

### Возможные проблемы

- Банки могут усложнить игру (для новичков)
- Финансовые кризисы могут раздражать

### Альтернативы (Принцип 9)

**Альтернатива A: Без банков** — только наличные
- Плюсы: просто
- Минусы: нереалистично для поздних эпох

**Альтернатива B: Только храмовые ссуды** — без эволюции
- Плюсы: просто + исторично для древности
- Минусы: не работает для индустриальной эпохи
