# 📌 Вопрос 12: Скорость перехода между стадиями (Q-015)

> **ID в реестре**: Q-015 | **Приоритет**: 🟡 средний | **Зависимости**: tech_tree.md (RESOLVED — дерево технологий)

---

## 🎯 Суть вопроса

Система предпосылок зашита в правила игры. Как именно формализовать? Когда племя становится «цивилизацией»? Когда «государством»?

---

## 🧠 Позиция Модели A (GLM) — начальная

### Предлагаемое решение

**1. Стадии = комбинация предпосылок (не календарь):**

| Стадия | Предпосылки | Что открывает |
|---|---|---|
| 🏕️ **Племя** | Старт (10-30 человек) | Базовые технологии |
| 🏘️ **Поселение** | T-012 глинобит + 100+ человек + земледелие ИЛИ скотоводство | Специализация |
| 🏛️ **Город** | T-043 города + 1000+ + письменность | Администрация |
| 🏰 **Государство** | T-041 религия + 5000+ + армия + налоги | Законы, война |
| 🏛️ **Империя** | T-070 архитектура + 50000+ + дороги | Колонии |
| 🏭 **Индустриальная** | T-130 паровая машина + 100000+ | Фабрики |

**2. Принцип «эмерджентность»:**
- Стадия **не наступает по календарю** — только при выполнении всех предпосылок
- Если предпосылки не выполнены → стадия не наступает, даже через 1000 лет
- Если предпосылки выполнены рано → стадия наступает раньше

**3. Связь с Q-017 (старение вождя):**
- Каждая стадия = «изменение общества» → давление на вождя
- Переход на новую стадию = эпохальный сдвиг → вождь стареет
- Адаптация = реформа (5-шаговый процесс)

### Аргументация

- Принцип 9 (бесконечное развитие): эпохи = состояние, не календарь
- Исторически: Рим стал империей при Августе (выполнены предпосылки), не по календарю
- Связь с Q-017 (старение от изменений)

### Возможные проблемы

- 6 стадий могут быть слишком жёсткими
- Игрок может хотеть «пропустить» стадию (если есть технологии)

### Альтернативы (Принцип 9)

**Альтернатива A: Календарные стадии** — по году
- Плюсы: просто
- Минусы: противоречит Принципу 9

**Альтернатива B: Без стадий** — только технологии
- Плюсы: чисто
- Минусы: теряется ощущение прогресса
