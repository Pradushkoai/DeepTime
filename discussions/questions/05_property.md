# 📌 Вопрос 05: Собственность

> **ID в реестре**: Q-012 | **Приоритет**: 🔴 высокий | **Зависимости**: Q-005 (Баланс фракций — нужно сначала)

---

## 🎯 Суть вопроса

Переход от родовой собственности (всё общее) к индивидуальной (моя хата, моя корова). Нужно определить:

1. **Какие типы собственности** существуют?
2. **Переход — событие или процесс**? (Разом или постепенно?)
3. **Как фракции влияют** (жречество защищает общину, торговцы хотят частную)?
4. **Что это даёт игроку** — налоги, рынки, банки?
5. **Как избегать крайностей** (коммунизм vs капитализм в древнем мире)?

---

## 🧠 Позиция Модели A (GLM) — начальная

### Предлагаемое решение

**1. 7 типов собственности (эволюционная шкала):**

| Тип | Что принадлежит кому | Эпоха | Эффект |
|---|---|---|---|
| 🏞️ **Родовая** (общинная) | Земля — роду, орудия — лично | Палеолит/Неолит | +солидарность, −инновации |
| 🏛️ **Храмовая** | Земля/скот — храму (богу) | Бронза (Египет, Шумер) | +казна храма, −налог игроку |
| 👑 **Государственная** | Земля — вождю/царю | Бронза/Железо | +налог, −свобода |
| 🏠 **Семейная** | Земля — семье (наследуется) | Железо | +стабильность, +налог |
| 🏭 **Частная** | Земля/фабрика — индивиду | Античность+ | +инновации, −равенство |
| 🤝 **Кооперативная** | Совместное владение | Любая | +компромисс, −скорость |
| 🔒 **Рабовладение** | Рабы — собственность | Античность | +дешёвая сила, −мораль |

**2. Переход — процесс, не событие:**

- Собственность **не вводится разом** — она **постепенно появляется**
- Игрок не может «объявить частную собственность» эдиктом
- Но может **создавать условия** (законы, налоги, прецеденты)
- Фракции **толкают** в свою сторону (торговцы → частная, жречество → храмовая)

**3. Механика перехода:**

- Каждый регион имеет **«уровень собственности»** (0-100 по каждому типу)
- Уровень меняется от:
  - Эдиктов (закон о наследовании → +семейная)
  - Событий (богатый купец покупает землю → +частная)
  - Фракций (торговцы у власти → +частная)
  - Технологий (письменность → +договоры → +частная)
- Когда уровень типа >50% → он **доминирует** в регионе

**4. Влияние фракций:**

| Фракция | Какой тип поддерживает |
|---|---|
| 🙏 Жречество | Храмовая |
| ⚔️ Военные | Государственная (вождя) |
| 💰 Торговцы | Частная |
| 🌾 Крестьяне | Семейная / Родовая |
| 🔨 Ремесленники | Семейная / Кооперативная |
| 📚 Учёные | Частная (договоры) |

**5. Что даёт игроку:**

| Тип собственности | Что открывает |
|---|---|
| Родовая | Базовый уровень — ничего доп. |
| Храмовая | Казна храма (можно занимать) |
| Государственная | Прямой налог в казну |
| Семейная | Налог на наследство, +стабильность |
| Частная | Налог на имущество, банки (позднее) |
| Кооперативная | Низкие налоги, но +инновации |
| Рабовладение | Дешёвая сила, но −счастье, риск бунта |

### Аргументация

- **Исторически**: собственность эволюционировала от родовой к частной (Мейн, Морган)
- **Принцип 9**: 7 типов = много путей, игрок выбирает
- **Эмерджентность**: собственность появляется через события, а не эдикты
- **Реиграбельность**: каждый раз разный баланс

### Возможные проблемы

- 7 типов могут быть сложными
- Переход «процессом» может быть медленным (игрок хочет быстрее)
- Рабовладение — чувствительная тема (как подавать?)

### Альтернативы (Принцип 9)

**Альтернатива A: 3 типа** (Общинная / Государственная / Частная)
- Плюсы: проще
- Минусы: теряется богатство (нет храмовой, кооперативной)

**Альтернатива B: Только бинарная** (Общинная vs Частная)
- Плюсы: чёткий конфликт
- Минусы: нереалистично (история сложнее)

**Альтернатива C: Игрок выбирает тип** эдиктом
- Плюсы: контроль
- Минусы: нереалистично (собственность не вводится указом)
