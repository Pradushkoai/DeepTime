# 📌 Вопрос 04: AI соседей и торговля

> **ID в реестре**: Q-006 | **Приоритет**: 🔴 высокий | **Зависимости**: Q-001 (RESOLVED — вождь гибрид)

---

## 🎯 Суть вопроса

Соседние цивилизации (AI) играют по тем же правилам, что и игрок. Нужно определить:

1. **Как AI развивается** — те же технологии, та же экономика?
2. **Как начать торговать** — что нужно для торгового пути?
3. **Торговля с дальними** — как начать торговать с цивилизацией через море?
4. **Дипломатия** — мир, война, альянсы, дань?
5. **Диффузия технологий** — как технологии распространяются через соседей?

---

## 🧠 Позиция Модели A (GLM) — начальная

### Предлагаемое решение

**1. AI-соседи = полноправные игроки:**

- Те же правила, что и игрок: технологии, экономика, фракции, вождь
- Те же ограничения: предпосылки, ресурсы, география
- AI принимает решения на основе **своих интересов** (а не скриптов)
- У каждого AI — свой «характер» (агрессивный, торговый, изоляционист)

**2. Уровни контакта (от нулевого до альянса):**

| Уровень | Что доступно | Условие |
|---|---|---|
| 0. **Неизвестно** | Ничего | Нет контакта |
| 1. **Знают о вас** | Видят на карте | Встреча (разведка/торговец) |
| 2. **Дипломатия** | Переговоры, обмен информацией | Посольство |
| 3. **Торговля** | Обмен ресурсами | Торговый путь |
| 4. **Союз** | Военная помощь, технологии | Договор |
| 5. **Вассал/Сюзерен** | Дань, протекторат | Война/дипломатия |

**3. Торговые пути (3 типа):**

| Тип | Что | Условие |
|---|---|---|
| 🛤️ **Караванный** | Сухопутный (лошадь/верблюд) | Дорога + мир |
| ⛵ **Морской** | Через море (корабль) | T-060b (парус) + порт + компас для океана |
| 🔄 **Чужими руками** | Через посредника | Третья цивилизация (караванщик) |

**Торговля открывает:**
- Ресурсы (медь из Кипра → в материковую Грецию)
- Технологии (диффузия — шанс перенять)
- Культуру (ценности, религия)

**4. Торговля с дальними цивилизациями (через море):**

- **T-060a** (вёсельное мореплавание) → только прибрежная торговля (видят берег)
- **T-060b** (парусное мореплавание) → короткие морские переходы (Эгейское море)
- **T-093** (компас) → океанская торговля (через Атлантику/Индийский океан)
- **T-091** (каравелла) → дальние океанские пути (Европа → Азия)

**5. Дипломатия:**

| Действие | Что | Условие |
|---|---|---|
| Мир | Прекращение войны | Договор |
| Торговый договор | Снижение пошлин | Доверие |
| Военный союз | Совместная война | Общий враг |
| Дань | Одна сторона платит | Сила (угроза войны) |
| Брак | Династический союз | Наследники |
| Обмен технологиями | Покупка/передача | Доверие + деньги |

**6. Диффузия технологий:**

- Если у соседа есть технология → **шанс перенять** через торговлю
- Чем больше торговых путей → выше шанс
- Можно **купить технологию** (плата ресурсами)
- Можно **украсть** (шпионаж — поздняя эпоха)

### Аргументация

- **Исторически**: Финикийцы разнесли алфавит через торговлю, Рим перенял культуру Греции
- **Принцип 9**: несколько путей к одной технологии (исследовать / перенять / купить / украсть)
- **Реиграбельность**: каждый раз разные соседи → разные стратегии
- **Эмерджентность**: мировой рынок сам балансируется

### Возможные проблемы

- AI может «глупить» в дипломатии
- Диффузия может быть слишком быстрой (все всё знают)
- Сильные цивилизации могут доминировать (римский сценарий)

### Альтернативы (Принцип 9)

**Альтернатива A: Скриптованные соседи** (как в Civilization)
- У каждого AI — заранее прописанная стратегия
- Плюсы: предсказуемо, исторично
- Минусы: теряется эмерджентность

**Альтернатива B: Только торговля** (без дипломатии)
- AI развиваются, но не воюют
- Плюсы: фокус на экономике
- Минусы: теряется война/дипломатия

**Альтернатива C: Полная симуляция** (как в EU4)
- Сотни AI-государств, всё эмерджентно
- Плюсы: максимум реализма
- Минусы: очень тяжело для процессора, сложно игроку
