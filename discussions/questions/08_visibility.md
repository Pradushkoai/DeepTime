# 📌 Вопрос 08: Слой видимости состояния общества (Q-020)

> **ID в реестре**: Q-020 | **Приоритет**: 🔴 высокий | **Зависимости**: вопросы 01-06 (все согласованы)

---

## 🎯 Суть вопроса

Ни один из 6 обсуждённых вопросов не описывает **обратную связь** — как игрок узнаёт о проблеме. Без единого слоя «индикаторов давления» все эти системы останутся невидимыми, и игрок будет решать вслепую, а потом получать незаслуженные штрафы.

**Принцип**: «игрок не может нести ответственность за то, чего не видит». Любая штрафующая механика обязана иметь предшествующий индикатор.

---

## 🧠 Позиция Модели A (GLM) — начальная

### Предлагаемое решение

**Минимальный набор индикаторов (7 категорий)**:

| Категория | Индикаторы | Связь с вопросом |
|---|---|---|
| **Фракции** | сила и обида **раздельно** | Q-005 |
| **Поселения** | свободные рабочие места, недокомплект, отток/приток | Q-002, Q-003 |
| **Казна/склады** | деньги, зерно, стратегическое сырьё | Q-012 |
| **Вождь** | возраст/эра + давление непоглощённого изменения | Q-017 |
| **Прогресс** | открытые предпосылки, недостающая категория | Q-004 |
| **AI соседи** | уровень контакта, отношения, известные связи | Q-006 |
| **Собственность** | подпись текущего состояния + чек-лист прав | Q-012 |

### Принципы слоя видимости:

1. **Любая штрафующая механика обязана иметь предшествующий индикатор** — нельзя наказывать за то, чего игрок не видел
2. **Индикаторы давления опережают срабатывание** — игрок видит накопление до того, как оно выстрелит
3. **Раздельное отображение связанных шкал** — сила и обида фракций не должны склеиваться в одну
4. **Связь с паттерном «накопление → срабатывание»** — все накопители (обида, давление, перенасыщение) отображаются единым образом

### Архитектура UI:

- **Главный экран** — компактная панель с 7 категориями (по 1-3 индикатора каждая)
- **Детальный экран** — при клике на категорию раскрывается полный список
- **Алерты** — всплывающие уведомления при критических значениях (но не popup-ад)
- **Цветовая индикация** — зелёный (норма) / жёлтый (внимание) / красный (критично)

### Аргументация

- Без видимости все 6 согласованных механик слепы
- «Наказание за невезение» = фрустрация (мы от этого ушли в Q-005 скрытые повестки)
- Единый паттерн «накопление → срабатывание» требует единого UI-слоя

### Возможные проблемы

- 7 категорий могут перегрузить UI
- Алерты могут раздражать (если слишком частые)
- Цветовая индикация может быть неочевидна для дальтоников

### Альтернативы (Принцип 9)

**Альтернатива A: Минимум (3 категории)** — фракции + казна + вождь
- Плюсы: просто
- Минусы: теряются поселения/прогресс/соседи/собственность

**Альтернатива B: Полная симуляция (как в EU4)** — десятки индикаторов
- Плюсы: максимум информации
- Минусы: перегрузка

**Альтернатива C: Контекстные индикаторы** — показываются только релевантные для текущей ситуации
- Плюсы: чистый UI
- Минусы: игрок может пропустить важное
