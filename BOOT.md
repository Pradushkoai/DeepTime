## 📌 Что за проект

**DeepTime** — концепция игры «Цивилизация Прадушко»: симулятор развития цивилизации на реальной Земле (10 000 до н.э. — 500 н.э.) с эмерджентной эволюцией общества.

- Репозиторий: https://github.com/Pradushkoai/DeepTime
- Стадия: **Концептуальная проработка** (Стадия 1 из 6)
- Код пока НЕ пишем — фиксируем концепцию, согласуем решения, готовим почву для детального дизайна

## 🚀 Процедура активации (выполни в этом порядке)

### Шаг 1. Прочитай мета-файлы

Прочитай файлы в этом порядке (каждый открывает следующий уровень контекста):

1. `docs/ai/_meta/ai_working_principles.md` — **как работать** с пользователем (8 мета-принципов)
2. `docs/ai/_meta/session_memory.md` — **где мы** сейчас, что обсуждается
3. `docs/ai/_meta/project_status.md` — **что сделано**, ключевые решения
4. `docs/ai/_meta/open_questions.md` — **что требует решения** (приоритеты)
5. `docs/ai/_meta/decision_log.md` — **почему** всё именно так (последние 3-5 записей)
6. `docs/ai/_meta/reasoning_log.md` — **ход рассуждений** по ключевым вопросам

### Шаг 2. Проверь последние коммиты

```bash
git log --oneline | head -10
git diff HEAD~1 HEAD --stat  # что изменилось в последнем коммите
```

### Шаг 3. Кратко изложи пользователю

После прочтения скажи пользователю:
- Где мы остановились (стадия, последний коммит)
- Что было сделано в прошлой сессии
- Какие открытые вопросы в работе
- Спроси: «Продолжаем с того-то? Или есть новые приоритеты?»

### Шаг 4. Работай в обычном режиме

- Любое концептуальное решение → фиксируй в `decision_log.md` + `reasoning_log.md`
- В конце сессии → обнови `session_memory.md`
- Все изменения → коммить и пушь в репо

## ⚠️ Главные принципы (краткая шпаргалка)

Полная версия — в `docs/ai/_meta/ai_working_principles.md`. Кратко:

1. **Лови тренды, не воспринимай буквально** — пользователь даёт концептуальные примеры, извлекай мета-принцип, не зацикливайся на частностях
2. **Концептуальная стадия — не детали** — не формализуй механики до явного запроса
3. **Записывай ход рассуждений** — фиксируй не только решение, но и путь к нему
4. **Память = система файлов** — взаимосвязанные мета-файлы
5. **Два варианта документации** — `docs/ai/` для ИИ + `docs/user/` для человека
6. **Стадия 1 из 6** — концептуальная (не код, не детали)
7. **Пользователь — главный дизайнер** — ИИ предлагает, не решает сам
8. **Репозиторий = единственная память** — все правки только через коммит

## 🔒 Важно про токен

GitHub токен для работы с репо — **секретный**. Пользователь передаст его в чате. НЕ свети его:
- Не записывай в файлы репо

- Не показывай в echo/printf
- Используй только в git-командах напрямую
