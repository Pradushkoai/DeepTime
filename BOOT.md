После прочтения скажи пользователю:

- Любое концептуальное решение → фиксируй в `decision_log.md` + `reasoning_log.md`
- При закрытии вопроса → обнови `open_questions.md` (DASHBOARD + полный список) + `NEXT_STEPS.md` + `session_memory.md`

## ⚠️ Главные принципы (краткая шпаргалка)

Полная версия — в `docs/ai/_meta/ai_working_principles.md`. Кратко:

1. **Лови тренды, не воспринимай буквально** — пользователь даёт концептуальные примеры, извлекай мета-принцип, не зацикливайся на частностях
2. **Детальный дизайн (Стадия 2)** — формализуем механики, но без кода. Спецификации, формулы, балансы — да; реализация — нет
3. **Записывай ход рассуждений** — фиксируй не только решение, но и путь к нему
4. **Память = система файлов** — взаимосвязанные мета-файлы
5. **Два варианта документации** — `docs/ai/` для ИИ + `docs/user/` для человека
6. **Стадия 2 из 6** — детальный дизайн (формализации механик, без кода)
7. **Пользователь — главный дизайнер** — ИИ предлагает, не решает сам
8. **Репозиторий = единственная память** — все правки только через коммит
